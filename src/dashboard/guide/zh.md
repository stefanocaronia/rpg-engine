# RPG Engine：完整指南

**RPG Engine** 让你和一位 **AI 主持人**一起玩桌面角色扮演游戏。你在**聊天**里和主持人交谈；RPG Engine 在幕后工作：它**记住世界**，**掷骰子**，**记账**。聊天旁边，你在浏览器里开着一个页面，也就是**仪表盘**，上面有你的角色卡、骰子、地图和日志。

本指南写给玩家：你不需要会编程。

## 快速开始 <!-- icon: send -->

1. 从 [nodejs.org](https://nodejs.org) 安装 **Node.js**（LTS 版本）。
2. 安装一个 **AI 智能体**，也就是主持人运行所在的程序，并登录：例如 Claude Code 或 Codex（[2.4](#24-connect-your-ai)）。
3. 在终端里安装 RPG Engine：`npm install -g rpg-engine`。
4. 创建战役：`rpg init "The Salt Isles"`。
5. 进入新文件夹：`cd "The Salt Isles"`，然后在那里启动你的智能体：Claude Code 用 `claude`，Codex 用 `codex`。它问你是否信任这个文件夹时，选择“是”（[2.4](#24-connect-your-ai)），然后写下 *你好！我们开始吧。* 主持人会回复你仪表盘的链接。

## 1. RPG Engine 是什么 <!-- icon: about -->

| 谁 | 做什么 |
|---|---|
| **你** | 扮演你的角色：角色做什么、说什么、尝试什么。 |
| **主持人**（AI） | 讲述故事，扮演其他所有人，决定会发生什么，要求掷骰。 |
| **RPG Engine** | 把世界保存在文件里，负责掷骰，计算生命值、金钱、时间和距离，在你发现之前替你保守秘密。 |

无论隔了几个晚上，哪怕换了新的聊天，甚至换了另一个 AI，世界都保持不变：

- **说过的话都算数。** 死去的反派不会复活。
- **骰子是真的。** 主持人无法左右骰子，除非你选了最简单的难度。
- **秘密就是秘密。** 主持人不会告诉你角色不知道的事。
- **世界在运转。** 你休息或赶路时，威胁也在推进，你能看到它们的迹象。
- **一个战役就是电脑上的一个文件夹**：想停就停，之后随时接着玩。

游戏以游戏系统的形式提供，它是主持人为你的战役安装的一个包。目前我们提供的是**第五版**，基于免费的系统参考文档 5.1（System Reference Document 5.1）。没有游戏系统时，你可以自由地玩，讲一个没有数字的故事。更多系统会陆续推出（[后续计划](#9-coming-later)）。

## 2. 快速上手 <!-- icon: path -->

### 2.1 你需要什么

- 一台装有 Windows、macOS 或 Linux 的电脑，以及一个网页浏览器。
- **Node.js 22** 或更新版本，从 [nodejs.org](https://nodejs.org) 下载。它自带 `npm`，用来安装 RPG Engine。
- 一个**终端**：在 Windows 上是“终端”或 PowerShell；在 macOS 上是“终端”。要在某个文件夹里打开终端，右键点击该文件夹，选择**在终端中打开**（Windows）或**服务 > 新建位于文件夹位置的终端**（macOS）。
- 一个给主持人用的 **AI 智能体**（[2.4](#24-connect-your-ai)），并选用它提供的**最大模型**：小模型更容易被说动，泄露秘密或打破规则。

### 2.2 安装

```text
npm install -g rpg-engine
```

输入 `rpg --version` 可以检查是否安装成功。每个战役只需用一次 `rpg`，用来创建战役；之后由你的智能体自动启动 RPG Engine。

### 2.3 创建战役

在你存放游戏的文件夹里打开终端（做法见 [2.1](#21-what-you-need)）：

```text
rpg init "The Salt Isles"
```

这会生成文件夹 `The Salt Isles`，里面是一个新战役。输入 `cd "The Salt Isles"` 进入这个文件夹。记住它在哪里：每次游玩都要回到这里。其余的一切，你之后在聊天或仪表盘里再选。`rpg init --help` 会列出可以现在就选的选项，比如 `--language it` 或 `--difficulty hard`。

主持人无法替你创建战役：在 `init` 之前，你的智能体不知道 RPG Engine 在哪里。

### 2.4 连接你的 AI

主持人运行在一个 **AI 智能体**里：这是一个在终端或桌面上运行的 AI 应用，能处理你电脑上的文件，比如 Claude Code 或 Codex。像 claude.ai 或 ChatGPT 这样的普通聊天，或者手机应用，都不够用：主持人需要读取你电脑上的战役文件。每个智能体都需要自己的套餐和登录：Claude Code 需要付费的 Claude 套餐，Codex 需要 ChatGPT 登录。你只需安装一次，从它自己的页面安装：[Claude Code](https://code.claude.com/docs/en/setup)，[Codex](https://learn.chatgpt.com/docs/codex/cli)。

- **Claude Code**：在战役文件夹里输入 `claude`。当它询问是否信任这个文件夹时，选择 **Yes, I trust this folder**。注意，默认选中的答案是 *No, exit*。战役里还有一个小钩子 `rpg --listen`，这个询问不会显示它：当你在仪表盘上操作时，它会立刻通知主持人。
- **Codex**：在战役文件夹里输入 `codex`，当它询问是否信任这个文件夹时，回答“是”。如果用它的桌面应用，请在设置里确认游戏的聊天已关闭记忆。
- **其他智能体**：在战役文件夹里启动它，并给它 MCP 服务器 `rpg mcp`。RPG Engine 是标准的 MCP 服务器：任何支持 MCP 的智能体都可以当主持人，本地运行的也行。

我们用 **Claude Code** 来游玩和测试；**Codex** 已经接入并检查过，但还没有用它完整玩过一个战役。战役会关闭智能体自带的记忆：游戏存在它的文件里，这样回到某个存档时，才是真正回到过去。

### 2.5 第一次聊天

随便写点什么，比如 *你好！我们开始吧。* 每次聊天中，主持人在第一次回答时都会给你**仪表盘的链接**，类似 `http://127.0.0.1:4750`：打开它，放在聊天旁边。

在主持人的两条消息之间，你的智能体会显示它用到的工具：不要打开它们的详情（在 Claude Code 里是 ctrl+o），其中可能含有秘密。

新战役要经过三个阶段，显示在仪表盘顶部：**1 设置**（你想怎么玩），**2 零号团**（你在游戏中创建角色），**3 游玩**。

### 2.6 设置：选择你的玩法

主持人只问还缺少的内容，每次问几个问题；仪表盘的**设置**步骤会把同样的问题显示成卡片。你可以写“你来定”，由主持人来选。之后一切都可以更改，在聊天里或在**设置**里都行。

| 设置项 | 决定什么 | 可选值 |
|---|---|---|
| **导师** | 主持人教你规则的程度 | 关闭、提示、教程 |
| **难度** | 世界有多难 | 故事、简单、普通、困难、残酷 |
| **致命度** | 在战斗中倒下意味着什么 | 叙事（永不死亡）、史诗（只在关键时刻）、骰子 |
| **存档** | 何时可以回到过去 | 永久死亡、检查点、自由（[3.8](#38-saves-and-going-back)） |
| **严谨度** | 食物、光线和旅行有多严格地遵循规则 | 流畅、规则、模拟 |
| **骰子** | 谁来掷你的骰子 | 数字、实体 |
| **单位** | 距离和重量 | 公制、英制 |
| **角色配音** | 你遇到的角色由谁来说话，从主持人到角色本人：始终是主持人；在关键时刻由角色本人说话，只知道自己所知道的，由主持人决定时机；或者始终由角色本人说话，针对主要角色或所有角色，更慢也更费钱，前提是你的 AI 应用支持 | 主持人、有时、主要角色、所有角色 |
| **同伴** | 谁与你同行 | 无、与你一起创建、由主持人创建、游戏中相遇 |
| **图片** | 地点、任务和你遇到的人的图片 | 无、按需、新地点、任务和你遇到的人（[3.11](#311-pictures)） |
| **底线**和**帷幕** | 什么永远不会出现，什么只在幕后发生 | 列表 |
| **语言** | 游戏和仪表盘的语言 | 任意 |

第五版还增加了**成长方式**：经验值或里程碑。

如果没有现成的世界，主持人还会问一个**前提**（类型、基调、几个要素，用你自己的话说），以及**准备方式**：边玩边即兴构建世界，或者一开始就全部准备好。

**主持人的风格**不会被问到，但你可以在聊天里或在**设置**里更改：**文风**（朴素、文艺、通俗冒险、俏皮），它编写的**故事类型**（情境、剧情线、单元剧、悬疑），可以**模仿的作者**，或者任何**用你自己的话**说的要求。

### 2.7 零号团：你的角色

你和主持人一起创建角色，就像在牌桌上一样。每个选择都由你来做，除非你请主持人代劳：你可以带着完整的想法、模糊的想法，或者什么都不带来。在掷任何骰子之前，主持人会告诉你属性值是怎么生成的。故事背景不是必需的；如果你写了，主持人会用你的话来写。然后主持人会为你的角色要一张图片（[3.7](#37-your-characters-story-and-picture)）。RPG Engine 会算出角色卡：你从不需要自己算。

## 3. 游玩 <!-- icon: chat -->

### 3.1 与主持人交谈

用你自己的话，写下你的角色做什么或说什么：

> 我问旅店老板，今晚还有谁路过。

想跳出故事时，请写在方括号里：*[擒抱是怎么运作的？]* 主持人也会用方括号回答。

你说出想做的尝试，主持人说出结果。主持人不会替你的角色做决定，也不会谈论引擎。你可以问主持人怎么使用控制面板。

**在控制面板上行动**：点击角色卡上的名称，比如武器、法术或随身物品，再选择对象；也可以点击一个人，与其交谈。控制面板会替你写好句子，例如 *我用硬头锤攻击兜帽强盗 1。*，你可以在**告诉主持人**之前修改。主持人听到的就像你在聊天里说的一样，也会照常裁定。如果你的 AI 应用无法自动接收，点击**复制**，再粘贴到聊天里。

### 3.2 掷骰

只有结果不确定而且重要时，主持人才会要求掷骰，并且会先说明赌注是什么。接下来：

- **在控制面板上**，横幅会为每个检定显示一个按钮，例如 *杂技 +4 · 优势*。点击它：骰子会落在页面上，主持人会听到结果。你也可以点击角色卡上亮起的那一行，从骰盘里掷骰，或者在横幅里写点别的。
- **手动**，在横幅的角落或**设置**里选择：横幅会告诉你要掷什么，你在角色卡或骰盘上自己掷。
- **实体骰子**，把骰子设置选为实体：你写下掷出的点数，*[我掷出了 14。]*，RPG Engine 会加上你的调整值。

**自由掷骰**：点击角色卡上的任意数字，或打开骰盘，随手掷着玩。它们不计入结果，主持人也看不到。

**主持人的掷骰**会显示在你的掷骰栏里，秘密掷骰除外。你随时可以问 *[刚才那次掷骰是真的吗？]*：对于秘密掷骰，主持人会给出一个指纹，证明它是在你发问之前掷出的。

### 3.3 场景与战斗

故事以**场景**推进：一场战斗、一次对话、探索、旅行、休息。每个场景结束时，游戏会自动存档，这个场景也会记入你的日志。

在战斗中，主持人会讲述每个不属于你的回合，并在需要你决定时停下。**场景**顶部会显示轮到谁，以及下一个是谁；你的角色卡在地图旁边。回合顺序、队伍的生命值，以及敌人的伤势（用文字描述），都留在页面一侧。如果你的角色倒下，死亡豁免会大大地显示在页面上。

### 3.4 时间、旅行与流动的世界

RPG Engine 会记录日期；两次游玩之间不会有时间流逝。说一句你要休息，*我们进行一次长休*，主持人同意后，休息就会恢复该恢复的东西。短休时，主持人可能会在控制面板上问你花费多少生命骰：一颗一颗地掷，看看每颗恢复多少，想停就停。说出你要去哪里，*我们沿路向北去罗卡*，RPG Engine 会算出路线、距离和天数，途中有事发生时会停下来。钱按游戏里的硬币计算，找零也包括在内。

反派的计划有期限。每过新的一天，主持人就会推进时间所推动的威胁，你能看到它们的迹象，但看不到时钟本身。

### 3.5 地图

**世界**显示你的角色所知道的地点、地点之间的道路，以及你走过的路径，其余部分笼罩在迷雾中。**场景**显示你所在之处的地图（如果有的话），以及谁站在哪里；战斗中轮到你时，你到不了的格子会被遮住。主持人问你往哪里移动时，点一下格子，或者直接写出来，比如 *E4*。

**世界**还保存着你的角色所知道的事。**见闻**列出角色所知道的人物、地点、派系、生物和故事，每条都按角色的了解来写：可以搜索，也可以打开一条完整阅读；文中的名称可以跳转到对应页面。**文档**保存角色找到的信件、告示和纸页，可以随时重读。**日历**显示今天、任务的期限和剩余时间，以及故事中的日子：有场景的那一天会通向日志里对应的章节。

### 3.6 任务、日志与笔记

角色接下的事务，会在**日志**里成为一个任务，附有目标、期限和衡量方式；给它加星，就会一直显示在场景顶部。日志还会一个场景一个场景地讲述你的**故事**，并保存你的**笔记**：笔记是私人的，除非你**分享**一条，主持人会把它当作你的想法来听，而不是事实。在**同伴**下，你可以读到同伴们的日记：他们会不时在一天或一个任务结束时，写下几行所思所感。

### 3.7 你的角色的故事与画像

在角色卡上，**描述**卡片里有一个框，用来写你的角色的故事：你同意之后，主持人会把它写进去。想要画像的话，可以把文件交给主持人（PNG、JPEG、WebP 或 SVG，最大 5 MB），并告诉主持人它在你电脑上的位置；也可以请人生成一张肖像（[3.11](#311-pictures)）：*[给我画一张肖像：灰发编成辫子，下巴上有一道疤。]*

### 3.8 存档与回到过去

RPG Engine 会在每个场景结束时保存整个战役。其余由**存档**设置决定：

| 存档 | 想存就存 | 回到过去 |
|---|---|---|
| **永久死亡** | 否 | 不可以 |
| **检查点** | 否 | 回到上一个存档，仅限角色死亡时 |
| **可用** | 是 | 回到任意存档 |

在所有模式下，你都可以**重新开始**，从游玩的起点或从零号团开始。可以在聊天里说，也可以在**存档**里操作。

回到过去之后，请**开启新聊天**：旧的聊天还记得那些已被撤销的事。在新聊天里写 *继续*，然后在存档里按**我已开启新聊天**。

### 3.9 游玩时段：停下与回来

想停就停：*[今晚就到这里吧。]* 一切都已保存在文件里。想回来时，在战役文件夹里启动你的 AI 应用，写 *继续*：主持人会给你一段简短的回顾，然后接着往下玩。

### 3.10 主持人的心情

控制面板顶部的机器人就是主持人：它的表情会跟随故事的基调，也绝不会泄露你还不知道的事。聊天关闭时，它会睡着。

### 3.11 图片

RPG Engine 可以按**图片**设置，为你到达的地点、接下的任务和遇见的人生成图片，你提出要求时也会生成角色的肖像。它使用你自己的 Codex 或 Claude Code，用你的登录账号，走你的套餐和额度：优先由 **Codex** 绘制，否则由 **Claude Code** 绘制。**设置**会告诉你这台电脑能不能生成图片，不能的话该怎么设置。你随时可以给主持人一张你自己的图片。

### 3.12 安全：底线、帷幕与停止

**底线**绝不会出现在游戏里；**帷幕**只会发生在画面之外。你可以随时写 *[停]*：主持人会立刻放下那段内容，并把它加入你的底线。

### 3.13 改变主意

每项设置都可以更改，在聊天里或在**设置**里都行。主持人在没有规则书可依时做出的裁定，会成为**先例**，下次遇到同样的问题，就会得到同样的答案。

## 4. 仪表盘 <!-- icon: party -->

仪表盘是一个网页，只在你自己的电脑上，通过这台电脑的浏览器打开。聊天开着时，它是活的。聊天关闭后，它会显示 *Not connected*；下次开始聊天，它会自动恢复。

- **队伍**：你的角色卡和同伴的角色卡。点击一个数字即可掷骰；把鼠标悬停在上面，可以看到这个数字的来源。如果数字旁有箭头标出骰子，还能看到什么会让这次掷骰更有利或更不利。旁边是掷骰记录。
- **场景**：你所在的地方，以及它的图片和地图、在场的人、正在发生的事。战斗中，这里会显示回合顺序和你的角色的卡片。
- **日志**：任务、故事、同伴的日记，还有你的笔记。
- **世界**：世界地图、你的角色所知道的事、找到的文件和日历。
- **骰盘**：选择骰子和调整值，然后掷出。×2 会让骰子数量加倍，调整值不加倍，就像重击时那样。
- **存档**、**帮助**、**设置**和**关于**，以图标的形式排在这一行的末尾。设置里还有页面自己的偏好：主题、骰子音效、骰子款式。

主持人向你提问时，它的提示条会一直停在页面顶部，不论你在哪个部分。

## 5. 游戏系统与自订规则 <!-- icon: dice -->

### 5.1 什么是游戏系统

它是一款游戏的全部数据：角色卡、数值、生物、物品、法术和规则文本。每个战役使用一个系统。RPG Engine 负责计算角色卡，以及消耗和恢复的资源；某项能力如何生效，则由主持人阅读规则后裁定，就像在牌桌上一样。

### 5.2 第五版

包含 SRD 5.1 中的种族、职业、子职业、一个背景和一个专长；319 个法术，以及武器、护甲、魔法物品和怪物；还有规则章节，主持人会按其原文查阅；以及完整的角色卡，数值全部算好。

它是一个独立的包：你设置战役时，主持人会提议并安装它。使用它的战役，在一台没有安装它的电脑上首次打开时，会自动安装，主持人也会告诉你。

你也可以玩 SRD 里没有的内容，来源是你自己拥有的书：主持人会把它写成战役的页面，RPG Engine 会把它当作自己的内容来处理。RPG Engine 只附带开放内容；主持人所知道的则不受限制。

你自己的手册可以作为你的资料库：告诉主持人它们在哪里，*[我的手册在 D:\Books\5e。]*，或者在 Packages › Library 中添加它们所在的文件夹，并在电脑弹出的窗口中点一次“是”。RPG Engine 会在这台电脑上读取它们；每个战役使用你在那里开启的文件夹。主持人在裁定规则时，会在查过 SRD 之后搜索这些文件夹，并注明书名和页码。文本格式最适合阅读，文字可选取的 PDF 也可以；扫描版 PDF 会通过页面图片来识别，仅限 Windows，需要几分钟，也会有少许错误。RPG Engine 绝不会修改你的手册，绝不会把其中的文字发送到任何地方，也绝不会把它们复制进战役。

### 5.3 自订规则与你自己的补充

请告诉主持人：*[自订规则：攻击掷出自然 1 时，武器会脱手。]* 主持人会把它记作牌桌上的约定；需要时，也会写一个页面，或在角色卡上写一个数值。已经写好的自订规则，可以作为文本文件放进战役的 `rules` 文件夹。

### 5.4 添加或导入你自己的游戏系统

游戏系统是一个包：主持人可以从 npm、文件夹或文件中安装它；不是我们提供的包，只有在你于电脑窗口中点“是”之后才会安装。制作游戏系统是开发者的工作，在 GitHub 上的 RPG Engine 文档中有说明。把你自己的一本书变成游戏系统，目前还做不到（[后续计划](#9-coming-later)）。

## 7. 战役从哪里来，以及它的语言 <!-- icon: world -->

### 7.1 拥有世界的三种方式

- **即时构建**：根据你的前提，主持人在你需要之前才构建每个地点、人物和情节，并把它们记下来。
- **开始前准备**：同上，只是世界在游玩之前就已构建好。
- **来自你自己的冒险或书**：把文件交给主持人，*[把这个冒险导入为我们的战役：D:\Books\adventure.pdf。不要告诉我里面的任何内容。]* 文本、EPUB、Word 文档，或可以选中文字的 PDF，读取效果最好；扫描版 PDF 会通过页面图片来读取，仅限 Windows，速度慢，还会有一些错误。你自己的 Codex 或 Claude Code 会在聊天之外读取它，否则由聊天中的主持人读取，走你的套餐：整份文档会发送给 OpenAI 或 Anthropic，适用你账户的条款以及你对训练用途的选择。仪表盘会显示进度；如果来源是小说，主持人会建议从哪里开始。它会写出地点、角色和秘密。

一个战役只玩一次：想再玩同一个冒险，请创建一个新战役。

### 7.2 语言

每个战役一种语言，即主持人的语言，仪表盘随之而变。仪表盘自带 26 种语言。其他任何语言，会由 Codex 或 Claude Code 在你的电脑上翻译；没有它们的话，则由聊天中的主持人翻译。第五版的意大利语术语来自官方的意大利语 SRD；规则文本保持英文，由主持人用你的语言讲述。

## 8. 好奇者专区：战役文件夹 <!-- icon: list -->

你完全不需要打开它，而且里面藏着战役的秘密。其中有 `campaign.yaml`（你的设置）、`state.yaml`（游戏进行到哪里）、`world/`（每个角色、地点、任务等各有一个 markdown 页面）、`rules/`（你的房规）、`images/`、`log.jsonl`（每一次改动）、`.saves/`、`.player/`（你的笔记），以及告诉 AI 代理 RPG Engine 在哪里的几个小文件。页面采用 Obsidian 的格式。如果你手动修改了某个页面，主持人会在下一次回答时得知。

RPG Engine 只待在这个文件夹里：它只在这里读写游戏，绝不会碰你的其他文件；你放规则书的文件夹，它只读取。在此之外，它只保留自己的数据文件夹（仪表盘的翻译、从你的规则书中读出的文本，以及你允许安装时的 Codex 或 Claude Code），还有绘制图片时用到的临时文件夹。你的代理若想在电脑上做其他任何事，都会先征求你的同意。

主持人使用的每条命令，也都可以在战役文件夹里运行：`rpg --help` 会列出它们。许多命令会打印出战役的秘密。

## 10. 问题与故障 <!-- icon: info -->

### 问题

**我需要懂规则吗？** 不需要。选择教程导师，想问什么就用方括号提问。

**主持人会作弊吗？** 除了难度为“故事”时，它无法更改 RPG Engine 已经掷出的结果，也无法更改已经确定的事实。

**要花钱吗？** RPG Engine 是免费的。主持人运行在你的智能体套餐上，或者用本地模型运行在你自己的电脑上。一个晚上的游戏就是一场很长的聊天：在最小的套餐上，你可能在晚上结束前就达到套餐的额度。图片、翻译和导入使用的是同一个套餐。RPG Engine 本身从不使用 API 密钥（按调用次数收费）：请用你的账户登录智能体，而不是用密钥。

**可以在手机上玩吗？** 不行：主持人运行在你的电脑上，仪表盘也只能在那里打开。

**可以和朋友一起玩吗？** 暂时不行：目前是一名玩家、一个角色，外加同伴（[以后推出](#9-coming-later)）。

**下次可以换一个 AI 吗？** 可以：用另一个智能体打开战役，写 *继续*。

### 故障

**仪表盘打不开。** 问主持人：`[仪表盘的链接是什么？]`。只有在该战役里有聊天开着、并且主持人已做出第一次回复之后，它才能用。

**主持人似乎不懂这个游戏。** 你的智能体没有加载 RPG Engine。请检查你是否在战役文件夹里启动了它，并且选择了信任。在 Claude Code 里，输入 `/mcp` 并重新连接 `rpg`。在 Codex 里，在战役文件夹中运行 `codex mcp list`，必须能看到 `rpg`。如果提示找不到 `rpg --version`，请重新安装 RPG Engine（[2.2](#22-install)）。

**更新。** 再运行一次 `npm install -g rpg-engine`，然后开启新聊天：正在运行的主持人会沿用它启动时的版本。

**主持人还记得我撤销过的事。** 开启新聊天，然后在存档里点**我已开启新聊天**。

**没有图片出现。** 设置 > 图片会告诉你这台电脑能否生成图片，以及怎么做。

**安装失败，或 `rpg` 无法启动。** `node --version` 必须显示 22 或更新版本。在 Windows 上，请让 RPG Engine 和你的战役远离含有 `&` 的路径。

**仪表盘链接变了。** 另一个程序占用了常用地址；主持人会给你新的链接。
