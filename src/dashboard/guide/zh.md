# RPG Engine：完整指南

**RPG Engine** 让你和一位 **AI 主持人**一起玩桌面角色扮演游戏。你在**聊天**里和主持人交谈；RPG Engine 在幕后工作：它**记住世界**，**掷骰子**，**记账**。聊天旁边，你在浏览器里开着一个页面，也就是**仪表盘**，上面有你的角色卡、骰子、地图和日志。

本指南写给玩家：你不需要会编程。

## 快速开始 <!-- icon: send -->

1. 从 [nodejs.org](https://nodejs.org) 安装 **Node.js**（LTS 版本）。
2. 安装一个 **AI 智能体**，也就是主持人运行所在的程序，并登录：例如 Claude Code 或 Codex（[2.4](#24-connect-your-ai)）。
3. 在终端里安装 RPG Engine：`npm install -g rpg-engine`。
4. 创建战役：`rpg init "The Salt Isles"`。
5. 进入新文件夹：`cd "The Salt Isles"`，然后在那里启动你的智能体：Claude Code 用 `claude`，Codex 用 `codex`。它问你是否信任这个文件夹时，选择“是”（[2.4](#24-connect-your-ai)），然后写下 *你好！我们开始吧。* 主持人会回复你仪表盘的链接。

## 1. RPG Engine 是什么 <!-- icon: about -->

| 谁 | 做什么 |
|---|---|
| **你** | 扮演你的角色：角色做什么、说什么、尝试什么。 |
| **主持人**（AI） | 讲述故事，扮演其他所有人，决定发生什么，要求掷骰。 |
| **RPG Engine** | 把世界存在文件里，掷骰子，计算生命值、金钱、时间和距离，在你发现之前保守秘密。 |

世界在每个夜晚之间保持不变，即使换了新聊天，甚至换了另一个 AI：

- **说过的话都算数。**死去的反派不会复活。
- **骰子是真的。**主持人无法左右骰子，除非你选了最简单的难度。
- **秘密始终是秘密。**主持人不会告诉你角色不知道的事。
- **世界在运转。**你休息或赶路时，威胁在逼近，你能看到它们的迹象。
- **战役就是你电脑上的一个文件夹：**想停就停，以后再接着玩。

目前 RPG Engine 只支持一个游戏系统，**第五版**，基于免费的系统参考文档 5.1（System Reference Document 5.1）。其他系统以后会有（[以后会有](#9-coming-later)）。

## 2. 开始使用 <!-- icon: path -->

### 2.1 你需要什么

- 一台装有 Windows、macOS 或 Linux 的电脑，以及一个网页浏览器。
- **Node.js 22** 或更新版本，从 [nodejs.org](https://nodejs.org) 获取。它自带 `npm`，用来安装 RPG Engine。
- 一个**终端**：在 Windows 上是“终端”或 PowerShell；在 macOS 上是“终端”。想在某个文件夹里打开终端，右键点击该文件夹，选择**在终端中打开**（Windows）或**服务 > 新建位于文件夹位置的终端窗口**（macOS）。
- 一个给主持人用的 **AI 智能体**（[2.4](#24-connect-your-ai)），并选它提供的**最大模型**：小模型更容易被人哄着泄露秘密，或者随意改规则。

### 2.2 安装

```text
npm install -g rpg-engine
```

用 `rpg --version` 检查是否装好。每个战役你只需用一次 `rpg`，用来创建战役；之后由你的智能体自动启动 RPG Engine。

### 2.3 创建战役

在你存放游戏的文件夹里打开终端（做法见 [2.1](#21-what-you-need)）：

```text
rpg init "The Salt Isles"
```

这会生成文件夹 `The Salt Isles`，里面是一个新战役。用 `cd "The Salt Isles"` 进入它。记住它的位置：每次游玩你都要回到这里。其余的一切，之后在聊天里或仪表盘上再选；`rpg init --help` 会列出可以现在就选的选项，比如 `--language it` 或 `--difficulty hard`。

主持人无法替你创建战役：在 `init` 之前，你的智能体并不知道 RPG Engine 在哪里。

### 2.4 连接你的 AI

主持人运行在一个 **AI 智能体**里：这是一个在终端或桌面上运行的 AI 应用，能够处理你电脑上的文件，比如 Claude Code 或 Codex。普通的聊天工具，如 claude.ai 或 ChatGPT，或者手机应用，都不行：主持人需要读取你电脑上的战役文件。每个智能体都需要自己的套餐和登录：Claude Code 需要付费的 Claude 套餐，Codex 需要 ChatGPT 账号登录。智能体只需安装一次，到它自己的页面操作：[Claude Code](https://code.claude.com/docs/en/setup)、[Codex](https://learn.chatgpt.com/docs/codex/cli)。

- **Claude Code**：在战役文件夹里输入 `claude`。当它问你是否信任这个文件夹时，选择 **Yes, I trust this folder**。当心：默认选中的答案是 *No, exit*。
- **Codex**：在战役文件夹里输入 `codex`，当它问你是否信任这个文件夹时，回答 yes。如果用它的桌面应用，请在设置里确认，游戏的聊天已关闭记忆功能。
- **其他智能体**：在战役文件夹里启动它，并给它配置 MCP 服务器 `rpg mcp`。RPG Engine 是标准的 MCP 服务器：任何支持 MCP 的智能体都可以当主持人，包括本地运行的智能体。

我们用 **Claude Code** 来游玩和测试；**Codex** 已经接入并检查过，但还没有用它完整地玩过一个战役；`init` 也会为 **Gemini CLI** 做好设置。战役会关闭智能体自带的记忆：游戏存在它的文件里，这样回到存档时才是真的回到过去。

### 2.5 第一次聊天

随便写点什么，比如 *你好！我们开始吧。* 每次聊天中，主持人的第一条回复都会给出你的**仪表盘链接**，类似 `http://127.0.0.1:4750`：打开它，放在聊天旁边。

在主持人的两条消息之间，你的智能体会显示它用到的工具：不要展开它们的详情（在 Claude Code 里是 ctrl+o），里面可能有秘密。

新战役会经过三个阶段，显示在仪表盘顶部：**1 设置**（你想怎么玩）、**2 零号团**（你在游戏中创建角色）、**3 游玩**。

### 2.6 设置：选择你的玩法

主持人只问还缺的内容，每次问几个问题；仪表盘的**设置**步骤会把同样的问题做成卡片。你可以写“你来定”，主持人就会替你选。之后一切都可以改，在聊天里或在**设置**里都行。

| 设置 | 决定什么 | 可选值 |
|---|---|---|
| **导师** | 主持人教你规则的程度 | off、hints、tutorial |
| **难度** | 世界有多严苛 | story、easy、normal、hard、brutal |
| **致命度** | 在战斗中倒下意味着什么 | narrative（永不死亡）、epic（只在关键时刻）、dice |
| **存档** | 你何时可以回头 | permadeath、checkpoint、free（[3.8](#38-saves-and-going-back)） |
| **严谨度** | 食物、光照和旅行对规则的遵循有多严 | smooth、rules、simulation |
| **骰子** | 谁来掷你的骰子 | digital、physical |
| **单位** | 距离和重量 | metric、imperial |
| **声音** | 你遇到的角色由谁来说话：在关键时刻由角色本人来说，只知道他们自己知道的事，由主持人来选择；或始终由主持人；或始终由角色本人，主要角色或所有角色皆可，更慢也更贵，需要你的 AI 应用支持 | auto、master、important、always |
| **同伴** | 谁与你同行 | none、made with you、made by the master、met in play |
| **图片** | 地点、任务和你遇到的角色的图片 | none、on request、new places、quests and those you meet（[3.11](#311-pictures)） |
| **底线**和**帷幕** | 什么永远不会出现，什么只在幕后发生 | 列表 |
| **语言** | 游戏和仪表盘的语言 | 任意 |

第五版还会增加**进阶**：经验值或里程碑。

如果没有现成的世界，主持人还会问一个**前提**（类型、基调、几个元素，用你自己的话说）和**准备方式**：边玩边构建世界，还是一开始就全部建好。

**主持人的风格**不会被主动询问，但你可以在聊天里或在**设置**里修改：**文风**（朴素、文学、通俗冒险、诙谐）、它编写的**故事**（情境、篇章、单元、悬疑）、一位**模仿其文风**的作者，或者任何**你自己的描述**。

### 2.7 零号团：你的角色

你和主持人一起创建角色，就像在牌桌上一样。每个选择都由你做，除非你请主持人代劳：你可以带着完整的想法、模糊的想法，或者什么都不带来。在掷任何骰子之前，主持人会先告诉你属性值是怎么生成的。角色的背景故事不是必需的；如果你给出一个，主持人会用你的话来写。然后主持人会为你的角色要一张图片（[3.7](#37-your-characters-story-and-picture)）。角色卡由 RPG Engine 算好：你永远不用自己算数。

## 3. 游玩 <!-- icon: chat -->

### 3.1 与主持人交谈

用你自己的话，写下你的角色做什么、说什么：

> 我问旅店老板，今晚还有谁路过。

想跳出故事，就写在方括号里：*[擒抱是怎么运作的？]* 主持人也会用方括号回答你。

你说明你要尝试什么，主持人说明发生了什么。主持人从不替你的角色做决定，也从不谈论引擎。你可以问主持人怎么使用仪表盘。

### 3.2 掷骰

只有结果不确定、而且很重要时，主持人才会要求掷骰，并且会先说明风险是什么。接下来：

- **在仪表盘上**，横幅会为每个检定显示一个按钮，例如 *Acrobatics +4 · with advantage*。点击它：骰子会落在页面上，主持人会得知结果。你也可以点击角色卡上亮起的那一行，从骰盘里掷骰，或者在横幅里写点别的。
- **手动**，在横幅的角落或在**设置**里选择：横幅会告诉你该掷什么，你从角色卡或骰盘里自己掷。
- **实体骰子**，骰子设置选为实体：你写下掷出的点数，*[我掷出了 14。]*，RPG Engine 会加上你的调整值。

**自由掷骰**：点击角色卡上的任意数字，或打开骰盘，就可以随手掷着玩。这些掷骰不计入结果，主持人也看不到。

**主持人的掷骰**会显示在你的掷骰栏里，暗骰除外。你随时可以问 *[刚才那次掷骰是真的吗？]*：对于暗骰，主持人会给出一个指纹，证明它是在你提问之前掷出的。

### 3.3 场景与战斗

故事以**场景**推进：一场战斗、一次交谈、探索、旅行、一次休整。每个场景结束时，游戏会自动存档，这个场景也会记入你的日志。

战斗中，主持人会讲述每个不属于你的回合，并停在需要你做决定的地方。**场景**顶部会显示轮到谁，以及下一个是谁，地图旁边是你的角色卡；回合顺序、队伍的生命值，以及敌人的伤势（用文字描述），都留在页面一侧。如果你的角色倒下，濒死豁免会大幅显示在页面上。

### 3.4 时间、旅行与流动的世界

RPG Engine 会记录日期；两次游戏之间不会有时间流逝。说一声你要休息，例如 *我们进行一次长休*，休息就会恢复该恢复的东西。说出你要去哪里，例如 *我们沿着北路前往罗卡*，RPG Engine 会算出路线、距离和天数，途中发生事情时会停下来。金钱按游戏里的硬币计算，包括找零。

反派有带期限的计划。每过新的一天，主持人都会推进那些被时间推动的威胁，你能看到它们的迹象，但永远看不到时钟本身。

### 3.5 地图

**世界**显示你的角色已知的地点、地点之间的道路，以及你走过的足迹，其余部分笼罩在迷雾中。**场景**显示你所在之处的地图（如果有的话），以及谁站在哪里；战斗中轮到你时，你无法到达的格子会被遮住。当主持人问你要移动到哪里时，点一下格子，或者写下它，例如 *E4*。

### 3.6 任务、日志与笔记

你的角色接下的事务会成为**日志**里的一项任务，附有目标、期限和衡量方式；给它加星，它就会一直显示在场景顶部。日志还会一个场景一个场景地讲述你的**故事**，并保存你的**笔记**：笔记是私密的，除非你**分享**其中一条，主持人会把它当作你的想法来听，而不是当作事实。

### 3.7 角色的故事与画像

在你的角色卡上，**描述**卡片里有一个填写角色故事的框：经你同意后，主持人会把故事写进去。想要一张图片，可以把文件交给主持人（PNG、JPEG、WebP 或 SVG，最大 5 MB），并告诉它文件在你电脑上的位置；也可以让主持人生成一幅画像（[3.11](#311-pictures)）：*[给我画一幅画像：灰色头发编成辫子，下巴上有一道疤。]*

### 3.8 存档与回到过去

RPG Engine 会在每个场景结束时保存整个战役。其余由**存档**设置决定：

| 存档 | 想存就存 | 回到过去 |
|---|---|---|
| **永久死亡** | 不可以 | 永远不能 |
| **检查点** | 不可以 | 回到最近的存档，仅在你的角色死亡时 |
| **自由** | 可以 | 回到任意存档 |

在每种模式下，你都可以**重新开始**，从游戏开头或从零号团开始。在聊天中说一声，或者在**存档**里操作即可。

回到过去之后，请**开启新聊天**：旧的聊天还记得那些被撤销的事。在新聊天里写 *继续*，然后在存档里点击**我已开启新聊天**。

### 3.9 游戏时段：停下与回来

想停就停：*[今晚就到这里吧。]* 一切都已保存在文件里。要回来时，在战役文件夹里启动你的智能体，然后写 *继续*：主持人会给你一个简短的回顾，然后接着进行。

### 3.10 主持人的情绪

仪表盘顶部的机器人就是主持人：它的表情会跟随故事的基调，而且绝不会泄露你还不知道的事。聊天关闭时，它会睡着。

### 3.11 图片

RPG Engine 可以为你到达的地点、接下的任务和遇到的人物生成图片，具体按**图片**设置而定；你要求时，也可以生成角色的画像。它使用你电脑上已有的工具和你自己的登录：有 **Codex** 就用 Codex 绘制，否则由 **Claude Code** 绘制。**设置**会告诉你这台电脑能不能生成图片，不能的话该如何配置。你随时可以把自己的图片交给主持人。

### 3.12 安全：底线、帷幕与停止

**底线**绝不会出现在游戏里；**帷幕**只在画面之外发生。你随时可以写 *[停]*：主持人会立刻放弃那段内容，并把它加入你的底线。

### 3.13 改变主意

每项设置都可以更改，在聊天中或在**设置**里都行。主持人在没有规则书可依时做出的裁定会成为**先例**，下次遇到同样的问题，就会得到同样的答案。

## 4. 仪表盘 <!-- icon: party -->

这是你自己电脑上的一个页面，只能在那台电脑的浏览器里打开，聊天开着时才有效。聊天关闭后，它会显示 *未连接*；下一次聊天开始时，它会自动恢复。

- **队伍**：你的角色卡和同伴的角色卡。点击数字即可掷骰；把鼠标悬停在数字上，可以看到它的来源。旁边是掷骰记录。
- **场景**：你所在的位置、它的图片和地图、在场的人，以及正在发生的事；战斗中，还有回合顺序和你的角色卡。
- **日志**：任务、故事、你的笔记。
- **世界**：你的角色所知的世界地图。
- **骰盘**：选择骰子和调整值，然后掷出。
- **存档**、**帮助**、**设置**和**关于**，以图标形式排在这一行的末尾。设置里还有页面自身的偏好：主题、骰子音效、骰子套装。

当主持人向你提问时，它的横幅会一直停在顶部，无论你在哪个版块。

## 5. 游戏系统与房规 <!-- icon: dice -->

### 5.1 什么是游戏系统

一款游戏的全部数据：它的角色卡、数值、生物、物品、法术和规则文本。每个战役只使用一种系统。RPG Engine 负责算出角色卡，以及消耗和恢复的资源；至于某项能力具体怎么起效，由主持人查阅规则后裁定，就像在牌桌上一样。

### 5.2 内置第五版

包含 SRD 5.1 中的种族、职业、子职业、一个背景和一个专长；319 个法术，以及武器、护甲、魔法物品和怪物；规则章节，主持人会按原文查阅；还有完整的角色卡，数值全部算好。

SRD 没有的内容，只要你有那本书，也可以玩：主持人会把它写成你战役里的页面，RPG Engine 会把它当作自带内容来处理。RPG Engine 只附带开放内容，而主持人所了解的内容不受此限。

你自己的手册可以做成你的资料库。告诉主持人它们在哪里，*[我的手册在 D:\Books\5e。]*，或者在“Packages › Library”里添加手册所在的文件夹，然后在电脑弹出的窗口中点一次“是”。RPG Engine 只在这台电脑上读取它们；每个战役使用你在那里开启的文件夹。主持人裁定规则时，会在 SRD 之后搜索这些手册，并注明书名和页码。手册最好是文本，或者文字可以选中的 PDF；扫描版 PDF 会按页面图片来识别，仅限 Windows，需要几分钟，也会有少量错误。RPG Engine 不会修改你的手册，不会把手册文字发送到任何地方，也不会把它复制进战役。

### 5.3 房规与你自己的补充

直接对主持人说：*[房规：攻击掷出自然 1 时，武器会脱手。]* 主持人会把它记作牌桌上的约定；需要时，也会写成一个页面，或者在角色卡上加一项数值。已经写好的房规，可以作为文本文件放进战役的 `rules` 文件夹。

### 5.4 添加或导入你自己的游戏系统

暂不支持：目前 RPG Engine 只能玩第五版（见[后续计划](#9-coming-later)）。

## 6. 扩展 <!-- icon: plus -->

暂不支持。扩展将在游戏系统之上为战役增加内容：一个世界、一场冒险、天气这样的功能、可分享的家规。

## 7. 战役的世界从哪里来，以及语言 <!-- icon: world -->

### 7.1 获得世界的三种方式

- **边玩边造**：主持人根据你的设定，在你需要之前一刻才构建每个地点、人物和剧情，并把它们记下来。
- **开局准备**：同上，但世界在游戏开始前就已构建好。
- **来自你自己的冒险或书籍**：把文件交给主持人，*[把这个冒险导入为我们的战役：D:\Books\adventure.pdf。里面的内容不要告诉我。]* 纯文本、EPUB、Word 文档，或文字可以选中的 PDF，读取效果最好。扫描版 PDF 会根据页面图片来识别，仅限 Windows，速度较慢，并且会有一些错误。你电脑上的 Codex 或 Claude Code 会在聊天之外读取文件，仪表盘会显示进度。如果导入的是小说，主持人会建议从哪里开始。主持人会写出地点、人物和秘密。

一个战役只能玩一次：想再玩同一个冒险，请新建一个战役。

### 7.2 语言

每个战役只有一种语言，即主持人使用的语言，仪表盘会随之切换。仪表盘自带 26 种语言。其他语言会由你电脑上的 Codex 或 Claude Code 翻译；如果没有它们，则由主持人在聊天中翻译。第五版的意大利语术语来自官方意大利语 SRD；规则文本仍保持英文，由主持人用你的语言讲述。

## 8. 好奇者专区：战役文件夹 <!-- icon: list -->

你完全不需要打开它，而且里面藏着战役的秘密。其中有 `campaign.yaml`（你的设置）、`state.yaml`（游戏进行到哪里）、`world/`（每个角色、地点、任务等各有一个 markdown 页面）、`rules/`（你的房规）、`images/`、`log.jsonl`（每一次改动）、`.saves/`、`.player/`（你的笔记），以及告诉 AI 代理 RPG Engine 在哪里的几个小文件。页面采用 Obsidian 的格式。如果你手动修改了某个页面，主持人会在下一次回答时得知。

RPG Engine 只待在这个文件夹里：它只在这里读写游戏，绝不会碰你的其他文件；你放规则书的文件夹，它只读取。在此之外，它只保留自己的数据文件夹（仪表盘的翻译、从你的规则书中读出的文本，以及你允许安装时的 Codex 或 Claude Code），还有绘制图片时用到的临时文件夹。你的代理若想在电脑上做其他任何事，都会先征求你的同意。

主持人使用的每条命令，也都可以在战役文件夹里运行：`rpg --help` 会列出它们。许多命令会打印出战役的秘密。

## 10. 问题与故障 <!-- icon: info -->

### 问题

**我需要懂规则吗？**不需要。选择教程导师，想问什么就在方括号里问。

**主持人会作弊吗？**它无法更改 RPG Engine 已掷出的结果，也无法更改已确定的事实；唯一的例外是故事难度。

**要花钱吗？**RPG Engine 是免费的。主持人运行在你的智能体套餐上，或者用本地模型运行在你自己的电脑上。一晚的游戏就是一场很长的聊天：在最小的套餐上，你可能在晚上结束前就达到套餐的上限。图片和翻译用的是同一个套餐。

**我能在手机上玩吗？**不能：主持人运行在你的电脑上，仪表盘也只能在那里打开。

**我能和朋友一起玩吗？**暂时不能：目前是一名玩家、一个角色，加上同伴（[以后会有](#9-coming-later)）。

**下次能换一个 AI 吗？**可以：在另一个智能体里打开这个战役，写下 *继续*。

### 故障

**仪表盘打不开。**问主持人：`[仪表盘的链接是什么？]`。只有在该战役里开着聊天、且主持人给出第一个回复之后，它才能用。

**主持人似乎不懂这个游戏。**你的智能体没有加载 RPG Engine。请检查你是在战役文件夹里启动它的，并且选择了信任。在 Claude Code 里，写 `/mcp` 并重新连接 `rpg`。在 Codex 里，在战役文件夹中运行 `codex mcp list`，结果里必须有 `rpg`。如果找不到 `rpg --version`，请重新安装 RPG Engine（[2.2](#22-install)）。

**更新。**再运行一次 `npm install -g rpg-engine`，然后开启一个新聊天：正在运行的主持人仍然使用它启动时的版本。

**主持人记得我撤销过的事。**开启一个新聊天，并在存档里按下**我已开启新聊天**。

**没有出现图片。**设置 > 图片会告诉你这台电脑能不能生成，以及怎么设置。

**安装失败，或 `rpg` 无法启动。**`node --version` 必须显示 22 或更高。在 Windows 上，请不要把 RPG Engine 和你的战役放在含有 `&` 的路径里。

**仪表盘链接变了。**另一个程序占用了常用的地址；主持人会给你新的链接。
