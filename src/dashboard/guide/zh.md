# RPG Engine：完整指南

**RPG Engine** 让你和一位 **AI 主持人**一起玩桌面角色扮演游戏。你在**仪表盘**里玩：这是电脑上的一个窗口，里面有你的角色卡、骰子、地图、日志，还有和主持人的**聊天**。RPG Engine 在幕后工作：它**记住世界**，**掷骰子**，**记账**。

本指南写给玩家：你不需要会编程。

## 快速开始 <!-- icon: send -->

1. 从 [nodejs.org](https://nodejs.org) 安装 **Node.js**（LTS 版本）。
2. 装好 Node.js 后，打开一个新的终端，在里面安装 RPG Engine（只需一次）：`npm install -g rpg-engine`。如果 Windows 提示已禁止运行脚本，请输入一次 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`，回答“是”，然后再试一次。
3. 输入 `rpg open`。它会问是否把 RPG Engine 的图标放到桌面和菜单里：按 Enter 表示同意。从此以后，你直接点图标就能启动 RPG Engine，不再需要终端（[2.2](#22-install)）。
4. 一个窗口会显示你的战役。点击**新建战役**，起个名字，再点击**创建**（[2.3](#23-create-a-campaign)）：战役的仪表盘会在一个独立的窗口里打开。
5. 在和主持人的聊天里，选择你的 AI 应用和它的模型：Claude Code 需要付费的 Claude 套餐，Codex 需要 ChatGPT 账号，免费或付费都行（[2.4](#24-connect-your-ai)）。如果没有安装这个应用，或者还没登录，页面会帮你安装或登录。点击**打开聊天**，再点击**开始**。第一次回答可能要等几分钟；之后主持人会问你想怎么玩，然后你们一起创建角色。

## 1. RPG Engine 是什么 <!-- icon: about -->

| 谁 | 做什么 |
|---|---|
| **你** | 扮演你的角色：角色做什么、说什么、尝试什么。 |
| **主持人**（AI） | 讲述故事，扮演其他所有人，决定会发生什么，要求掷骰。 |
| **RPG Engine** | 把世界保存在文件里，负责掷骰，计算生命值、金钱、时间和距离，在你发现之前替你保守秘密。 |

无论隔了几个晚上，哪怕换了新的聊天，甚至换了另一个 AI，世界都保持不变：

- **说过的话都算数。** 死去的反派不会复活。
- **骰子是真的。** 主持人无法左右骰子，除非你选了最简单的难度。
- **秘密就是秘密。** 主持人不会告诉你角色不知道的事。
- **世界在运转。** 你休息或赶路时，威胁也在推进，你能看到它们的迹象。
- **一个战役就是电脑上的一个文件夹**：想停就停，之后随时接着玩。

游戏以游戏系统的形式提供，它是主持人为你的战役安装的一个包。目前我们提供的是**第五版**，基于免费的系统参考文档 5.1（System Reference Document 5.1）。没有游戏系统时，你可以自由地玩，讲一个没有数字的故事。更多系统会陆续推出（[后续计划](#9-coming-later)）。

## 2. 快速上手 <!-- icon: path -->

### 2.1 你需要什么

- 一台装有 Windows、macOS 或 Linux 的电脑，以及一个网页浏览器。
- **Node.js 24** 或更新版本，从 [nodejs.org](https://nodejs.org) 下载。它自带 `npm`，用来安装 RPG Engine。
- 一个**终端**，只在安装 RPG Engine 时用一次：在 Windows 上是“终端”或 PowerShell；在 macOS 上是“终端”。要在某个文件夹里打开终端，右键点击该文件夹，选择**在终端中打开**（Windows）或**服务 > 新建位于文件夹位置的终端**（macOS）。如果 Windows 提示已禁止运行脚本，请输入一次 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`，并回答“是”。
- 一个给主持人用的 **AI 应用**，用你自己的账号（[2.4](#24-connect-your-ai)）：页面可以帮你安装。请选用它提供的**最大模型**：小模型更容易被说动，泄露秘密或打破规则。

### 2.2 安装

```text
npm install -g rpg-engine
rpg open
```

第一行安装 RPG Engine；输入 `rpg --version` 可以检查是否安装成功。如果 npm 提示可以更新自身，不用理会。

`rpg open` 会打开 RPG Engine 的窗口，里面是你的战役。第一次打开时，它会在终端里问是否把图标添加到桌面和开始菜单（Mac 上是“应用程序”）：按 Enter 表示同意。从此以后，双击图标就行，不再需要终端。如果没有图标，每次游玩时都输入 `rpg open`；之后可以用 `rpg icon` 添加图标，用 `rpg icon --remove` 删除图标。

### 2.3 创建战役

RPG Engine 的窗口把你的战役显示成卡片，最近打开的排在最前。点击**新建战役**，填写**名称**、**语言**和**游戏系统**：其余的由你和主持人一起完成。战役会放进以它的名称命名的文件夹，位于你的用户文件夹里的 `RPG Engine` 文件夹中（在 Windows 上，用户文件夹是 `C:\Users\<name>`）；点击**选择其他文件夹…**，可以改放到你选的一个空文件夹里。在**主持人**下，你可以先为第一次聊天选好 AI 应用和模型（[2.4](#24-connect-your-ai)）。点击**创建**：战役的仪表盘会在一个独立的窗口里打开。

下次点击卡片就能打开对应的战役；已经打开的，会显示**当前已打开**。点击**打开文件夹…**，可以添加这台电脑上已有的战役。卡片上的小叉会把它从列表里移除：它的文件仍留在原处。

### 2.4 连接你的 AI

主持人运行在你电脑上的一个 **AI 应用**里，用你自己的账号：Claude Code、Codex、OpenCode 或 Antigravity。像 claude.ai 或 ChatGPT 这样的普通聊天，或者手机应用，都不够用：主持人需要读取你电脑上的战役文件。每个应用都需要自己的账号：Claude Code 需要付费的 Claude 套餐（Pro 或更高）；Codex 需要 ChatGPT 账号，免费或付费都行；Antigravity 需要 Google 账号，免费使用每周有额度限制；OpenCode 在一段时间内有一些免费模型，也可以用你自己的服务商的模型，本地运行的也行。

在仪表盘的聊天里，在**你的 AI 应用**下选择应用，再选择它的**模型**和**主持人的思考**：页面会给出建议。思考越多，速度越慢，也越费你的套餐额度。如果某个应用还没准备好，页面会说明它缺什么，并给出一个按钮来解决：

- **Claude Code** 和 **Codex**：点击**安装 Claude Code** 或**安装 Codex**，会把它下载到这台电脑上 RPG Engine 自己的文件夹里；点击**登录 Claude Code** 或**登录 Codex**，会在浏览器里打开它的登录页面。RPG Engine 看不到你的密码。
- **OpenCode** 和 **Antigravity**：点击**获取 OpenCode** 或**获取 Antigravity**，会打开它的网站，你在那里安装。OpenCode 不用登录就能玩；Antigravity 在它自己的应用里登录。然后回到这里，点击**重新检查**。

Antigravity 标有**试用中**：它可能跳出游戏，用它自己的方式提问，所以玩的时候，Claude Code、Codex 或 OpenCode 更合适。Antigravity 会保留你过去的聊天，它的记忆无法关闭：主持人已被告知绝不读取这些内容。你写的内容会发送给 Google，Google 可能安排人员查看：请不要在游戏里写入个人信息。RPG Engine 不是 Google 的产品。我们用 **Claude Code** 玩和测试得最多：其他几个应用还没有完整玩过一个战役。

在仪表盘的聊天里，主持人只通过 RPG Engine 接触你的电脑：不会自己打开你的任何文件。RPG Engine 只会读取战役之外你选定的内容，而且要先在你电脑的窗口里点“是”。

你也可以在 AI 应用自带的聊天里玩，在终端里或在它的桌面应用里都行（[2.8](#28-the-other-way-your-ai-apps-own-chat)）。

### 2.5 第一次聊天

选好应用和模型后，点击**打开聊天**：应用会启动，可能要几秒钟。然后点击**开始**，或者随便写点什么，比如 *你好！我们开始吧。* 主持人布置场景时，第一次回答可能要等几分钟。

聊天有自己的部分，叫**角色扮演**，也可以放在页面旁边：聊天顶部的小按钮可以把它放在**在独立标签页**、**左侧**或**右侧**，拖动它的边缘可以把它拉宽。

新战役要经过三个阶段，显示在仪表盘顶部：**1 设置**（你想怎么玩），**2 零号团**（你在游戏中创建角色），**3 游玩**。

### 2.6 设置：选择你的玩法

主持人只问还缺少的内容，每次问几个问题；仪表盘的**设置**步骤会把同样的问题显示成卡片。你可以写“你来定”，由主持人来选。之后一切都可以更改，在聊天里或在**设置**里都行。

| 设置项 | 决定什么 | 可选值 |
|---|---|---|
| **导师** | 主持人教你规则的程度 | 关闭、提示、教程 |
| **难度** | 世界有多难 | 故事、简单、普通、困难、残酷 |
| **致命度** | 在战斗中倒下意味着什么 | 叙事（永不死亡）、史诗（只在关键时刻）、骰子 |
| **存档** | 何时可以回到过去 | 永久死亡、检查点、自由（[3.8](#38-saves-and-going-back)） |
| **严谨度** | 食物、光线和旅行有多严格地遵循规则 | 流畅、规则、模拟 |
| **骰子** | 谁来掷你的骰子 | 数字、实体 |
| **单位** | 距离和重量 | 公制、英制 |
| **角色配音** | 你遇到的角色由谁来说话，从主持人到角色本人：始终是主持人；在关键时刻由角色本人说话，只知道自己所知道的，由主持人决定时机；或者始终由角色本人说话，针对主要角色或所有角色，更慢也更费钱，前提是你的 AI 应用支持 | 主持人、有时、主要角色、所有角色 |
| **你的角色** | 角色在零号团里怎么创建 | 与主持人一起、由主持人、你自己的（[2.7](#27-session-zero-your-character)） |
| **同伴** | 谁与你同行 | 无、与你一起创建、由主持人创建、游戏中相遇 |
| **图片** | 地点、任务和你遇到的人的图片 | 无、按需、新地点、任务和你遇到的人（[3.11](#311-pictures)） |
| **底线**和**帷幕** | 什么永远不会出现，什么只在幕后发生 | 列表 |
| **语言** | 游戏和仪表盘的语言 | 任意 |

第五版还增加了**成长方式**：经验值或里程碑。

如果没有现成的世界，主持人还会问一个**前提**（类型、基调、一些元素，以及你在游戏里最喜欢什么，比如战斗、悬疑、对话或探索，用你自己的话说）、**准备**：边玩边构建世界，或在开始时一次建好；还有**长度**：一个晚上、几次游戏（三到五个晚上），或者开放式，一个冒险接着一个冒险。有长度的故事结束后，你随时可以继续玩下去。

**主持人的风格**不会被问到，但你可以在聊天里或在**设置**里更改：**文风**（朴素、文艺、通俗冒险、俏皮），主持人编写的**故事**（情境、剧情线、单元剧、悬疑），可以**模仿作者**，或者任何**自定义**的要求。

### 2.7 零号团：你的角色

你和主持人一起创建角色，就像在牌桌上一样。每个选择都由你来做，除非你请主持人代劳：你可以带着完整的想法、模糊的想法，或者什么都不带来；也可以请主持人根据你的几句话全部做好。在有等级的游戏里，主持人会问你从几级开始：除非你想从别的等级开始，否则从一级开始。掷任何骰子之前，主持人会先告诉你属性值是怎么生成的。角色的背景故事不是必需的；如果你写了，主持人会用你的话来写。然后主持人会请你为角色提供一张图片（[3.7](#37-your-characters-story-and-picture)）。RPG Engine 会算出角色卡：你从不需要自己算。

你已经有角色了吗，来自别的游戏或别的战役？在设置阶段选择**我已有了**，然后把角色交给主持人：把角色卡粘贴到聊天里。在 AI 应用自带的聊天里，你还可以说明文件在你电脑上的位置（PDF、图片或文本都可以）；在仪表盘的聊天里，主持人不会打开你的任何文件。主持人会按原样写下这个角色，保持它原有的等级，对照规则和世界进行检查，并与你商定任何不合适的地方。

### 2.8 另一种方式：你的 AI 应用自带的聊天

你也可以在 AI 应用自己的聊天里玩，在终端里或在它的桌面应用里都行，仪表盘开在旁边。这时，你要在终端里创建战役，就在你存放游戏的文件夹里（做法见 [2.1](#21-what-you-need)），而且一定要带上名字：`rpg init "The Salt Isles"` 会生成文件夹 `The Salt Isles`，里面是一个新战役。每个应用在那里需要的东西，RPG Engine 会自己准备好。

在那个文件夹里启动你的应用：Claude Code 用 `claude`，Codex 用 `codex`，Antigravity 用 `agy`，OpenCode 用 `opencode`；或者在它的桌面应用里打开这个文件夹。当它问是否信任这个文件夹时，回答“是”：注意，在 Claude Code 里，默认选中的答案是 *No, exit*。任何支持 MCP 的其他智能体也可以当主持人：在战役文件夹里启动它，并给它 MCP 服务器 `rpg mcp`。

写下 *你好！我们开始吧。* 每次聊天中，主持人在第一次回答时都会给你**仪表盘的链接**，类似 `http://127.0.0.1:4750`：打开它，放在聊天旁边。

- 在主持人的两条消息之间，你的应用会显示它用到的工具：不要打开它们的详情（在 Claude Code 里是 ctrl+o），其中可能含有秘密。
- 战役会关闭应用自带的记忆：游戏存在它的文件里，这样回到某个存档时，才是真正回到过去。在 Codex 的桌面应用里，请在设置里确认游戏的聊天已关闭记忆。
- 如果主持人说找不到 RPG Engine 的工具，请在战役文件夹里输入 `rpg init`，然后开启一个新聊天。
- 同一时间只有一个聊天在玩一个战役：你自己的聊天开着时，仪表盘的聊天会等待。

## 3. 游玩 <!-- icon: chat -->

### 3.1 与主持人交谈

用你自己的话，写下你的角色做什么或说什么：

> 我问旅店老板，今晚还有谁路过。

想跳出故事时，请写 `[OOC: …]`（角色之外）：*[OOC: 擒抱是怎么运作的？]* 主持人也会用同样的方式回答；在仪表盘的聊天里，它在游戏之外说的话会单独显示，并标有 OOC。

在仪表盘的聊天里，在底部的输入框里写字，按 Enter 发送；Shift+Enter 换行。主持人回答时，点击**停止**可以让主持人中止，你写的话会留在输入框里。当主持人向你提问时，问题会附带按钮，包括掷骰按钮：点击其中一个，或者写下你的回答。输入框下方会显示应用和模型；应用允许的话，在主持人回答完之后，点击模型就可以更换。点击**关闭聊天**会结束聊天；游戏仍保存在文件里。

你说出想做的尝试，主持人说出结果。主持人不会替你的角色做决定，也不会谈论引擎。你可以问主持人怎么使用控制面板。

**在仪表盘上行动**：点击角色卡上的名称，比如武器、法术或随身物品，它的卡片会说明这是什么；背包可以用它的箭头展开，点它的 ⓘ 则显示它的卡片。然后选择要对它做什么。不需要对象的操作，比如**装备**，会请你在同一个按钮上确认，*确认：我装备盾牌*：再按一次，就会发给主持人。针对某人的操作，比如**攻击**，会问你对象是谁，可以在列表里选，也可以在地图上点一下；然后按钮会显示完整的句子，*我用硬头锤攻击兜帽强盗 1*，点一下就发出。想用自己的方式来说，可以点击一个人与其交谈，或者直接在聊天里写。主持人听到的就像你在聊天里说的一样，也会照常裁定，并用按钮问你还缺少的内容。如果你的 AI 应用无法即时通知主持人，主持人会在你下次在聊天里写字时读到；如果之前聊天已经关闭，点击**再说一遍**，就会再发送一次。

### 3.2 掷骰

只有结果不确定而且重要时，主持人才会要求掷骰，并且会先说明赌注是什么。接下来：

- **在控制面板上**，横幅会为每个检定显示一个按钮，例如 *杂技 +4 · 优势*。点击它：骰子会落在页面上，主持人会听到结果。你也可以点击角色卡上亮起的那一行，从骰盘里掷骰，或者在横幅里写点别的。
- **手动**，在横幅的角落或**设置**里选择：横幅会告诉你要掷什么，你在角色卡或骰盘上自己掷。
- **实体骰子**，把骰子设置选为实体：你写下掷出的点数，*[我掷出了 14。]*，RPG Engine 会加上你的调整值。

**自由掷骰**：点击角色卡上的任意数字，或打开骰盘，随手掷着玩。它们不计入结果，主持人也看不到。

**主持人的掷骰**会显示在你的掷骰栏里，秘密掷骰除外。你随时可以问 *[刚才那次掷骰是真的吗？]*：对于秘密掷骰，主持人会给出一个指纹，证明它是在你发问之前掷出的。

### 3.3 场景与战斗

故事以**场景**推进：一场战斗、一次对话、探索、旅行、休息。每个场景结束时，游戏会自动存档，这个场景会记入你的日志，故事转折时，主持人还会把上一章之后的各个场景写成你的故事之书中的新一章。

在战斗中，主持人会讲述每个不属于你的回合，并在需要你决定时停下。**场景**顶部会显示轮到谁，以及下一个是谁；你的角色卡在地图旁边。回合顺序、队伍的生命值，以及敌人的伤势（用文字描述），都留在页面一侧。如果你的角色倒下，死亡豁免会大大地显示在页面上。

**长期指令**：对同伴说一件需要长期有效的事，比如 *从现在起，一律留一个活口*，主持人就会一直记着，直到你撤销。同伴会在角色性格允许的范围内遵守；如果有同伴不愿照做，会当面说出来。你可以在**设置**里找到这些指令，在那里添加或删除。

### 3.4 时间、旅行与流动的世界

RPG Engine 会记录日期。两次游玩之间，游戏时间会停止，除非你在**设置**里选择让时间继续流逝（比如每离开一周，游戏里过一天），或者请主持人这样做。说一句你要休息，*我们进行一次长休*，主持人同意后，休息就会恢复该恢复的东西。短休时，主持人可能会在控制面板上问你花费多少生命骰：一颗一颗地掷，看看每颗恢复多少，想停就停。说出你要去哪里，*我们沿路向北去罗卡*，RPG Engine 会算出路线、距离和天数，途中有事发生时会停下来。钱按游戏里的硬币计算，找零也包括在内。

反派的计划有期限。每过新的一天，主持人就会推进时间所推动的威胁，你能看到它们的迹象，但看不到时钟本身。

### 3.5 地图

**世界**显示你的角色所知道的地点、地点之间的道路，以及你走过的路径，其余部分笼罩在迷雾中。**场景**显示你所在之处的地图（如果有的话），以及谁站在哪里；战斗中轮到你时，你到不了的格子会被遮住。主持人问你往哪里移动时，点一下格子，或者直接写出来，比如 *E4*。

**世界**还保存着你的角色所知道的事。**见闻**列出角色所知道的人物、地点、派系、生物和故事，每条都按角色的了解来写：可以搜索，也可以打开一条完整阅读；文中的名称可以跳转到对应页面。**文档**保存角色找到的信件、告示和纸页，可以随时重读。**日历**显示今天、任务的期限和剩余时间，以及故事中的日子：有场景的那一天会通向日志时间线里对应的场景。

### 3.6 任务、日志与笔记

角色接下的事务，会在**日志**里成为一个任务，附有目标、期限和衡量方式；给它加星，就会一直显示在场景顶部。在**故事**下，日志会把你的故事讲成一本书：每当故事出现转折，主持人就会按你选择的风格，把上一章之后的各个场景写成新的一章文字；你可以一章一章地读，最后读到的一章会有书签标记，也可以下载为 Markdown 或网页，用来打印或分享给别人。如果游戏是之前开始的，可以请主持人写出到目前为止的故事。**时间线**列出各个场景，按序编号，并写明每个场景中发生的事。日志还保存着你的**笔记**：笔记是私人的，除非你**分享**一条，主持人会把它当作你的想法来听，而不是事实。在**同伴**下，你可以读到同伴们的日记：他们会不时在一天或一个任务结束时，写下几行所思所感。

### 3.7 你的角色的故事与画像

在角色卡上，**描述**卡片里有一个框，用来写你的角色的故事：你同意之后，主持人会把它写进去。想要画像的话，可以把文件交给主持人（PNG、JPEG、WebP 或 SVG，最大 5 MB），并告诉主持人它在你电脑上的位置；也可以请人生成一张肖像（[3.11](#311-pictures)）：*[给我画一张肖像：灰发编成辫子，下巴上有一道疤。]*

### 3.8 存档与回到过去

RPG Engine 会在每个场景结束时保存整个战役。其余由**存档**设置决定：

| 存档 | 想存就存 | 回到过去 |
|---|---|---|
| **永久死亡** | 否 | 不可以 |
| **检查点** | 否 | 回到上一个存档，仅限角色死亡时 |
| **可用** | 是 | 回到任意存档 |

在所有模式下，你都可以**重新开始**，从游玩的起点或从零号团开始。可以在聊天里说，也可以在**存档**里操作。

回到过去之后，请**开启新聊天**：旧的聊天还记得那些已被撤销的事。在仪表盘的聊天里，点击**关闭聊天**，再点击**新聊天**；在 AI 应用自带的聊天里，开启一个新对话（Claude Code 里用 `/clear`）。在新聊天里写 *继续*。然后告诉主持人这是新聊天：在**存档**里点击**我已开启新聊天**，或者在聊天里说一声。在此之前，主持人不会继续。

如果你不知道 git 是什么，可以跳过这一段。如果战役文件夹是一个 git 仓库，**设置**里会有一个 **Git** 部分，在你选择之前全部关闭：可以在每次游玩开始时、每次存档时和每个场景结束时提交（commit），也可以在提交之后推送（push）。提交是战役在那一刻的快照；推送是把快照发送到线上的仓库（比如 GitHub），这样在这台电脑之外也留有一份副本。存档和你与主持人的聊天记录不会进入仓库，除非你允许；只有仓库是私有的，才允许聊天记录进入。

### 3.9 游玩时段：停下与回来

想停就停：*[今晚就到这里吧。]* 一切都已保存在文件里。想回来时，从图标打开 RPG Engine，点击你的战役。如果你没关聊天，它会自己恢复。如果关了，点击**继续聊天**。然后点击**继续故事**：主持人会用几句话告诉你之前玩到了哪里，然后接着往下玩。如果游戏关闭时主持人还在回答，或者主持人的一个问题还在等你回答，这个按钮会改为**从这里继续**。点击**新聊天**，会在同一个游戏上打开一个全新的聊天。在 AI 应用自带的聊天里，就在战役文件夹里启动它，然后写 *继续*。

### 3.10 主持人的心情

仪表盘顶部的机器人就是主持人：它的表情会跟随故事的基调，也绝不会泄露你还不知道的事。仪表盘没有连上游戏时，它会睡着。

### 3.11 图片

RPG Engine 可以按**图片**设置，为你到达的地点、接下的任务和遇见的人生成图片，你提出要求时也会生成角色的肖像。图片由你自己的 AI 应用用它自己的方式生成，使用你的登录账号，走你的套餐和额度：**Claude** 把它们画成矢量图，**Codex** 和 **Antigravity** 用绘制的方式生成，**OpenCode** 在聊天里画简单的矢量图。在 **设置 > 战役 > 图片** 里，即使你的主持人是另一个应用，也可以让 Codex 或 Antigravity 来绘制：你选的那个做不到时，就由你的聊天来生成。**设置**会告诉你这台电脑能不能生成图片，不能的话该怎么设置。你随时可以给角色或任何你看到的页面添加自己的图片：把鼠标指针移到页面的某张图片上，图片角落会出现一个小小的图片按钮（用键盘也可以，在手机上则始终显示）；在**世界**里，你打开的页面还有**更换图片…**，没有图片时则是**添加图片…**。把鼠标指针放在图片上，或让它的按钮获得焦点，也可以用 Ctrl+V（Mac 上用 ⌘V）粘贴你复制的图片。你的图片会取代原有的图片。也可以把文件放进战役的 **inbox** 文件夹，再告诉主持人它是给哪个页面的。

### 3.12 安全：底线、帷幕与停止

**底线**绝不会出现在游戏里；**帷幕**只会发生在画面之外。你可以随时写 *[停]*：主持人会立刻放下那段内容，并把它加入你的底线。

### 3.13 改变主意

每项设置都可以更改，在聊天里或在**设置**里都行。主持人在没有规则书可依时做出的裁定，会成为**先例**，下次遇到同样的问题，就会得到同样的答案。

## 4. 仪表盘 <!-- icon: party -->

仪表盘是你自己电脑上的一个页面，在独立的窗口里，只能在这台电脑上打开。只要它的窗口开着，它就是活的，有没有聊天都一样；你关掉窗口大约三十秒后，游戏会停止，聊天也随之结束。不会丢失任何东西：一切都在文件里。在 AI 应用自带的聊天里，聊天开着时它才是活的。游戏断开时，页面会显示*未连接*：点击**重开战役**，或者在你自己的应用里开启下一个聊天。带房子图标的**战役**按钮，会带你回到全部战役。

- **角色扮演**：和主持人的聊天，不在页面旁边时就在这里（[2.5](#25-the-first-chat)）。
- **队伍**：你的角色卡和同伴的角色卡。点击一个数字即可掷骰；把鼠标悬停在上面，可以看到这个数字的来源。如果数字旁有箭头标出骰子，还能看到什么会让这次掷骰更有利或更不利。主持人为你准备选项时（比如升级的时候），角色卡上会出现一条通知，点开就能查看：你可以随时选择，先读一读选项所指的页面，遇到需要掷骰的选项就掷骰，最后确认；故事会照常继续。旁边是掷骰记录。
- **场景**：你所在的地方，以及它的图片和地图、在场的人、正在发生的事。战斗中，这里会显示回合顺序和你的角色的卡片。
- **日志**：任务、书一般的故事、时间线、同伴的日记，还有你的笔记。
- **世界**：世界地图、你的角色所知道的事、找到的文档和日历。
- **骰盘**：选择骰子和调整值，然后掷出。×2 会让骰子数量加倍，调整值不加倍，就像重击时那样。
- **存档**、**帮助**、**设置**和**关于**，以图标的形式排在这一行的末尾。**设置**里还有页面自己的偏好，在**仪表盘**下：模式、骰子音效、骰子款式，以及**主题**，也就是页面的配色、骰面和图片。可选的主题有：游戏系统自带的；你在 Packages › Add 中从目录、GitHub 链接、.zip 或文件夹添加的主题；或者页面自带的。如果某个主题自带的样式表让页面难以阅读，可以在这里关闭**主题自带样式**：**设置**页始终不带主题样式显示，地址是页面地址后面加上 `#/settings/page`。

主持人向你提问时，它的提示条会一直停在页面顶部，不论你在哪个部分。

## 5. 游戏系统与房规 <!-- icon: dice -->

### 5.1 什么是游戏系统

一款游戏的全部数据：角色卡、数值、生物、物品、法术和规则文本。每个战役只玩一种系统。RPG Engine 负责计算角色卡，以及消耗和恢复的资源；某项能力具体如何生效，由主持人查阅规则后裁定，就像在牌桌上一样。

### 5.2 第五版

包含 SRD 5.1 的种族、职业、子职业、一个背景和一个专长；319 个法术，以及武器、护甲、魔法物品和怪物；还有规则章节，主持人会按原文查阅；以及完整的、已算好的角色卡。

它是一个独立的包：你设置战役时，主持人会提议使用它，并为你安装。玩这套系统的战役，第一次在没有安装它的电脑上打开时，会自动安装，主持人也会告诉你。

SRD 里没有的内容，你也可以玩，只要来自你自己拥有的书：主持人会把它写成你战役的页面，RPG Engine 将它们视为自己的内容。RPG Engine 只附带开放内容；主持人所知道的则不受此限。

你自己的手册可以成为你的资料库：告诉主持人它们在哪里，*[我的手册在 D:\Books\5e。]*，或者在 扩展包 › 资料库 中添加它们所在的文件夹，并在电脑弹出的窗口里点一次“是”。RPG Engine 会在这台电脑上读取它们；每个战役使用你在那里打开的文件夹，主持人在裁定规则时会在 SRD 之后搜索这些手册，并注明书名和页码。纯文本，或文字可以选中的 PDF，读取效果最好；扫描版 PDF 则是根据页面图片来识别的，只支持 Windows，需要几分钟，也会有少量错误。RPG Engine 绝不会修改你的手册，绝不会把手册文字发送到任何地方，也绝不会把它复制进战役。

### 5.3 房规与你自己的补充

对主持人说：*[房规：攻击掷出自然 1 时，武器会脱手。]* 主持人会把它记为牌桌上的约定；需要时，也会写成一个页面，或角色卡上的一个数值。已经写好的房规，可以作为文本文件放进战役的 `rules` 文件夹。

当主持人为你的战役修改游戏系统中的某个页面时，比如某个生物的生命值或某个法术的射程，仪表盘会在该内容出现的每个位置，于名称后标上一个小星号。扩展包 › 已安装 会在对应的游戏系统下，列出被修改的内容，并与系统原有的内容并排显示；你的角色还不了解的生物，只会显示名称。在那里，你可以把页面恢复成系统原本的写法，但要等当前场景结束之后；仪表盘无法撤销修改，只有主持人才能重新写下这项修改。

### 5.4 添加或导入你自己的游戏系统

游戏系统是一个包：主持人可以从 npm、文件夹或文件安装。不是我们提供的包，只有在你同意后才会安装，你可以在 AI 助手的表单或电脑的窗口中确认。制作游戏系统是开发者的工作，详见 RPG Engine 在 GitHub 上的文档。把你的书变成游戏系统，目前还不支持（[后续推出](#9-coming-later)）。

## 6. 扩展 <!-- icon: plus -->

扩展可以在游戏系统之外，为战役增添新内容：比如每天黎明都会变化的天气，或者用骰子撬锁。在“扩展包 › 添加”中添加：可以从列表里选，也可以输入它在 npm 上的名称，或选择一个文件夹或文件。不是我们制作的扩展会带有代码，只有你同意后才会添加，同意要在电脑弹出的窗口里确认。为其他游戏系统制作的扩展会注明适用的系统，不能添加。在“扩展包 › 已安装”中，你可以更新或移除扩展；你提出要求时，主持人也可以添加扩展。

## 7. 战役从哪里来，以及它的语言 <!-- icon: world -->

### 7.1 拥有世界的三种方式

- **即时构建**：根据你的前提，主持人在你需要之前才构建每个地点、人物和情节，并把它们记下来。
- **开始前准备**：同上，只是世界在游玩之前就已构建好。
- **来自你自己的冒险或书**：把文件交给主持人，*[把这个冒险导入为我们的战役：D:\Books\adventure.pdf。不要告诉我里面的任何内容。]* 战役之外的文件，要先在你电脑的窗口里点“是”才会被读取；放进战役 **inbox** 文件夹的文件，会立刻被读取。文本、EPUB、Word 文档，或可以选中文字的 PDF，读取效果最好；扫描版 PDF 会通过页面图片来读取，仅限 Windows，速度慢，还会有一些错误。读取由你自己的 AI 应用在聊天之外完成，否则由聊天中的主持人读取，走你的套餐：在 Claude Code 或 Codex 里，由这两者之一读取；在 Antigravity 里，由你的 Antigravity 读取；在 OpenCode 里，由你最近在其中选择的模型读取。整份文档会发送给负责读取的那个模型的开发方，适用你账户的条款以及你对训练用途的选择。仪表盘会显示进度；如果来源是小说，主持人会建议从哪里开始。主持人会写出地点、角色和秘密。

一个战役只玩一次：想再玩同一个冒险，请创建一个新战役。

### 7.2 语言

每个战役一种语言，即主持人的语言，仪表盘随之而变。仪表盘自带 26 种语言。其他任何语言，会由你自己的 AI 应用在聊天之外，在你的电脑上翻译（Codex 或 Claude Code；在 Antigravity 和 OpenCode 里，则由它们自己翻译）；都做不到时，由聊天中的主持人翻译。第五版的意大利语术语来自官方的意大利语 SRD；规则文本保持英文，由主持人用你的语言讲述。

## 8. 好奇者专区：战役文件夹 <!-- icon: list -->

你完全不需要打开它，而且里面存着你战役的秘密。其中有 `campaign.yaml`（你的设置）、`state.yaml`（游戏进行到哪里）、`world/`（每个角色、地点、任务等各占一页 markdown）、`rules/`（你的房规）、`images/`、`log.jsonl`（每一次改动）、`sessions/`（你与主持人的聊天文字记录，来自 Claude Code 和 Codex）、`.saves/`、`.player/`（你的笔记），以及告诉 AI 助手 RPG Engine 在哪里的几个小文件。页面采用 Obsidian 的格式。如果你手动修改了某个页面，主持人会在下一次回答时得知。

RPG Engine 只在这个文件夹内活动：它只在这里读写游戏，绝不会碰你的其他文件；你的手册所在的文件夹，它只读取。在这个文件夹之外，它只保留自己的数据文件夹（仪表盘的翻译、它从你的手册中读出的文字，以及你允许安装的 Codex 或 Claude Code），还有绘制图片时用到的临时文件夹。你的 AI 助手若想在电脑上做别的事，都会先征求你的同意。游戏系统或扩展就是代码，和所有 npm 包一样：不是我们提供的包，会以你的权限在你的电脑上运行，RPG Engine 只有在你同意后才会安装，你可以在 AI 助手的表单或电脑的窗口中确认。只对你信任其作者的包说“是”。

主持人用到的每一条命令，也都可以在战役文件夹里运行：`rpg --help` 会列出它们。许多命令会打印出战役的秘密。

## 10. 问题与故障 <!-- icon: info -->

### 问题

**我需要懂规则吗？** 不需要。选择教程导师，想问什么就用 `[OOC: …]` 提问。

**主持人会作弊吗？** 除了难度为“故事”时，它无法更改 RPG Engine 已经掷出的结果，也无法更改已经确定的事实。

**要花钱吗？** RPG Engine 是免费的。主持人运行在你的 AI 应用的套餐上，或者用本地模型运行在你自己的电脑上。一个晚上的游戏就是一场很长的聊天：在最小的套餐上，你可能在晚上结束前就达到套餐的额度。图片、翻译和导入使用的是同一个套餐。RPG Engine 本身从不使用 API 密钥（按调用次数收费）：请用你的账号登录 AI 应用，而不是用密钥。

**可以在手机上玩吗？** 不行：主持人运行在你的电脑上，仪表盘也只能在那里打开。

**可以和朋友一起玩吗？** 暂时不行：目前是一名玩家、一个角色，外加同伴（[以后推出](#9-coming-later)）。

**下次可以换一个 AI 吗？** 可以：打开聊天之前，在聊天里选另一个应用；或者用另一个应用打开战役，然后写 *继续*。

### 故障

**战役打不开。** 从图标再次打开 RPG Engine，或者在终端里输入 `rpg open`，然后点击这个战役。如果它的仪表盘显示*未连接*，点击**重开战役**。卡片上写着**找不到文件夹**，说明它的文件夹丢了：先把它从列表里移除，再用**打开文件夹…**，在文件夹现在的位置重新添加。在 AI 应用自带的聊天里，只有该战役的聊天开着时，仪表盘才能用：问主持人 `[OOC: 仪表盘的链接是什么？]`。在 Claude 应用里，聊天在后台放置一段时间后会休眠，页面也会随之休眠：点一下这个聊天，页面就会在同一个地址恢复。

**主持人似乎不懂这个游戏。** 这发生在 AI 应用自带的聊天里：它没有加载 RPG Engine。请检查你是否在战役文件夹里启动了它，并且选择了信任。在 Claude Code 里，输入 `/mcp` 并重新连接 `rpg`。在 Codex 里，在战役文件夹中运行 `codex mcp list`，必须能看到 `rpg`。如果提示找不到 `rpg --version`，请重新安装 RPG Engine（[2.2](#22-install)）。

**Windows 找不到 `claude`。** 这发生在你自己安装了 Claude Code 的情况下。它的安装程序会用黄色提示告诉你这一点，并写明它安装到了哪个文件夹：把那个文件夹加入 PATH（系统属性 > 环境变量），然后打开一个新的终端。

**更新。** 有更新的 RPG Engine 发布时，仪表盘会提示你：在 Packages › Installed 里，RPG Engine 排在最前面，旁边有**更新**按钮；然后照页面的提示做。或者在终端里再运行一次 `npm install -g rpg-engine`，然后开启新聊天：正在运行的主持人会沿用它启动时的版本。

**主持人还记得我撤销过的事。** 开启新聊天，然后在存档里点**我已开启新聊天**。

**某个应用装不上。** 页面会说明原因：点击**重试**。或者从它的开发方网站自己安装，然后点击**重新检查**。

**登录页面没有在浏览器里打开。** 页面在等你登录时，点击它显示的**重新打开登录页面**，或者点击**取消**，再试一次。

**仪表盘的聊天提示另一个聊天正在玩。** 你自己在 AI 应用里打开的某个聊天正在玩这个战役：在那里继续玩，或者把它关掉，改在仪表盘里玩。

**没有图片出现。** **设置** > 战役 > 图片会告诉你这台电脑能否生成图片，以及怎么做。

**安装失败，或 `rpg` 无法启动。** `node --version` 必须显示 24 或更新版本。如果 Windows 提示已禁止运行脚本，见 [2.1](#21-what-you-need)。在 Windows 上，请让 RPG Engine 和你的战役远离含有 `&` 的路径。

**仪表盘链接变了。** 在 AI 应用自带的聊天里，每个战役都有自己的地址，一场聊天接一场聊天都不变。只有当另一个程序已经占用了这个地址时，它才会变：主持人会给你新的链接，之后就一直用这个新链接。同一个战役的第二个聊天会让页面保持在同一个地址，等你关掉第一个聊天后，才会接管这个页面。
