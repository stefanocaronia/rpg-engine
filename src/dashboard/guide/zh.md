# RPG Engine：完整指南

**RPG Engine** 让你与一位 **AI 主持人** 一起玩桌面角色扮演游戏。

你在 **聊天** 里和主持人交谈：主持人讲述故事，扮演其他所有人，并裁定发生的一切。

RPG Engine 在幕后工作：它会 **记住世界**，**掷骰子**，还会 **记好账目**。

聊天旁边，你在浏览器里开着一个页面，也就是 **仪表盘**。上面有你的角色的角色卡、骰子、地图和日志。

这份指南写给玩家：你不需要会编程。

## 快速开始 <!-- icon: send -->

1. 从 [nodejs.org](https://nodejs.org) 安装 **Node.js**（LTS 版本）。
2. 安装 **Claude Code** 或 **Codex**，也就是主持人运行所在的 AI 应用，并登录（[2.4](#24-connect-your-ai)）。
3. 打开终端，安装 RPG Engine：`npm install -g rpg-engine`。
4. 在终端里创建战役：`rpg init "The Salt Isles"`。
5. 在新文件夹里打开 Claude Code 或 Codex，写下 *你好！我们开始吧。* 主持人会回复仪表盘的链接：把它打开，放在聊天旁边。

本指南的其余部分会详细解释每一步，然后讲怎么玩。

## 1. RPG Engine 是什么 <!-- icon: about -->

### 谁负责什么

| 谁 | 做什么 |
|---|---|
| **你** | 扮演你的角色。说出角色做什么、说什么、尝试什么。 |
| **主持人**（AI） | 讲述故事，扮演所有其他角色，决定发生什么，要求掷骰。 |
| **RPG Engine** | 把一切记在文件里，掷骰子，计算生命值、金钱、时间和距离，在你发现之前替你保守秘密。 |

AI 擅长讲故事，却不擅长记忆。放着不管，它会忘记谁欠你钱、你还剩几支箭，或者桥在两次游戏之前就烧毁了。RPG Engine 把这些全部记下来，所以世界在每个晚上之间保持一致，即使换了新聊天，甚至换了另一个 AI。

### 玩起来是什么感觉

你在聊天里写字，就像在桌边说话：

> 我慢慢推开门，往里看。

主持人回答你看到的东西，并在轮到你选择时停下。遇到不确定又重要的事，主持人会说明风险，并要求掷骰。掷骰的按钮会出现在你的仪表盘上。你点一下，骰子落在页面上，主持人告诉你发生了什么。

### 它有何不同

- **世界是持久的。** 说过的事就是真的。死掉的反派不会复活。
- **骰子是真的。** 主持人无法操纵骰子（除非你选了最简单的难度）。
- **秘密始终是秘密。** 角色不知道的事，主持人绝不会告诉你，哪怕你再三追问。
- **世界不会等你。** 你休息或赶路时，威胁仍在推进，你会看到它们的迹象。
- **许多个夜晚，一个故事。** 战役就是你电脑上的一个文件夹。你可以随时停下，以后再接着玩。

### 目前能玩的游戏

RPG Engine 为任何桌面角色扮演游戏而设计。目前内置一个游戏系统：**第五版**（来自免费的系统参考文档 5.1）。其他游戏会陆续加入；见[游戏系统](#5-game-systems-and-house-rules)和[以后会有](#9-coming-later)。

## 2. 开始使用 <!-- icon: path -->

### 2.1 你需要什么

- 一台运行 Windows、macOS 或 Linux 的电脑。
- **Node.js 22** 或更新版本。从 [nodejs.org](https://nodejs.org) 获取：“LTS”版本就行。它自带 `npm`，用来安装 RPG Engine。
- 一个**终端**，也就是输入命令的窗口：在 Windows 上是“终端”应用或 PowerShell；在 macOS 上是“终端”。你用它来安装 RPG Engine、创建每个战役，以及启动 Claude Code 或 Codex。
- 一个 **AI 主机**，也就是主持人运行所在的应用：**Claude Code** 或 **Codex**，并有相应的订阅方案和登录账号。见 [2.4](#24-connect-your-ai)。
- 主机提供的**最大模型**。小模型容易上当：在我们的测试中，它把秘密告诉了自称是真正主持人的玩家。
- 一个网页浏览器，用来打开仪表盘。

你登录主机用的账号还有别的用处：RPG Engine 在你的电脑上用它来绘制地点的图片，并把仪表盘翻译成它没有内置的语言。见[图片](#311-pictures)和[语言](#72-languages)。

**在文件夹里打开终端。** 许多步骤会说“在战役文件夹里”。在 Windows 上，在文件资源管理器中右键点击该文件夹，选择**在终端中打开**。在 macOS 上，在访达中右键点击该文件夹，选择**服务 > 新建位于文件夹的终端窗口**。或者，在已打开的终端里写 `cd` 加上文件夹的路径，例如 `cd "C:\Users\me\Games\The Salt Isles"`。

### 2.2 安装

打开终端，写下：

```text
npm install -g rpg-engine
```

这样你就有了 `rpg` 命令。检查是否成功：

```text
rpg --version
```

每个战役只需用一次 `rpg`，用来创建它。之后你只和主持人交谈：你的 AI 主机会自动启动 RPG Engine，用的也是同一个 `rpg` 命令。

### 2.3 创建战役

战役就是一个文件夹。在你存放游戏的文件夹里打开终端，写下：

```text
rpg init "The Salt Isles"
```

这会创建文件夹 `The Salt Isles`，里面有一个新战役，并告诉你下一步做什么：

```text
Created the campaign "The Salt Isles" in C:\Users\me\Games\The Salt Isles.
To play, open Claude Code or Codex in this folder and say hello: the master asks you the rest.

For the master: Still to agree with the player: ...
```

*For the master* 之后的几行是给主持人看的，主持人会在聊天里读到它们：你不用管。记住文件夹在哪里：每次游戏你都要回到这里。如果不写文件夹名，`rpg init` 会把你当前所在的文件夹变成战役。

`init` 会准备战役需要的一切：设置、世界文件夹，以及几个小文件。这些小文件告诉你的 AI 主机使用 RPG Engine，并且不要在战役之外保留自己的记忆。

你现在不需要选任何东西。主持人会在聊天里问你其余的问题，你也可以在仪表盘上选择。如果你已经知道一些选择，可以在这里直接给出：

```text
rpg init salt-isles --name "The Salt Isles" --language en --system 5e --difficulty normal --lethality dice
```

这会创建文件夹 `salt-isles`，里面是战役 *The Salt Isles*：文件夹名没有空格，战役名则随你喜欢。

| 选项 | 设置什么 | 可选值 |
|---|---|---|
| `--name` | 战役的名称 | 任意；不写则用文件夹名 |
| `--language` | 游戏的语言 | 一个代码，如 `en`、`it`、`fr` |
| `--system` | 游戏系统 | `5e`，目前唯一的选择 |
| `--difficulty` | 世界有多难 | `story`、`easy`、`normal`、`hard`、`brutal` |
| `--lethality` | 在战斗中倒下意味着什么 | `narrative`、`epic`、`dice` |

`rpg init --help` 也会列出它们。战役不能放在另一个战役的文件夹里面。

你不能让主持人来创建战役：在 `init` 之前，文件夹里没有任何东西告诉你的 AI 主机 RPG Engine 在哪里。

### 2.4 连接你的 AI

RPG Engine 可与 **Claude Code** 和 **Codex** 配合使用。其他使用 MCP 工具的 AI 应用也许同样可行，但我们不作保证。

**安装你的主机。** Claude Code 和 Codex 在终端里运行：它们不是手机上的 Claude 或 ChatGPT 应用。各自需要自己的方案和登录：Claude Code 需要付费的 Claude 方案，Codex 需要 ChatGPT 登录。请按它们各自的页面安装并登录：[Claude Code](https://code.claude.com/docs/en/setup) 和 [Codex](https://learn.chatgpt.com/docs/codex/cli)。这一步只需做一次，所有战役通用。

**Claude Code。** 在战役文件夹里打开终端，写下 `claude`。第一次运行时，它会问你是否信任这个文件夹，并说明该文件夹允许使用游戏的工具（`mcp__rpg`）：选择 **Yes, I trust this folder**。注意：默认选中的答案是 *No, exit*，所以直接按回车会关闭 Claude Code。这样就好了：战役已经告诉 Claude Code 使用 RPG Engine 及其工具，并关闭它自己的记忆。

**Codex。** 在战役文件夹里打开终端，写下 `codex`。当它问你是否信任这个文件夹时，选择信任：战役自带的设置会告诉 Codex RPG Engine 在哪里、允许使用它的工具并关闭它的记忆，而 Codex 只会在你信任的文件夹里读取这些设置。在桌面应用中，请确认游戏聊天的记忆功能已关闭。

**为什么记忆很重要。** 战役保存在它的文件里。如果主机还自己记着一些事，回到存档就不是真正的回去：主持人仍会记得被撤销的内容。

### 2.5 第一次聊天

随便写点什么，例如：

> 你好！我们开始吧。

主持人会读取游戏进行到哪里，然后回答。每次聊天的第一个回答里，它都会给你**仪表盘的链接**（类似 `http://127.0.0.1:4750`）。在浏览器里打开它，整局游戏都放在聊天旁边。每个战役在不同聊天之间保持同一个链接，除非被别的程序占用了：那时主持人会给你新的链接。

在主持人的消息之间，你的主机会用简短的几行显示主持人用到的工具。不要展开它们的详情（在 Claude Code 里是 ctrl+o）：详情里可能显示主持人写下的内容，包括秘密。

新战役会经历三个阶段，就像有真人主持人的游戏。仪表盘在顶部显示它们：*1 设置 · 2 零号团 · 3 游戏*：

1. **设置**：你选择想怎么玩。在故事之外进行。
2. **零号团**：你在游戏中创建角色。
3. **游戏**：故事本身。

### 2.6 设置：选择怎么玩

主持人只问还缺的问题，每次问几个。如果你写“你来定”，主持人会自己选择，并告诉你选了什么。打开仪表盘后，它的第一步**设置**会把同样的问题显示成卡片：一次一个问题，每个值都附有含义，常用的那个标着**推荐**。在那里选择，主持人就不会在聊天里再问；**跳过**则把问题留到以后。聊天负责处理只能用文字说清的事：新世界的前提、语言，以及图片（只有你的电脑能生成时，主持人才会问）。所以页面上问的问题比下表列的少。

你不必研究这张表：它是用来查阅的。这些设置以后都可以更改，在聊天里或在仪表盘的**设置**里都行。更改从主持人的下一次回答起生效。

| 设置 | 决定什么 | 可选值 | 推荐 |
|---|---|---|---|
| **导师**（问法是“你对这个游戏有多熟悉？”） | 主持人在故事之外教你规则的程度 | **关闭**（只有故事；想问时把问题写在方括号里），**提示**（在重要选择之前给一句简短提示，规则被漏掉时也会提醒），**教学**（每条规则第一次出现时讲解，每次掷骰的完整算式，战斗后简短复盘） | 按你的回答：没玩过 → 教学，玩过一点 → 提示，我很熟 → 关闭 |
| **难度** | 世界有多难：战斗、敌人战术、线索、宝藏、威胁推进得多快 | 故事、简单、普通、困难、残酷 | |
| **致命度** | 在战斗中倒下意味着什么 | **叙事**（你的角色永远不会死），**史诗**（只在对故事重要时才死），**骰子**（由骰子决定） | 跟随难度：故事 → 叙事，简单 → 史诗，普通及以上 → 骰子 |
| **存档** | 你何时可以回头 | **永久死亡**（永不；只能重新开始战役），**存档点**（回到上一个场景结束时，仅在角色死亡时），**自由**（回到任意存档，想存档就能存档） | 存档点 |
| **严谨度** | 食物、光源、疲劳、负重、法术材料和旅行遵循规则的严格程度 | **流畅**（主持人一笔带过），**规则**（照规则书：火把会烧尽，口粮会吃完），**模拟**（超出规则：磨损、腐坏、天气） | 流畅 |
| **骰子** | 谁来掷你角色的骰子 | **数字**（RPG Engine 在页面上掷），**实体**（你自己掷，并告诉主持人点数） | |
| **单位** | 故事中的距离和重量 | 公制、英制 | |
| **同伴** | 谁与你同行 | 无、零号团中与你一起创建、由主持人创建、在游戏中遇到 | |
| **图片** | 地点和任务的图片 | 无、按需、新地点和新任务 | 只问一次，且只在你的电脑能生成时问 |
| **底线** | 游戏中绝不出现的内容 | 一个列表，或没有 | |
| **帷幕** | 可以发生、但只在幕后的内容 | 一个列表，或没有 | |
| **语言** | 游戏和仪表盘的语言 | 任意 | 根据你的书写判断，并向你确认 |

游戏系统可以加入自己的设置。第五版增加了**成长**：你的角色如何升级，是靠**经验值**，还是靠故事的**里程碑**。

**难度在游戏中意味着什么。** 故事：敌人弱小天真，线索显而易见，物资充足；主持人可以放松自己的掷骰。简单：敌人简单，资源慷慨。普通：敌人合理，每个结论有三条线索，价格和宝藏为标准水平。困难：敌人聪明，线索隐晦，资源稀缺，威胁推进很快。残酷：敌人会伏击、撤退、补刀倒下的人，资源极度稀缺，休息条件最苛刻。战斗的规模总会按你当前的队伍来定。

**如果没有现成的世界**，设置阶段还会多问两件事：

- **前提**：类型、基调和世界的几个要素，用你自己的话来说。例如：*“低魔奇幻，阴郁但留有希望。一座河边小镇，一处闹鬼的渡口，山丘里的一个邪教。”*
- **准备**：**随玩随建**（主持人在你需要之前才构建世界的每个部分；推荐）或**开局备齐**。

然后主持人会为战役提议一个名字。当没有遗漏的问题，并且你说准备好了，游戏就进入零号团。

### 2.7 零号团：你的角色

零号团本身就是游戏：你和主持人一起创建角色，就像在桌边一样。

- **每个选择都由你做主**，除非你请主持人代劳。你可以带着完整的想法来（“一个离开神殿的半精灵牧师”），也可以带着模糊的想法（“会治疗，但脾气不好的人”），或者什么都没有（“给我个惊喜，然后让我改”）。
- **属性值。** 在掷任何骰子之前，主持人会告诉你方法和保底措施。第五版中：标准数组、点数购买，或 4d6 去掉最低值。你们商定的方法会记在桌面约定里。
- **你的故事**从来不是必需的。如果你提供了，主持人会用你的话把它写下来，向你复述一次，并把其中的人物和地点编进世界。你也可以在仪表盘上写（见[队伍](#party)）。
- **个性**（第五版）：一个特点、一个理想、一个羁绊和一个缺陷，来自你的背景表格或你自己的设想。
- **一张图片。** 角色创建好后，主持人会向你要一张角色的图片：你电脑上的一个文件。如果你的 AI 主机能自己画图，主持人也可能提议画一张。

角色卡上的数字由 RPG Engine 根据你的选择算出：你不用自己做任何计算。角色都创建好、你确认之后，故事就开始了。

## 3. 游戏 <!-- icon: chat -->

### 3.1 与主持人交谈

用你自己的话写出角色做什么或说什么。简短就行。

> 我问旅店老板，今晚还有谁来过。
>
> “我们不是来惹麻烦的，”我说，手离开剑柄。
>
> 我爬上屋顶，等着。

**要在故事之外说话**，把话写在方括号里：

> [擒抱是怎么运作的？]
>
> [这一轮我还能用反应吗？]
>
> [今晚就到这里吧。]

主持人也会用方括号回答，然后回到故事里。

**你说想尝试什么；主持人说发生了什么。** 违背世界逻辑或已确立事实的事不会发生：主持人会在故事里告诉你，并提出可行的做法。

**主持人绝不替你的角色做决定。** 它不会替你说话、感受或选择。拿不准时，它会问你。

**主持人从不谈论引擎。** 问它有没有在记录这些事，它会像主持人那样回答：“我都记着：下次从这里继续。”

**你可以问主持人怎么使用仪表盘。** 它了解这个页面：“我在哪里看我的法术？”“怎么手动掷骰？”

### 3.2 掷骰

**什么时候掷骰。** 只有结果不确定且重要时，主持人才会要求掷骰。否则它会答应，或者说“可以，但是……”。掷骰之前，主持人会说明风险和适用的检定，然后停下。你去掷骰，或者改变主意：

> **主持人：** 岩架又窄又湿。如果你滑倒，就会掉进河里，摔得很惨。需要一次敏捷（体操）检定，或者你也可以回去找楼梯。
>
> **你：** 我试试。

**在仪表盘上掷骰。** 主持人要求时，页面顶部会出现一个横幅，每种检定一个按钮，例如 *体操 +4 · 优势*。点一下：骰子落在页面上，主持人听到结果。你还可以：

- 点击角色卡上对应的那一行，它会亮起金色；
- 从骰盘里掷合适的骰子；
- 在横幅里写下自己的话，如果你想做别的事。

**手动掷骰。** 如果你想自己挑骰子，在横幅角落打开**手动**（或在**设置**里打开）。检定的按钮会消失，横幅会像主持人那样告诉你该掷什么：*请自己掷体操，用角色卡或骰子都可以。* 点击角色卡上亮起的那一行，或从骰盘里掷合适的骰子：RPG Engine 替你掷骰、加上你的加值，主持人听到结果。角色卡和骰盘都无法完成的检定，例如会重掷 1 点的伤害，仍保留它的按钮。手动模式会在这个浏览器里一直开着，直到你关掉它。

**整局都用实体骰子。** 当**骰子**设置为实体时，主持人会用文字要求你掷骰，你把掷出的点数写下来：

> [我掷出了 14。]

RPG Engine 会加上你的调整值，并拒绝你的骰子不可能掷出的点数。

**自由掷骰。** 点击角色卡上的任意数字，或打开骰盘，就可以随便掷着玩。自由掷骰从不计入，也不会被记录，主持人永远看不到。自由掷出的 20，以后也不会变成真正的 20。

**主持人的掷骰。** 主持人为敌人和其他角色掷骰，同样通过 RPG Engine。大多数掷骰会显示在你的掷骰栏里。当你不该看到结果时，主持人会暗中掷骰。你随时可以问：

> [刚才那次掷骰是真的吗？]

对于公开的掷骰，主持人会给出数字和理由。对于暗中的掷骰，主持人会给出一个指纹，证明这次掷骰是在你提问之前完成的。

**聊天中的掷骰**会以方括号出现，紧跟在它所决定的时刻之后：*[说服 14 + 3 = 17]*。然后故事讲述结果。

### 3.3 场景与战斗

主持人以**场景**来推进故事：一场战斗、一次对话、探索、旅行、休息、一次挑战（追逐、竞速、谜题）。你不用管理它们：这是 RPG Engine 划分故事章节的方式。每个场景结束时，游戏会自动存档，场景会进入你日志里的故事。

**战斗中**，主持人会依次讲完所有不属于你的回合，附上每一次掷骰，并**停在你可以做决定的地方**：你的回合、一次反应、一个选择。轮到你时，说出你做什么：

> 我对门边那个施放圣火术。

仪表盘的**战斗**部分显示回合顺序、轮到谁、队伍的生命值，以及敌人的伤势（未受伤、受伤、重伤、倒下：用文字表示，绝不用数字）。如果你的角色倒下，死亡豁免会大大地显示在页面上。

**当战斗胜负已定**，主持人可能会提议用一条消息讲完剩下的部分。

### 3.4 时间、旅行与运转的世界

**时间。** 每个行动在故事里都要花时间，RPG Engine 记着日期：第3天，清晨。主持人按世界自己的方式报时：黎明、第三声钟响、日落。两次游戏之间不会有时间流逝：你从停下的地方接着玩。

**休息。** 说你要休息，主持人就会应用休息能恢复的东西，比如生命值和法术位：

> 我们扎营，进行一次长休。

**旅行。** 说出你想去哪里：

> 我们沿大路向北去 Rocca。

RPG Engine 会按你的速度算出路线、距离和天数，并把你送到那里。旅程会在途中发生预定事件时、每天行程结束时以及抵达时停下。出发之前，你可以问一个地点有多远：

> [Rocca 有多远？步行要多久？]

**世界不会等你。** 反派有带期限和进度钟的计划。每过一天，主持人会推进时间所推动的威胁，你会看到它们的迹象：一则传闻、一道痕迹、小镇里的一点变化。你永远看不到进度钟本身，只能看到它留下的痕迹。

**金钱**用游戏里的硬币计算。付款、出售、收款：RPG Engine 负责找零。

### 3.5 地图

**世界地图**（仪表盘：**世界**）只显示你的角色认识的地点、它们之间的道路、你走过的路径，以及覆盖其余一切的迷雾。点击一个地点，可以看到你对它的了解和距离。

**地点地图**（仪表盘：**场景**，战斗中则在**战斗**）会在主持人为你所在之处绘制地图时出现：墙壁、门、地面，以及用标记表示的谁站在哪里。在战斗中轮到你时，你到不了的格子会被遮住，所以你一眼就能看出能去哪里。当主持人问你的角色移动到哪里时，页面会打开地图，你点一个格子，或者写下它，例如 *E4*。

### 3.6 任务、日志与笔记

**任务。** 当你的角色接下一项委托，它就会成为你**日志**里的一个任务：谁委托的、在哪里、期限、列成清单的目标，以及它衡量的东西（带剩余时间的期限、进度钟、计数）。点它的星标来关注：它会以小卡片的形式留在场景的顶部，并显示下一个目标。任务由故事来结束，绝不会自行结束。

**故事。** 日志的故事标签页把你的战役呈现为一条时间线：每个场景是一章，带有地点、日期和简短摘要，最新的在最前。

**你的笔记。** 在日志的笔记标签页里，你可以写自己的笔记：推测、名字、计划。它们留在你的电脑上，主持人不会读，除非你**分享**其中一条。分享的笔记会在主持人的下一次回答时传达给它，作为你的想法，而不是事实。你的推测不会因为你写下来就变成真的。一条要求停止或回避某些内容的笔记，等同于你在桌边亲口说出。

### 3.7 角色的故事与图片

在角色的角色卡上，**描述**卡片里有一个框，可以写下角色的故事。发送之后，经你同意，主持人会用自己的话把它写进角色里。

至于角色的图片，在聊天里把图片文件交给主持人，并写明它在你电脑上的位置（PNG、JPEG、WebP 或 SVG，最大 5 MB）：

> [这是我角色的肖像：C:\Users\me\Pictures\mira.png]

主持人会把它复制进战役，它会出现在仪表盘上你角色的标记上。你随时可以用同样的方式更换。RPG Engine 本身只绘制地点和任务的图片（见[图片](#311-pictures)）。

### 3.8 存档与回头

RPG Engine 会在**每个场景结束时**自动保存整个战役。你能用这些存档做什么，取决于**存档**设置：

| 存档 | 想存就存 | 回头 |
|---|---|---|
| **永久死亡** | 不能 | 永不；只能重新开始战役 |
| **存档点** | 不能 | 回到上一个存档，仅在你的角色死亡时 |
| **自由** | 可以 | 回到任意存档，随时 |

在所有模式下，你都可以**重新开始**：从游戏开头用同一个角色，或从零号团用一个新角色。

这一切都可以在聊天里做（“[我们回到决斗之前吧。]”），也可以在仪表盘的**存档**部分做。

**回到存档之后，请开启新聊天。** 你一直在玩的那个聊天还记得被撤销的内容。和主持人开启一个新聊天（Claude Code 里用 `/clear`，Codex 里用 `/new`），写下 *继续*，然后在存档里按**我已开启新聊天**，或者在新聊天里告诉主持人。千万不要恢复旧聊天。在你确认之前，主持人不会继续。

### 3.9 游戏次数：停下与回来

**你可以随时结束本次游戏：**

> [今晚就到这里吧。]

没有“存档并退出”这回事：一切早已在文件里了。

**要关闭**聊天，在 Claude Code 里写 `/exit`，在 Codex 里写 `/quit`。仪表盘会安静下来，直到下一次聊天。

**要回来**，在战役文件夹（`init` 打印出的那个）里打开终端，在那里启动你的主机，然后写下 *继续*。主持人会读取游戏进行到哪里，给你一段简短的回顾，并以正在发生的事开场。新聊天不会丢失任何东西：战役保存在它的文件里，而不是聊天里。

主持人不会在结束时问例行的问题。只有当它发现哪里出了问题，才会简短地问一下。

### 3.10 主持人的情绪

仪表盘顶部是主持人的头像，一个小机器人。它的表情随故事的基调变化：危险逼近时忧虑，遇到大胆的主意时欣喜，剧情反转时惊讶。遇到自然 20 或自然 1 时，它会短暂地做出反应。它从不显露你还不该知道的事：陷阱触发之前不会咧嘴笑。你的队伍的标记也会显示他们的情绪。聊天关闭时，机器人会睡着。

### 3.11 图片

RPG Engine 可以按**图片**设置的要求，为你到达的每个地点和接下的每个任务生成一张图片。它使用你电脑上已有的东西：

- **Codex**，用你的 ChatGPT 登录：一幅绘画。
- 否则用 **Claude Code**，用你的 Claude 登录：一幅线稿。

图片用的是你自己的方案，不是我们的。**设置**部分会告诉你，你的电脑能否生成图片，如果不能，还会给出配置的步骤。没有图片时，页面会显示每种地点的标记作为替代。你也可以把自己的图片交给主持人，用于任何地点或角色。

### 3.12 安全：底线、帷幕与停止

- **底线**：游戏中绝不出现的内容。
- **帷幕**：可以发生、但只在幕后的内容。
- **停止**：你可以随时叫停某项内容，无需解释。在故事之外写下：

> [停止]

主持人会立刻放弃该内容，并把它加入你的底线，此后每一次游戏都适用。你可以在**设置**里查看和修改底线与帷幕。

### 3.13 改变主意

每项设置在战役期间都可以更改：在聊天里（“[把难度调高一点。]”）或在**设置**里。主持人会在下一次回答时得知更改。主持人没有依据规则书做出的裁定会成为**先例**并被保存下来，所以下次同样的问题会得到同样的答案。

## 4. 仪表盘分区介绍 <!-- icon: party -->

仪表盘是你自己电脑上的一个页面。主持人在每次聊天开始时给你它的链接。它实时跟随游戏：主持人改动了什么，页面也跟着改变。

只有你玩游戏的那台电脑的浏览器才能打开它：手机或平板不行，即使在同一个 Wi-Fi 下也一样。页面也适应窄窗口：这时各分区会移到底部的栏里，图标会移进菜单。

页面的寿命与聊天相同。关闭聊天后，仍开着的页面会显示*未连接*，角色卡保持原样，主持人的机器人会睡着；在战役里再次开启聊天，等主持人回答之后，页面会自动恢复。

### 顶部

- **主持人的头像**，带有它的情绪。
- 战役的名称、游戏系统、**游戏时间**，以及游戏是否**已连接**（聊天已连上）。
- 各分区：**队伍**、**场景**、**战斗**（仅在战斗期间）、**日志**、**世界**；在这一排的末尾，以图标显示：**存档**、**帮助**、**设置**、**关于**。
- 浅色和深色主题，在右上角。

当主持人问你什么事时，它的横幅会一直停在页面顶部，无论你在哪个分区。

### 队伍

你的角色卡，以及同伴的角色卡。角色卡的每个部分都是一张可以展开和收起的卡片。

- **点击一个数字**可以掷着玩。把鼠标放在数字上，可以看到它的构成（“+5：感知 +3，熟练加值 +2”）。
- **生命值、法术位和使用次数**以条形和圆点显示。
- **状态和效果**连同持续时间一起显示。
- **描述**里是你角色的文字，以及把角色故事发送给主持人的输入框。
- 生命值为 0 时，**死亡豁免**会大大地显示在名字下方。
- 角色卡旁边（窄屏时在下方）：**掷骰记录**，最新的在前，包含你的掷骰和你可以看到的主持人的掷骰。**清空**会清空列表；**恢复**会把它找回来。自由掷骰以虚线和淡色显示。

带有属性数据块的同伴，例如狼，显示的是它的属性数据块，而不是完整的角色卡。

### 场景

你的队伍所在之处：地点的图片和名称、周围的地点、该地点的地图（如果有）、在场的人，以及正在进行的场景和当下发生的事。你关注的任务在顶部。

### 战斗

仅在战斗期间出现。顶部：当前是第几轮、谁在行动、下一个是谁。下方：回合顺序，每个战斗者及其状态，你的队伍用数字，敌人用文字；你的角色手头有什么（护甲等级、生命值、攻击）；该地点的地图，正在行动的那位被圈出。轮到你时，**战斗**链接会闪动金光，无论你在哪个分区。

### 日志

三个标签页：

- **任务**：进行中、已完成和已失败的任务，每个是一张卡片，带有目标、以计时器显示的期限，以及进度钟。星标用来关注任务。
- **故事**：战役的章节，逐场景排列，最新的在前。
- **笔记**：你自己的笔记，在你分享之前是私密的。

### 世界

你的角色所了解的世界地图，其余部分被迷雾覆盖。拖动来移动，滚轮或双指缩放。点击一个地点可打开它的卡片。旁边有一个地点列表，最近的在前。如果有不止一张地图（一座城市、一块大陆、另一个位面），可以用标签页在它们之间切换。

### 骰盘

骰子按钮会打开骰盘：选择骰子和调整值，然后掷出。当同一种骰子有两个或更多时，可以选择计入哪些：**全部**、**最高**（只算最高的）或**最低**（只算最低的）。你选的骰子会保留，直到你按**清空**，所以同一个伤害掷骰每轮只需点一下。当主持人要求掷骰时，骰盘会告诉你该用哪些骰子。

### 存档

你的存档，最新的在前，每个都带有地点、游戏日期和创建时间。**立即存档**（自由存档时可用）、**回到此存档**，以及红色的**重新开始**（分两步确认）。见[存档与回头](#38-saves-and-going-back)。

### 设置

你的设置，分成几组：游戏、学习游戏（导师，以及已经向你讲解过的规则）、骰子和度量、内容边界（底线和帷幕）、图片、语言。点击一个值来选择；它下方是这个值的含义。再往下是页面自己的偏好，只保存在这个浏览器里：主题、骰子的声音、**骰子套装**（树脂、金属、木头、石头）、圆角或直角边缘、手动掷骰。

主持人自己的设置，例如房规和先例，不在这里：它们留在聊天里。

### 帮助与关于

**帮助**：就是本指南。**关于**：RPG Engine 是什么、它的链接、它的许可证，以及游戏系统的署名。

### 游戏之前：设置与零号团

当新战役处于第一步**设置**时，整个页面都用来提问：一次一个问题，每个问题都附有各个值的含义和推荐值。**你来定**把问题交给主持人，唯独底线和帷幕例外，它们永远由你决定；**跳过**则把问题留到以后。最后点**我准备好了**。

### 页面的提示

有时页面会在自己上方显示一条通知：战役文件出了问题（主持人会修复）、游戏离开了（聊天已关闭）、页面正在翻译。

## 5. 游戏系统与房规 <!-- icon: dice -->

### 5.1 什么是游戏系统

游戏系统是一款游戏的数据：它的角色卡、数字、生物、物品、法术和规则文本。每个战役使用一个系统。

RPG Engine 会算出你的角色卡，以及消耗和恢复的东西，比如生命值和法术位，就像电子角色卡那样。至于一项能力或一个法术具体怎么运作，由主持人阅读规则并裁定，就像在桌边一样。

### 5.2 内置第五版

RPG Engine 内置 **5e**，来自系统参考文档 5.1（2014 年的规则，以 Creative Commons 免费发布）。它包括：

- SRD 中的种族、职业、子职业、一个背景和一个专长；
- SRD 中的 319 个法术、武器、护甲和装备、魔法物品和怪物；
- 规则章节，主持人按其确切文字查阅；
- 完整的、已算好的角色卡：属性调整值、豁免、技能、护甲等级、攻击、法术豁免 DC、法术位、生命骰、按等级获得的特性、经验值和升级；
- 能恢复该恢复之物的休息；附带规则文本的状态；专注提醒。

**SRD 之外的内容。** 你可以在第五版里使用 SRD 没有的内容，比如你拥有的书里的某个职业或怪物。主持人了解这个游戏，可以阅读你的手册，也可以搜索网络。它会把需要的东西写成战役的页面，RPG Engine 对这些页面的处理方式完全相同。我们内置的内容受许可证限制；主持人所知道的则不受限制。

RPG Engine 与第五版兼容。

### 5.3 房规与你自己的补充

你不需要碰任何文件。直接请主持人：

> [房规：攻击掷出自然 1 时，你会掉落武器。]
>
> [我想玩血猎人。我有这本书：这是职业特性。]
>
> [在这个战役里，短休需要 10 分钟。]

主持人会用以下方式之一把它们记录进你的战役：

- **桌面约定**，用文字写成，例如上面的掉落武器或短休。主持人会把它和战役的设置放在一起，从此照此执行。主持人在没有依据规则书时做出的裁定也以同样方式保存，作为**先例**。
- **新页面**，例如一个职业、一个种族或一件物品。新职业与系统自带的职业运作方式相同：你的等级、生命骰和特性都会计入。新种族可以在现有种族的基础上构建（“像精灵，另加……”）；一把有名字的剑可以基于长剑构建。
- **角色卡的新数字**：一个字段、一张表、一个公式、一个休息后恢复的计数器。例如战斗大师的卓越骰，短休后恢复。房规还可以替换系统的某个公式。

如果你已经写好了房规，也可以把它们作为文本文件放进战役的 `rules` 文件夹（见[战役文件夹](#8-for-the-curious-the-campaign-folder)）：主持人会先读它们，再读规则书中同名的规则。

### 5.4 添加或导入你自己的游戏系统

目前 RPG Engine 只能玩第五版。其他游戏系统会陆续推出，添加你自己的系统、或根据你拥有的游戏手册生成系统的方法也会有。见[以后会有](#9-coming-later)。

## 6. 扩展 <!-- icon: plus -->

**扩展暂时还不可用。** 扩展会在游戏系统之上为战役增添内容：一个世界、一场冒险、一项功能（比如天气或塔罗牌），或可共享的房规。你可以为每个战役选择使用哪些扩展。第五版计划中的首批扩展是天气和开锁。

## 7. 战役从哪里来，以及它的语言 <!-- icon: world -->

### 7.1 获得世界的三种方式

**随玩随建。** 你在设置阶段给出一个前提，主持人在游戏过程中构建世界：每个地点、人物和阴谋，都在你需要之前才创建，并从此保留。这是最快的玩法：安装、创建，几分钟后你就在创建角色了。凡是编造出来的东西都不会丢失：一旦说出，就被写下来，并且成为事实。

**开局备齐。** 同样的前提，但选择**准备：开局备齐**，主持人会在游戏开始前构建世界的地点、势力、威胁及其计划。第一次游戏开始得更晚，但幕后准备得更充分。

**来自现有的战役或冒险。** 目前没有导入按钮。把你的冒险交给主持人（一份文本，或你的主机能读的 PDF），请它布置好：

> [我有这个冒险的 PDF。请把它设置成我们的战役：读一遍，把里面的地点、人物和秘密写下来。里面的内容一点都别告诉我。]

主持人用你的 AI 主机的工具读取它，并把它写成战役的页面，包括秘密，你会在游戏中逐步发现。Claude Code 能读 PDF；用 Codex 的话，文本或 markdown 文件更稳妥。请在设置阶段、零号团之前完成这一步。

主持人工作时，不要展开它读取或写入内容的详情（在 Claude Code 里是 ctrl+o）：详情会显示冒险的文本，包括秘密。主持人自己会照常保守秘密。

一旦战役有了自己的页面，设置阶段就不再询问前提和准备了。即使是写好的战役，当你去到文本没有涉及的地方，主持人也会创建所需的内容并记录下来。

**一个战役只玩一次。** 想再玩同一个冒险，就创建一个新战役。在一个战役之内，你仍可以按存档设置的允许，回到某个存档或重新开始。

### 7.2 语言

**每个战役一种语言**：主持人的语言。主持人用它写作，仪表盘也跟随它。主持人根据你的书写判断语言，并向你确认。

**仪表盘**内置英语和意大利语（精心校订），以及另外 24 种语言：法语、德语、西班牙语、葡萄牙语（巴西）、荷兰语、瑞典语、挪威语、丹麦语、芬兰语、冰岛语、俄语、乌克兰语、波兰语、捷克语、罗马尼亚语、匈牙利语、希腊语、土耳其语、阿拉伯语、希伯来语、印地语、中文、日语、韩语。阿拉伯语和希伯来语从右向左阅读：页面会镜像翻转，而地图和骰子保持原样。

你在设置里选择的**任何其他语言**，会在你的电脑上由 Codex 或 Claude Code 用你自己的登录在后台翻译，从你当前打开的分区开始。每种语言只做一次，所有战役通用。在翻译完成之前，页面显示英语。设置会告诉你翻译是正在进行、已经完成，还是你的电脑无法进行。

**游戏术语。** 第五版自带来自官方意大利语 SRD 的意大利语术语，所以意大利玩家读到的是 *Classe Armatura*、*tiro salvezza*、*vantaggio*。其他语言则会得到翻译后的系统术语。

**游戏系统自身的文本**（法术、怪物、规则章节）保持英语。主持人阅读它们，并用你的语言讲给你听。

**战役中途更换语言**会保留已经写好的页面不变；主持人会用新语言写新的页面。

## 8. 给好奇者：战役文件夹 <!-- icon: list -->

你从来不需要打开它。如果你打开了，要知道**里面有战役的秘密**：读了它就会剧透。

战役文件夹里有：

- `campaign.yaml`：你的设置；
- `state.yaml`：游戏当前进行到哪里：阶段、日期、正在进行的场景；
- `world/`：每个角色、地点、势力、任务、物品、事件、话题或生物各一页，都是 markdown 文件；
- `rules/`：你的房规文本文件，如果你添加了的话（`init` 不会创建它）；
- `images/`：图片，有了图片之后才有；
- `log.jsonl`：每一次改动，按顺序记录；
- `.saves/`：存档，从第一个开始；
- `.player/`：你在日志里的个人笔记，主持人不会读；
- `sessions/`：由 RPG Engine 维护；
- `AGENTS.md`、`CLAUDE.md`、`.mcp.json`、`.claude/`、`.codex/`、`.gemini/`：这些小文件告诉 AI 主机 RPG Engine 在哪里，并关闭它们的记忆。RPG Engine 会让它们保持最新；请保持原样。

这些页面是普通的 markdown，带有 `[[Rocca]]` 这样的链接，也就是 Obsidian 的格式：主持人的笔记本可以在那里打开。**如果你手动修改了某个页面**，主持人会在下一次回答时得知改动的内容。

**命令行。** 主持人做的一切都通过命令完成，你也可以在战役文件夹里运行这些命令。玩游戏时你从不需要它们，而且许多命令会打印出战役的秘密，比如 `rpg status` 和 `rpg show`。`rpg --help` 会列出全部命令，`rpg roll --help` 会解释其中一个。在聊天开着的时候运行会改动内容的命令是没问题的：主持人会在下一次回答时得知，就像得知手动修改的页面一样。

## 10. 问题与故障 <!-- icon: info -->

### 问题

**我需要懂规则吗？** 不需要。选择教学导师，主持人会边玩边教你，一次一条规则。你随时可以在方括号里提问。

**主持人会作弊吗？** 它无法更改 RPG Engine 掷出的结果，除非难度是故事，而且它从不更改已确立的事实。你可以问任何一次掷骰是不是真的。

**我能作弊吗？** 你可以试试。主持人不会轻信你说的事实：你消息里一行看起来像游戏消息的文字，仍然只是你的话，而且主持人从不确认你对秘密的猜测。

**要花钱吗？** RPG Engine 是免费的。主持人运行在你自己的 Claude 或 ChatGPT 方案上，而一晚的游戏就是一场很长的聊天：在最低档的方案上，你可能在晚上结束前就达到方案的用量上限。图片和翻译用的是同一个方案。

**我能在手机上玩吗？** 不能。主持人运行在你的电脑上，仪表盘只能在那台电脑的浏览器里打开。

**我能和朋友一起玩吗？** 暂时不能：目前是一名玩家、一个角色，外加同伴。多人同桌会随角色功能一起推出。

**下次我能换一个 AI 吗？** 可以。战役保存在它的文件里：在另一个主机里打开它，写下 *继续*。

**如果我关掉浏览器会怎样？** 什么也不会丢。聊天开着时重新打开链接就行；页面会回到游戏当前的位置。

**我能玩我拥有的 D&D 内容吗？** 可以。主持人可以使用你的书、它自己的知识和网络。RPG Engine 内置的内容只限于免费内容；你的游戏用什么，由你决定。

### 故障

**仪表盘打不开。** 向主持人要链接：`[仪表盘的链接是什么？]`。页面只在该战役里有聊天开着时才能用，而且要等主持人在该聊天里第一次回答之后。聊天关闭后，浏览器无法访问页面；仍开着的页面会显示*未连接*。

**主持人好像不懂这个游戏，或者编造工具。** 你的 AI 主机没有加载 RPG Engine。

- 首先，确认你是**在战役文件夹里**启动主机的，并且你选了信任它。
- **Claude Code**：写 `/mcp`。如果 `rpg` 在列表里但失败了，选中它，然后点 **Reconnect**。如果它不在列表里，关闭 Claude Code，在战役文件夹里写 `claude mcp reset-project-choices`，然后重新启动。
- **Codex**：在战役文件夹里的终端中写 `codex mcp list`。如果缺少 `rpg`，说明 Codex 不信任该文件夹：在那里重新启动它，被问到时选择信任。
- 两者通用：如果终端里的 `rpg --version` 提示找不到该命令，请重新安装 RPG Engine（[2.2](#22-install)），并打开一个新终端。

**更新之后，什么都没变。** 正在运行的主持人保留着它启动时的版本。开启一个新聊天，或者在 Claude Code 里重新连接服务器（`/mcp`，然后选 `rpg`，再点 **Reconnect**）。

**主持人还记得我撤销的事。** 你回到了某个存档，却在同一个聊天里继续玩。开启一个新聊天，并在存档里按**我已开启新聊天**。

**主持人又问了我已经在页面上回答过的设置问题。** 告诉它：`[那些我已经在仪表盘上选好了。]`

**没有出现图片。** 打开设置 > 图片：它会告诉你这台电脑能否生成图片，如果不能，还会给出步骤，每条命令旁都有复制按钮。

**页面是英语，但我选了另一种语言。** 它正在后台翻译；设置会告诉你进展如何。如果这台电脑上没有 Codex 或 Claude Code，页面会一直是英语。

**主持人说战役有问题。** 它会自己修复。如果你手动编辑过文件，它可能会问你本意是什么。

**Windows：`npm` 在我的文件夹里失败。** 不要把战役或 RPG Engine 放在含有 `&` 的路径下。

**安装失败，或者 `rpg` 无法启动。** 用 `node --version` 检查你的 Node.js 版本：必须是 22 或更新。如果更旧，请从 [nodejs.org](https://nodejs.org) 安装 LTS 版本，然后重新安装 RPG Engine。

**仪表盘的链接变了。** 另一个程序占用了战役常用的地址，或者 Windows 保留了它。RPG Engine 换了另一个；主持人会给你新的链接。其他一切都不变。
