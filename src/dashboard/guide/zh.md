# RPG Engine：完整指南

**RPG Engine** 让你和一位 **AI 主持人**一起玩桌面角色扮演游戏。你在**仪表盘**里玩：这是电脑上的一个窗口，里面有你的角色卡、骰子、地图、日志，还有和主持人的**聊天**。

本指南教你怎么玩。页面上的按钮会自己说明用途：把鼠标指针停在按钮上，就能看到它的作用。

## 快速开始 <!-- icon: send -->

1. 从 [nodejs.org](https://nodejs.org) 安装 **Node.js**（LTS 版本）。
2. 打开一个新的终端，输入 `npm install -g rpg-engine`。如果 Windows 提示已禁止运行脚本，请输入 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`，回答“是”，然后再试一次。
3. 输入 `rpg open`。它会把 RPG Engine 的图标放到你的桌面上（[2.2](#22-installing)）。从此以后，你直接点图标就能启动 RPG Engine。
4. 点击**新建战役**，起个名字，再点击**创建**（[2.3](#23-a-new-campaign)）。
5. 在聊天里，选择你的 AI 应用和它的模型（[2.4](#24-connect-your-ai)）：Claude Code 需要付费的 Claude 套餐，Codex 需要 ChatGPT 账号，免费或付费都行。点击**打开聊天**，再点击**开始**。

第一次回答可能要等几分钟。之后主持人会问你想怎么玩，然后你们一起创建角色。

## 1. RPG Engine 是什么 <!-- icon: about -->

| 谁 | 做什么 |
|---|---|
| **你** | 扮演你的角色：角色做什么、说什么、尝试什么。 |
| **主持人**（AI） | 讲述故事，扮演其他所有人，决定会发生什么，要求掷骰。 |
| **RPG Engine** | 把世界保存在文件里，负责掷骰，计算生命值、金钱、时间和距离，在你发现之前替你保守秘密。 |

无论隔了几个晚上，哪怕换了新的聊天，甚至换了另一个 AI，世界都保持不变：

- **说过的话都算数。** 死去的反派不会复活。
- **骰子是真的。** 主持人无法改动骰子，除非你选了最简单的难度。
- **秘密就是秘密。** 主持人不会告诉你角色不知道的事。
- **世界在运转。** 你休息或赶路时，威胁也在推进。
- **一个战役就是电脑上的一个文件夹**：想停就停，之后随时接着玩。

游戏以游戏系统的形式提供。目前我们提供的是**第五版**，基于免费的系统参考文档 5.1（System Reference Document 5.1）。没有游戏系统时，你可以自由地玩，讲一个没有数字的故事。

## 2. 快速上手 <!-- icon: path -->

### 2.1 你需要什么

- 一台装有 Windows、macOS 或 Linux 的电脑。
- **Node.js 24** 或更新版本，从 [nodejs.org](https://nodejs.org) 下载。
- 一个**终端**，只在安装时用：在 Windows 上是“终端”或 PowerShell；在 macOS 上是“终端”。
- 一个给主持人用的 **AI 应用**，用你自己的账号（[2.4](#24-connect-your-ai)）。

### 2.2 安装

```text
npm install -g rpg-engine
rpg open
```

第一行安装 RPG Engine。如果 npm 提示可以更新自身，不用理会。

`rpg open` 会打开 RPG Engine 的窗口。第一次打开时，它还会把图标放到你的桌面和菜单里：从此以后，你直接点图标就能启动。想删除图标，请输入 `rpg icon --remove`。

如果安装失败，请检查 `node --version` 显示的是不是 24 或更高。如果 Windows 提示已禁止运行脚本，请输入 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`，并回答“是”。在 Windows 上，RPG Engine 和你的战役所在的路径里不要含有 `&`。

### 2.3 创建战役

点击**新建战役**，填写**名称**、**语言**和**游戏系统**。其余的由你和主持人一起完成。点击**创建**：战役会在一个独立的窗口里打开。

主持人和仪表盘都使用战役的语言。第五版的规则文本仍是英文，主持人会用你的语言讲给你听。

战役是一个以它的名称命名的文件夹，位于你的用户文件夹里的 `RPG Engine` 文件夹中。下次点击它的卡片就能打开。

### 2.4 连接你的 AI

主持人运行在你电脑上的一个 **AI 应用**里，用你自己的账号。像 claude.ai 或 ChatGPT 这样的网页聊天不够用：主持人必须能读取战役的文件。

- **Claude Code**：需要付费的 Claude 套餐（Pro 或更高）。
- **Codex**：需要 ChatGPT 账号，免费或付费都行。
- **OpenCode**：不需要账号；一段时间内有一些免费模型，也可以用你自己的服务商的模型，本地运行的也行。
- **Antigravity**：需要 Google 账号；免费使用每周有额度限制。

在聊天里，选择应用，再选择它的**模型**和**主持人的思考**。如果应用没有安装，或者你还没登录，会有一个按钮帮你安装、登录，或打开它的网站。RPG Engine 看不到你的密码。

玩一个晚上就是一场很长的聊天：用最小的套餐，晚上还没结束就可能用完额度。请用你手头最大的模型来玩：小模型更容易被说动，泄露秘密。

我们用 **Claude Code** 玩和测试 RPG Engine 最多。Antigravity 标有**试用中**：它可能跳出游戏，还会把你的聊天保存在无法关闭的记忆里。你在那里写的内容会发送给 Google，Google 可能安排人员查看。RPG Engine 不是 Google 的产品。

### 2.5 第一次聊天

点击**打开聊天**，再点击**开始**。第一次回答可能要等几分钟。然后新战役要经过三个阶段：

1. **设置**：主持人问你想怎么玩，每次问几个问题：世界有多难，角色会不会死，什么时候可以回到某个存档。写“*你来定*”，就由主持人来选。之后一切都可以更改。
2. **零号团**：你和主持人一起创建角色，就像在牌桌上一样。角色卡上的数字由 RPG Engine 来算。如果你已经有角色了，把它的角色卡粘贴到聊天里。
3. **游戏**：主持人布置第一个场景。

### 2.6 在你的 AI 应用里玩

你也可以在 AI 应用自带的聊天里玩，在终端里或在它的桌面应用里都行，仪表盘开在旁边。

1. 在你存放游戏的文件夹里打开终端：右键点击该文件夹，选择**在终端中打开**（Windows）或**服务 > 新建位于文件夹位置的终端**（macOS）。
2. 输入 `rpg init "The Salt Isles"`：它会生成文件夹 `The Salt Isles`，里面是一个新战役。
3. 在那个文件夹里启动你的应用：`claude`，`codex`，Antigravity 用 `agy`，或 `opencode`。当它问是否信任这个文件夹时，回答“是”：注意，在 Claude Code 里，默认选中的答案是 *No, exit*。
4. 写下 *你好！我们开始吧。* 主持人会给你仪表盘的链接：打开它，放在聊天旁边。

需要知道的几点：

- 不要打开你的应用所用工具的详情（在 Claude Code 里是 ctrl+o）：其中可能含有秘密。
- 在 Codex 的桌面应用里，请为游戏的聊天关闭记忆。
- 如果主持人不认识这个游戏，请在战役文件夹里输入 `rpg init`，然后开启一个新聊天。
- 如果 Windows 找不到 `claude`，请把它的安装程序提示的文件夹添加到 PATH，然后打开一个新的终端。
- 同一时间只有一个聊天在玩一个战役：你自己的聊天开着时，仪表盘的聊天会等待。

## 3. 游玩 <!-- icon: chat -->

### 3.1 与主持人交谈

写下你的角色做什么或说什么：

> 我问旅店老板，今晚还有谁路过。

你说出想做的尝试，主持人说出结果。主持人不会替你的角色做决定。

想跳出故事时，请写 `[OOC: …]`（角色之外）：*[OOC: 擒抱是怎么运作的？]* 你可以向主持人询问规则，或者仪表盘怎么用。

主持人向你提问时，点它给的按钮，或者用你自己的话回答。你也可以直接在角色卡上行动：点击一件武器、一个法术或一件物品，再选择要做什么。

**长期指令**：对同伴说一件需要长期有效的事，比如 *从现在起，一律留一个活口*。主持人会一直记着，直到你撤销。

### 3.2 掷骰

只有结果不确定而且重要时，主持人才会要求掷骰。横幅会显示这次掷骰：点击它，骰子就会落下。

骰子属于 RPG Engine，不属于主持人。你随时可以问 *[刚才那次掷骰是真的吗？]*：即使是秘密掷骰，主持人也能证明它是在你发问之前掷出的。

如果**骰子**设置选为实体，请自己掷骰子，并写下点数：*[我掷出了 14。]* 你随手掷着玩的骰子，不论是从角色卡上掷，还是用**自由掷骰**，都不计入结果。

### 3.3 场景、战斗与旅行

故事以**场景**推进：一场战斗、一次对话、一段旅程、一次休息。每个场景结束时，游戏会自动存档，这个场景会记入你的日志。

在战斗中，主持人会讲述每个不属于你的回合，并在需要你决定时停下。

说出你要去哪里，*我们沿路向北去罗卡*：RPG Engine 会算出距离和天数，途中有事发生时会停下来。与此同时，反派的计划仍在推进，你能看到它们的迹象。

### 3.4 存档

RPG Engine 会在每个场景结束时为战役存档。何时可以回到过去，由**存档**设置决定：

- **永久死亡**：不可以。
- **存档点**：回到上一个存档，仅限角色死亡时。
- **可用**：回到任意存档，想存档时也可以随时存。

在所有模式下，你都可以重新开始，在聊天里说，或在**存档**里操作。

回到过去之后，请开启新聊天，因为旧的聊天还记得那些已被撤销的事：

1. 点击**关闭聊天**，再点击**新聊天**。在 AI 应用自带的聊天里，开启一个新对话（Claude Code 里用 `/clear`）。
2. 写下 *继续*。
3. 在**存档**里点击**我已开启新聊天**。在此之前，主持人会一直等着。

### 3.5 停下与回来

想停就停：一切都已存档。关闭仪表盘的窗口，不久之后游戏就会停止。不会丢失任何东西。

想回来时，从图标打开 RPG Engine，点击你的战役。点击**继续聊天**，再点击**继续故事**：主持人会告诉你之前玩到了哪里，然后接着往下玩。下次你也可以换一个 AI 应用。

### 3.6 内容边界与停止

**底线**绝不会出现在游戏里；**帷幕**只会发生在画面之外。你可以在**设置**里设定它们。

你随时可以写 *[停]*：主持人会放下那段内容，并把它加入你的底线。

### 3.7 图片

主持人可以按**图片**设置，为地点、任务和人物生成图片，你提出要求时也会生成角色的肖像。图片由你的 AI 应用生成，使用你的套餐。如果一张图片都没有出现，**设置**会告诉你这台电脑能不能生成图片。

你也可以在页面上，给你的角色或世界中的某个页面添加自己的图片。

## 4. 仪表盘 <!-- icon: party -->

这是你查看游戏的窗口。它只显示你的角色所知道的事。

- **角色扮演**：和主持人的聊天，不在页面旁边时就在这里。
- **队伍**：你的角色卡、同伴的角色卡，以及掷骰。
- **场景**：你所在的地方、在场的人和地图；战斗中，这里会显示回合顺序。
- **日志**：任务、书一般的故事、同伴的日记，还有你的笔记。
- **世界**：世界地图、你的角色所知道的事、找到的文档和日历。
- **存档**：回到过去和重新开始。
- **设置**：你的玩法，以及页面的外观。
- **扩展包**：游戏系统、扩展、你自己的手册和更新：RPG Engine 有新版本时，会在这里告诉你。

如果页面显示未连接，请点击**重开战役**。

想在家里用手机玩：在**设置**的**仪表盘**里，打开**手机访问**，用手机扫描二维码，手机和电脑要连同一个 Wi-Fi。Windows 可能会问 Node.js 能否使用网络：请只在专用网络上允许，并把这个 Wi-Fi 设为专用网络。游戏数据未加密传输：只在你信任的网络上使用，比如你家里的；绝不要在公共场所、酒店或办公室的 Wi-Fi 上使用。用完后请关闭。电脑上的最后一个窗口关闭时，游戏也会随之结束。

如果某个主题让页面难以阅读，请在页面地址末尾加上 `#/settings/page`，然后关闭**主题自带样式**。

## 5. 规则、手册与扩展 <!-- icon: dice -->

**游戏系统**是一款游戏的全部数据：角色卡、生物、物品、法术和规则。RPG Engine 负责计算角色卡；规则怎么用，由主持人查阅并裁定，就像在牌桌上一样。

**第五版**包含《系统参考文档 5.1》（System Reference Document 5.1）中的免费规则。你也可以玩自己所持书籍里的内容：主持人会把它写进你的战役。

**你的手册**：告诉主持人手册在哪里，或者在**扩展包**中添加手册所在的文件夹。主持人会在其中查规则，并注明书名和页码。RPG Engine 不会修改手册，也不会把手册复制进战役。

**自定规则**：对主持人说，*[House rule: a natural 1 on an attack means you drop your weapon.]* 主持人会记住这条规则。主持人裁定过一次的事，下次也照此执行。

**扩展**可以给游戏增添内容，比如天气。在**扩展包**中添加，或者直接请主持人添加。

## 6. 你自己的冒险 <!-- icon: world -->

如果没有现成的世界，主持人会根据你的设定构建一个，并一直保留。

想玩自己持有的冒险模组或书籍，请把文件交给主持人：*[Import this adventure as our campaign: D:\Books\adventure.pdf. Don't tell me anything that's in it.]* 战役文件夹以外的文件，要等你同意后才会读取。文本、EPUB、Word，或者可以选中文字的 PDF，读取效果最好。

整份文档都会发送给运行这个 AI 的公司。一个战役只能玩一次：想再玩同一个冒险，请新建一个战役。

## 7. 你的数据 <!-- icon: lock -->

- 战役就是一个文件夹。里面存着战役的秘密，也有你和主持人的聊天记录：你不需要打开它。
- RPG Engine 只在这个文件夹里读写。你的手册只会被读取；战役以外的其他内容，要等你在电脑弹出的窗口中同意后才会动。
- 在仪表盘的聊天中，主持人不会自行打开你的任何文件。
- 你写的内容会发送给提供主持人模型的公司，适用你账号的条款。若使用本地模型，内容只留在你的电脑上。
- 不是我们提供的游戏系统或扩展，是会在你电脑上运行的代码：必须经你同意才能安装。只对你信任的作者说同意。
- 如果战役文件夹是 git 仓库，可以在**设置**中让它帮你提交。只有仓库是私有的，才让聊天记录一起提交。
- 开启**手机访问**后，游戏会通过家庭网络从电脑直接传到手机，不经过任何外部服务，也不加密：同一网络里的人可能读到内容。
