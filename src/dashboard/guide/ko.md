# RPG Engine: 전체 가이드

**RPG Engine**은 **AI 게임 마스터**와 함께 테이블탑 롤플레잉 게임을 즐길 수 있게 해 줘요. **채팅**으로 GM과 대화해요. RPG Engine은 뒤에서 **세계를 기억하고**, **주사위를 굴리고**, **계산을 맡아요**. 채팅 옆에는 브라우저에 페이지를 하나 열어 두어요. 바로 **대시보드**예요. 캐릭터 시트, 주사위, 지도, 일지가 있어요.

이 가이드는 플레이어를 위한 글이에요. 프로그래밍을 몰라도 괜찮아요.

## 빠른 시작 <!-- icon: send -->

1. [nodejs.org](https://nodejs.org)에서 **Node.js**를 설치해요(LTS 버전).
2. GM이 실행될 프로그램인 **AI 에이전트**를 설치하고 로그인해요. 예를 들면 Claude Code나 Codex가 있어요([2.4](#24-connect-your-ai)).
3. 터미널에서 RPG Engine을 설치해요: `npm install -g rpg-engine`.
4. 캠페인을 만들어요: `rpg init "The Salt Isles"`.
5. 새로 생긴 폴더로 이동해요: `cd "The Salt Isles"`. 그 안에서 에이전트를 시작해요. Claude Code는 `claude`, Codex는 `codex`예요. 폴더를 신뢰하는지 물으면 예를 선택해요([2.4](#24-connect-your-ai)). 그다음 *안녕하세요! 시작해 봐요.*라고 써요. GM이 대시보드 링크로 답해요.

## 1. RPG Engine이란 <!-- icon: about -->

| 누가 | 하는 일 |
|---|---|
| **나** | 캐릭터를 플레이해요. 캐릭터가 무엇을 하고, 말하고, 시도할지 정해요. |
| **GM** (AI) | 이야기를 이끌고, 나머지 모든 인물을 연기하고, 일어날 일을 정하고, 굴림을 요청해요. |
| **RPG Engine** | 세계를 파일로 보관하고, 주사위를 굴리고, 체력과 돈, 시간, 거리를 계산하고, 비밀은 발견하기 전까지 지켜요. |

세계는 저녁이 지나도 그대로예요. 새 채팅에서도, 다른 AI와 함께해도 마찬가지예요.

- **한 말은 사실로 남아요.** 죽은 악당은 계속 죽은 채로 있어요.
- **주사위는 진짜예요.** GM은 주사위를 조작할 수 없어요. 단, 가장 쉬운 난이도를 골랐다면 예외예요.
- **비밀은 비밀로 남아요.** GM은 캐릭터가 모르는 것을 절대 알려 주지 않아요.
- **세계는 움직여요.** 쉬거나 여행하는 동안에도 위협은 다가오고, 그 징후를 볼 수 있어요.
- **캠페인은 컴퓨터의 폴더예요.** 원할 때 멈추고, 나중에 이어서 할 수 있어요.

게임은 게임 시스템으로 제공돼요. 게임 시스템은 GM이 캠페인에 설치하는 패키지예요. 지금은 무료 System Reference Document 5.1을 바탕으로 한 **5판**을 제공해요. 게임 시스템이 없으면 숫자 없이 이야기만 즐기는 자유 플레이를 해요. 다른 시스템도 나올 예정이에요 ([나중에 추가될 기능](#9-coming-later)).

## 2. 시작하기 <!-- icon: path -->

### 2.1 준비물

- Windows, macOS, Linux 중 하나가 설치된 컴퓨터와 웹 브라우저.
- [nodejs.org](https://nodejs.org)에서 받을 수 있는 **Node.js 22** 이상. 설치하면 `npm`도 함께 설치돼요. `npm`으로 RPG Engine을 설치해요.
- **터미널**: Windows에서는 터미널이나 PowerShell, macOS에서는 터미널이에요. 폴더에서 터미널을 열려면 폴더를 마우스 오른쪽 버튼으로 클릭하고 **터미널에서 열기**(Windows) 또는 **서비스 > 폴더에서 새로운 터미널**(macOS)을 선택해요.
- GM을 맡을 **AI 에이전트** ([2.4](#24-connect-your-ai)). 에이전트가 제공하는 **가장 큰 모델**을 쓰세요. 작은 모델은 설득에 넘어가 비밀을 알려 주거나 규칙을 어기기 쉬워요.

### 2.2 설치

```text
npm install -g rpg-engine
```

`rpg --version`을 입력하면 설치가 잘 됐는지 확인할 수 있어요. `rpg`는 캠페인을 만들 때 한 번만 써요. 그 뒤에는 에이전트가 알아서 RPG Engine을 시작해요.

### 2.3 캠페인 만들기

게임을 모아 두는 폴더에서 터미널을 열어요. 방법은 [2.1](#21-what-you-need)에 있어요.

```text
rpg init "The Salt Isles"
```

그러면 `The Salt Isles` 폴더가 만들어지고, 그 안에 새 캠페인이 생겨요. `cd "The Salt Isles"`로 폴더 안으로 들어가세요. 폴더 위치를 기억해 두세요. 플레이할 때마다 이곳으로 돌아와야 해요. 나머지는 나중에 채팅이나 대시보드에서 정하면 돼요. 지금 몇 가지를 정하고 싶다면 `rpg init --help`로 옵션을 볼 수 있어요. 예를 들면 `--language it`나 `--difficulty hard` 같은 옵션이 있어요.

GM은 캠페인을 대신 만들 수 없어요. `init`을 하기 전에는 에이전트가 RPG Engine이 어디 있는지 알 방법이 없기 때문이에요.

### 2.4 AI 연결하기

GM은 **AI 에이전트** 안에서 움직여요. AI 에이전트는 터미널이나 데스크톱에서 쓰는 AI 앱으로, 컴퓨터의 파일을 다룰 수 있어요. Claude Code나 Codex가 그 예예요. claude.ai나 ChatGPT 같은 일반 채팅이나 휴대폰 앱으로는 부족해요. GM이 컴퓨터에 있는 캠페인 파일에 접근할 수 있어야 하기 때문이에요. 에이전트마다 요금제와 로그인이 따로 필요해요. Claude Code는 유료 Claude 요금제, Codex는 ChatGPT 로그인이 필요해요. 설치는 각 에이전트의 페이지에서 한 번만 하면 돼요. [Claude Code](https://code.claude.com/docs/en/setup), [Codex](https://learn.chatgpt.com/docs/codex/cli)

- **Claude Code**: 캠페인 폴더에서 `claude`를 입력해요. 폴더를 신뢰하는지 물으면 **Yes, I trust this folder**를 선택하세요. 주의하세요. 처음 선택돼 있는 답은 *No, exit*이에요. 캠페인에는 작은 훅 `rpg --listen`도 들어 있어요. 이 질문에는 나오지 않지만, 대시보드에서 행동하면 GM에게 바로 알려 주는 역할을 해요.
- **Codex**: 캠페인 폴더에서 `codex`를 입력하고, 폴더를 신뢰하는지 물으면 승인해요. 데스크톱 앱에서는 설정에서 게임 채팅의 메모리가 꺼져 있는지 확인하세요.
- **다른 에이전트**: 캠페인 폴더에서 에이전트를 시작하고 MCP 서버 `rpg mcp`를 연결해요. RPG Engine은 표준 MCP 서버예요. MCP를 지원하는 에이전트라면 로컬 에이전트를 포함해 어떤 것이든 GM이 될 수 있어요.

저희는 **Claude Code**로 플레이하고 테스트해요. **Codex**는 연결과 확인을 마쳤지만, 아직 캠페인 하나를 끝까지 플레이해 보지는 못했어요. 캠페인은 에이전트 자체의 메모리를 꺼요. 게임은 파일에 저장되기 때문에, 세이브로 돌아가면 정말 그 시점으로 돌아가요.

### 2.5 첫 채팅

아무 말이나 써 보세요. 예를 들어 *안녕! 시작해 보자.*처럼요. 채팅을 시작할 때마다 GM은 첫 답변에서 **대시보드 링크**를 알려 줘요. `http://127.0.0.1:4750` 같은 주소예요. 링크를 열어서 채팅 옆에 띄워 두세요.

GM이 메시지를 보내는 사이에 에이전트가 사용하는 도구가 표시돼요. 도구의 자세한 내용은 열지 마세요(Claude Code에서는 ctrl+o). 비밀이 드러날 수 있어요.

새 캠페인은 대시보드 위쪽에 표시되는 세 단계를 거쳐요. **1 설정**(플레이 방식 정하기), **2 세션 0**(플레이하면서 캐릭터 만들기), **3 플레이**예요.

### 2.6 설정: 플레이 방식 정하기

GM은 아직 정해지지 않은 것만 한 번에 몇 가지씩 물어봐요. 대시보드의 **설정** 단계에는 같은 질문이 카드로 나와요. "알아서 해 줘"라고 쓰면 GM이 골라요. 모든 항목은 나중에 채팅이나 **설정**에서 바꿀 수 있어요.

| 설정 | 정하는 것 | 값 |
|---|---|---|
| **멘토** | GM이 규칙을 얼마나 가르쳐 줄지 | 끄기, 힌트, 튜토리얼 |
| **난이도** | 세계가 얼마나 어렵게 흘러갈지 | 스토리, 쉬움, 보통, 어려움, 잔혹 |
| **치명도** | 전투에서 쓰러지면 어떻게 되는지 | 서사형(죽지 않음), 서사시형(중요할 때만), 주사위 |
| **세이브** | 언제 되돌아갈 수 있는지 | 영구 사망, 체크포인트, 자유 ([3.8](#38-saves-and-going-back)) |
| **엄격도** | 식량, 빛, 이동에 규칙을 얼마나 엄격히 적용할지 | 매끄럽게, 규칙대로, 시뮬레이션 |
| **주사위** | 누가 주사위를 굴릴지 | 디지털, 실물 |
| **단위** | 거리와 무게 | 미터법, 야드파운드법 |
| **캐릭터 음성** | 만나는 인물들의 대사를 누가 맡을지. GM이 모두 맡거나, 중요한 순간에는 인물이 직접 말하되 자신이 아는 것만 알고 말하게 하거나(GM이 정해요), 주요 인물이나 모든 인물을 항상 인물 본인이 말하게 해요. 후자는 더 느리고 비용이 더 들며, 사용하는 AI 앱이 지원할 때만 가능해요 | GM, 가끔, 주요 인물, 모두 |
| **동료** | 누가 함께 여행할지 | 없음, 함께 만들기, GM이 만들기, 플레이 중 만나기 |
| **이미지** | 장소, 퀘스트, 만나는 인물의 이미지 | 없음, 요청 시, 새 장소, 퀘스트와 만나는 인물 ([3.11](#311-pictures)) |
| **금지선**과 **베일** | 절대 나오지 않는 주제와, 화면 밖에서만 일어나는 주제 | 목록 |
| **언어** | 게임과 대시보드의 언어 | 아무 언어 |

5판에는 **성장 방식**이 더해져요. 경험치나 마일스톤 중에서 골라요.

세계관이 정해져 있지 않으면 GM이 **전제**도 물어봐요. 장르, 분위기, 몇 가지 요소, 그리고 게임에서 가장 즐기는 것을 직접 말해 주면 돼요. 전투, 미스터리, 대화, 탐험 같은 것이 있어요. 또 **준비 방식**도 물어봐요. 진행하면서 그때그때 세계를 만들지, 처음에 한꺼번에 만들지 정해요.

**GM의 문체**는 따로 묻지 않지만, 채팅이나 **설정**에서 바꿀 수 있어요. **문장**(담백하게, 문학적으로, 펄프풍으로, 재치 있게), GM이 만들어 내는 **이야기**(상황, 서사 줄기, 에피소드, 미스터리), **따라 쓸** 작가, 또는 **원하는 대로** 말로 적은 무엇이든 정할 수 있어요.

### 2.7 세션 0: 캐릭터 만들기

테이블에서 하듯이 GM과 함께 캐릭터를 만들어요. 모든 선택은 플레이어의 몫이에요. GM에게 대신 정해 달라고 하지 않는 한요. 구상이 완전하든, 막연하든, 아무것도 없든 그대로 와도 돼요. GM은 주사위를 굴리기 전에 능력치를 어떻게 정하는지 알려 줘요. 캐릭터의 배경 이야기는 꼭 필요하지 않아요. 직접 쓰면 GM이 그 내용을 플레이어의 말 그대로 옮겨 적어요. 그다음 GM이 캐릭터의 이미지를 요청해요([3.7](#37-your-characters-story-and-picture)). 시트는 RPG Engine이 계산하니, 직접 계산할 일은 없어요.

## 3. 플레이 <!-- icon: chat -->

### 3.1 GM과 이야기하기

캐릭터가 하는 행동이나 말을 자유롭게 적어요.

> 여관 주인에게 오늘 밤 또 누가 지나갔는지 물어봐요.

이야기 밖의 말은 대괄호 안에 적어요. *[붙잡기는 어떻게 하나요?]* GM도 대괄호로 답해요.

시도할 일은 직접 말해요. 그 결과는 GM이 알려 줘요. GM은 캐릭터 대신 결정하지 않고, 엔진에 대해서도 말하지 않아요. 대시보드 사용법은 GM에게 물어볼 수 있어요.

**대시보드에서 행동하기**: 캐릭터 시트에서 무기, 주문, 소지품 같은 이름을 클릭하고 대상을 고르세요. 사람을 클릭하면 말을 걸 수 있어요. 대시보드가 *후드 쓴 산적 1에게 메이스로 공격해요.* 같은 문장을 써 줘요. **GM에게 말하기**를 누르기 전에 문장을 고칠 수 있어요. GM은 이 문장을 채팅에서 한 말처럼 듣고, 다른 행동과 똑같이 판정해요. 사용 중인 AI 앱이 문장을 직접 받지 못하면 **복사**를 눌러 채팅에 붙여 넣을 수 있게 준비해요.

### 3.2 굴림

GM은 결과가 불확실하고 중요할 때만 굴림을 요청해요. 먼저 무엇이 걸려 있는지도 알려 줘요. 그다음은 이래요.

- **대시보드에서**는 배너에 판정마다 버튼이 나타나요. 예를 들면 *곡예 +4 · 이점 적용* 같은 버튼이에요. 버튼을 누르면 주사위가 화면에 떨어지고 GM이 결과를 들어요. 불이 들어온 캐릭터 시트의 줄을 클릭해도 되고, 주사위 트레이에서 주사위를 던져도 돼요. 배너에 다른 내용을 적을 수도 있어요.
- **직접 굴리기**는 배너 모서리나 **설정**에서 켤 수 있어요. 배너가 무엇을 굴릴지 알려 주면 캐릭터 시트나 주사위 트레이에서 직접 굴려요.
- **실물 주사위**는 주사위 설정을 실물로 바꾸면 쓸 수 있어요. 나온 눈을 *[14가 나왔어요.]* 처럼 적으면 RPG Engine이 수정치를 더해 줘요.

**자유 굴림**: 캐릭터 시트의 아무 숫자나 클릭하거나 주사위 트레이를 열어 재미로 굴려 보세요. 자유 굴림은 결과에 반영되지 않고 GM도 보지 못해요.

**GM의 굴림**은 비밀 굴림을 빼고 굴림 열에 표시돼요. *[아까 그 굴림은 진짜였나요?]* 하고 언제든 물어볼 수 있어요. 비밀 굴림이면 GM이 지문을 알려 줘요. 질문하기 전에 굴렸다는 증거예요.

### 3.3 장면과 전투

이야기는 **장면** 단위로 흘러가요. 전투, 대화, 탐험, 이동, 휴식이 장면이 될 수 있어요. 장면이 끝날 때마다 게임이 자동으로 저장되고, 그 장면은 일지에 들어가요.

전투에서 GM은 캐릭터의 차례가 아닌 차례를 모두 이야기하고, 선택할 수 있는 순간에 멈춰요. **장면** 맨 위에는 지금 누구의 차례인지와 다음 차례가 누구인지가 나와요. 지도 옆에는 캐릭터 카드가 보여요. 차례 순서, 파티의 체력, 적이 얼마나 다쳐 보이는지는 말로 표현되어 페이지 옆에 계속 보여요. 캐릭터가 쓰러지면 죽음 내성 굴림이 화면에 크게 나타나요.

### 3.4 시간, 여행, 움직이는 세계

RPG Engine이 날짜를 관리해요. 세션과 세션 사이에는 시간이 흐르지 않아요. *긴 휴식을 취해요* 하고 말하고 GM이 동의하면, 휴식으로 회복해야 할 것이 회복돼요. 짧은 휴식에서는 GM이 대시보드에서 체력 주사위를 몇 개 쓸지 물을 수 있어요. 하나씩 굴리고, 얼마나 회복되는지 보고, 원할 때 멈추면 돼요. 가는 곳을 말하면, 예를 들어 *북쪽 길로 로카를 향해 가요*, RPG Engine이 길과 거리와 날짜를 계산해요. 가는 도중에 일이 생기면 거기서 멈춰요. 돈은 게임 속 동전으로 계산하고, 거스름돈도 줘요.

악당에게는 기한이 있는 계획이 있어요. 새 날이 올 때마다 GM은 시간이 흐른 만큼 위협을 움직여요. 그 징후는 보이지만 시계 자체는 보이지 않아요.

### 3.5 지도

**세계**에는 캐릭터가 아는 장소, 장소 사이의 길, 지나온 길이 보이고, 나머지는 안개에 덮여 있어요. **장면**에는 지금 있는 장소의 지도가 있으면 누가 어디에 서 있는지와 함께 보여요. 전투 중 내 차례에는 갈 수 없는 칸이 가려져요. GM이 어디로 움직일지 물으면 칸을 누르거나 *E4* 처럼 적어요.

**세계**에는 캐릭터가 아는 것도 담겨 있어요. **지식**에는 캐릭터가 아는 사람, 장소, 세력, 생물, 이야기가 캐릭터가 아는 만큼만 나와요. 검색하거나, 하나를 열어 전체를 읽을 수 있어요. 본문 속 이름을 누르면 그 페이지로 가요. **문서**에는 캐릭터가 찾은 편지, 공고, 쪽지가 있어서 다시 읽을 수 있어요. **달력**에는 오늘 날짜, 퀘스트 기한과 남은 시간, 이야기가 흐른 날들이 나와요. 장면이 있는 날을 누르면 일지의 해당 장으로 가요.

### 3.6 퀘스트, 일지, 메모

캐릭터가 맡은 일은 **일지**에서 퀘스트가 돼요. 목표, 기한, 시계로 재는 진행 상황이 함께 나와요. 별표를 누르면 장면 맨 위에 계속 보여요. 일지는 **이야기**를 장면별로 들려주고 **메모**도 보관해요. 메모는 비공개예요. **공유**를 누르면 GM이 그 메모를 사실이 아니라 캐릭터의 생각으로 들어요. **동료**에서는 동료의 일기를 읽을 수 있어요. 동료는 가끔, 하루나 퀘스트가 끝날 때 자신이 생각하고 느낀 것을 몇 줄 적어요.

### 3.7 캐릭터의 이야기와 그림

캐릭터 시트의 **설명** 카드에는 캐릭터의 이야기를 적는 칸이 있어요. 동의하면 GM이 내용을 적어 넣어 줘요. 그림을 넣으려면 컴퓨터에 있는 파일(PNG, JPEG, WebP, SVG, 최대 5MB)의 위치를 GM에게 알려 주세요. 초상화를 만들어 달라고 할 수도 있어요([3.11](#311-pictures)). *[초상화를 만들어 줘요. 땋은 회색 머리에 턱에 흉터가 있어요.]*

### 3.8 세이브와 되돌리기

RPG Engine은 장면이 끝날 때마다 캠페인 전체를 저장해요. 나머지는 **세이브** 설정이 정해요.

| 세이브 | 원할 때 저장 | 되돌리기 |
|---|---|---|
| **permadeath** | 불가 | 불가 |
| **checkpoint** | 불가 | 캐릭터가 죽었을 때만 마지막 세이브로 |
| **가능** | 가능 | 어느 세이브로든 |

어떤 모드에서든 **처음부터 다시 시작**할 수 있어요. 플레이 처음이나 세션 0부터 시작해요. 채팅에서 말하거나 **세이브**에서 하세요.

되돌린 뒤에는 **새 채팅을 열어** 주세요. 이전 채팅은 취소된 일을 기억하고 있어요. 새 채팅에 *계속*이라고 적고, 세이브에서 **새 채팅을 열었어요**를 누르세요.

### 3.9 세션: 멈추고 다시 돌아오기

원할 때 언제든 멈출 수 있어요. *[오늘 밤은 여기까지 해요.]* 모든 내용은 이미 파일에 저장되어 있어요. 돌아올 때는 캠페인 폴더에서 에이전트를 시작하고 *계속*이라고 적으세요. GM이 짧게 요약해 주고 이어서 진행해요.

### 3.10 GM의 기분

대시보드 맨 위의 로봇이 GM이에요. 표정은 이야기의 분위기를 따라가요. 아직 모르는 내용은 표정으로 드러내지 않아요. 채팅이 닫혀 있으면 잠들어 있어요.

### 3.11 그림

RPG Engine은 도착한 장소, 맡은 퀘스트, 만난 인물의 그림을 만들 수 있어요. **그림** 설정에 따라 달라져요. 요청하면 캐릭터의 초상화도 만들어요. 사용자의 Codex나 Claude Code를 로그인 정보와 요금제 한도 안에서 써요. **Codex**가 있으면 Codex가 그리고, 없으면 **Claude Code**가 그려요. 이 컴퓨터에서 그림을 만들 수 있는지, 안 된다면 어떻게 준비하는지는 **설정**에서 확인하세요. 직접 가진 그림은 언제든 GM에게 줄 수 있어요.

### 3.12 안전: 금지선, 베일, 중단

**금지선**은 게임에 절대 나오지 않아요. **베일**은 화면 밖에서만 일어나요. 언제든 *[중단]*이라고 적으세요. GM이 그 내용을 바로 빼고 금지선에 추가해요.

### 3.13 마음 바꾸기

모든 설정은 채팅이나 **설정**에서 바꿀 수 있어요. GM이 규칙서 없이 내린 판정은 **선례**가 돼요. 다음에 같은 질문이 나오면 같은 답을 받아요.

## 4. 대시보드 <!-- icon: party -->

내 컴퓨터에서만 열리는 페이지예요. 그 컴퓨터의 브라우저에서만 볼 수 있고, 채팅이 열려 있는 동안만 작동해요. 채팅을 닫으면 *Not connected*라고 표시돼요. 다음 채팅을 열면 저절로 다시 연결돼요.

- **파티**: 내 캐릭터 시트와 동료들의 시트가 있어요. 숫자를 클릭하면 그 숫자로 굴려요. 숫자 위에 마우스를 올리면 그 숫자가 어디서 나왔는지 볼 수 있어요. 주사위 옆에 화살표가 있으면 굴림을 유리하게 하거나 불리하게 하는 요인도 보여요. 옆에는 굴림 기록이 있어요.
- **장면**: 현재 위치, 그림과 지도, 그곳에 있는 인물, 지금 벌어지는 일을 보여줘요. 전투 중에는 차례와 내 캐릭터의 카드를 보여줘요.
- **일지**: 퀘스트, 이야기, 동료들의 일기, 내 메모가 있어요.
- **세계**: 세계 지도, 내 캐릭터가 아는 것, 찾은 문서, 달력이 있어요.
- **주사위 트레이**: 주사위와 수정치를 고른 뒤 던져요. ×2는 주사위만 두 배로 하고 수정치는 두 배로 하지 않아요. 치명타 때와 같아요.
- **세이브**, **도움말**, **설정**, **정보**는 줄 끝에 아이콘으로 있어요. 설정에서는 페이지 자체의 환경설정도 바꿀 수 있어요. 테마, 주사위 소리, 주사위 세트가 있어요.

GM이 무언가를 물으면 어느 섹션에 있어도 질문 배너가 맨 위에 계속 표시돼요.

## 5. 게임 시스템과 하우스 룰 <!-- icon: dice -->

### 5.1 게임 시스템이란

게임 하나의 데이터예요. 캐릭터 시트, 수치, 크리처, 아이템, 주문, 규칙 문서가 들어 있어요. 캠페인 하나는 시스템 하나로 플레이해요. RPG Engine은 캐릭터 시트와 소모되고 회복되는 자원을 계산해요. 능력이 어떻게 작동하는지는 GM이 규칙을 읽고 정해요. 실제 테이블에서 하는 것과 같아요.

### 5.2 5판

SRD 5.1의 종족, 클래스, 서브클래스, 배경 하나, 재주 하나가 들어 있어요. 주문 319개와 무기, 방어구, 마법 물품, 몬스터도 있어요. 규칙 장은 GM이 정확한 원문으로 읽고, 캐릭터 시트는 모두 계산돼요.

5판은 별도의 패키지예요. 캠페인을 만들 때 GM이 제안하고 설치해요. 5판으로 하는 캠페인은 이 패키지가 없는 컴퓨터에서 처음 열릴 때 자동으로 설치되고, GM이 알려 줘요.

SRD에 없는 내용도 가지고 있는 책으로 플레이할 수 있어요. GM이 그 내용을 캠페인의 페이지로 써 주고, RPG Engine은 그 페이지를 기본 내용처럼 다뤄요. RPG Engine은 공개된 콘텐츠만 포함해요. GM이 아는 내용에는 제한이 없어요.

가지고 있는 매뉴얼을 라이브러리로 쓸 수 있어요. GM에게 위치를 알려 주세요. *[내 매뉴얼은 D:\Books\5e에 있어.]* 아니면 패키지 › 라이브러리에서 폴더를 추가하고, 컴퓨터에 뜨는 창에서 한 번 허용해 주세요. RPG Engine은 이 컴퓨터에서 매뉴얼을 읽어요. 각 캠페인은 켜 둔 폴더를 사용하고, GM은 규칙을 정할 때 SRD 다음으로 이 폴더를 찾아보며 책과 쪽수를 밝혀요. 텍스트나 텍스트를 선택할 수 있는 PDF가 가장 잘 읽혀요. 스캔한 PDF는 페이지 그림에서 읽어요. 이 기능은 Windows에서만 되고, 몇 분 걸리며 오류가 조금 있을 수 있어요. RPG Engine은 매뉴얼을 절대 바꾸지 않고, 내용을 어디로도 보내지 않으며, 캠페인에 복사하지도 않아요.

### 5.3 하우스 룰과 직접 만든 추가 요소

GM에게 부탁해 보세요. *[하우스 룰: 공격에서 내추럴 1이 나오면 무기를 떨어뜨려.]* GM은 이를 테이블의 약속으로 기억해요. 필요하면 페이지를 쓰거나 캐릭터 시트의 수치를 만들어요. 이미 글로 정리한 하우스 룰은 텍스트 파일로 만들어 캠페인의 `rules` 폴더에 넣을 수 있어요.

### 5.4 직접 만든 게임 시스템 추가하기

게임 시스템은 패키지예요. GM이 npm, 폴더, 파일에서 설치할 수 있어요. 우리가 만든 것이 아닌 패키지는 컴퓨터에 뜨는 창에서 허용해야만 설치돼요. 게임 시스템을 만드는 일은 개발자의 작업이며, GitHub의 RPG Engine 문서에 설명되어 있어요. 가지고 있는 책을 게임 시스템으로 바꾸는 기능은 아직 없어요 ([나중에 추가될 기능](#9-coming-later)).

## 6. 확장 기능 <!-- icon: plus -->

확장 기능은 게임 시스템 위에 캠페인에 필요한 요소를 더해 줘요. 새벽마다 바뀌는 날씨나 주사위로 자물쇠를 따는 기능이 그 예예요. 확장 기능은 패키지 › 추가에서 목록으로 추가하거나, npm 이름, 폴더, 파일로 추가해요. 우리가 만들지 않은 확장 기능은 코드를 포함하고 있어서, 컴퓨터에 뜨는 창에서 허락해야만 추가돼요. 다른 게임 시스템용으로 만든 확장 기능은 어떤 시스템용인지 알려 주고, 추가되지 않아요. 패키지 › 설치됨에서 확장 기능을 업데이트하거나 삭제할 수 있어요. 원하면 GM이 직접 추가해 주기도 해요.

## 7. 캠페인은 어디서 오는가, 그리고 언어 <!-- icon: world -->

### 7.1 세계를 얻는 세 가지 방법

- **그때그때 만들기**: 플레이어의 전제를 바탕으로, 필요하기 직전에 GM이 장소, 인물, 줄거리를 만들고 기억해 둬요.
- **처음에 준비하기**: 위와 같지만, 플레이 전에 세계를 미리 만들어요.
- **직접 가진 모험이나 책으로**: GM에게 파일을 주세요. *[이 모험을 우리 캠페인으로 가져와 줘요: D:\Books\adventure.pdf. 안에 있는 내용은 말해 주지 마세요.]* 텍스트, EPUB, Word 문서, 글자를 선택할 수 있는 PDF가 가장 잘 읽혀요. 스캔한 PDF는 페이지 이미지로 읽는데, Windows에서만 가능하고 느리며 오류가 조금 있어요. 읽는 일은 플레이어의 Codex나 Claude Code가 채팅 밖에서 하거나, 아니면 채팅 속 GM이 플레이어의 요금제로 해요. 문서 전체가 OpenAI나 Anthropic에 전달되며, 플레이어 계정의 약관과 학습 사용 설정을 따라요. 진행 상황은 대시보드에 나와요. 소설이라면 GM이 어디서 시작할지 제안해요. 장소, 인물, 비밀은 GM이 써요.

캠페인은 한 번만 플레이해요. 같은 모험을 다시 하려면 새 캠페인을 만드세요.

### 7.2 언어

캠페인마다 언어는 하나예요. GM의 언어이고, 대시보드가 그 언어를 따라요. 대시보드는 26개 언어로 제공돼요. 그 밖의 언어는 컴퓨터에서 Codex나 Claude Code가 번역하고, 둘 다 없으면 채팅 속 GM이 번역해요. 5판의 이탈리아어 용어는 공식 이탈리아어 SRD에서 가져와요. 규칙 본문은 영어 그대로이고, GM이 플레이어의 언어로 풀어서 말해 줘요.

## 8. 궁금한 분을 위한 캠페인 폴더 <!-- icon: list -->

폴더를 열 필요는 전혀 없어요. 캠페인의 비밀이 들어 있기도 해요. 폴더에는 `campaign.yaml`(설정), `state.yaml`(게임 진행 상태), `world/`(캐릭터, 장소, 퀘스트 등을 한 페이지씩 담은 마크다운), `rules/`(하우스 룰), `images/`, `log.jsonl`(모든 변경 기록), `.saves/`, `.player/`(메모), 그리고 AI 에이전트에게 RPG Engine의 위치를 알려 주는 작은 파일들이 있어요. 페이지는 Obsidian 형식이에요. 페이지를 직접 고치면 GM이 다음 답변에서 그 변경을 알게 돼요.

RPG Engine은 이 폴더 안에서만 작동해요. 게임을 읽고 쓰는 곳도 여기뿐이고, 다른 파일은 건드리지 않아요. 매뉴얼이 있는 폴더는 읽기만 해요. 이 폴더 밖에는 자체 데이터 폴더만 둬요. 대시보드 번역, 매뉴얼에서 읽은 텍스트, 설치를 허용했을 때의 Codex나 Claude Code가 여기에 해당해요. 그림을 그리는 동안 쓰는 임시 폴더도 있어요. 에이전트가 컴퓨터에서 다른 일을 하려면 먼저 물어봐요.

GM이 쓰는 모든 명령은 캠페인 폴더에서 직접 실행할 수도 있어요. `rpg --help`를 입력하면 목록이 나와요. 많은 명령이 캠페인의 비밀을 그대로 보여 줘요.

## 9. 앞으로 추가될 기능 <!-- icon: hourglass -->

- **GM이 되어 보기**: AI가 파티를 맡아 플레이해요.
- **제작자 모드**: AI와 함께 모험을 쓰고, 내보내서 공유해요.
- **한 컴퓨터에서 여러 명이 함께 플레이**: 각자 자기 캐릭터로, 같은 채팅에서 차례를 나눠 플레이해요.
- **더 많은 확장 기능**: 공유할 수 있는 세계관, 기능, 하우스 룰을 만나 보세요.
- **다른 게임**: 더 많은 게임 시스템과 직접 만든 시스템을 지원해요.

## 10. 질문과 문제 <!-- icon: info -->

### 질문

**규칙을 알아야 하나요?** 아니요. 멘토를 튜토리얼로 설정하고, 궁금할 때마다 대괄호로 물어보세요.

**GM이 속임수를 쓸 수 있나요?** RPG Engine이 굴린 결과는 바꿀 수 없어요. 난이도가 이야기일 때만 예외예요. 이미 정해진 사실도 바꿀 수 없어요.

**비용이 드나요?** RPG Engine은 무료예요. GM은 에이전트의 요금제나, 컴퓨터에서 돌리는 로컬 모델로 움직여요. 하룻밤 플레이는 긴 채팅이에요. 가장 낮은 요금제에서는 저녁이 끝나기 전에 요금제 한도에 닿을 수 있어요. 이미지, 번역, 가져오기도 같은 요금제를 써요. RPG Engine 자체는 API 키를 쓰지 않아요. API 키는 호출마다 요금이 나가요. 에이전트에는 키가 아니라 계정으로 로그인하세요.

**휴대폰으로 플레이할 수 있나요?** 아니요. GM은 컴퓨터에서 움직이고, 대시보드도 그 컴퓨터에서만 열려요.

**친구들과 함께 플레이할 수 있나요?** 아직은 안 돼요. 지금은 플레이어 한 명, 캐릭터 하나, 그리고 동료가 함께해요([나중에 추가될 기능](#9-coming-later)).

**다음에는 다른 AI를 써도 되나요?** 네. 다른 에이전트에서 캠페인을 열고 *계속*이라고 쓰세요.

### 문제

**대시보드가 열리지 않아요.** GM에게 물어보세요. `[대시보드 링크가 뭐예요?]` 해당 캠페인에서 채팅이 열려 있고 GM이 첫 답변을 한 뒤에만 열려요.

**GM이 게임을 모르는 것 같아요.** 에이전트가 RPG Engine을 불러오지 못한 거예요. 캠페인 폴더에서 에이전트를 시작했는지, 폴더를 신뢰했는지 확인하세요. Claude Code에서는 `/mcp`를 입력하고 `rpg`를 다시 연결하세요. Codex에서는 캠페인 폴더에서 `codex mcp list`를 실행했을 때 `rpg`가 보여야 해요. `rpg --version`이 인식되지 않으면 RPG Engine을 다시 설치하세요([2.2](#22-install)).

**업데이트.** `npm install -g rpg-engine`을 다시 실행하고 새 채팅을 여세요. 이미 실행 중인 GM은 시작했을 때의 버전을 그대로 유지해요.

**GM이 되돌린 일을 기억하고 있어요.** 새 채팅을 열고 세이브에서 **새 채팅을 열었어요**를 누르세요.

**이미지가 나타나지 않아요.** 설정 > 이미지에서 이 컴퓨터가 이미지를 만들 수 있는지, 어떻게 하면 되는지 확인할 수 있어요.

**설치가 실패하거나 `rpg`가 시작되지 않아요.** `node --version`이 22 이상이어야 해요. Windows에서는 RPG Engine과 캠페인을 `&`가 들어간 경로에 두지 마세요.

**대시보드 링크가 바뀌었어요.** 다른 프로그램이 기존 주소를 사용 중이에요. GM이 새 링크를 알려 줘요.
