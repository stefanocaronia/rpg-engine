# RPG Engine：完全ガイド

**RPG Engine**では、**AIをGM**にして、テーブルトークRPGを遊べます。遊ぶ場所は**ダッシュボード**です。パソコン上のウィンドウに、キャラクターシート、ダイス、マップ、ジャーナル、GMとの**チャット**が並びます。

このガイドでは、遊び方を説明します。ページのボタンについては、ページ自身が説明します。ボタンにポインターを重ねると、何をするボタンかが表示されます。

## クイックスタート <!-- icon: send -->

1. [nodejs.org](https://nodejs.org)から**Node.js**をインストールします（LTS版）。
2. 新しいターミナルを開き、`npm install -g rpg-engine`と入力します。Windowsでスクリプトの実行が無効だと表示されたら、`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`と入力し、yesと答えて、もう一度試します。
3. `rpg open`と入力します。デスクトップにアイコンを置くか聞かれたら、Enterを押します（[2.2](#22-installing)）。以後はアイコンからRPG Engineを起動します。
4. **新規キャンペーン**を押し、名前を付けて**作成**を押します（[2.3](#23-a-new-campaign)）。
5. チャットで、AIアプリとモデルを選びます（[2.4](#24-connect-your-ai)）。Claude Codeには有料のClaudeプラン、CodexにはChatGPTアカウント（無料でも有料でも可）が必要です。**チャットを開く**、**開始**の順に押します。

最初の返事には数分かかることがあります。そのあと、GMが遊び方を尋ね、一緒にキャラクターを作ります。

## 1. RPG Engineとは <!-- icon: about -->

| 誰が | 何をするか |
|---|---|
| **自分** | キャラクターを演じます。キャラクターの行動、セリフ、挑戦を決めます。 |
| **GM**（AI） | 物語を語り、ほかの全員を演じ、出来事を決め、ロールを求めます。 |
| **RPG Engine** | 世界をファイルに保存し、ダイスを振り、ヒットポイント、お金、時間、距離を数え、発見するまで秘密を守ります。 |

世界は、次の晩になっても、新しいチャットでも、別のAIでも変わりません。

- **語られたことは真実のままです。** 倒された悪役は倒されたままです。
- **ダイスは本物です。** GMは出目を変えられません。ただし、いちばん易しい難易度は例外です。
- **秘密は秘密のままです。** キャラクターが知らないことを、GMが教えることはありません。
- **世界は動きます。** 休んだり旅をしたりしている間も、脅威は進みます。
- **キャンペーンはパソコン上のフォルダです。** いつでも中断して、あとで続けられます。

ゲームは、ゲームシステムとして提供されます。現在あるのは、無料のSystem Reference Document 5.1にもとづく**第5版**です。ゲームシステムがない場合は、数値のない物語を自由に遊びます。

## 2. はじめに <!-- icon: path -->

### 2.1 必要なもの

- Windows、macOS、Linuxのいずれかが動くパソコン。
- **Node.js 24**以降。[nodejs.org](https://nodejs.org)から入手します。
- **ターミナル**：インストールにだけ使います。Windowsではターミナル（Terminal）またはPowerShell、macOSではターミナルです。
- GMになる**AIアプリ**と、自分のアカウント（[2.4](#24-connect-your-ai)）。

### 2.2 インストール

```text
npm install -g rpg-engine
rpg open
```

1行目でRPG Engineをインストールします。npmが自身の更新を勧めてきても、無視して大丈夫です。

`rpg open`で、RPG Engineのウィンドウが開きます。初回は、デスクトップとメニューにアイコンを追加するか聞かれます。Enterを押すと追加されます。以後はアイコンから起動します。

インストールに失敗したら、`node --version`が24以上になっているか確認します。Windowsでスクリプトの実行が無効だと表示されたら、`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`と入力し、yesと答えます。Windowsでは、RPG Engineとキャンペーンを、`&`を含むパスに置かないでください。

### 2.3 キャンペーンを作る

**新規キャンペーン**を押し、**名前**、**言語**、**ゲームシステム**を決めます。そのほかは、GMと一緒に作ります。**作成**を押すと、専用のウィンドウでキャンペーンが開きます。

GMとダッシュボードは、キャンペーンの言語で話します。第5版のルールの文章は英語のままですが、GMが自分の言語で伝えます。

キャンペーンは、その名前のフォルダに入ります。場所は、ユーザーフォルダの中の`RPG Engine`フォルダです。次回からは、カードをクリックします。

### 2.4 AIをつなぐ

GMは、パソコン上の**AIアプリ**の中で、自分のアカウントを使って動きます。claude.aiやChatGPTのようなウェブのチャットでは足りません。GMは、キャンペーンのファイルにアクセスする必要があるからです。

- **Claude Code**：有料のClaudeプラン（Pro以上）。
- **Codex**：ChatGPTアカウント（無料でも有料でも可）。
- **OpenCode**：アカウントは不要です。期間限定の無料モデルがあるほか、自分で用意したプロバイダーのモデルやローカルのモデルも使えます。
- **Antigravity**：Googleアカウント。無料枠には週ごとの制限があります。

チャットで、アプリを選び、続けて**モデル**と**GMの思考**を選びます。アプリが入っていない場合やログインしていない場合は、ボタンでインストールやログインができ、アプリのサイトも開けます。RPG Engineがパスワードを見ることはありません。

一晩のプレイは長いチャットになります。いちばん小さなプランでは、夜が終わる前に上限に達することがあります。使えるなかで最大のモデルで遊んでください。小さなモデルは、口車に乗せられて秘密を明かしやすくなります。

プレイとテストは、主に**Claude Code**で行っています。Antigravityは**お試し中**です。ゲームの外に出ることがあり、チャットをメモリーに保存し、そのメモリーはオフにできません。書いた内容はGoogleに送られ、人が読むことがあります。RPG EngineはGoogleの製品ではありません。

### 2.5 最初のチャット

**チャットを開く**を押し、続けて**開始**を押します。最初の返事には数分かかることがあります。新しいキャンペーンは、そのあと3つの段階を進みます。

1. **設定**：GMが遊び方を数問ずつ尋ねます。世界の厳しさ、死ぬことがあるか、いつセーブに戻れるか、などです。GMに選んでほしいときは、*自分で決める*ではなく「おまかせ」と書きます。すべて、あとから変えられます。
2. **セッションゼロ**：テーブルを囲むときと同じように、GMと一緒にキャラクターを作ります。シートの計算はRPG Engineが行います。すでにキャラクターがいる場合は、そのシートをチャットに貼り付けます。
3. **プレイ**：GMが最初のシーンを用意します。

### 2.6 AIアプリ自身のチャットで遊ぶ

AIアプリ自身のチャットで遊ぶこともできます。ターミナルでもデスクトップアプリでも使え、ダッシュボードはその横に開いておきます。

1. ゲームを置いておくフォルダで、ターミナルを開きます。フォルダを右クリックして、Windowsでは**ターミナルで開く**、macOSでは**サービス > フォルダに新規ターミナル**を選びます。
2. `rpg init "The Salt Isles"`と入力します。`The Salt Isles`というフォルダができ、新しいキャンペーンが入ります。
3. そのフォルダでアプリを起動します。`claude`、`codex`、Antigravityは`agy`、または`opencode`です。フォルダを信頼するか聞かれたら、yesと答えます。Claude Codeでは、最初に選ばれているのは*No, exit*です。
4. *こんにちは！始めましょう。*と書きます。GMがダッシュボードへのリンクを伝えるので、チャットの横に開きます。

知っておくと役立つこと：

- アプリが使っているツールの詳細は開かないでください（Claude Codeではctrl+o）。秘密が表示されることがあります。
- Codexのデスクトップアプリでは、ゲームのチャットのメモリーをオフにします。
- GMがゲームを知らない様子なら、キャンペーンのフォルダで`rpg init`と入力し、新しいチャットを開きます。
- Windowsで`claude`が見つからないときは、インストーラーが示したフォルダをPATHに追加し、新しいターミナルを開きます。
- キャンペーンを遊べるチャットは、一度に1つです。自分で開いたチャットが開いている間、ダッシュボードのチャットは待機します。

## 3. プレイ <!-- icon: chat -->

### 3.1 GMと話す

キャラクターの行動やセリフを書きます。

> 宿の主人に、今夜ほかに誰が通ったかを尋ねる。

試すことを伝えるのはプレイヤーで、何が起こるかを伝えるのはGMです。GMがキャラクターの行動を勝手に決めることはありません。

物語の外で話すときは、`[OOC: …]`（キャラクターを離れた発言）と書きます：*[OOC: 組みつきのルールはどうなっていますか？]* GMには、ルールやダッシュボードの使い方を尋ねられます。

GMから質問されたら、ボタンで答えるか、自分の言葉で書きます。キャラクターシートから行動することもできます。武器、呪文、持ち物をクリックして、したいことを選びます。

**常時指示**：仲間に長く続けてほしいことを伝えます。たとえば*今後は、必ず一人は生かしておく*のように伝えると、GMは取り消されるまでその指示を保ちます。

### 3.2 ダイスロール

GMがロールを求めるのは、結果が不確かで、しかも重要なときだけです。バナーにロールが表示されます。クリックすると、ダイスが転がります。

ダイスはGMではなく、RPG Engineのものです。*[今のロールは本物でしたか？]*といつでも尋ねられます。秘密のロールでも、GMは、尋ねる前に振ったことを証明できます。

**ダイス**の設定を物理にしている場合は、自分のダイスを振って、出た目を書きます。*[14が出た。]* キャラクターシートや**フリーロール**で遊びとして振ったロールは、一切数えられません。

### 3.3 シーン、戦闘、旅

物語は**シーン**ごとに進みます。戦闘、会話、移動、休息などです。シーンが終わるたびにゲームが自動でセーブされ、そのシーンはジャーナルに入ります。

戦闘では、自分以外のターンはすべてGMが語り、判断が必要な場面で止まります。

行き先を伝えます。*北のロッカへの道を行く*のように伝えると、RPG Engineが距離と日数を計算し、途中で何かが起こるとそこで止まります。その間も悪役の計画は進み、その兆しが見えます。

### 3.4 セーブ

RPG Engineは、シーンが終わるたびにキャンペーンをセーブします。いつ戻れるかは、**セーブ**の設定で決まります。

- **永久死亡**：戻れません。
- **チェックポイント**：最後のセーブまで戻れます。キャラクターが死亡したときだけです。
- **未使用**：任意のセーブまで戻れます。好きなときにセーブもできます。

どのモードでも、チャットか**セーブ**で、やり直すことができます。

戻ったあとは、新しいチャットを開いてください。古いチャットは、取り消されたことを覚えているからです。

1. **チャットを閉じる**を押してから、**新規チャット**を押します。AIアプリ自身のチャットでは、新しい会話を開きます（Claude Codeでは`/clear`）。
2. *続ける*と書きます。
3. セーブの**新しいチャットを開いた**を押します。押すまで、GMは待ちます。

### 3.5 中断と再開

やめたいときにいつでもやめられます。すべてすでにセーブされています。ダッシュボードのウィンドウを閉じると、しばらくしてゲームが止まります。失われるものはありません。

再開するには、アイコンからRPG Engineを開き、キャンペーンをクリックします。**チャットを再開**を押し、続けて**続きから再開**を押すと、GMがここまでの流れを伝え、続きを進めます。次回は、別のAIアプリを選ぶこともできます。

### 3.6 制限と中止

**ライン**はゲームに決して登場しません。**ヴェール**は画面の外でだけ起こります。どちらも**設定**で決めます。

いつでも*[stop]*と書いてください。GMはその内容をすぐにやめ、ラインに加えます。

### 3.7 画像

GMは、場所、クエスト、人物の画像を作らせることができます。作るかどうかは**画像**の設定で決まります。頼めば、キャラクターの肖像も作ります。作るのは自分のAIアプリで、自分のプランが使われます。画像が表示されない場合は、このパソコンで作れるかどうかが**設定**で分かります。

キャラクターやワールドのページに、自分の画像を付けることもできます。ページ上で付けられます。

## 4. ダッシュボード <!-- icon: party -->

ゲームを見るためのウィンドウです。キャラクターが知っていることだけが表示されます。

- **ゲーム**：GMとのチャット。ページの横に置いていないときに表示されます。
- **パーティ**：自分のシートと仲間のシート、そしてロールの結果。
- **シーン**：現在地、そこにいる人物、マップ。戦闘中はターンも表示されます。
- **ジャーナル**：クエスト、本のようなストーリー、仲間の日記、自分のメモ。
- **ワールド**：ワールドマップ、キャラクターが知っていること、見つけた文書、カレンダー。
- **セーブ**：セーブに戻ること、やり直すこと。
- **設定**：遊び方と、ページの見た目。
- **パッケージ**：ゲームシステム、拡張、自分のマニュアル、更新。新しいRPG Engineが出ると、ここに表示されます。

ページに接続されていないと表示されたら、**キャンペーンを再開**を押します。

家でスマートフォンから遊ぶには、**設定**の**ダッシュボード**で**スマホからのアクセス**をオンにし、パソコンと同じWi-Fiにつないだスマートフォンでコードを読み取ります。WindowsからNode.jsにネットワークの使用を許可するか聞かれたら、プライベートネットワークで許可し、そのWi-Fiをプライベートネットワークに設定します。ゲームの通信は暗号化されません。自宅のように信頼できるネットワークでだけ使ってください。公共の場所、ホテル、職場のWi-Fiでは使わないでください。使い終わったらオフにします。パソコンの最後のウィンドウを閉じると、ゲームも終了します。

テーマのせいでページが読みにくいときは、ページのアドレスの末尾に`#/settings/page`を付けて、**テーマ独自のスタイル**をオフにします。

## 5. ルール、マニュアル、拡張 <!-- icon: dice -->

**ゲームシステム**とは、1つのゲームのデータです。キャラクターシート、クリーチャー、アイテム、呪文、ルールがまとまっています。キャラクターシートの計算は RPG Engine が行います。ルールをどう適用するかは、テーブルで遊ぶときと同じように、GM が読んで判断します。

**第5版**には、System Reference Document 5.1 の無料ルールが入っています。手元にある書籍の内容も使えます。GM がキャンペーンに書き込みます。

**手持ちのマニュアル**：GM に置き場所を伝えるか、**パッケージ**にそのフォルダを追加します。GM はそこからルールを調べ、書名とページを示します。RPG Engine がマニュアルを書き換えることはありません。キャンペーンにコピーすることもありません。

**ハウスルール**：GM に *[ハウスルール：攻撃の出目1では武器を落とす。]* と頼みます。GM はそのルールを覚えておきます。一度出した裁定は、次回以降も有効です。

**拡張**は、天候など、ゲームに要素を加えます。**パッケージ**で追加するか、GM に頼みます。

## 6. オリジナルの冒険 <!-- icon: world -->

世界が用意されていない場合は、GM が前提設定をもとに世界を作り、それを保ちます。

手元の冒険や書籍で遊ぶときは、GM にそのファイルを渡します。*[この冒険をキャンペーンとして取り込んで：D:\Books\adventure.pdf。中に書かれていることは教えないで。]* キャンペーンの外にあるファイルは、了承したあとにだけ読み込まれます。テキスト、EPUB、Word、または文字を選択できる PDF が最適です。

文書は丸ごと、それを読む AI の会社に送られます。キャンペーンは一度だけ遊ぶものです。同じ冒険をもう一度遊ぶときは、新しいキャンペーンを作成します。

## 7. データの扱い <!-- icon: lock -->

- キャンペーンは1つのフォルダです。キャンペーンの秘密も、GM とのチャットも入っています。開く必要はありません。
- RPG Engine が読み書きするのは、そのフォルダの中だけです。マニュアルは読むだけです。キャンペーンの外にあるほかのものは、了承したあとにだけ、パソコンのウィンドウで確認してから扱います。
- ダッシュボードのチャットでは、GM が勝手にファイルを開くことはありません。
- 書いた内容は、GM を担うモデルの会社に、アカウントの規約に従って送られます。ローカルモデルなら、パソコンの外には出ません。
- 当方以外が作ったゲームシステムや拡張は、パソコン上で動くコードです。了承したときにだけ導入されます。信頼できる作者のものにだけ、了承してください。
- キャンペーンのフォルダが git リポジトリの場合は、**設定**からコミットできます。チャットを含めるのは、リポジトリが非公開のときだけにしてください。
- **スマホからのアクセス**をオンにすると、ゲームは暗号化されないまま、パソコンから家庭内ネットワークを通じてスマホに送られます。外部のサービスは通りません。同じネットワークにいる人なら、内容を読める可能性があります。
