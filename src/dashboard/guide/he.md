# RPG Engine: המדריך המלא

**RPG Engine** מאפשר לשחק משחק תפקידים שולחני עם **בינה מלאכותית בתפקיד המנחה**. מדברים עם המנחה ב**צ'אט**; RPG Engine עובד מאחורי הקלעים: הוא **זוכר את העולם**, **מטיל את הקוביות** ו**מנהל את החשבונות**. לצד הצ'אט משאירים בדפדפן דף פתוח, **הלוח** (dashboard), עם דף הדמות, הקוביות, המפות והיומן.

המדריך הזה מיועד לשחקנים: אין צורך לדעת תכנות.

## התחלה מהירה <!-- icon: send -->

1. להתקין את **Node.js** מהאתר [nodejs.org](https://nodejs.org) (גרסת LTS).
2. להתקין **סוכן בינה מלאכותית**, התוכנה שבה המנחה פועל, ולהתחבר אליו: למשל Claude Code או Codex ([2.4](#24-connect-your-ai)).
3. בטרמינל, להתקין את RPG Engine: `npm install -g rpg-engine`.
4. ליצור קמפיין: `rpg init "The Salt Isles"`.
5. להיכנס לתיקייה החדשה, `cd "The Salt Isles"`, ולהפעיל בה את הסוכן: `claude` עבור Claude Code, `codex` עבור Codex. לאשר כשהוא שואל אם סומכים על התיקייה ([2.4](#24-connect-your-ai)), ואז לכתוב *שלום! בוא נתחיל.* המנחה עונה עם הקישור ללוח.

## 1. מהו RPG Engine <!-- icon: about -->

| מי | מה הוא עושה |
|---|---|
| **אתה** | משחקים את הדמות: מה היא עושה, אומרת ומנסה. |
| **המנחה** (הבינה המלאכותית) | מספר את הסיפור, משחק את כל השאר, מחליט מה קורה, מבקש הטלות. |
| **RPG Engine** | שומר את העולם בקבצים, מטיל את הקוביות, סופר נקודות חיים, כסף, זמן ומרחקים, ושומר סודות עד שמגלים אותם. |

העולם נשאר זהה מערב לערב, גם בצ'אט חדש, וגם עם בינה מלאכותית אחרת:

- **מה שנאמר נשאר נכון.** נבל שמת נשאר מת.
- **הקוביות אמיתיות.** המנחה לא יכול לעוות אותן, אלא ברמת הקושי הקלה ביותר, אם בוחרים בה.
- **סודות נשארים סודות.** המנחה אף פעם לא מספר מה שהדמות אינה יודעת.
- **העולם זז.** איומים מתקדמים בזמן מנוחה או מסע, ואפשר לראות את סימניהם.
- **קמפיין הוא תיקייה** במחשב: אפשר להפסיק מתי שרוצים ולהמשיך מאוחר יותר.

כיום RPG Engine משחק מערכת משחק אחת, **מהדורה חמישית**, מתוך מסמך הכללים החופשי System Reference Document 5.1. אחרות יגיעו ([בהמשך](#9-coming-later)).

## 2. תחילת העבודה <!-- icon: path -->

### 2.1 מה צריך

- מחשב עם Windows, macOS או Linux, ודפדפן.
- **Node.js 22** ומעלה, מ-[nodejs.org](https://nodejs.org). הוא מביא איתו את `npm`, שמתקין את RPG Engine.
- **טרמינל**: ב-Windows, Terminal או PowerShell; ב-macOS, Terminal. כדי לפתוח טרמינל בתוך תיקייה, לוחצים על התיקייה בלחצן הימני ובוחרים **פתח בטרמינל** (Windows) או **שירותים > טרמינל חדש בתיקייה** (macOS).
- **סוכן AI** שישמש כמנחה ([2.4](#24-connect-your-ai)), עם **המודל הגדול ביותר** שהוא מציע: מודל קטן קל יותר לשכנע לחשוף סודות או לעקוף את הכללים.

### 2.2 התקנה

```text
npm install -g rpg-engine
```

הפקודה `rpg --version` בודקת שההתקנה הצליחה. את `rpg` מפעילים פעם אחת לכל קמפיין, כדי ליצור אותו; אחר כך הסוכן מפעיל את RPG Engine בעצמו.

### 2.3 יצירת קמפיין

פותחים טרמינל בתיקייה שבה שומרים את המשחקים ([2.1](#21-what-you-need) מסביר איך):

```text
rpg init "The Salt Isles"
```

הפקודה יוצרת את התיקייה `The Salt Isles` עם קמפיין חדש בתוכה; נכנסים אליה עם `cd "The Salt Isles"`. כדאי לזכור היכן היא נמצאת: חוזרים אליה בכל פעם שמשחקים. את כל השאר בוחרים אחר כך, בצ'אט או בדשבורד; `rpg init --help` מציג את האפשרויות לבחירה כבר עכשיו, כמו `--language it` או `--difficulty hard`.

המנחה לא יכול ליצור קמפיין: לפני `init` שום דבר לא מספר לסוכן איפה RPG Engine.

### 2.4 חיבור ה-AI

המנחה פועל בתוך **סוכן AI**: אפליקציית AI, בטרמינל או בשולחן העבודה, שיכולה לעבוד עם הקבצים שבמחשב, כמו Claude Code או Codex. צ'אט רגיל כמו claude.ai או ChatGPT, או אפליקציה בטלפון, לא מספיקים: המנחה צריך גישה לקבצי הקמפיין שבמחשב. לכל סוכן יש מנוי והתחברות משלו: ל-Claude Code נדרש מנוי בתשלום ל-Claude, ל-Codex נדרשת התחברות עם ChatGPT. מתקינים אותו פעם אחת, מהדף שלו: [Claude Code](https://code.claude.com/docs/en/setup), [Codex](https://learn.chatgpt.com/docs/codex/cli).

- **Claude Code**: בתיקיית הקמפיין כותבים `claude`. כשהוא שואל אם לתת אמון בתיקייה, בוחרים **Yes, I trust this folder**; שימו לב, התשובה שמסומנת מראש היא *No, exit*. בקמפיין יש גם הוק קטן, `rpg --listen`, שהשאלה לא מציגה: הוא מודיע למנחה מיד כשפועלים מהדשבורד.
- **Codex**: בתיקיית הקמפיין כותבים `codex`, ועונים כן כשהוא שואל אם לתת אמון בתיקייה. באפליקציית שולחן העבודה שלו, כדאי לבדוק בהגדרות שהזיכרונות כבויים עבור הצ'אטים של המשחק.
- **סוכן אחר**: מפעילים אותו בתיקיית הקמפיין ומחברים אליו את שרת ה-MCP `rpg mcp`. RPG Engine הוא שרת MCP סטנדרטי: כל סוכן שתומך ב-MCP יכול להיות המנחה, גם סוכנים מקומיים.

אנחנו משחקים ובודקים עם **Claude Code**; **Codex** מחובר ונבדק, אבל עדיין לא שוחק איתו קמפיין שלם. הקמפיין מכבה את הזיכרון של הסוכן עצמו: המשחק חי בקבצים שלו, כך שחזרה לשמירה היא חזרה אמיתית.

### 2.5 הצ'אט הראשון

כותבים משהו, כמו *שלום! בואו נתחיל.* בתשובה הראשונה של כל צ'אט המנחה נותן את **הקישור לדשבורד**, משהו כמו `http://127.0.0.1:4750`: פותחים אותו ומשאירים לצד הצ'אט.

בין הודעות המנחה הסוכן מציג את הכלים שהוא משתמש בהם: לא לפתוח את הפרטים שלהם (ב-Claude Code, ctrl+o), הם עלולים לחשוף סודות.

קמפיין חדש עובר שלושה שלבים, שמוצגים בראש הדשבורד: **1 הגדרות** (איך רוצים לשחק), **2 סשן אפס** (יוצרים דמות, תוך כדי משחק), **3 משחק**.

### 2.6 הגדרות: בחירת אופן המשחק

המנחה שואל רק את מה שעדיין חסר, כמה שאלות בכל פעם; השלב **הגדרות** בדשבורד מציג את אותן שאלות ככרטיסים. אפשר לכתוב "תחליט" והמנחה יבחר. הכול אפשר לשנות אחר כך, בצ'אט או ב**הגדרות**.

| הגדרה | מה היא קובעת | ערכים |
|---|---|---|
| **מנטור** | כמה המנחה מלמד את הכללים | כבוי, רמזים, הדרכה |
| **רמת קושי** | עד כמה העולם קשה | סיפור, קל, רגיל, קשה, אכזרי |
| **קטלניות** | מה משמעות הנפילה בקרב | סיפורית (אין מוות), אפית (רק כשזה חשוב), קוביות |
| **שמירות** | מתי אפשר לחזור אחורה | מוות קבוע, נקודת ביקורת, פנוי ([3.8](#38-saves-and-going-back)) |
| **קפדנות** | עד כמה אוכל, אור ומסעות כפופים לכללים | חלק, כללים, הדמיה |
| **קוביות** | מי מטיל את הקוביות | דיגיטליות, פיזיות |
| **יחידות מידה** | מרחקים ומשקלים | מטרי, אימפריאלי |
| **קולות** | מי מדבר בשם הדמויות שפוגשים: ברגעי מפתח הדמות עצמה, שיודעת רק את מה שהיא יודעת, לפי בחירת המנחה; המנחה תמיד; או תמיד הדמות, לעיקריות או לכולן, לאט ויקר יותר, במקום שאפליקציית ה-AI מאפשרת | אוטומטי, מנחה, חשובות, תמיד |
| **בני לוויה** | מי מטייל איתכם | אין, נוצרו יחד איתכם, נוצרו בידי המנחה, נפגשים במשחק |
| **תמונות** | תמונות של מקומות, משימות ומי שפוגשים | אין, לפי בקשה, מקומות חדשים, משימות ומי שפוגשים ([3.11](#311-pictures)) |
| **קווים אדומים** ו**וילונות** | מה אף פעם לא מופיע, ומה קורה רק מחוץ למסך | רשימות |
| **שפה** | שפת המשחק והדשבורד | כל שפה |

מהדורה חמישית מוסיפה **התקדמות**: נקודות ניסיון או אבני דרך.

אם אין עולם כתוב, המנחה שואל גם **רעיון פתיחה** (ז'אנר, אווירה, כמה אלמנטים, במילים שלכם) ו**הכנה**: לבנות את העולם תוך כדי משחק, או כולו בהתחלה.

**הסגנון של המנחה** אף פעם לא נשאל, אבל אפשר לשנות אותו בצ'אט או ב**הגדרות**: **הפרוזה** (פשוטה, ספרותית, פאלפ, צינית), **הסיפורים** שהוא ממציא (מצבים, קשתות, פרקים, תעלומה), סופר או סופרת ש**כותבים כמוהם**, או כל דבר אחר **במילים שלכם**.

### 2.7 סשן אפס: הדמות שלכם

יוצרים את הדמות יחד עם המנחה, כמו ליד שולחן. כל בחירה היא שלכם, אלא אם מבקשים מהמנחה לבחור: אפשר לבוא עם רעיון מלא, עם רעיון מעורפל, או בלי כלום. המנחה מסביר איך נקבעים ערכי היכולות לפני שמוטלת קובייה כלשהי. סיפור רקע אף פעם לא חובה; אם מספקים אחד, המנחה כותב אותו במילים שלכם. אחר כך המנחה שואל על תמונה של הדמות ([3.7](#37-your-characters-story-and-picture)). RPG Engine מחשב את דף הדמות: אין צורך לעשות חישובים.

## 3. משחקים <!-- icon: chat -->

### 3.1 שיחה עם המנחה

כותבים מה הדמות עושה או אומרת, במילים שלכם:

> אני שואל את בעל הפונדק מי עוד עבר כאן הלילה.

מחוץ לסיפור, כותבים בסוגריים מרובעים: *[איך עובדת היאבקות?]* המנחה עונה גם הוא בסוגריים.

אתם אומרים מה אתם מנסים; המנחה אומר מה קורה. המנחה אף פעם לא מחליט בשם הדמות, ואף פעם לא מדבר על המנוע. אפשר לשאול אותו איך משתמשים בדשבורד.

**פעולה מהדשבורד**: לוחצים על שם בדף הדמות, כמו נשק, לחש או משהו שנושאים, ואז על מי שהוא מיועד לו; או לוחצים על דמות כדי לדבר איתה. הדשבורד כותב את המשפט, *אני תוקף את שודד 1 עם אלה.*, ואפשר לשנות אותו לפני **לומר למנחה**. המנחה שומע אותו כאילו נאמר בצ'אט, ופוסק בו כמו בכל פעולה אחרת. במקום שאפליקציית ה-AI לא יכולה לשמוע אותו בעצמה, **העתקה** מכינה אותו להדבקה בצ'אט.

### 3.2 הטלות

המנחה מבקש הטלה רק כשהתוצאה אינה ודאית וחשובה, ואומר קודם מה על הפרק. אחר כך:

- **בדשבורד**, באנר מציג כפתור לכל בדיקה, כמו *אקרובטיקה +4 · ביתרון*. לוחצים עליו: הקוביות נופלות על הדף והמנחה שומע את התוצאה. אפשר גם ללחוץ על השורה בדף הדמות שנדלקת, להטיל קוביות מהמגש, או לכתוב משהו אחר בבאנר.
- **ידנית**, בפינת הבאנר או ב**הגדרות**: הבאנר אומר מה להטיל, ומטילים מדף הדמות או מהמגש.
- **קוביות פיזיות**, כשהגדרת הקוביות על פיזיות: כותבים את הפאות שהוטלו, *[הטלתי 14.]*, ו-RPG Engine מוסיף את המתאמים.

**הטלות חופשיות**: לוחצים על כל מספר בדף הדמות, או פותחים את המגש, כדי להטיל להנאה. הן אף פעם לא נחשבות והמנחה אף פעם לא רואה אותן.

**ההטלות של המנחה** מופיעות בעמודת ההטלות, חוץ מהסודיות. תמיד אפשר לשאול *[ההטלה הזאת הייתה אמיתית?]*: על הטלה סודית המנחה נותן טביעת אצבע שמוכיחה שהיא בוצעה לפני ששאלתם.

### 3.3 סצנות וקרבות

הסיפור מתנהל ב**סצנות**: קרב, שיחה, חקירה, מסע, מנוחה. בסוף כל סצנה המשחק נשמר מעצמו, והסצנה נכנסת ליומן.

בקרב המנחה מתאר כל תור שאינו שלכם, ועוצר במקום שבו אפשר להחליט. ה**סצנה** מציגה למעלה של מי התור ומי הבא, ואת הכרטיס של הדמות לצד המפה; סדר התורות, נקודות הפגיעה של החבורה ועד כמה האויבים נראים פצועים, במילים, נשארים בצד הדף. אם הדמות נופלת, הצלות המוות מופיעות בגדול על הדף.

### 3.4 זמן, מסעות והעולם שנע

RPG Engine מנהל את התאריך; בין סשנים לא עובר זמן. אומרים שנחים, *אנחנו נחים מנוחה ארוכה*, וברגע שהמנחה מסכים המנוחה מחזירה את מה שהיא צריכה להחזיר. במנוחה קצרה המנחה עשוי לשאול בדשבורד כמה קוביות פגיעה מוציאים: מטילים אותן אחת אחת, רואים כמה כל אחת מרפאה, ועוצרים מתי שרוצים. אומרים לאן הולכים, *אנחנו לוקחים את הדרך צפונה אל רוקה*, ו-RPG Engine מחשב את הדרך, המרחק והימים, ועוצר כשמשהו קורה בדרך. כסף נספר במטבעות המשחק, כולל עודף.

לנבלים יש תוכניות עם מועדים. בכל יום חדש המנחה מקדם את האיומים שהזמן קידם, ורואים את סימניהם, אף פעם לא את השעון עצמו.

### 3.5 מפות

**עולם** מציג את המקומות שהדמות מכירה, את הדרכים ביניהם ואת השביל שנעשה, עם ערפל על השאר. **סצנה** מציגה את מפת המקום שבו נמצאים, כשיש לו מפה, עם מי שעומד היכן; בקרב, בתור שלכם, המשבצות שאי אפשר להגיע אליהן מכוסות בצעיף. כשהמנחה שואל לאן זזים, נוגעים במשבצת, או כותבים אותה, כמו *E4*.

### 3.6 משימות, יומן ופתקים

מטלה שהדמות לוקחת הופכת למשימה ב**יומן**, עם המטרות שלה, המועד שלה ומה שהיא מודדת; מסמנים אותה בכוכב כדי שתישאר בולטת בראש ה**סצנה**. היומן גם מספר את ה**סיפור** שלכם, סצנה אחר סצנה, ושומר את ה**פתקים**: פרטיים, אלא אם **משתפים** פתק, ואז המנחה שומע אותו כמה שחושבים, אף פעם לא כעובדה.

### 3.7 הסיפור והתמונה של הדמות

בדף הדמות, בכרטיס **תיאור** יש תיבה לסיפור של הדמות: המנחה כותב בה, אחרי שאומרים כן. בשביל תמונה, נותנים למנחה קובץ (PNG, JPEG, WebP או SVG, עד 5 MB) יחד עם המקום שלו במחשב, או מבקשים ליצור דיוקן ([3.11](#311-pictures)): *[צרו לי דיוקן: שיער אפור בצמה, צלקת בסנטר.]*

### 3.8 שמירות וחזרה אחורה

RPG Engine שומר את כל הקמפיין בסוף כל סצנה. הגדרת ה**שמירות** קובעת את השאר:

| שמירות | לשמור כשרוצים | לחזור אחורה |
|---|---|---|
| **מוות קבוע** | לא | אף פעם |
| **נקודת ביקורת** | לא | לשמירה האחרונה, רק כשהדמות מתה |
| **פנוי** | כן | לכל שמירה |

בכל מצב אפשר **להתחיל מחדש**, מתחילת המשחק או מסשן אפס. עושים זאת בצ'אט או ב**שמירות**.

אחרי חזרה אחורה, **פותחים צ'אט חדש**: הישן זוכר את מה שבוטל. כותבים *המשך* בצ'אט החדש, ואז לוחצים על **נפתח צ'אט חדש** בשמירות.

### 3.9 סשנים: עצירה וחזרה

אפשר לעצור מתי שרוצים: *[נעצור כאן להלילה.]* הכול כבר שמור בקבצים. כדי לחזור, מפעילים את הסוכן בתיקיית הקמפיין וכותבים *המשך*: המנחה נותן סיכום קצר וממשיך.

### 3.10 מצב הרוח של המנחה

הרובוט בראש הדשבורד הוא המנחה: הפנים שלו עוקבות אחרי האווירה של הסיפור, ואף פעם לא חושפות את מה שעדיין לא ידוע. כשהצ'אט סגור, הוא ישן.

### 3.11 תמונות

RPG Engine יכול ליצור תמונות של המקומות שמגיעים אליהם, של המשימות שלוקחים ושל מי שפוגשים, לפי הגדרת ה**תמונות**, ודיוקן של הדמות כשמבקשים. הוא משתמש ב-Codex או ב-Claude Code שלכם, עם ההתחברות שלכם, במנוי שלכם ובמגבלות שלו: **Codex** מצייר אותן, ואם לא, **Claude Code** מצייר. ה**הגדרות** אומרות אם המחשב הזה יכול ליצור אותן, ואיך מגדירים אם לא. תמיד אפשר לתת למנחה תמונה משלכם.

### 3.12 בטיחות: קווים אדומים, וילונות ועצירה

**קווים אדומים** אף פעם לא מופיעים במשחק; **וילונות** קורים רק מחוץ למסך. בכל רגע אפשר לכתוב *[עצירה]*: המנחה זונח את התוכן הזה מיד ומוסיף אותו לקווים האדומים.

### 3.13 שינוי דעה

כל הגדרה אפשר לשנות, בצ'אט או ב**הגדרות**. פסיקה שהמנחה נותן בלי הספר הופכת ל**תקדים**, כך שאותה שאלה תקבל בפעם הבאה אותה תשובה.

## 4. לוח הבקרה <!-- icon: party -->

דף במחשב שלך, שנפתח רק בדפדפן של אותו מחשב, וחי כל עוד הצ'אט פתוח. כשהצ'אט נסגר, מוצג בו *Not connected*, והוא חוזר מעצמו עם הצ'אט הבא.

- **חבורה**: דף הדמות שלך ושל בני הלוויה. לוחצים על מספר כדי להטיל אותו, ומרחפים מעליו כדי לראות מאיפה הוא בא. לצדו, ההטלות.
- **סצנה**: איפה אתם, התמונה והמפה שלה, מי נמצא שם, מה קורה. בקרב, התורות וכרטיס הדמות.
- **יומן**: משימות, הסיפור, הפתקים שלך.
- **עולם**: מפת העולם כפי שהדמות מכירה אותו.
- **מגש הקוביות**: בוחרים קוביות ומתאם, ומטילים.
- **שמירות**, **עזרה**, **הגדרות** ו**אודות**, כסמלים בסוף השורה. ההגדרות כוללות גם את ההעדפות של הדף עצמו: ערכת נושא, צליל הקוביות, סט הקוביות.

כשהמנחה שואל אותך משהו, הבאנר שלו נשאר למעלה, בכל מקטע שבו נמצאים.

## 5. מערכות משחק וחוקי בית <!-- icon: dice -->

### 5.1 מהי מערכת משחק

הנתונים של משחק אחד: דף הדמות שלו, המספרים, היצורים, הפריטים, הלחשים וטקסט החוקים. כל קמפיין משחק במערכת אחת. RPG Engine מחשב את דף הדמות ואת מה שהושקע ומה שחוזר. איך תכונה פועלת, המנחה קורא בחוקים ומחליט, כמו ליד שולחן המשחק.

### 5.2 מהדורה חמישית, כלולה

הגזעים, המקצועות, תתי-המקצועות, רקע ויכולת מיוחדת (feat) מתוך ה-SRD 5.1; 319 הלחשים, הנשקים, השריונות, הפריטים הקסומים והמפלצות; פרקי החוקים, שהמנחה קורא לפי הנוסח המדויק שלהם; דף הדמות המלא, מחושב.

אפשר גם לשחק בתוכן שחסר ב-SRD, מתוך ספר שברשותך: המנחה כותב אותו כדפים של הקמפיין, ו-RPG Engine מתייחס אליהם כאל שלו. RPG Engine מגיע רק עם תוכן פתוח; הידע של המנחה אינו מוגבל.

המדריכים שלך יכולים להיות הספרייה שלך: אפשר לומר למנחה איפה הם, *[המדריכים שלי נמצאים ב-D:\Books\5e.]*, או להוסיף את התיקייה שלהם ב-Packages › Library, ולאשר בחלון שהמחשב מציג, פעם אחת. RPG Engine קורא אותם במחשב הזה; כל קמפיין משתמש בתיקיות שהופעלו שם, והמנחה מחפש בהן כשהוא מכריע בחוק, אחרי ה-SRD, ומציין את הספר והעמוד. הם נקראים הכי טוב כטקסט, או כקובצי PDF שאפשר לסמן בהם טקסט; PDF סרוק נקרא מתמונות העמודים שלו, ב-Windows בלבד, בכמה דקות ועם כמה טעויות. RPG Engine לעולם לא משנה את המדריכים שלך, לעולם לא שולח את הטקסט שלהם לשום מקום ולעולם לא מעתיק אותו לקמפיין.

### 5.3 חוקי בית והוספות משלך

אפשר לבקש מהמנחה: *[חוק בית: 1 טבעי בהתקפה אומר שהנשק נופל מהיד.]* המנחה שומר אותו כהסכם של השולחן, או כותב דף או מספר בדף הדמות כשצריך. חוקי בית שכבר כתובים אפשר לשים כקובצי טקסט בתיקיית `rules` של הקמפיין.

### 5.4 הוספה או ייבוא של מערכת משחק משלך

עדיין לא: כיום RPG Engine משחק רק במהדורה החמישית ([בהמשך](#9-coming-later)).

## 7. מאיפה בא קמפיין, ובאיזו שפה <!-- icon: world -->

### 7.1 שלוש דרכים לקבל עולם

- **נבנה תוך כדי משחק**: מהרעיון המוביל שלך, המנחה בונה כל מקום, דמות ועלילה רגע לפני שצריך אותם, ושומר אותם.
- **מוכן מההתחלה**: אותו דבר, כשהעולם נבנה לפני המשחק.
- **מהרפתקה או מספר משלך**: לתת למנחה את הקובץ שלו, *[ייבא את ההרפתקה הזאת כקמפיין שלנו: D:\Books\adventure.pdf. אל תגלה לי שום דבר ממה שכתוב בה.]* הכי טוב לקרוא אותה כטקסט, EPUB, מסמך Word או PDF שאפשר לסמן בו טקסט. PDF סרוק נקרא מתוך תמונות הדפים שלו, רק ב-Windows, לאט ועם כמה טעויות. ה-Codex או ה-Claude Code שלך קורא אותו מחוץ לצ'אט, ואם לא, המנחה בצ'אט, בתוכנית שלך: המסמך כולו נשלח ל-OpenAI או ל-Anthropic, לפי תנאי החשבון שלך והבחירה שלו לגבי אימון. לוח הבקרה מראה כמה כבר נקרא; מתוך רומן, המנחה מציע מאיפה להתחיל. הוא כותב את המקומות, הדמויות והסודות.

קמפיין משחקים פעם אחת: כדי לשחק שוב באותה הרפתקה, יוצרים קמפיין חדש.

### 7.2 שפות

שפה אחת לכל קמפיין, זו של המנחה, ולוח הבקרה עוקב אחריה. לוח הבקרה מגיע עם 26 שפות. כל שפה אחרת מתורגמת במחשב שלך בידי Codex או Claude Code, או, בלעדיהם, בידי המנחה בצ'אט. המונחים של המהדורה החמישית באיטלקית מגיעים מה-SRD האיטלקי הרשמי; טקסט החוקים נשאר באנגלית, והמנחה מספר אותו בשפה שלך.

## 8. למתעניינים: תיקיית הקמפיין <!-- icon: list -->

אין צורך לפתוח אותה לעולם, והיא מכילה את הסודות של הקמפיין. יש בה את `campaign.yaml` (ההגדרות), את `state.yaml` (מצב המשחק), את `world/` (דף markdown אחד לכל דמות, מקום, משימה ושאר הדברים), את `rules/` (חוקי הבית), את `images/`, את `log.jsonl` (כל שינוי), את `.saves/`, את `.player/` (הפתקים שלך), ואת הקבצים הקטנים שמגלים לסוכני AI איפה RPG Engine. הדפים בפורמט של Obsidian. אם משנים דף ביד, המנחה יודע על כך בתשובה הבאה שלו.

RPG Engine נשאר בתיקייה הזאת: הוא קורא וכותב את המשחק רק בה, ואף פעם לא נוגע בקבצים האחרים שלך; את תיקיות המדריכים הוא רק קורא. מחוץ לה הוא שומר רק תיקיות נתונים משלו (התרגומים של הדשבורד, הטקסט שנקרא מהמדריכים, ואת Codex או Claude Code אם מאשרים להתקין אותם) ותיקיות זמניות בזמן שמציירים תמונה. כל דבר אחר שהסוכן רוצה לעשות במחשב, הוא שואל קודם.

כל פקודה שהמנחה משתמש בה אפשר להריץ גם בתיקיית הקמפיין: `rpg --help` מציג את רשימתן. רבות מהן מדפיסות את סודות הקמפיין.

## 10. שאלות ובעיות <!-- icon: info -->

### שאלות

**צריך להכיר את החוקים?** לא. לבחור במנטור הדרכה, ולשאול בסוגריים מתי שרוצים.

**המנחה יכול לרמות?** הוא לא יכול לשנות הטלה ש-RPG Engine ביצע, חוץ מברמת קושי סיפור, ולא עובדות שכבר נקבעו.

**זה עולה כסף?** RPG Engine חינמי. המנחה פועל על התוכנית של הסוכן שלך, או על המחשב שלך עם מודל מקומי. ערב משחק הוא צ'אט ארוך: בתוכניות הקטנות ביותר אפשר להגיע למגבלת התוכנית לפני שהערב נגמר. תמונות, תרגומים וייבוא משתמשים באותה תוכנית. RPG Engine עצמו אף פעם לא משתמש במפתח API, שמשלמים עליו לפי קריאה: להתחבר לסוכן עם החשבון, לא עם מפתח.

**אפשר לשחק בטלפון?** לא: המנחה פועל על המחשב שלך, ולוח הבקרה נפתח רק שם.

**אפשר לשחק עם חברים?** עוד לא: כיום שחקן אחד, דמות אחת, ועוד בני לוויה ([בהמשך](#9-coming-later)).

**אפשר להשתמש ב-AI אחר בפעם הבאה?** כן: לפתוח את הקמפיין בסוכן אחר ולכתוב *המשך*.

### בעיות

**לוח הבקרה לא נפתח.** לשאול את המנחה: `[מה הקישור ללוח הבקרה?]`. הוא עובד רק כשצ'אט פתוח באותו קמפיין, אחרי התשובה הראשונה של המנחה.

**נראה שהמנחה לא מכיר את המשחק.** הסוכן לא טען את RPG Engine. לבדוק שהפעלת אותו בתיקיית הקמפיין ואישרת אמון. ב-Claude Code, לכתוב `/mcp` ולחבר מחדש את `rpg`. ב-Codex, הפקודה `codex mcp list` בתיקיית הקמפיין חייבת להציג את `rpg`. אם `rpg --version` לא נמצא, להתקין את RPG Engine שוב ([2.2](#22-install)).

**עדכון.** להריץ שוב `npm install -g rpg-engine`, ואז לפתוח צ'אט חדש: מנחה שכבר רץ נשאר עם הגרסה שבה התחיל.

**המנחה זוכר משהו שביטלתי.** לפתוח צ'אט חדש וללחוץ על **נפתח צ'אט חדש** ב-שמירות.

**לא מופיעות תמונות.** הגדרות > תמונות אומר אם המחשב הזה יכול להכין אותן, ואיך.

**ההתקנה נכשלת, או ש-`rpg` לא עולה.** `node --version` חייב להראות 22 או חדש יותר. ב-Windows, להרחיק את RPG Engine ואת הקמפיינים מנתיבים שמכילים `&`.

**הקישור ללוח הבקרה השתנה.** תוכנה אחרת תפסה את הכתובת הרגילה; המנחה נותן לך את הקישור החדש.
