# RPG Engine: המדריך המלא

**RPG Engine** מאפשר לשחק משחק תפקידים שולחני עם **בינה מלאכותית בתפקיד המנחה**. מדברים עם המנחה ב**צ'אט**; RPG Engine עובד מאחורי הקלעים: הוא **זוכר את העולם**, **מטיל את הקוביות** ו**מנהל את החשבונות**. לצד הצ'אט משאירים בדפדפן דף פתוח, **הלוח** (dashboard), עם דף הדמות, הקוביות, המפות והיומן.

המדריך הזה מיועד לשחקנים: אין צורך לדעת תכנות.

## התחלה מהירה <!-- icon: send -->

1. להתקין את **Node.js** מהאתר [nodejs.org](https://nodejs.org) (גרסת LTS).
2. להתקין **סוכן בינה מלאכותית**, התוכנה שבה המנחה פועל, ולהתחבר אליו: למשל Claude Code או Codex ([2.4](#24-connect-your-ai)).
3. בטרמינל, להתקין את RPG Engine: `npm install -g rpg-engine`.
4. ליצור קמפיין: `rpg init "The Salt Isles"`.
5. להיכנס לתיקייה החדשה, `cd "The Salt Isles"`, ולהפעיל בה את הסוכן: `claude` עבור Claude Code, `codex` עבור Codex. לאשר כשהוא שואל אם סומכים על התיקייה ([2.4](#24-connect-your-ai)), ואז לכתוב *שלום! בוא נתחיל.* המנחה עונה עם הקישור ללוח.

## 1. מהו RPG Engine <!-- icon: about -->

| מי | מה עושים |
|---|---|
| **אתה** | משחקים את הדמות: מה היא עושה, אומרת ומנסה. |
| **המנחה** (ה־AI) | מספר את הסיפור, מגלם את כל האחרים, מחליט מה קורה, מבקש הטלות. |
| **RPG Engine** | שומר את העולם בקבצים, מטיל את הקוביות, סופר נקודות חיים, כסף, זמן ומרחקים, ושומר סודות עד שמגלים אותם. |

העולם נשאר אותו עולם מערב אחד לשני, גם בצ'אט חדש, וגם עם AI אחר:

- **מה שנאמר נשאר נכון.** נבל שמת נשאר מת.
- **הקוביות אמיתיות.** המנחה לא יכול לעוות אותן, חוץ מברמת הקושי הקלה ביותר, אם בוחרים בה.
- **סודות נשארים סודיים.** המנחה אף פעם לא מגלה מה שהדמות אינה יודעת.
- **העולם ממשיך לזוז.** איומים מתקדמים בזמן מנוחה או מסע, ורואים את האותות שלהם.
- **קמפיין הוא תיקייה** במחשב: אפשר לעצור בכל רגע ולהמשיך מאוחר יותר.

משחק מגיע כמערכת משחק, חבילה שהמנחה מתקין לקמפיין: כיום המערכת שלנו היא **המהדורה החמישית**, מתוך ה־System Reference Document 5.1 החופשי. בלי מערכת משחק משחקים בחופשיות, סיפור בלי מספרים. מערכות נוספות יגיעו ([בהמשך](#9-coming-later)).

## 2. תחילת העבודה <!-- icon: path -->

### 2.1 מה צריך

- מחשב עם Windows, macOS או Linux, ודפדפן אינטרנט.
- **Node.js 22** או חדש יותר, מהאתר [nodejs.org](https://nodejs.org). הוא מביא איתו את `npm`, שמתקין את RPG Engine.
- **טרמינל**: ב-Windows, Terminal או PowerShell; ב-macOS, Terminal. כדי לפתוח טרמינל בתוך תיקייה, לוחצים עליה לחיצה ימנית ובוחרים **Open in Terminal** (ב-Windows) או **Services > New Terminal at Folder** (ב-macOS).
- **סוכן AI** שישמש כמנחה ([2.4](#24-connect-your-ai)), עם **המודל הגדול ביותר** שהוא מציע: קל יותר לשכנע מודל קטן לחשוף סודות או לעקוף את החוקים.

### 2.2 התקנה

```text
npm install -g rpg-engine
```

הפקודה `rpg --version` בודקת שההתקנה הצליחה. משתמשים ב-`rpg` פעם אחת בכל קמפיין, כדי ליצור אותו. אחר כך הסוכן מפעיל את RPG Engine בעצמו.

### 2.3 יצירת קמפיין

פותחים טרמינל בתיקייה שבה שומרים את המשחקים ([2.1](#21-what-you-need) מסביר איך):

```text
rpg init "The Salt Isles"
```

הפקודה יוצרת את התיקייה `The Salt Isles` עם קמפיין חדש בתוכה. נכנסים אליה עם `cd "The Salt Isles"`. כדאי לזכור איפה היא נמצאת: חוזרים אליה בכל פעם שמשחקים. את כל השאר בוחרים אחר כך, בצ'אט או בדשבורד. הפקודה `rpg init --help` מציגה את האפשרויות לבחירת כמה דברים כבר עכשיו, כמו `--language it` או `--difficulty hard`.

המנחה לא יכול ליצור קמפיין במקומך: לפני `init`, שום דבר לא מראה לסוכן איפה RPG Engine נמצא.

### 2.4 חיבור ה-AI

המנחה פועל בתוך **סוכן AI**: אפליקציית AI, בטרמינל או בשולחן העבודה, שיכולה לעבוד עם הקבצים שבמחשב, כמו Claude Code או Codex. צ'אט רגיל כמו claude.ai או ChatGPT, או אפליקציה בטלפון, אינם מספיקים: המנחה צריך לגשת לקבצי הקמפיין שבמחשב. לכל סוכן יש מנוי והתחברות משלו: ל-Claude Code דרוש מנוי בתשלום של Claude, ול-Codex התחברות עם ChatGPT. מתקינים אותו פעם אחת, מהדף שלו: [Claude Code](https://code.claude.com/docs/en/setup), [Codex](https://learn.chatgpt.com/docs/codex/cli).

- **Claude Code**: בתיקיית הקמפיין כותבים `claude`. כשהוא שואל אם לסמוך על התיקייה, בוחרים **Yes, I trust this folder**. זהירות: התשובה שמסומנת מראש היא *No, exit*. לקמפיין יש גם הוק קטן, `rpg --listen`, שהשאלה לא מציגה: הוא מודיע למנחה מיד כשפועלים מהדשבורד.
- **Codex**: בתיקיית הקמפיין כותבים `codex`, ועונים yes כשהוא שואל אם לסמוך על התיקייה. באפליקציית שולחן העבודה שלו, כדאי לבדוק בהגדרות שהזיכרונות כבויים בצ'אטים של המשחק.
- **סוכן אחר**: מפעילים אותו בתיקיית הקמפיין ונותנים לו את שרת ה-MCP `rpg mcp`. RPG Engine הוא שרת MCP סטנדרטי: כל סוכן שתומך ב-MCP יכול להיות המנחה, כולל סוכנים מקומיים.

אנחנו משחקים ובודקים עם **Claude Code**. **Codex** מחובר ונבדק, אבל עוד לא שוחק איתו קמפיין שלם. הקמפיין מכבה את הזיכרון של הסוכן עצמו: המשחק חי בקבצים שלו, כך שחזרה לשמירה באמת מחזירה אחורה.

### 2.5 הצ'אט הראשון

כותבים כל דבר, למשל *שלום! בואו נתחיל.* בתשובה הראשונה בכל צ'אט המנחה נותן את **הקישור לדשבורד**, משהו כמו `http://127.0.0.1:4750`. פותחים אותו ושומרים אותו ליד הצ'אט.

בין ההודעות של המנחה הסוכן מציג את הכלים שהוא משתמש בהם. לא לפתוח את הפרטים שלהם (ב-Claude Code, ctrl+o): הם עלולים לחשוף סודות.

קמפיין חדש עובר שלושה שלבים, שמוצגים בראש הדשבורד: **1 הגדרות** (איך רוצים לשחק), **2 סשן אפס** (יוצרים את הדמות, תוך כדי משחק), **3 משחק**.

### 2.6 הגדרות: בחירת אופן המשחק

המנחה שואל רק את מה שעדיין חסר, כמה שאלות בכל פעם. השלב **הגדרות** בדשבורד מציג את אותן שאלות ככרטיסים. אם כותבים "תחליט/י אתה", המנחה בוחר. אפשר לשנות הכול אחר כך, בצ'אט או ב**הגדרות**.

| הגדרה | מה היא קובעת | ערכים |
|---|---|---|
| **מנטור** | כמה המנחה מלמד אותך את החוקים | off, hints, tutorial |
| **רמת קושי** | עד כמה העולם קשה | story, easy, normal, hard, brutal |
| **קטלניות** | מה המשמעות של נפילה בקרב | narrative (אף פעם לא מתים), epic (רק כשזה משמעותי), dice |
| **שמירות** | מתי אפשר לחזור אחורה | permadeath, checkpoint, free ([3.8](#38-saves-and-going-back)) |
| **קפדנות** | באיזו מידה אוכל, אור ומסעות כפופים לחוקים | smooth, rules, simulation |
| **קוביות** | מי מטיל את הקוביות | digital, physical |
| **יחידות מידה** | מרחקים ומשקלים | metric, imperial |
| **קולות הדמויות** | מי מדבר בשם הדמויות שפוגשים, מהמנחה ועד הדמויות עצמן: המנחה תמיד; ברגעים מרכזיים הדמות עצמה, כשהיא יודעת רק את מה שהיא יודעת, לפי בחירת המנחה; או תמיד הדמות, לדמויות הראשיות או לכולן, לאט ויקר יותר, במקום שבו אפליקציית ה-AI מאפשרת | the master, sometimes, main characters, everyone |
| **בני לוויה** | מי מטייל איתך | none, made with you, made by the master, met in play |
| **תמונות** | תמונות של מקומות, משימות ודמויות שפוגשים | none, on request, new places, quests and those you meet ([3.11](#311-pictures)) |
| **קווים אדומים** ו**וילונות** | מה אף פעם לא מופיע, ומה קורה רק מחוץ למסך | רשימות |
| **שפה** | שפת המשחק ושפת הדשבורד | כל שפה |

המהדורה החמישית מוסיפה **התקדמות**: נקודות ניסיון או אבני דרך.

כשאין עולם כתוב, המנחה שואל גם **תקציר רעיוני** (ז'אנר, אווירה, כמה מרכיבים, במילים שלך) ו**הכנה**: לבנות את העולם תוך כדי משחק, או הכול בהתחלה.

**הסגנון של המנחה** אף פעם לא נשאל, אבל אפשר לשנות אותו בצ'אט או ב**הגדרות**: **הפרוזה** (פשוטה, ספרותית, פאלפ, צינית), **הסיפורים** שהוא ממציא (סיטואציות, קשתות עלילה, פרקים, מסתורין), מחבר לכתוב **בסגנונו**, או כל דבר אחר **במילים שלך**.

### 2.7 סשן אפס: הדמות שלך

יוצרים את הדמות יחד עם המנחה, כמו סביב שולחן משחק. כל בחירה היא שלך, אלא אם מבקשים מהמנחה לבחור: אפשר להגיע עם רעיון מלא, עם רעיון מעורפל או בלי כלום. המנחה מסביר איך נקבעים ערכי היכולות לפני שמוטלת קובייה כלשהי. אין חובה לכתוב סיפור רקע; אם נותנים אחד, המנחה כותב אותו במילים שלך. אחר כך המנחה מבקש תמונה של הדמות ([3.7](#37-your-characters-story-and-picture)). RPG Engine מחשב את דף הדמות: אף פעם לא צריך לעשות חישובים.

## 3. משחק <!-- icon: chat -->

### 3.1 שיחה עם המנחה

כותבים מה הדמות עושה או אומרת, במילים שלך:

> אני שואל את בעל הפונדק מי עוד עבר כאן הערב.

כדי לדבר מחוץ לסיפור, כותבים בין סוגריים מרובעים: *[איך עובדת היאחזות?]* המנחה עונה גם הוא בסוגריים.

אתה אומר מה אתה מנסה לעשות, והמנחה אומר מה קורה. המנחה לעולם לא מחליט בשביל הדמות, ולעולם לא מדבר על המנוע. אפשר לשאול אותו איך משתמשים בלוח הבקרה.

**פעולה מתוך לוח הבקרה**: לוחצים על שם בדף הדמות, כמו נשק, לחש או משהו שהדמות נושאת, ואז על מי שהפעולה מכוונת אליו. אפשר גם ללחוץ על דמות כדי לדבר איתה. לוח הבקרה כותב את המשפט, *אני תוקף את Hooded Bandit 1 עם Mace.*, ואפשר לשנות אותו לפני **לומר למנחה**. המנחה שומע אותו כאילו נאמר בצ'אט, ופוסק לגביו כמו בכל פעולה אחרת. כשאפליקציית ה-AI לא יכולה לשמוע אותו בעצמה, **העתקה** מכינה אותו להדבקה בצ'אט.

### 3.2 הטלות

המנחה מבקש הטלה רק כשהתוצאה אינה ודאית וחשובה, ומספר קודם מה על הכף. אחר כך:

- **בלוח הבקרה**, מופיע כרזה עם כפתור לכל בדיקה, כמו *Acrobatics +4 · with advantage*. לוחצים עליו: הקוביות נופלות על הדף והמנחה שומע את התוצאה. אפשר גם ללחוץ על השורה שנדלקת בדף הדמות, להטיל קוביות מהמגש, או לכתוב משהו אחר בכרזה.
- **ידנית**, בפינת הכרזה או ב**הגדרות**: הכרזה אומרת מה להטיל, וההטלה נעשית מדף הדמות או מהמגש.
- **קוביות פיזיות**, כשהגדרת הקוביות היא פיזיות: כותבים את הערכים שהוטלו, *[הטלתי 14.]*, ו-RPG Engine מוסיף את המתאמים.

**הטלות חופשיות**: לוחצים על כל מספר בדף הדמות, או פותחים את המגש, כדי להטיל להנאה. הן אף פעם לא נספרות, והמנחה אף פעם לא רואה אותן.

**ההטלות של המנחה** מופיעות בעמודת ההטלות שלך, חוץ מהסודיות. תמיד אפשר לשאול *[האם ההטלה ההיא הייתה אמיתית?]*: על הטלה סודית המנחה נותן טביעת אצבע שמוכיחה שההטלה נעשתה לפני ששאלת.

### 3.3 סצנות וקרבות

הסיפור מתנהל ב**סצנות**: קרב, שיחה, חקירה, מסע, מנוחה. בסוף כל סצנה המשחק נשמר מעצמו, והסצנה נכנסת ליומן.

בקרב המנחה מספר על כל תור שאינו שלך, ועוצר איפה שאפשר להחליט. ב**סצנה** מוצג למעלה של מי התור ומי הבא אחריו, וכרטיס הדמות שלך מוצג לצד המפה. סדר התורים, נקודות הפגיעה של החבורה ומצבם של האויבים, במילים, נשארים בצד הדף. אם הדמות נופלת, הטלות ההצלה מול המוות מופיעות בגדול על הדף.

### 3.4 זמן, מסעות והעולם שנע

RPG Engine עוקב אחרי התאריך. בין סשנים לא עובר זמן. אומרים שנחים, *אנחנו נחים מנוחה ארוכה*, וכשהמנחה מסכים, המנוחה מחזירה את מה שצריך. במנוחה קצרה המנחה עשוי לשאול בלוח הבקרה כמה קוביות פגיעה להוציא: מטילים אותן אחת אחת, רואים כמה כל אחת מרפאה, ועוצרים מתי שרוצים. אומרים לאן הולכים, *אנחנו יוצאים בדרך צפונה לרוקה*, ו-RPG Engine מחשב את הדרך, המרחק והימים, ועוצר כשמשהו קורה בדרך. כסף נספר במטבעות המשחק, כולל עודף.

לנבלים יש תוכניות עם מועדים. בכל יום חדש המנחה מקדם את האיומים שהזמן קידם, ורואים את סימניהם, אף פעם לא את השעון עצמו.

### 3.5 מפות

**עולם** מציג את המקומות שהדמות מכירה, את הדרכים ביניהם ואת השביל שנצעד, עם ערפל על השאר. **סצנה** מציגה את מפת המקום שבו נמצאים, כשיש לו מפה, ומי עומד היכן. בקרב, בתור שלך, המשבצות שאי אפשר להגיע אליהן מכוסות. כשהמנחה שואל לאן זזים, נוגעים במשבצת או כותבים אותה, כמו *E4*.

**עולם** גם שומר את מה שהדמות יודעת. **ידע** מפרט את האנשים, המקומות, הפלגים, היצורים והסיפורים שהדמות מכירה, כל אחד כפי שהיא מכירה אותו: אפשר לחפש בו, או לפתוח פריט כדי לקרוא אותו במלואו. שם בטקסט מוביל לדף שלו. **מסמכים** שומרים את המכתבים, ההודעות והדפים שנמצאו, לקריאה חוזרת. **לוח שנה** מציג את היום, את מועדי המשימות עם הזמן שנותר, ואת ימי הסיפור: יום עם סצנות מוביל לפרקים שלו ב**יומן**.

### 3.6 משימות, יומן ופתקים

מטלה שהדמות לוקחת על עצמה הופכת למשימה ב**יומן**, עם המטרות שלה, המועד שלה ומה שהיא מודדת. מסמנים אותה בכוכב כדי להשאיר אותה בולטת בראש הסצנה. היומן גם מספר את **הסיפור**, סצנה אחר סצנה, ושומר את **הפתקים**: פרטיים, אלא אם **לשתף** אחד מהם. המנחה שומע אותו כמחשבה של הדמות, אף פעם לא כעובדה. תחת **בני לוויה** קוראים את היומנים של בני הלוויה: מדי פעם, בסוף יום או משימה, הם כותבים כמה שורות על מה שהם חושבים ומרגישים.

### 3.7 הסיפור והתמונה של הדמות

בדף הדמות, בכרטיס **תיאור** יש תיבה לסיפור של הדמות: המנחה כותב בה אחרי שמאשרים. לתמונה, נותנים למנחה קובץ (PNG, JPEG, WebP או SVG, עד 5 MB) יחד עם המיקום שלו במחשב, או מבקשים ליצור דיוקן ([3.11](#311-pictures)): *[צור לי דיוקן: שיער אפור בצמה, צלקת על הסנטר.]*

### 3.8 שמירות וחזרה אחורה

RPG Engine שומר את כל הקמפיין בסוף כל סצנה. הגדרת **שמירות** קובעת את השאר:

| שמירות | לשמור כשרוצים | לחזור אחורה |
|---|---|---|
| **permadeath** | לא | אף פעם |
| **checkpoint** | לא | לשמירה האחרונה, רק כשהדמות מתה |
| **פנוי** | כן | לכל שמירה |

בכל מצב אפשר **להתחיל מחדש**, מתחילת המשחק או מסשן אפס. עושים זאת בצ'אט או ב**שמירות**.

אחרי חזרה אחורה, **פותחים צ'אט חדש**: הצ'אט הישן זוכר את מה שבוטל. כותבים *המשך* בצ'אט החדש, ואז לוחצים על **נפתח צ'אט חדש** בשמירות.

### 3.9 סשנים: לעצור ולחזור

אפשר לעצור מתי שרוצים: *[בואו נעצור כאן להערב.]* הכול כבר שמור בקבצים. כדי לחזור, מפעילים את הסוכן בתיקיית הקמפיין וכותבים *המשך*: המנחה נותן סיכום קצר וממשיך.

### 3.10 מצב הרוח של המנחה

הרובוט בראש לוח הבקרה הוא המנחה: הפנים שלו עוקבות אחרי הטון של הסיפור, ולעולם לא מגלות את מה שעוד לא ידוע. כשהצ'אט סגור, הוא ישן.

### 3.11 תמונות

RPG Engine יכול ליצור תמונות של המקומות שמגיעים אליהם, של המשימות שלוקחים ושל מי שפוגשים, לפי הגדרת **התמונות**, ואת הדיוקן של הדמות כשמבקשים. הוא משתמש ב-Codex או ב-Claude Code שלך, עם ההתחברות שלך, בתוכנית שלך ובמגבלות שלה: **Codex** מצייר אותן, ואחרת **Claude Code** מצייר אותן. **הגדרות** אומרות אם המחשב הזה יכול ליצור אותן, ואיך להגדיר אם לא. תמיד אפשר לתת למנחה תמונה משלך.

### 3.12 בטיחות: קווים אדומים, וילונות ועצירה

**קווים אדומים** אף פעם לא מופיעים במשחק. **וילונות** קורים רק מחוץ למסך. בכל רגע אפשר לכתוב *[עצור]*: המנחה זונח מיד את התוכן הזה ומוסיף אותו לקווים האדומים שלך.

### 3.13 שינוי החלטה

אפשר לשנות כל הגדרה, בצ'אט או ב**הגדרות**. פסיקה שהמנחה נותן בלי הספר הופכת ל**תקדים**, כך ששאלה זהה תקבל את אותה תשובה בפעם הבאה.

## 4. הלוח <!-- icon: party -->

דף בדפדפן במחשב שלך, שנפתח רק בדפדפן של אותו מחשב ופעיל כל עוד הצ'אט פתוח. כשהצ'אט נסגר, מופיע בו *Not connected*. הוא חוזר מעצמו עם הצ'אט הבא.

- **חבורה**: דף הדמות שלך ודפי הדמות של בני הלוויה. לחיצה על מספר מטילה אותו. מעבר עם העכבר מעליו מראה מאיפה הוא בא, וכשחץ מסמן את הקובייה, מה משפר את ההטלה או מחליש אותה. לידו מופיעות ההטלות.
- **סצנה**: המקום שבו הדמות נמצאת, התמונה והמפה שלו, מי נמצא שם ומה קורה. בקרב: התורות והכרטיס של הדמות.
- **יומן**: משימות, הסיפור, היומנים של בני הלוויה והפתקים שלך.
- **עולם**: מפת העולם, מה שהדמות יודעת, המסמכים שנמצאו ולוח השנה.
- **מגש הקוביות**: בוחרים קוביות ומתאם, ומטילים. ‏×2 מכפיל את הקוביות ולא את המתאם, כמו בפגיעה קריטית.
- **שמירות**, **עזרה**, **הגדרות** ו**אודות**: סמלים בסוף השורה. בהגדרות יש גם את ההעדפות של הדף עצמו: ערכת נושא, צליל הקוביות וסוג הקוביות.

כשהמנחה שואל משהו, הבאנר שלו נשאר בראש הדף, בכל חלק שבו נמצאים.

## 5. מערכות משחק וחוקי בית <!-- icon: dice -->

### 5.1 מהי מערכת משחק

הנתונים של משחק אחד: דף הדמות שלו, המספרים, היצורים, החפצים, הלחשים וטקסט החוקים. כל קמפיין משחק במערכת אחת. RPG Engine מחשב את דף הדמות ואת מה שמוצא וחוזר; איך יכולת עובדת, המנחה קורא בחוקים ומחליט, כמו סביב שולחן.

### 5.2 המהדורה החמישית

הגזעים, המקצועות, תת־המקצועות, רקע וכשרון אחד מתוך ה־SRD 5.1; 319 הלחשים, הנשקים, השריונות, החפצים הקסומים והמפלצות; פרקי החוקים, שהמנחה קורא לפי הנוסח המדויק שלהם; דף הדמות המלא, מחושב.

זו חבילה בפני עצמה: המנחה מציע אותה בעת הגדרת קמפיין ומתקין אותה. קמפיין שמשחק בה מתקין אותה בעצמו בפעם הראשונה שהוא נפתח במחשב שאין בו החבילה, והמנחה מודיע על כך.

אפשר גם לשחק תוכן שחסר ב־SRD, מספר שבבעלותך: המנחה כותב אותו כדפים של הקמפיין, ו־RPG Engine מתייחס אליהם כאל דפים שלו. RPG Engine מגיע רק עם תוכן פתוח; מה שהמנחה יודע אינו מוגבל.

אפשר להפוך את המדריכים שלך לספרייה: לומר למנחה איפה הם, *[המדריכים שלי נמצאים ב־D:\Books\5e.]*, או להוסיף את התיקייה שלהם ב־Packages › Library, ולאשר בחלון שהמחשב מציג, פעם אחת. RPG Engine קורא אותם במחשב הזה; כל קמפיין משתמש בתיקיות שמפעילים שם, והמנחה מחפש בהן כשהוא מכריע בחוק, אחרי ה־SRD, ומציין את הספר והעמוד. הם נקראים הכי טוב כטקסט, או כקובצי PDF שאפשר לבחור בהם טקסט; PDF סרוק נקרא מתמונות העמודים שלו, ב־Windows בלבד, בכמה דקות ועם כמה טעויות. RPG Engine אף פעם לא משנה את המדריכים, לא שולח את הטקסט שלהם לשום מקום ולא מעתיק אותו לקמפיין.

### 5.3 חוקי בית והוספות משלך

אפשר לבקש מהמנחה: *[חוק בית: 1 טבעי בהתקפה אומר שהנשק נופל מהיד.]* המנחה שומר אותו כהסכם של השולחן, או כותב דף או מספר בדף הדמות כשצריך. חוקי בית שכבר כתובים אפשר לשים כקובצי טקסט בתיקיית `rules` של הקמפיין.

### 5.4 הוספה או ייבוא של מערכת משחק משלך

מערכת משחק היא חבילה: המנחה מתקין אותה מ־npm, מתיקייה או מקובץ, ואת זו שאינה שלנו רק באישור שלך, בחלון במחשב. יצירת מערכת כזו היא עבודה של מפתחים, והיא מתוארת במסמכים של RPG Engine ב־GitHub. הפיכת ספר משלך למערכת משחק עדיין אינה זמינה ([בהמשך](#9-coming-later)).

## 7. מאיפה בא קמפיין, ובאיזו שפה <!-- icon: world -->

### 7.1 שלוש דרכים לקבל עולם

- **נבנה תוך כדי משחק**: מהרעיון המוביל שלך, המנחה בונה כל מקום, דמות ועלילה רגע לפני שצריך אותם, ושומר אותם.
- **מוכן מההתחלה**: אותו דבר, כשהעולם נבנה לפני המשחק.
- **מהרפתקה או מספר משלך**: לתת למנחה את הקובץ שלו, *[ייבא את ההרפתקה הזאת כקמפיין שלנו: D:\Books\adventure.pdf. אל תגלה לי שום דבר ממה שכתוב בה.]* הכי טוב לקרוא אותה כטקסט, EPUB, מסמך Word או PDF שאפשר לסמן בו טקסט. PDF סרוק נקרא מתוך תמונות הדפים שלו, רק ב-Windows, לאט ועם כמה טעויות. ה-Codex או ה-Claude Code שלך קורא אותו מחוץ לצ'אט, ואם לא, המנחה בצ'אט, בתוכנית שלך: המסמך כולו נשלח ל-OpenAI או ל-Anthropic, לפי תנאי החשבון שלך והבחירה שלו לגבי אימון. לוח הבקרה מראה כמה כבר נקרא; מתוך רומן, המנחה מציע מאיפה להתחיל. הוא כותב את המקומות, הדמויות והסודות.

קמפיין משחקים פעם אחת: כדי לשחק שוב באותה הרפתקה, יוצרים קמפיין חדש.

### 7.2 שפות

שפה אחת לכל קמפיין, זו של המנחה, ולוח הבקרה עוקב אחריה. לוח הבקרה מגיע עם 26 שפות. כל שפה אחרת מתורגמת במחשב שלך בידי Codex או Claude Code, או, בלעדיהם, בידי המנחה בצ'אט. המונחים של המהדורה החמישית באיטלקית מגיעים מה-SRD האיטלקי הרשמי; טקסט החוקים נשאר באנגלית, והמנחה מספר אותו בשפה שלך.

## 8. למתעניינים: תיקיית הקמפיין <!-- icon: list -->

אין צורך לפתוח אותה לעולם, והיא מכילה את הסודות של הקמפיין. יש בה את `campaign.yaml` (ההגדרות), את `state.yaml` (מצב המשחק), את `world/` (דף markdown אחד לכל דמות, מקום, משימה ושאר הדברים), את `rules/` (חוקי הבית), את `images/`, את `log.jsonl` (כל שינוי), את `.saves/`, את `.player/` (הפתקים שלך), ואת הקבצים הקטנים שמגלים לסוכני AI איפה RPG Engine. הדפים בפורמט של Obsidian. אם משנים דף ביד, המנחה יודע על כך בתשובה הבאה שלו.

RPG Engine נשאר בתיקייה הזאת: הוא קורא וכותב את המשחק רק בה, ואף פעם לא נוגע בקבצים האחרים שלך; את תיקיות המדריכים הוא רק קורא. מחוץ לה הוא שומר רק תיקיות נתונים משלו (התרגומים של הדשבורד, הטקסט שנקרא מהמדריכים, ואת Codex או Claude Code אם מאשרים להתקין אותם) ותיקיות זמניות בזמן שמציירים תמונה. כל דבר אחר שהסוכן רוצה לעשות במחשב, הוא שואל קודם.

כל פקודה שהמנחה משתמש בה אפשר להריץ גם בתיקיית הקמפיין: `rpg --help` מציג את רשימתן. רבות מהן מדפיסות את סודות הקמפיין.

## 10. שאלות ובעיות <!-- icon: info -->

### שאלות

**צריך להכיר את החוקים?** לא. לבחור במנטור הדרכה, ולשאול בסוגריים מתי שרוצים.

**המנחה יכול לרמות?** הוא לא יכול לשנות הטלה ש-RPG Engine ביצע, חוץ מברמת קושי סיפור, ולא עובדות שכבר נקבעו.

**זה עולה כסף?** RPG Engine חינמי. המנחה פועל על התוכנית של הסוכן שלך, או על המחשב שלך עם מודל מקומי. ערב משחק הוא צ'אט ארוך: בתוכניות הקטנות ביותר אפשר להגיע למגבלת התוכנית לפני שהערב נגמר. תמונות, תרגומים וייבוא משתמשים באותה תוכנית. RPG Engine עצמו אף פעם לא משתמש במפתח API, שמשלמים עליו לפי קריאה: להתחבר לסוכן עם החשבון, לא עם מפתח.

**אפשר לשחק בטלפון?** לא: המנחה פועל על המחשב שלך, ולוח הבקרה נפתח רק שם.

**אפשר לשחק עם חברים?** עוד לא: כיום שחקן אחד, דמות אחת, ועוד בני לוויה ([בהמשך](#9-coming-later)).

**אפשר להשתמש ב-AI אחר בפעם הבאה?** כן: לפתוח את הקמפיין בסוכן אחר ולכתוב *המשך*.

### בעיות

**לוח הבקרה לא נפתח.** לשאול את המנחה: `[מה הקישור ללוח הבקרה?]`. הוא עובד רק כשצ'אט פתוח באותו קמפיין, אחרי התשובה הראשונה של המנחה.

**נראה שהמנחה לא מכיר את המשחק.** הסוכן לא טען את RPG Engine. לבדוק שהפעלת אותו בתיקיית הקמפיין ואישרת אמון. ב-Claude Code, לכתוב `/mcp` ולחבר מחדש את `rpg`. ב-Codex, הפקודה `codex mcp list` בתיקיית הקמפיין חייבת להציג את `rpg`. אם `rpg --version` לא נמצא, להתקין את RPG Engine שוב ([2.2](#22-install)).

**עדכון.** להריץ שוב `npm install -g rpg-engine`, ואז לפתוח צ'אט חדש: מנחה שכבר רץ נשאר עם הגרסה שבה התחיל.

**המנחה זוכר משהו שביטלתי.** לפתוח צ'אט חדש וללחוץ על **נפתח צ'אט חדש** ב-שמירות.

**לא מופיעות תמונות.** הגדרות > תמונות אומר אם המחשב הזה יכול להכין אותן, ואיך.

**ההתקנה נכשלת, או ש-`rpg` לא עולה.** `node --version` חייב להראות 22 או חדש יותר. ב-Windows, להרחיק את RPG Engine ואת הקמפיינים מנתיבים שמכילים `&`.

**הקישור ללוח הבקרה השתנה.** תוכנה אחרת תפסה את הכתובת הרגילה; המנחה נותן לך את הקישור החדש.
