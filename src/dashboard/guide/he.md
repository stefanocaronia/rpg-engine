# RPG Engine: המדריך המלא

**RPG Engine** מאפשר לשחק משחק תפקידים שולחני עם **בינה מלאכותית בתור מנחה**.

מדברים עם המנחה ב**צ'אט**: המנחה מספר את הסיפור, מגלם את כל השאר ופוסק מה קורה.

RPG Engine עובד מאחורי הקלעים: הוא **זוכר את העולם**, **מטיל את הקוביות** ו**מנהל את החשבונות**.

לצד הצ'אט משאירים בדפדפן דף פתוח, **לוח הבקרה**, עם דף הדמות, הקוביות, המפות והיומן.

המדריך מיועד לשחקנים. אין צורך לדעת תכנות.

## התחלה מהירה <!-- icon: send -->

1. להתקין את **Node.js** מ-[nodejs.org](https://nodejs.org) (גרסת ה-LTS).
2. להתקין את **Claude Code** או את **Codex**, אפליקציית הבינה המלאכותית שהמנחה רץ בתוכה, ולהתחבר ([2.4](#24-connect-your-ai)).
3. לפתוח טרמינל ולהתקין את RPG Engine: `npm install -g rpg-engine`.
4. בטרמינל, ליצור קמפיין: `rpg init "The Salt Isles"`.
5. לפתוח את Claude Code או את Codex בתיקייה החדשה ולכתוב *שלום! בוא נתחיל.* המנחה עונה עם הקישור ללוח הבקרה: לפתוח אותו לצד הצ'אט.

בהמשך המדריך מוסבר כל שלב, ואחר כך איך משחקים.

## 1. מהו RPG Engine <!-- icon: about -->

### מי עושה מה

| מי | מה הוא עושה |
|---|---|
| **אתה** | משחק את הדמות. אומר מה היא עושה, אומרת ומנסה. |
| **המנחה** (הבינה המלאכותית) | מספר את הסיפור, מגלם כל דמות אחרת, מחליט מה קורה, מבקש הטלות. |
| **RPG Engine** | זוכר הכול בקבצים, מטיל את הקוביות, סופר נקודות חיים, כסף, זמן ומרחקים, ושומר סודות עד שמגלים אותם. |

בינה מלאכותית טובה בסיפור סיפורים וגרועה בזכירה. בלי עזרה היא שוכחת מי חייב לך כסף, כמה חיצים נשארו לך, או שהגשר נשרף לפני שני סשנים. RPG Engine שומר את כל זה, ולכן העולם נשאר זהה מערב לערב, גם בצ'אט חדש ואפילו עם בינה מלאכותית אחרת.

### איך זה מרגיש

כותבים בצ'אט כמו שמדברים סביב שולחן:

> אני דוחף את הדלת לאט ומציץ פנימה.

המנחה עונה במה שרואים, ועוצר כשמגיע הרגע לבחור. כשמשהו לא ברור וחשוב, המנחה אומר מה על הכף ומבקש הטלה. כפתורי ההטלה מופיעים בלוח הבקרה. לוחצים, הקוביות נופלות על הדף, והמנחה מספר מה קורה.

### מה מייחד אותו

- **העולם קבוע.** מה שנאמר נשאר נכון. נבל שמת נשאר מת.
- **הקוביות אמיתיות.** המנחה לא יכול לעקם אותן (חוץ מברמת הקושי הקלה ביותר, אם בוחרים בה).
- **סודות נשארים סודות.** המנחה לא מגלה מה שהדמות לא יודעת, גם אם מתעקשים.
- **העולם ממשיך לנוע גם בלעדיך.** איומים מתקדמים בזמן מנוחה או מסע, ורואים את הסימנים שלהם.
- **הרבה ערבים, סיפור אחד.** קמפיין הוא תיקייה במחשב. אפשר לעצור מתי שרוצים ולהמשיך אחר כך.

### המשחק שזמין היום

RPG Engine נבנה לכל משחק תפקידים שולחני. היום מגיע איתו מערכת משחק אחת: **המהדורה החמישית** (מתוך System Reference Document 5.1 החופשי). משחקים נוספים יגיעו. ראו [מערכות משחק](#5-game-systems-and-house-rules) ו[בקרוב](#9-coming-later).

## 2. תחילת העבודה <!-- icon: path -->

### 2.1 מה צריך

- מחשב עם Windows, macOS או Linux.
- **Node.js 22** ומעלה. להוריד מ-[nodejs.org](https://nodejs.org): גרסת "LTS" מתאימה. היא כוללת את `npm`, שמתקין את RPG Engine.
- **טרמינל**, החלון שבו כותבים פקודות: ב-Windows, אפליקציית Terminal או PowerShell; ב-macOS, Terminal. משתמשים בו כדי להתקין את RPG Engine, ליצור כל קמפיין ולהפעיל את Claude Code או את Codex.
- **אפליקציית AI**, האפליקציה שהמנחה פועל בתוכה: **Claude Code** או **Codex**, עם התוכנית וההתחברות שלה. ראו [2.4](#24-connect-your-ai).
- **המודל הגדול ביותר** שהאפליקציה מציעה. מודל קטן נותן להערים עליו: בבדיקות שלנו הוא סיפר סודות לשחקן שטען שהוא המנחה האמיתי.
- דפדפן, בשביל הדשבורד.

ההתחברות לאפליקציית ה-AI משמשת גם למשהו נוסף: RPG Engine משתמש בה, על המחשב שלך, כדי לצייר תמונות של מקומות, משימות, דמויות שפוגשים והדמות שלך, וכדי לתרגם את הדשבורד לשפות שאינן כלולות בו. ראו [תמונות](#311-pictures) ו-[שפות](#72-languages).

**איך פותחים טרמינל בתוך תיקייה.** שלבים רבים אומרים "בתיקיית הקמפיין". ב-Windows, לוחצים קליק ימני על התיקייה ב-File Explorer ובוחרים **פתיחה בטרמינל**. ב-macOS, לוחצים קליק ימני על התיקייה ב-Finder ובוחרים **שירותים > טרמינל חדש בתיקייה**. אפשר גם, בטרמינל שכבר פתוח, לכתוב `cd` ואת נתיב התיקייה, כמו `cd "C:\Users\me\Games\The Salt Isles"`.

### 2.2 התקנה

לפתוח טרמינל ולכתוב:

```text
npm install -g rpg-engine
```

הפקודה הזו נותנת את הפקודה `rpg`. כדי לבדוק שההתקנה הצליחה:

```text
rpg --version
```

משתמשים ב-`rpg` פעם אחת לכל קמפיין, כדי ליצור אותו. אחר כך רק מדברים עם המנחה: אפליקציית ה-AI מפעילה את RPG Engine בעצמה, עם אותה פקודת `rpg`.

### 2.3 יצירת קמפיין

קמפיין הוא תיקייה. לפתוח טרמינל בתיקייה שבה שומרים את המשחקים, ולכתוב:

```text
rpg init "The Salt Isles"
```

הפקודה יוצרת את התיקייה `The Salt Isles` עם קמפיין חדש בתוכה, ואומרת מה לעשות הלאה:

```text
Created the campaign "The Salt Isles" in C:\Users\me\Games\The Salt Isles.
To play, open Claude Code or Codex in this folder and say hello: the master asks you the rest.

For the master: Still to agree with the player: ...
```

השורות שאחרי *For the master* מיועדות למנחה, שקורא אותן בצ'אט: אין בהן צורך בשום פעולה מצדך. כדאי לזכור היכן התיקייה: חוזרים אליה בכל פעם שמשחקים. בלי שם תיקייה, `rpg init` הופך את התיקייה הנוכחית לקמפיין.

`init` יוצר כל מה שהקמפיין צריך: את ההגדרות שלו, את תיקיות העולם, ואת הקבצים הקטנים שאומרים לאפליקציית ה-AI להשתמש ב-RPG Engine ולא לשמור זיכרון משלה מחוץ לקמפיין.

אין צורך לבחור כלום עכשיו. המנחה שואל את השאר בצ'אט, או שאפשר לבחור בדשבורד. מי שכבר יודע מה הוא רוצה יכול לציין זאת כאן:

```text
rpg init salt-isles --name "The Salt Isles" --language en --system 5e --difficulty normal --lethality dice
```

הפקודה יוצרת את התיקייה `salt-isles`, ובתוכה את הקמפיין *The Salt Isles*: שם תיקייה בלי רווחים, ושם קמפיין כרצונך.

| אפשרות | מה היא קובעת | ערכים |
|---|---|---|
| `--name` | שם הקמפיין | כל שם; שם התיקייה אם משמיטים |
| `--language` | שפת המשחק | קוד, כמו `en`, `it`, `fr` |
| `--system` | מערכת המשחק | `5e`, כרגע היחידה |
| `--difficulty` | עד כמה העולם קשה | `story`, `easy`, `normal`, `hard`, `brutal` |
| `--lethality` | מה משמעות הנפילה בקרב | `narrative`, `epic`, `dice` |

גם `rpg init --help` מציג אותן. אי אפשר ליצור קמפיין בתוך תיקייה של קמפיין אחר.

אי אפשר לבקש מהמנחה ליצור קמפיין: לפני `init`, אין בתיקייה שום דבר שאומר לאפליקציית ה-AI איפה RPG Engine.

### 2.4 חיבור ה-AI

RPG Engine עובד עם **Claude Code** ועם **Codex**. אפליקציות AI אחרות שתומכות בכלי MCP אולי יעבדו גם, אבל איננו מבטיחים זאת.

**התקנת האפליקציה.** Claude Code ו-Codex רצים בטרמינל: הם אינם אפליקציית Claude או ChatGPT שבטלפון. לכל אחד דרושות תוכנית והתחברות משלו: ל-Claude Code תוכנית Claude בתשלום, ל-Codex התחברות ל-ChatGPT. יש לפעול לפי הדפים שלהם כדי להתקין ולהתחבר: [Claude Code](https://code.claude.com/docs/en/setup) ו-[Codex](https://learn.chatgpt.com/docs/codex/cli). עושים זאת פעם אחת, לכל הקמפיינים.

**Claude Code.** לפתוח טרמינל בתיקיית הקמפיין ולכתוב `claude`. בפעם הראשונה הוא שואל אם סומכים על התיקייה, ואומר שהתיקייה מתירה את כלי המשחק (`mcp__rpg`): לבחור **Yes, I trust this folder**. זהירות: התשובה שמסומנת מראש היא *No, exit*, ולכן לחיצה מיידית על Enter סוגרת את Claude Code. זה הכול: הקמפיין כבר אמר ל-Claude Code להשתמש ב-RPG Engine ובכלים שלו, ולכבות את הזיכרון שלו.

**Codex.** לפתוח טרמינל בתיקיית הקמפיין ולכתוב `codex`. כשהוא שואל אם סומכים על התיקייה, עונים כן: ההגדרות של הקמפיין אומרות ל-Codex איפה RPG Engine, מתירות את הכלים שלו ומכבות את הזיכרון שלו, ו-Codex קורא אותן רק בתיקייה שסומכים עליה. באפליקציית שולחן העבודה, יש לוודא שהזיכרונות כבויים בצ'אטים של המשחק.

**למה הזיכרון חשוב.** הקמפיין חי בקבצים שלו. אם האפליקציה גם זוכרת דברים בעצמה, חזרה לשמירה לא תהיה חזרה אמיתית: המנחה עדיין יזכור את מה שבוטל.

### 2.5 הצ'אט הראשון

לכתוב משהו, למשל:

> היי! בואו נתחיל.

המנחה קורא איפה המשחק עומד ועונה. בתשובה הראשונה בכל צ'אט הוא נותן את **הקישור לדשבורד** (משהו כמו `http://127.0.0.1:4750`). לפתוח אותו בדפדפן ולהשאיר ליד הצ'אט לאורך כל המשחק. כל קמפיין שומר על אותו קישור מצ'אט לצ'אט, אלא אם תוכנה אחרת תפסה אותו: אז המנחה נותן את החדש.

בין ההודעות של המנחה, האפליקציה מראה את הכלים שהמנחה משתמש בהם, בשורות קצרות. לא לפתוח את הפרטים שלהם (ב-Claude Code, ctrl+o): הם עלולים להראות מה שהמנחה כותב, כולל סודות.

קמפיין חדש עובר שלושה שלבים, כמו משחק עם מנחה אנושי. הדשבורד מראה אותם בראש הדף: *1 הגדרות · 2 סשן אפס · 3 משחק*:

1. **הגדרות**: בוחרים איך רוצים לשחק. מחוץ לסיפור.
2. **סשן אפס**: יוצרים את הדמות, תוך כדי משחק.
3. **משחק**: הסיפור.

### 2.6 הגדרות: בחירת אופן המשחק

המנחה שואל רק את מה שעדיין חסר, כמה שאלות בכל פעם. כשכותבים "תחליט", המנחה בוחר ואומר במה בחר. כשהדשבורד פתוח, השלב הראשון שלו, **הגדרות**, מראה את אותן שאלות ככרטיסים: שאלה אחת בכל פעם, כל ערך עם משמעותו, והרגיל מסומן **מומלץ**. בוחרים שם, והמנחה לא ישאל שוב בצ'אט; **דילוג** משאיר שאלה למאוחר יותר. הצ'אט מסדיר את מה שרק מילים יכולות: הנחת היסוד של עולם חדש, השפה, והתמונות, שעליהן המנחה שואל רק אם המחשב מסוגל ליצור אותן. לכן הדף שואל פחות שאלות ממה שהטבלה שלהלן מונה.

אין צורך ללמוד את הטבלה: היא נועדה לעיון. אפשר לשנות כל אחת מההגדרות האלה אחר כך, בצ'אט או ב**הגדרות** של הדשבורד. שינוי נכנס לתוקף מהתשובה הבאה של המנחה.

| הגדרה | מה היא קובעת | ערכים | מומלץ |
|---|---|---|---|
| **מנטור** (נשאל כ"כמה טוב אתם מכירים את המשחק?") | כמה המנחה מלמד את החוקים, מחוץ לסיפור | **כבוי** (הסיפור בלבד; שואלים בסוגריים כשרוצים), **רמזים** (עצה קצרה לפני בחירות חשובות וכשחוק חומק), **הדרכה** (כל חוק מוסבר בפעם הראשונה, כל החישוב של כל הטלה, סיכום קצר אחרי קרבות) | לפי התשובה: מעולם לא שיחקתי → הדרכה, קצת → רמזים, אני מכיר → כבוי |
| **רמת קושי** | עד כמה העולם קשה: קרבות, טקטיקות האויבים, רמזים, אוצר, מהירות התקדמות האיומים | סיפורי, קל, רגיל, קשה, אכזרי | |
| **קטלניות** | מה משמעות הנפילה בקרב | **סיפורית** (הדמות לא מתה לעולם), **אפית** (מתה רק כשזה חשוב לסיפור), **קוביות** (הקוביות מחליטות) | נגזרת מרמת הקושי: סיפורי → סיפורית, קל → אפית, רגיל ומעלה → קוביות |
| **שמירות** | מתי מותר לחזור אחורה | **מוות לצמיתות** (אף פעם; אפשר רק להתחיל את הקמפיין מחדש), **נקודת ביקורת** (חזרה לסוף הסצנה האחרונה, רק אם הדמות מתה), **חופשי** (חזרה לכל שמירה, ושמירה בכל פעם שמבקשים) | נקודת ביקורת |
| **קפדנות** | עד כמה אוכל, אור, עייפות, משקל נשיאה, רכיבי כישוף ומסעות מקפידים על החוקים | **חלק** (המנחה מדלג עליהם), **חוקים** (כמו שכתוב: לפידים כבים, אספקה נגמרת), **הדמיה** (מעבר לחוקים: בלאי, התקלקלות, מזג אוויר) | חלק |
| **קוביות** | מי מטיל את קוביות הדמות | **דיגיטלי** (RPG Engine מטיל, בדף), **פיזי** (מטילים בעצמכם ומדווחים על התוצאה) | |
| **יחידות מידה** | מרחקים ומשקלים בסיפור | מטרי, אימפריאלי | |
| **בני לוויה** | מי מטייל איתך | אין, נוצרים איתך בסשן אפס, נוצרים בידי המנחה, נפגשים במשחק | |
| **תמונות** | תמונות של מקומות, משימות ומי שפוגשים, ודיוקן הדמות כשמבקשים | אין, לפי בקשה, מקומות חדשים, משימות ומי שפוגשים | נשאל פעם אחת, רק אם המחשב מסוגל ליצור אותן |
| **קווים אדומים** | מה לא מופיע במשחק לעולם | רשימה, או כלום | |
| **וילונות** | מה יכול לקרות, אבל רק מחוץ למסך | רשימה, או כלום | |
| **שפה** | שפת המשחק והדשבורד | כל שפה | נלקחת מאופן הכתיבה, ומאושרת |

מערכת המשחק יכולה להוסיף הגדרות משלה. המהדורה החמישית מוסיפה **התקדמות**: איך הדמות עולה ברמה, עם **נקודות ניסיון** או ב**אבני דרך** של הסיפור.

**מה משמעות רמת הקושי במשחק.** סיפורי: אויבים חלשים ותמימים, רמזים ברורים, שפע מכל דבר; המנחה רשאי לרכך את ההטלות של עצמו. קל: אויבים פשוטים, משאבים נדיבים. רגיל: אויבים הגיוניים, שלושה רמזים לכל מסקנה, מחירים ואוצר סטנדרטיים. קשה: אויבים חכמים, רמזים עדינים, משאבים מועטים, איומים שמתקדמים מהר. אכזרי: אויבים שמארבים, נסוגים ומגמרים את הנופלים, משאבים מועטים מאוד, המנוחות הקשות ביותר. הקרבות תמיד מותאמים לחבורה כפי שהיא עכשיו.

**כשאין עולם כתוב**, ההכנה שואלת שני דברים נוספים:

- **הנחת יסוד**: הז'אנר, הטון וכמה מרכיבים של העולם, במילים שלך. למשל: *"פנטזיה נמוכה, קודרת אבל עם תקווה. עיירה על נהר, מעבר מוכה רוחות, כת בגבעות."*
- **הכנה**: **תוך כדי תנועה** (המנחה בונה כל חלק של העולם רגע לפני שצריכים אותו; מומלץ) או **הכול בהתחלה**.

אחר כך המנחה מציע שם לקמפיין. כשלא חסר דבר ואומרים שמוכנים, המשחק עובר לסשן אפס.

**הסגנון של המנחה** לא נשאל לעולם: אפשר לשנות אותו מתי שרוצים, בצ'אט או ב**הגדרות**, שם יש לו קבוצה משלו. הטון נשאר בהנחת היסוד; הסגנון הוא האופן שבו מספרים.

- **פרוזה**: **פשוטה** (משפטים קצרים, פרט קונקרטי אחד בכל פעם; הרגילה), **ספרותית** (יותר מקום בשיאים), **פאלפ** (מתוח, חי, קצר, וכל הודעה מסתיימת באיום או בקרס) או **אירונית** (מספר עם חצי חיוך כלפי העולם, אף פעם לא כלפי הדמות).
- **סיפורים**, למה שהמנחה ממציא, אף פעם לא להרפתקה כתובה: **מצבים** (פלגים, איומים ומקומות עם סודות, בלי עלילה מרכזית; הרגיל), **קשתות** (איום מרכזי שמתקדם בשלבים), **פרקים** (סיפור שנסגר בכל סשן) או **תעלומה** (כל סיפור הוא חקירה, והאמת שלו נקבעת קודם).
- **לכתוב כמו**: סופר שדרך הסיפור שלו המנחה מאמץ במקום הפרוזה: הקצב שלו והפרטים שהוא בוחר, אף פעם לא המשפטים, השמות או המקומות שלו, ואף פעם לא יותר ממה שהדמות רואה.
- **במילים שלך**: כל דבר אחר, בכמה מילים, כמו *"גוף שלישי, זמן עבר"*. המנחה מספר בגוף שני, בזמן הווה, אלא אם מבקשים אחרת.

### 2.7 סשן אפס: הדמות שלך

סשן אפס הוא משחק: יוצרים את הדמות יחד עם המנחה, כמו סביב שולחן.

- **כל בחירה היא שלך**, אלא אם מבקשים מהמנחה לבחור. אפשר לבוא עם רעיון מלא ("חצי-אלף כוהן שעזב את המקדש שלו"), עם רעיון מעורפל ("מישהו שמרפא, אבל לא נחמד בזה"), או עם כלום ("תפתיע אותי, ואז תן לי לשנות").
- **ערכי תכונות.** המנחה אומר מהי השיטה ומהי רשת הביטחון לפני שמוטלת קובייה כלשהי. במהדורה החמישית: המערך הסטנדרטי, קניית נקודות, או 4d6 בלי הנמוכה. השיטה שמסכימים עליה נשארת בהסכמות השולחן.
- **הסיפור שלך** לעולם אינו חובה. אם נותנים סיפור, המנחה כותב אותו במילים שלך, מקריא אותו פעם אחת, וקושר את האנשים והמקומות שבו אל העולם. אפשר גם לכתוב אותו בדשבורד (ראו [חבורה](#party)).
- **אישיות** (מהדורה חמישית): תכונה, אידיאל, קשר ופגם, מהטבלאות של הרקע או משלך.
- **תמונה.** אחרי שהדמות נוצרה, המנחה מבקש תמונה שלה: קובץ מהמחשב, או דיוקן שנוצר על המחשב לפי התיאור (ראו [התמונה של הדמות](#37-your-characters-story-and-picture)).

המספרים בדף הדמות מחושבים על ידי RPG Engine לפי הבחירות: אף פעם לא צריך לעשות חשבונות. כשהדמויות נוצרו ומאשרים, הסיפור מתחיל.

## 3. משחק <!-- icon: chat -->

### 3.1 שיחה עם המנחה

לכתוב מה הדמות עושה או אומרת, במילים שלך. קצר זה בסדר.

> אני שואל את בעל הפונדק מי עוד עבר כאן הערב.
>
> "לא באנו לצרות", אני אומר, והיד רחוקה מהחרב.
>
> אני מטפס על הגג וממתין.

**מחוץ לסיפור**, כותבים בסוגריים מרובעים:

> [איך עובדת אחיזה?]
>
> [אפשר עוד להשתמש בתגובה שלי בסבב הזה?]
>
> [נעצור כאן להערב.]

המנחה עונה גם הוא בסוגריים מרובעים, ואז חוזר לסיפור.

**אתה אומר מה אתה מנסה; המנחה אומר מה קורה.** דבר ששובר את ההיגיון של העולם או עובדות שכבר נקבעו לא קורה: המנחה אומר זאת, בתוך הסיפור, ומציע מה אפשרי.

**המנחה אף פעם לא מחליט בשביל הדמות.** הוא לא יגרום לה לדבר, להרגיש או לבחור. במקרה של ספק, הוא שואל.

**המנחה אף פעם לא מדבר על המנוע.** אם שואלים אותו אם הוא עוקב אחרי הדברים, הוא עונה כמו מנחה: "אני שומר הכול: ממשיכים מכאן בפעם הבאה."

**אפשר לשאול את המנחה איך משתמשים בדשבורד.** הוא מכיר את הדף: "איפה אני רואה את הכישופים שלי?", "איך מטילים ידנית?"

### 3.2 הטלות

**מתי יש הטלה.** המנחה מבקש הטלה רק כשהתוצאה לא ודאית וחשובה. אחרת הוא אומר כן, או "כן, אבל". לפני ההטלה, המנחה אומר מה על הפרק ואילו בדיקות מתאימות, ועוצר. אתה מטיל, או משנה את דעתך:

> **מנחה:** הכרכוב צר ורטוב. אם תחליק, תיפול רחוק אל הנהר. בדיקת זריזות (אקרובטיקה), או שאפשר לחזור ולחפש את המדרגות.
>
> **אתה:** אנסה.

**הטלה בדשבורד.** כשהמנחה מבקש, מופיע בראש הדף באנר עם כפתור לכל בדיקה, למשל *אקרובטיקה +4 · עם יתרון*. ללחוץ עליו: הקוביות נופלות בדף, והמנחה שומע את התוצאה. אפשר גם:

- ללחוץ על השורה המתאימה בדף הדמות, והיא מוארת בזהב;
- להטיל את הקוביות המתאימות מהמגש;
- לכתוב מילים משלך בבאנר במקום, אם רוצים לעשות משהו אחר.

**הטלה ידנית.** מי שמעדיף לבחור את הקוביות בעצמו יכול להפעיל **ידנית** בפינת הבאנר (או ב**הגדרות**). כפתור הבדיקה נעלם, והבאנר אומר מה להטיל כמו שמנחה היה אומר: *הטל אקרובטיקה בעצמך, בדף הדמות או עם הקוביות.* ללחוץ על השורה שמוארת בדף הדמות, או להטיל את הקוביות המתאימות מהמגש: RPG Engine מטיל אותן, מוסיף את המתאם והמנחה שומע את התוצאה. בדיקה שלא הדף ולא המגש יכולים לבצע, כמו נזק שמטיל מחדש 1-ים, שומרת על הכפתור שלה. **ידנית** נשאר פעיל בדפדפן הזה עד שמכבים אותו.

**קוביות פיזיות לכל המשחק.** כשהגדרת **קוביות** על פיזיות, המנחה מבקש את ההטלות במילים וכותבים את התוצאות שיצאו:

> [הטלתי 14.]

RPG Engine מוסיף את המתאמים ודוחה תוצאה שהקוביות אינן יכולות להראות.

**הטלות חופשיות.** ללחוץ על כל מספר בדף הדמות, או לפתוח את מגש הקוביות, כדי להטיל סתם בשביל הכיף. הטלות חופשיות אף פעם לא נחשבות, אף פעם לא נרשמות, והמנחה אף פעם לא רואה אותן. 20 חופשי לא הופך לאמיתי אחר כך.

**ההטלות של המנחה.** המנחה מטיל עבור אויבים ואחרים גם הוא עם RPG Engine. רוב ההטלות מוצגות בעמודת ההטלות. כשאסור לראות תוצאה, המנחה מטיל בסוד. תמיד אפשר לשאול:

> [ההטלה הזאת הייתה אמיתית?]

על הטלה גלויה, המנחה נותן את המספרים והסיבה. על הטלה סודית, טביעת אצבע שמוכיחה שההטלה נעשתה לפני ששאלו.

**הטלות בצ'אט** מופיעות בסוגריים מרובעים, מיד אחרי הרגע שהן מכריעות: *[שכנוע 14 + 3 = 17]*. אחר כך הסיפור מספר את התוצאה.

### 3.3 סצנות וקרבות

המנחה מנהל את הסיפור ב**סצנות**: קרב, שיחה, חקירה, מסע, מנוחה, אתגר (מרדף, מרוץ, חידה). אין צורך לנהל אותן: כך RPG Engine שומר את פרקי הסיפור. בסוף כל סצנה המשחק נשמר מעצמו, והסצנה נכנסת לסיפור שביומן.

**בקרב**, המנחה מספר את כל התורות שאינן שלך, בזו אחר זו, עם כל הטלה, ו**עוצר איפה שאפשר להחליט**: התור שלך, תגובה, בחירה. בתור שלך, אומרים מה עושים:

> אני מטיל להבה קדושה על זה שליד הדלת.

מדור **קרב** בדשבורד מציג את סדר התורות, של מי התור, את נקודות הפגיעה של החבורה, ועד כמה האויבים נראים פצועים (בריא, פצוע, מדמם, נפל: במילים, לעולם לא במספרים). אם הדמות נופלת, הצלות המוות מופיעות בגדול בדף.

**כשהקרב כבר הוכרע**, המנחה יכול להציע לספר את השאר בהודעה אחת.

### 3.4 זמן, מסעות ועולם שנע

**זמן.** כל פעולה לוקחת זמן בסיפור, ו-RPG Engine שומר את התאריך: יום 3, בוקר מוקדם. המנחה מספר את הזמן כפי שהעולם מודד אותו: עלות השחר, הפעמון השלישי, רדת הלילה. בין סשנים לא עובר זמן: ממשיכים מהמקום שבו נעצרו.

**מנוחות.** אומרים שנחים, והמנחה מחיל את מה שמנוחה מחזירה, כמו נקודות פגיעה ותאי כישוף:

> אנחנו מקימים מחנה ונחים מנוחה ארוכה.

**מסעות.** אומרים לאן רוצים ללכת:

> אנחנו לוקחים את הדרך צפונה אל רוקה.

RPG Engine מחשב את הדרך, את המרחק ואת הימים לפי הקצב שלכם, ומעביר אתכם לשם. מסע נעצר כשקורה בדרך משהו מתוכנן, בסוף המסע של כל יום, ובהגעה. אפשר לשאול כמה רחוק מקום לפני היציאה:

> [כמה רחוקה רוקה, וכמה זמן ייקח ללכת אליה ברגל?]

**העולם נע גם בלעדיך.** לנבלים יש תוכניות עם מועדים ושעונים. בכל יום חדש, המנחה מקדם את האיומים שהזמן קידם, ורואים את האותות שלהם: שמועה, עקבה, שינוי בעיירה. השעון עצמו אף פעם לא נראה, רק מה שהוא משאיר אחריו.

**כסף** נספר במטבעות המשחק. לשלם, למכור, לקבל תשלום: RPG Engine מחשב את העודף.

### 3.5 מפות

**מפת העולם** (בדשבורד: **עולם**) מראה רק את המקומות שהדמות מכירה, עם הדרכים ביניהם, השביל שנעבר, והערפל על כל השאר. ללחוץ על מקום כדי לראות מה ידוע עליו וכמה הוא רחוק.

**מפת מקום** (בדשבורד: **סצנה**, ו**קרב** בזמן קרב) מופיעה כשהמנחה משרטט אחת למקום שבו נמצאים: קירות, דלתות, הקרקע, ומי עומד איפה, כאסימונים. בקרב, בתור שלך, המשבצות שאי אפשר להגיע אליהן מכוסות בצעיף, כך שרואים במבט אחד לאן אפשר ללכת. כשהמנחה שואל לאן הדמות זזה, הדף פותח את המפה ונוגעים במשבצת, או כותבים אותה, למשל *E4*.

### 3.6 משימות, יומן ופתקים

**משימות.** כשהדמות מקבלת על עצמה משימה, היא הופכת למשימה ב**יומן**: מי נתן אותה, איפה, עד מתי, המטרות שלה כרשימה, ומה היא מודדת (מועד אחרון עם הזמן שנותר, שעון, ספירה). לסמן אחת בכוכב שלה כדי לעקוב אחריה: היא נשארת קטנה בראש **סצנה**, עם המטרה הבאה שלה. המשימה מסתיימת כשהסיפור מסיים אותה, אף פעם לא מעצמה.

**הסיפור.** לשונית הסיפור ביומן היא הקמפיין שלך כציר זמן: כל סצנה היא פרק, עם המקום, התאריך וסיכום קצר, האחרונה ראשונה.

**הפתקים שלך.** בלשונית הפתקים ביומן כותבים פתקים משלך: תיאוריות, שמות, תוכניות. הם נשארים במחשב והמנחה לא קורא אותם, אלא אם **לשתף** אחד. פתק משותף מגיע למנחה בתשובה הבאה שלו כמה שאתה חושב, לעולם לא כעובדה. התיאוריה שלך לא הופכת לאמת כי כתבת אותה. פתק שמבקש להפסיק או להימנע מתוכן מסוים נחשב כאילו נאמר ליד השולחן.

### 3.7 הסיפור והתמונה של הדמות

בדף הדמות, בכרטיס **תיאור** יש תיבה לכתיבת הסיפור של הדמות. שולחים, והמנחה כותב אותו לתוך הדמות במילים שלו, אחרי שאומרים כן.

לתמונת הדמות, נותנים למנחה קובץ תמונה בצ'אט, עם המקום שלו במחשב (PNG, JPEG, WebP או SVG, עד 5 MB):

המנחה מעתיק אותו לקמפיין, והוא מופיע על האסימון של הדמות בדשבורד. אפשר להחליף אותו באותו אופן מתי שרוצים.

או ליצור את הדיוקן, במקום שבו המחשב יכול ליצור תמונות (ראו [תמונות](#311-pictures)): לתאר את הדמות למנחה, או לתת למנחה לתאר אותה.

הדיוקן מראה בדיוק מה הדמות במשחק, בני עמה כפי שהעולם הזה מכיר אותם, גמד גבעות כגמד גבעות, עם המראה שתיארת. הוא מגיע בתוך דקה בערך, על האסימון של הדמות. גם לבני הלוויה אפשר ליצור דיוקן באותו אופן.

### 3.8 שמירות וחזרה אחורה

RPG Engine שומר את כל הקמפיין **בסוף כל סצנה**, מעצמו. מה אפשר לעשות עם השמירות האלה תלוי בהגדרת **שמירות**:

| שמירות | לשמור כשרוצים | לחזור אחורה |
|---|---|---|
| **מוות סופי** | לא | אף פעם; אפשר רק להתחיל את הקמפיין מחדש |
| **נקודת ביקורת** | לא | לשמירה האחרונה, רק כשהדמות מתה |
| **חופשית** | כן | לכל שמירה, מתי שרוצים |

בכל מצב אפשר **להתחיל מחדש**: מתחילת המשחק עם אותה דמות, או מסשן אפס עם דמות חדשה.

אפשר לעשות את כל זה בצ'אט ("[בואו נחזור לפני הדו-קרב.]") או במדור **שמירות** בדשבורד.

**אחרי חזרה אחורה, לפתוח צ'אט חדש.** הצ'אט ששיחקתם בו זוכר את מה שבוטל. לפתוח צ'אט חדש עם המנחה (`/clear` ב-Claude Code, `/new` ב-Codex), לכתוב *המשך*, ואז ללחוץ על **נפתח צ'אט חדש** בשמירות, או לומר זאת למנחה בצ'אט החדש. לעולם לא להמשיך את הצ'אט הישן. עד לאישור, המנחה לא ימשיך.

### 3.9 סשנים: עצירה וחזרה

**אפשר לסיים את הסשן** מתי שרוצים:

> [נעצור כאן להערב.]

אין "שמירה ויציאה": הכול כבר בקבצים.

**כדי לסגור** את הצ'אט, לכתוב `/exit` ב-Claude Code, או `/quit` ב-Codex. הדשבורד משתתק עד הצ'אט הבא.

**כדי לחזור**, לפתוח טרמינל בתיקיית הקמפיין (זו ש-`init` הדפיס), להפעיל שם את המארח ולכתוב *המשך*. המנחה קורא איפה המשחק עומד, נותן סיכום קצר, ופותח במשהו שקורה. צ'אט חדש לא מאבד כלום: הקמפיין חי בקבצים שלו, לא בצ'אט.

המנחה לא שואל שאלות שגרתיות בסוף. רק אם הבחין שמשהו לא עבד, הוא שואל בקצרה.

### 3.10 מצב הרוח של המנחה

בראש הדשבורד נמצא האווטאר של המנחה, רובוט קטן. הפנים שלו עוקבות אחרי טון הסיפור: מודאג כשהסכנה גדלה, שמח מרעיון נועז, מופתע מתפנית. הוא מגיב לרגע ל-20 טבעי או ל-1 טבעי. הוא אף פעם לא מגלה מה שעדיין לא ידוע: אין חיוך רחב לפני שהמלכודת נפתחת. גם האסימונים של החבורה מראים מצבי רוח. כשהצ'אט סגור, הרובוט ישן.

### 3.11 תמונות

RPG Engine יכול ליצור תמונה לכל מקום שמגיעים אליו, לכל משימה שמקבלים ולכל דמות או סוג יצור שפוגשים, מצוירים כפי שרואים אותם, לפי הגדרת **תמונות**, ואת דיוקן הדמות כשמבקשים. הוא משתמש במה שכבר נמצא במחשב:

- **Codex**, עם ההתחברות ל-ChatGPT: תמונה מצוירת בצבע.
- אחרת **Claude Code**, עם ההתחברות ל-Claude: ציור.

התמונה משתמשת בתוכנית שלך, לא בשלנו. מדור **הגדרות** אומר אם אפשר ליצור תמונות במחשב, ואם לא, מראה את שלבי ההכנה. בלי תמונות, הדף מציג במקומן את הסימן של כל סוג מקום. אפשר גם לתת למנחה תמונה משלך לכל מקום או דמות.

### 3.12 בטיחות: קווים אדומים, וילונות ועצירה

- **קווים אדומים**: מה שאף פעם לא מופיע במשחק.
- **וילונות**: מה שיכול לקרות, אבל רק מחוץ למסך.
- **עצירה**: בכל רגע אפשר לעצור תוכן, בלי להסביר. לכתוב זאת מחוץ לסיפור:

> [עצור]

המנחה עוזב אותו מיד ומוסיף אותו לקווים האדומים, לכל הסשנים הבאים. אפשר לראות ולשנות את הקווים האדומים והוילונות ב**הגדרות**.

### 3.13 שינוי דעה

אפשר לשנות כל הגדרה במהלך הקמפיין: בצ'אט ("[בואו נקשה על זה.]") או ב**הגדרות**. המנחה שומע על שינוי בתשובה הבאה שלו. הכרעה שהמנחה עשה בלי הספר הופכת ל**תקדים** ונשמרת, כך שאותה שאלה תקבל אותה תשובה בפעם הבאה.

## 4. לוח הבקרה, מדור אחר מדור <!-- icon: party -->

לוח הבקרה הוא דף במחשב שלך. המנחה נותן את הקישור שלו בתחילת כל צ'אט. הוא עוקב אחרי המשחק בזמן אמת: כשהמנחה משנה משהו, הדף משתנה גם הוא.

רק הדפדפן של המחשב שבו משחקים יכול לפתוח אותו: לא טלפון או טאבלט, גם לא באותה רשת Wi-Fi. הדף מתאים גם לחלון צר: אז המדורים עוברים לסרגל בתחתית, והסמלים לתפריט.

הדף חי כל עוד הצ'אט חי. אם סוגרים את הצ'אט, דף שנשאר פתוח מציג *לא מחובר* עם דף הדמות כפי שהיה, והרובוט של המנחה נרדם; פותחים שוב צ'אט בקמפיין, ואחרי שהמנחה ענה, הדף חוזר מעצמו.

### למעלה

- **האווטאר של המנחה**, עם מצב הרוח שלו.
- שם הקמפיין, מערכת המשחק, **זמן המשחק** והאם המשחק **מחובר** (הצ'אט מחובר).
- המדורים: **חבורה**, **סצנה**, **קרב** (רק בזמן קרב), **יומן**, **עולם**; בסוף השורה, כסמלים: **שמירות**, **עזרה**, **הגדרות**, **אודות**.
- ערכת הנושא הבהירה והכהה, בפינה הימנית העליונה.

כשהמנחה שואל משהו, השלט שלו נשאר בראש הדף, בכל מדור שלא תהיו.

### חבורה

דף הדמות שלך, ושל בני הלוויה. כל חלק בדף הוא כרטיס שאפשר לפתוח ולסגור.

- **ללחוץ על מספר** כדי להטיל אותו בשביל הכיף. מצביעים על מספר כדי לראות איך הוא מורכב ("+5: חוכמה ‏+3, מיומנות ‏+2").
- **נקודות חיים, משבצות ושימושים** מוצגים כפסים וכנקודות.
- **מצבים והשפעות** מוצגים עם משך הזמן שלהם.
- **תיאור** מחזיק את הטקסט של הדמות, ואת התיבה לשלוח למנחה את סיפור הדמות.
- ב-0 נקודות חיים, **הטלות ההצלה מפני המוות** מופיעות בגדול מתחת לשם.
- לצד הדף (מתחתיו במסך צר): **ההטלות**, החדשה ראשונה, שלך ושל המנחה שמותר לראות. **ניקוי** מרוקן את הרשימה; **שחזור** מחזיר אותה. הטלות חופשיות מוצגות מקווקוות ועמומות.

בן לוויה עם דף יצור, כמו זאב, מציג את דף היצור שלו במקום דף דמות מלא.

### סצנה

איפה החבורה נמצאת: התמונה והשם של המקום, המקומות סביבו, מפת המקום כשיש כזו, מי נמצא שם, והסצנה הפתוחה עם מה שקורה עכשיו. המשימה שעוקבים אחריה נמצאת למעלה.

### קרב

רק בזמן קרב. למעלה: הסבב, מי פועל, מי הבא. למטה: סדר התורות, כל לוחם עם מצבו, החבורה במספרים והאויבים במילים; מה שיש לדמות בהישג יד (Classe Armatura, נקודות חיים, התקפות); מפת המקום, עם הפועל מוקף בטבעת. בתור שלך הקישור לקרב פועם בזהב, בכל מקום שתהיו.

### יומן

שלוש לשוניות:

- **משימות**: פעילות, שהושלמו ושנכשלו, כל אחת ככרטיס עם המטרות שלה, המועד האחרון שלה כטיימר והשעונים שלה. הכוכב עוקב אחרי משימה.
- **סיפור**: פרקי הקמפיין, סצנה אחר סצנה, האחרון ראשון.
- **פתקים**: הפתקים שלך, פרטיים עד שמשתפים אחד.

### עולם

מפת העולם כפי שהדמות מכירה אותו, עם הערפל על השאר. גוררים כדי להזיז, גלגלת או צביטה כדי להתקרב. לוחצים על מקום לכרטיס שלו. רשימת המקומות, הקרוב ראשון, נמצאת לצדו. כשיש יותר ממפה אחת (עיר, יבשת, מישור אחר), לשוניות מחליפות ביניהן.

### מגש הקוביות

כפתור הקוביות פותח את המגש: בוחרים קוביות ומתאם, ומטילים. עם שתי קוביות או יותר מאותו סוג, בוחרים אילו נספרות: **הכול**, **גבוה** (רק הגבוהה ביותר) או **נמוך** (רק הנמוכה ביותר). הקוביות שבחרתם נשארות עד שלוחצים **ניקוי**, כך שאותה הטלת נזק היא לחיצה אחת בכל סבב. בזמן שהמנחה מבקש הטלה, המגש אומר אילו קוביות עונות עליה.

### שמירות

השמירות שלך, החדשה ראשונה, כל אחת עם המקום שלה, תאריך המשחק ומתי נוצרה. **לשמור עכשיו** (עם שמירות חופשיות), **לחזור לכאן**, ו**להתחיל מחדש**, באדום, בשני שלבים. ראו [שמירות וחזרה אחורה](#38-saves-and-going-back).

### הגדרות

ההגדרות שלך, בקבוצות: המשחק, ללמוד את המשחק (המנטור והחוקים שכבר הוסברו לך), קוביות ומידות, גבולות (קווים אדומים ווילונות), תמונות, שפה. לוחצים על ערך כדי לבחור; מתחתיו, מה הוא אומר. אחר כך ההעדפות של הדף עצמו, שנשמרות בדפדפן הזה בלבד: ערכת הנושא, הצליל של הקוביות, **סט הקוביות** (שרף, מתכת, עץ, אבן), קצוות מעוגלים או חדים, הטלה ידנית.

ההגדרות של המנחה עצמו, כמו חוקי בית ותקדימים, אינן כאן: הן נשארות בצ'אט.

### עזרה ואודות

**עזרה**: המדריך הזה. **אודות**: מהו RPG Engine, הקישורים שלו, הרישיונות שלו, והקרדיטים של מערכת המשחק.

### לפני המשחק: הגדרות וסשן אפס

כשקמפיין חדש בשלב הראשון שלו, **הגדרות**, כל הדף שואל את השאלות שלו: אחת בכל פעם, כל אחת עם מה שהערכים שלה אומרים והערך המומלץ. **ההחלטה שלך** משאיר שאלה למנחה, חוץ מקווים אדומים ווילונות, שהם תמיד שלך; **דילוג** משאיר אותה למאוחר יותר. בסוף, **אפשר להתחיל**.

### הודעות מהדף

לפעמים הדף מציג הודעה מעל עצמו: בעיה בקבצי הקמפיין (המנחה מתקן), המשחק לא זמין (הצ'אט סגור), הדף בתהליך תרגום.

## 5. מערכות משחק וחוקי בית <!-- icon: dice -->

### 5.1 מהי מערכת משחק

מערכת משחק היא הנתונים של משחק אחד: דף הדמות שלו, המספרים, היצורים, הפריטים, הלחשים וטקסט החוקים. כל קמפיין משחק במערכת אחת.

RPG Engine מחשב את דף הדמות ואת מה שמוצא ומה שחוזר, כמו נקודות חיים ומשבצות לחשים, כמו שעושה דף דמות דיגיטלי. איך תכונה או לחש פועלים, המנחה קורא בחוקים ומחליט, כמו ליד שולחן המשחק.

### 5.2 מהדורה חמישית, כלולה

RPG Engine מגיע עם **5e**, מתוך ה-System Reference Document 5.1 (חוקי 2014, חינמיים תחת Creative Commons). הוא כולל:

- את הגזעים, המקצועות, תתי-המקצועות, רקע אחד ונס אחד של ה-SRD;
- את 319 הלחשים, את הנשקים, השריונות והציוד, את החפצים הקסומים ואת המפלצות של ה-SRD;
- את פרקי החוקים, שהמנחה מחפש לפי הטקסט המדויק שלהם;
- את דף הדמות המלא, מחושב: מתאמי תכונות, שמירות, כישורים, Classe Armatura, התקפות, דרגת הקושי של הלחשים, משבצות, קוביות חיים, יכולות לפי רמה, ניסיון ועליית רמה;
- מנוחות שמחזירות את מה שצריך; מצבים עם טקסט החוק שלהם; תזכורות לריכוז.

**תוכן מעבר ל-SRD.** אפשר לשחק במהדורה החמישית עם תוכן שחסר ב-SRD, כמו מקצוע או מפלצת מספר שברשותך. המנחה מכיר את המשחק, יכול לקרוא את הספרים שלך ויכול לחפש באינטרנט. המנחה כותב את מה שהוא צריך כדפים של הקמפיין שלך, ו-RPG Engine עובד איתם באותו אופן. מה שאנחנו מספקים מוגבל ברישיון; מה שהמנחה שלך יודע אינו מוגבל.

RPG Engine מספק רק תוכן מקורי או בעל רישיון פתוח: למהדורה החמישית, ה-SRD 5.1 תחת CC BY 4.0. כל דבר אחר שמופיע במשחק נכתב בידי הבינה המלאכותית או בידיך, כדפים של הקמפיין שלך במחשב שלך: הוא אינו חלק מ-RPG Engine, ואנחנו לא מפיצים אותו.

RPG Engine תואם למהדורה החמישית.

### 5.3 חוקי בית ותוספות משלך

אין צורך לגעת באף קובץ. מבקשים מהמנחה:

> [חוק בית: 1 טבעי בהתקפה אומר שהנשק נופל מהיד.]
>
> [אני רוצה לשחק צייד דם (Blood Hunter). הספר ברשותי: הנה יכולות המקצוע.]
>
> [בקמפיין הזה, מנוחה קצרה נמשכת 10 דקות.]

המנחה רושם אותם בקמפיין, באחת מהדרכים האלה:

- **הסכמה של השולחן**, במילים, כמו הנשק שנופל או המנוחה הקצרה למעלה. המנחה שומר אותה עם הגדרות הקמפיין ומשחק לפיה מכאן והלאה. הכרעה שהמנחה מקבל בלי הספר נשמרת באותה דרך, כ**תקדים**.
- **דף חדש**, כמו מקצוע, גזע או פריט. מקצוע חדש פועל כמו מקצועות המערכת: הרמה, קוביות החיים והיכולות שלך נספרים בו. גזע חדש יכול להתבסס על גזע קיים ("כמו האלף, ובנוסף…"); חרב בעלת שם יכולה להתבסס על החרב הארוכה.
- **מספרים חדשים לדף הדמות**: שדה, טבלה, נוסחה, מונה שמנוחה מחזירה. לדוגמה, קוביות העליונות של לוחם מאסטר שחוזרות במנוחה קצרה. חוק בית יכול גם להחליף אחת מהנוסחאות של המערכת.

אם כבר כתבת חוקי בית, אפשר גם להניח אותם כקובצי טקסט בתיקיית `rules` של הקמפיין (ראו [תיקיית הקמפיין](#8-for-the-curious-the-campaign-folder)): המנחה קורא אותם לפני החוק של הספר באותו שם.

### 5.4 הוספה או ייבוא של מערכת משחק משלך

כיום RPG Engine משחק רק במהדורה החמישית. מערכות משחק נוספות יגיעו, וכך גם דרך להוסיף מערכת משלך, או להפוך משחק שברשותך למערכת מתוך הספרים שלו. ראו [בהמשך](#9-coming-later).

## 6. הרחבות <!-- icon: plus -->

**הרחבות עדיין אינן זמינות.** הרחבה תוסיף משהו לקמפיין מעל מערכת המשחק שלו: עולם, הרפתקה, יכולת כמו מזג אוויר או חפיסת טארוט, חוקי בית לשיתוף. תבחרו אילו מהן כל קמפיין משתמש. הראשונות המתוכננות למהדורה החמישית הן מזג אוויר ופריצת מנעולים.

## 7. מאיפה בא קמפיין, והשפה שלו <!-- icon: world -->

### 7.1 שלוש דרכים לקבל עולם

**נוצר תוך כדי משחק.** נותנים הנחת יסוד בהכנה, והמנחה בונה את העולם תוך כדי: כל מקום, אדם ועלילה רגע לפני שצריך אותם, ונשמרים מאז. זו הדרך המהירה ביותר לשחק: מתקינים, יוצרים, ותוך כמה דקות כבר יוצרים דמות. שום דבר שהומצא לא הולך לאיבוד: ברגע שנאמר, הוא נכתב ונשאר נכון.

**מוכן בהתחלה.** אותה הנחת יסוד, אבל עם **הכנה: הכול בהתחלה**, המנחה בונה את המקומות, הפלגים, האיומים והתוכניות שלהם לפני שהמשחק מתחיל. הסשן הראשון מתחיל מאוחר יותר, עם יותר מוכן מאחורי הקלעים.

**מקמפיין או הרפתקה קיימים.** היום אין כפתור ייבוא. נותנים למנחה את ההרפתקה (טקסט או PDF שהמארח יכול לקרוא) ומבקשים ממנו להכין אותה:

> [יש לי את ההרפתקה הזו כ-PDF. הכן אותה ככמפיין שלנו: קרא אותה, וכתוב את המקומות, הדמויות והסודות שלה. אל תגלה לי שום דבר ממה שכתוב בה.]

המנחה קורא אותה עם הכלים של מארח הבינה המלאכותית וכותב אותה כדפי קמפיין, כולל הסודות, שתגלו במשחק. Claude Code קורא קובצי PDF; עם Codex, קובץ טקסט או markdown הוא בחירה בטוחה יותר. עושים זאת בזמן ההכנה, לפני סשן אפס.

בזמן שהמנחה עובד, לא לפתוח את הפרטים של מה שהוא קורא או כותב (ב-Claude Code, ctrl+o): הם מראים את טקסט ההרפתקה, כולל הסודות. המנחה עצמו שומר את הסודות, כמו תמיד.

ברגע שיש לקמפיין דפים משלו, ההכנה מפסיקה לשאול על הנחת יסוד והכנה. גם בקמפיין כתוב, כשהולכים למקום שהטקסט לא מכסה, המנחה יוצר את מה שצריך ורושם אותו.

**קמפיין משחקים פעם אחת.** כדי לשחק שוב את אותה הרפתקה, יוצרים קמפיין חדש. בתוך קמפיין אפשר עדיין לחזור לשמירה או להתחיל מחדש, כפי שההגדרה שמירות מתירה.

### 7.2 שפות

**שפה אחת לקמפיין**: זו של המנחה. המנחה כותב בה, ולוח הבקרה עוקב אחריה. המנחה לוקח אותה מאופן הכתיבה שלך, ומאשר אותה.

**לוח הבקרה** מגיע באנגלית ובאיטלקית (בעריכה קפדנית) וב-24 שפות נוספות: צרפתית, גרמנית, ספרדית, פורטוגזית (ברזילאית), הולנדית, שוודית, נורווגית, דנית, פינית, איסלנדית, רוסית, אוקראינית, פולנית, צ'כית, רומנית, הונגרית, יוונית, טורקית, ערבית, עברית, הינדי, סינית, יפנית, קוריאנית. ערבית ועברית נקראות מימין לשמאל: הדף מתהפך, והמפות והקוביות נשארות כפי שצוירו.

**כל שפה אחרת** שבוחרים ב**הגדרות** מתורגמת במחשב שלך, ברקע, על ידי Codex או Claude Code עם ההתחברות שלך, החל מהמדור שפתוח. זה נעשה פעם אחת לכל שפה, לכל הקמפיינים. עד שהתרגום מוכן, הדף באנגלית. ההגדרות אומרות אם התרגום בעיצומו, מוכן, או בלתי אפשרי במחשב שלך.

**מילות המשחק.** המהדורה החמישית מביאה את המונחים שלה באיטלקית מה-SRD האיטלקי הרשמי, כך ששחקנים איטלקים קוראים *Classe Armatura*, *tiro salvezza*, *vantaggio*. בשפות אחרות מונחי המערכת מתורגמים.

**הטקסט של מערכת המשחק עצמה** (הלחשים, המפלצות, פרקי החוקים) נשאר באנגלית. המנחה קורא אותו ומספר לך אותו בשפה שלך.

**החלפת שפה באמצע קמפיין** משאירה את הדפים שכבר נכתבו כפי שהם; המנחה כותב חדשים בשפה החדשה.

## 8. לסקרנים: תיקיית הקמפיין <!-- icon: list -->

אף פעם אין צורך לפתוח אותה. אם פותחים, כדאי לדעת ש**היא מחזיקה את הסודות** של הקמפיין: קריאה בה קלקלה את המשחק.

תיקיית קמפיין מחזיקה:

- `campaign.yaml`: ההגדרות שלך;
- `state.yaml`: איפה המשחק עומד עכשיו: השלב, התאריך, הסצנה הפתוחה;
- `world/`: דף אחד לכל דמות, מקום, פלג, משימה, חפץ, אירוע, נושא או יצור, כקובצי markdown;
- `rules/`: חוקי הבית שלך כקובצי טקסט, אם מוסיפים (`init` לא יוצר אותה);
- `images/`: התמונות, כשיש כאלה;
- `log.jsonl`: כל שינוי, לפי הסדר;
- `.saves/`: השמירות, מהראשונה ואילך;
- `.player/`: הפתקים שלך מהיומן, שהמנחה לא קורא;
- `sessions/`: מנוהלת על ידי RPG Engine;
- `AGENTS.md`, `CLAUDE.md`, `.mcp.json`, `.claude/`, `.codex/`, `.gemini/`: הקבצים הקטנים שאומרים למארחי הבינה המלאכותית איפה RPG Engine ושומרים על הזיכרון שלהם כבוי. RPG Engine מעדכן אותם; להשאיר אותם כמו שהם.

הדפים הם markdown פשוט עם קישורים כמו `[[Rocca]]`, הפורמט של Obsidian: אפשר לפתוח שם את המחברת של המנחה. **אם משנים דף ביד**, המנחה שומע מה השתנה בתשובה הבאה שלו.

**שורת הפקודה.** כל מה שהמנחה עושה עובר דרך פקודות שאפשר להריץ גם בעצמכם, בתיקיית הקמפיין. אין צורך בהן כדי לשחק, ורבות מהן מדפיסות את סודות הקמפיין, כמו `rpg status` ו-`rpg show`. `rpg --help` מונה את כולן, ו-`rpg roll --help` מסביר אחת. פקודה ששינתה משהו בזמן שצ'אט פתוח זה בסדר: המנחה שומע על כך בתשובה הבאה שלו, כמו על דף ששונה ביד.

## 10. שאלות ובעיות <!-- icon: info -->

### שאלות

**צריך לדעת את החוקים?** לא. בוחרים את המנטור בהדרכה והמנחה מלמד תוך כדי, חוק אחד בכל פעם. תמיד אפשר לשאול בסוגריים מרובעים.

**המנחה יכול לרמות?** הוא לא יכול לשנות הטלה ש-RPG Engine ביצע, חוץ מברמת קושי story, והוא אף פעם לא משנה עובדות שכבר נקבעו. אפשר לשאול אם הטלה כלשהי הייתה אמיתית.

**אני יכול לרמות?** אפשר לנסות. המנחה לא לוקח את המילה שלך כעובדה: שורה בהודעה שנראית כהודעת משחק היא עדיין רק מילים שלך, והמנחה אף פעם לא מאשר ניחושים שלך על סודות.

**זה עולה כסף?** RPG Engine חינמי. המנחה רץ על תוכנית Claude או ChatGPT שלך, וערב משחק הוא צ'אט ארוך: בתוכניות הקטנות ביותר אפשר להגיע למגבלת התוכנית לפני שהערב נגמר. תמונות ותרגומים משתמשים באותה תוכנית.

**אפשר לשחק בטלפון?** לא. המנחה רץ על המחשב, ולוח הבקרה נפתח רק בדפדפן של אותו מחשב.

**אפשר לשחק עם חברים?** עדיין לא: היום שחקן אחד, דמות אחת, ועוד בני לוויה. כמה אנשים ליד השולחן יגיעו עם תפקידים.

**אפשר להשתמש בבינה מלאכותית אחרת בפעם הבאה?** כן. הקמפיין חי בקבצים שלו: פותחים אותו במארח אחר וכותבים *המשך*.

**מה אם סוגרים את הדפדפן?** שום דבר לא הולך לאיבוד. פותחים שוב את הקישור כל עוד הצ'אט פתוח; הדף חוזר לאן שהמשחק נמצא.

**אפשר לשחק תוכן D&D שברשותי?** כן. המנחה יכול להשתמש בספרים שלך, בידע שלו וברשת. מה ש-RPG Engine מספק מוגבל לתוכן חופשי; מה שהמשחק שלך משתמש בו תלוי בך.

### בעיות

**לוח הבקרה לא נפתח.** לבקש מהמנחה את הקישור: `[מה הקישור ללוח הבקרה?]`. הדף עובד רק כל עוד צ'אט עם המנחה פתוח בקמפיין הזה, ורק אחרי התשובה הראשונה של המנחה באותו צ'אט. כשהצ'אט סגור, הדפדפן לא מגיע לדף; דף שנשאר פתוח אומר *לא מחובר*.

**נראה שהמנחה לא מכיר את המשחק, או ממציא כלים.** מארח הבינה המלאכותית לא טען את RPG Engine.

- קודם, לבדוק שהפעלתם את המארח **בתיקיית הקמפיין**, ושאמרתם שסומכים עליה.
- **Claude Code**: לכתוב `/mcp`. אם `rpg` שם אבל נכשל, לבחור בו, ואז **Reconnect**. אם הוא חסר, לסגור את Claude Code, לכתוב `claude mcp reset-project-choices` בתיקיית הקמפיין, ולהפעיל אותו שוב.
- **Codex**: לכתוב `codex mcp list` בטרמינל, בתיקיית הקמפיין. אם `rpg` חסר, Codex לא סומך על התיקייה: להפעיל אותו שוב שם ולענות כן כשהוא שואל.
- בשניהם: אם `rpg --version` בטרמינל אומר שהפקודה לא נמצאה, להתקין שוב את RPG Engine ([2.2](#22-install)) ולפתוח טרמינל חדש.

**אחרי עדכון, שום דבר לא השתנה.** מנחה שרץ שומר על הגרסה שאיתה התחיל. לפתוח צ'אט חדש, או ב-Claude Code לחבר מחדש את השרת (`/mcp`, ואז `rpg`, ואז **Reconnect**).

**המנחה זוכר משהו שביטלתי.** חזרתם לשמירה אבל המשכתם לשחק באותו צ'אט. לפתוח צ'אט חדש וללחוץ **נפתח צ'אט חדש** במדור שמירות.

**המנחה שואל שאלות הכנה שכבר עניתי עליהן בדף.** לומר לו: `[בחרתי אותן בלוח הבקרה.]`

**לא מופיעות תמונות.** לפתוח הגדרות > תמונות: הדף אומר אם המחשב הזה יכול ליצור אותן, ואת השלבים אם לא, כל פקודה עם כפתור להעתקה.

**הדף באנגלית אבל בחרתי שפה אחרת.** הוא מתורגם ברקע; ההגדרות אומרות איך זה מתקדם. בלי Codex או Claude Code במחשב הזה, הוא נשאר באנגלית.

**המנחה אומר שיש בעיות בקמפיין.** הוא מתקן אותן בעצמו. אם ערכתם קבצים ביד, הוא עשוי לשאול מה התכוונתם.

**Windows: `npm` נכשל בתיקייה שלי.** לא לשמור את הקמפיין, או את RPG Engine, בנתיב שמכיל `&`.

**ההתקנה נכשלת, או ש-`rpg` לא עולה.** לבדוק את גרסת Node.js עם `node --version`: היא חייבת להיות 22 או חדשה יותר. אם היא ישנה יותר, להתקין את גרסת ה-LTS מ-[nodejs.org](https://nodejs.org), ואז להתקין שוב את RPG Engine.

**הקישור ללוח הבקרה השתנה.** תוכנית אחרת השתמשה בכתובת הרגילה של הקמפיין, או ש-Windows שמרה אותה. RPG Engine לקח כתובת אחרת; המנחה נותן את הקישור החדש. שום דבר אחר לא משתנה.
