# RPG Engine: המדריך המלא

**RPG Engine** מאפשר לשחק משחק תפקידים שולחני עם **בינה מלאכותית בתפקיד המנחה**.

המשחק מתנהל בשיחה עם המנחה בתוך **צ'אט**: המנחה מספר את הסיפור, מגלם את כל שאר הדמויות וקובע מה קורה.

RPG Engine עובד מאחורי הקלעים: הוא **זוכר את העולם**, **מטיל את הקוביות** ו**מנהל את החישובים**.

לצד הצ'אט נשאר פתוח בדפדפן דף נוסף, **הלוח**, ובו דף הדמות, הקוביות, המפות והיומן.

המדריך הזה מיועד לשחקנים: אין צורך לדעת תכנות.

## Quick start <!-- icon: send -->

1. להתקין את **Node.js** מהאתר [nodejs.org](https://nodejs.org) (גרסת ה-LTS).
2. להתקין את **Claude Code** או את **Codex**, אפליקציית הבינה המלאכותית שבה המנחה פועל, ולהתחבר ([2.4](#24-connect-your-ai)).
3. לפתוח טרמינל ולהתקין את RPG Engine: `npm install -g rpg-engine`.
4. בטרמינל, ליצור קמפיין: `rpg init "The Salt Isles"`.
5. לפתוח את Claude Code או את Codex בתיקייה החדשה ולכתוב *שלום! בואו נתחיל.* המנחה עונה עם הקישור ללוח: לפתוח אותו לצד הצ'אט.

המשך המדריך מסביר כל שלב, ואחר כך איך משחקים.

## 1. What RPG Engine is <!-- icon: about -->

### Who does what

| מי | מה עושה |
|---|---|
| **אתה** | משחק את הדמות. אומר מה היא עושה, אומרת ומנסה. |
| **המנחה** (הבינה המלאכותית) | מספר את הסיפור, מגלם כל דמות אחרת, מחליט מה קורה, מבקש הטלות. |
| **RPG Engine** | זוכר הכול בקבצים, מטיל את הקוביות, סופר נקודות חיים, כסף, זמן ומרחקים, ושומר סודות עד שמגלים אותם. |

בינה מלאכותית טובה בלספר סיפורים וגרועה בלזכור. אם משאירים אותה לבד, היא שוכחת מי חייב לך כסף, כמה חיצים נשארו לך, או שהגשר נשרף לפני שני סשנים. RPG Engine שומר את כל זה, ולכן העולם נשאר אותו עולם מערב לערב, גם בצ'אט חדש, גם עם בינה מלאכותית אחרת.

### What it feels like

כותבים בצ'אט, כמו שמדברים סביב שולחן:

> אני דוחף את הדלת לאט ומציץ פנימה.

המנחה עונה במה שרואים, ועוצר כשמגיע הזמן לבחור. כשמשהו לא ברור וחשוב, המנחה אומר מה מונח על הכף ומבקש הטלה. כפתורי ההטלה מופיעים בלוח. לוחצים, הקוביות נופלות על הדף, והמנחה מספר מה קרה.

### What makes it different

- **העולם קבוע.** מה שנאמר נשאר נכון. נבל שמת נשאר מת.
- **הקוביות אמיתיות.** המנחה לא יכול לעקם אותן (חוץ מברמת הקושי הקלה ביותר, אם בוחרים בה).
- **סודות נשארים סודות.** המנחה אף פעם לא מגלה מה שהדמות לא יודעת, גם אם מתעקשים.
- **העולם ממשיך לזוז בלעדיך.** איומים מתקדמים בזמן שנחים או נוסעים, ואפשר לראות את סימניהם.
- **הרבה ערבים, סיפור אחד.** קמפיין הוא תיקייה במחשב. אפשר לעצור מתי שרוצים ולהמשיך אחר כך.

### The game it plays today

RPG Engine נבנה לכל משחק תפקידים שולחני. כרגע מגיעה איתו מערכת משחק אחת: **המהדורה החמישית** (מתוך ה-System Reference Document 5.1 החופשי). משחקים נוספים יגיעו; ראו [מערכות משחק](#5-game-systems-and-house-rules) ו[בקרוב](#9-coming-later).

## 2. Getting started <!-- icon: path -->

### 2.1 What you need

- מחשב עם Windows, macOS או Linux.
- **Node.js 22** ומעלה. להוריד מהאתר [nodejs.org](https://nodejs.org): גרסת ה-"LTS" מתאימה. הוא מגיע עם `npm`, שמתקין את RPG Engine.
- **טרמינל**, החלון שבו כותבים פקודות: ב-Windows, אפליקציית Terminal או PowerShell; ב-macOS, Terminal. משתמשים בו כדי להתקין את RPG Engine, ליצור כל קמפיין ולהפעיל את Claude Code או את Codex.
- **מארח בינה מלאכותית**, האפליקציה שבה המנחה פועל: **Claude Code** או **Codex**, עם התוכנית וההתחברות שלהם. ראו [2.4](#24-connect-your-ai).
- **המודל הגדול ביותר** שהמארח מציע. מודל קטן נותן להערים עליו: בבדיקות שלנו הוא גילה סודות לשחקן שטען שהוא המנחה האמיתי.
- דפדפן, בשביל הלוח.

ההתחברות למארח משרתת עוד דבר: RPG Engine משתמש בה, במחשב שלך, כדי לצייר תמונות של מקומות ולתרגם את הלוח לשפות שאינן מגיעות איתו. ראו [תמונות](#311-pictures) ו[שפות](#72-languages).

**איך פותחים טרמינל בתיקייה.** שלבים רבים אומרים "בתיקיית הקמפיין". ב-Windows, לוחצים קליק ימני על התיקייה ב-File Explorer ובוחרים **Open in Terminal**. ב-macOS, לוחצים קליק ימני על התיקייה ב-Finder ובוחרים **Services > New Terminal at Folder**. או, בטרמינל שכבר פתוח, כותבים `cd` ואת נתיב התיקייה, למשל `cd "C:\Users\me\Games\The Salt Isles"`.

### 2.2 Install

לפתוח טרמינל ולכתוב:

```text
npm install -g rpg-engine
```

זה נותן לך את הפקודה `rpg`. כדי לבדוק שההתקנה הצליחה:

```text
rpg --version
```

משתמשים ב-`rpg` פעם אחת לכל קמפיין, כדי ליצור אותו. אחר כך רק מדברים עם המנחה: מארח הבינה המלאכותית מפעיל את RPG Engine בעצמו, עם אותה פקודת `rpg`.

### 2.3 Create a campaign

קמפיין הוא תיקייה. לפתוח טרמינל בתיקייה שבה שומרים את המשחקים, ולכתוב:

```text
rpg init "The Salt Isles"
```

זה יוצר את התיקייה `The Salt Isles` עם קמפיין חדש בתוכה, ואומר מה לעשות הלאה:

```text
Created the campaign "The Salt Isles" in C:\Users\me\Games\The Salt Isles.
To play, open Claude Code or Codex in this folder and say hello: the master asks you the rest.

For the master: Still to agree with the player: ...
```

השורות שאחרי *For the master* מיועדות למנחה, שקורא אותן בצ'אט: אין לך מה לעשות איתן. כדאי לזכור איפה התיקייה: חוזרים אליה בכל פעם שמשחקים. בלי שם תיקייה, `rpg init` הופך את התיקייה הנוכחית לקמפיין.

`init` יוצר את כל מה שהקמפיין צריך: ההגדרות שלו, תיקיות העולם, והקבצים הקטנים שאומרים למארח הבינה המלאכותית להשתמש ב-RPG Engine ולא לשמור זיכרון משלו מחוץ לקמפיין.

אין צורך לבחור כלום עכשיו. המנחה שואל את השאר בצ'אט, או שבוחרים בלוח. אם כבר ידועות כמה בחירות, אפשר לתת אותן כאן:

```text
rpg init salt-isles --name "The Salt Isles" --language en --system 5e --difficulty normal --lethality dice
```

זה יוצר את התיקייה `salt-isles`, ובתוכה הקמפיין *The Salt Isles*: שם תיקייה בלי רווחים, ושם הקמפיין כרצונך.

| אפשרות | מה היא קובעת | ערכים |
|---|---|---|
| `--name` | שם הקמפיין | כל שם; אם משמיטים, שם התיקייה |
| `--language` | שפת המשחק | קוד, כמו `en`, `it`, `fr` |
| `--system` | מערכת המשחק | `5e`, כרגע היחידה |
| `--difficulty` | כמה קשה העולם | `story`, `easy`, `normal`, `hard`, `brutal` |
| `--lethality` | מה משמעות הנפילה בקרב | `narrative`, `epic`, `dice` |

גם `rpg init --help` מציג אותן. אי אפשר ליצור קמפיין בתוך תיקייה של קמפיין אחר.

אי אפשר לבקש מהמנחה ליצור קמפיין: לפני `init` אין בתיקייה שום דבר שאומר למארח הבינה המלאכותית איפה RPG Engine.

### 2.4 Connect your AI

RPG Engine עובד עם **Claude Code** ועם **Codex**. אפליקציות בינה מלאכותית אחרות שמשתמשות בכלי MCP אולי יעבדו גם, אבל איננו מבטיחים זאת.

**התקנת המארח.** Claude Code ו-Codex פועלים בטרמינל: הם לא אפליקציית Claude או ChatGPT שבטלפון. לכל אחד תוכנית והתחברות משלו: ל-Claude Code תוכנית Claude בתשלום, ל-Codex התחברות ל-ChatGPT. לפי הדפים שלהם מתקינים ומתחברים: [Claude Code](https://code.claude.com/docs/en/setup) ו-[Codex](https://learn.chatgpt.com/docs/codex/cli). עושים זאת פעם אחת, לכל הקמפיינים.

**Claude Code.** לפתוח טרמינל בתיקיית הקמפיין ולכתוב `claude`. בפעם הראשונה הוא שואל אם סומכים על התיקייה, ואומר שהתיקייה מתירה את כלי המשחק (`mcp__rpg`): לבחור **Yes, I trust this folder**. זהירות: התשובה שמסומנת מראש היא *No, exit*, ולכן לחיצה מיידית על Enter סוגרת את Claude Code. זה הכול: הקמפיין כבר אמר ל-Claude Code להשתמש ב-RPG Engine ובכלים שלו, ולכבות את הזיכרון שלו.

**Codex.** לפתוח טרמינל בתיקיית הקמפיין ולכתוב `codex`. כשהוא שואל אם סומכים על התיקייה, לענות כן: ההגדרות של הקמפיין אומרות ל-Codex איפה RPG Engine, מתירות את הכלים שלו ומכבות את הזיכרון שלו, ו-Codex קורא אותן רק בתיקייה שסומכים עליה. באפליקציית שולחן העבודה, לוודא שהזיכרונות כבויים בצ'אטים של המשחק.

**למה הזיכרון חשוב.** הקמפיין חי בקבצים שלו. אם המארח זוכר דברים גם בעצמו, חזרה לשמירה לא תהיה חזרה אמיתית: המנחה עדיין יזכור את מה שבוטל.

### 2.5 The first chat

לכתוב משהו, למשל:

> שלום! בואו נתחיל.

המנחה קורא איפה המשחק עומד ועונה. בתשובה הראשונה בכל צ'אט הוא נותן את **הקישור ללוח** (משהו כמו `http://127.0.0.1:4750`). לפתוח אותו בדפדפן ולהשאיר אותו לצד הצ'אט לאורך כל המשחק. כל קמפיין שומר על אותו קישור מצ'אט לצ'אט, אלא אם תוכנה אחרת תפסה אותו: אז המנחה נותן את החדש.

בין ההודעות של המנחה, המארח מציג בשורות קצרות את הכלים שהמנחה משתמש בהם. לא לפתוח את הפירוט שלהם (ב-Claude Code, ctrl+o): הוא עלול להראות מה שהמנחה כותב, כולל סודות.

קמפיין חדש עובר שלושה שלבים, כמו משחק עם מנחה אנושי. הלוח מציג אותם למעלה: *1 הגדרות · 2 סשן אפס · 3 משחק*:

1. **הגדרות**: בוחרים איך רוצים לשחק. מחוץ לסיפור.
2. **סשן אפס**: יוצרים את הדמות, תוך כדי משחק.
3. **משחק**: הסיפור.

### 2.6 Settings: choosing how you play

המנחה שואל רק מה שעדיין חסר, כמה שאלות בכל פעם. אם כותבים "ההחלטה שלך", המנחה בוחר ואומר מה בחר. כשהלוח פתוח, השלב הראשון שלו, **הגדרות**, מציג את אותן שאלות ככרטיסים: שאלה אחת בכל פעם, כל ערך עם משמעותו, והרגיל מסומן **מומלץ**. בוחרים שם, והמנחה לא ישאל שוב בצ'אט; **דילוג** משאיר שאלה לאחר כך. הצ'אט מסדר את מה שרק מילים יכולות לסדר: הנחת היסוד של עולם חדש, השפה, והתמונות, שעליהן המנחה שואל רק אם המחשב יכול ליצור אותן. לכן הדף שואל פחות שאלות ממה שהטבלה למטה מונה.

אין צורך ללמוד את הטבלה: היא נועדה לעיון. אפשר לשנות כל אחת מההגדרות האלה אחר כך, בצ'אט או ב**הגדרות** של הלוח. שינוי נכנס לתוקף מהתשובה הבאה של המנחה.

| הגדרה | מה היא קובעת | ערכים | מומלץ |
|---|---|---|---|
| **מנטור** (נשאל כ"כמה טוב אתם מכירים את המשחק?") | כמה המנחה מלמד את החוקים, מחוץ לסיפור | **כבוי** (הסיפור בלבד; שואלים בסוגריים מרובעים כשרוצים), **רמזים** (טיפ קצר לפני בחירות חשובות וכשחוק חומק), **מדריך** (כל חוק מוסבר בפעם הראשונה, הסכום המלא של כל הטלה, סיכום קצר אחרי קרבות) | לפי התשובה: מעולם לא שיחקתי → מדריך, קצת → רמזים, אני מכיר → כבוי |
| **רמת קושי** | כמה קשה העולם: קרבות, טקטיקות אויבים, רמזים, אוצרות, מהירות התקדמות האיומים | סיפור, קל, רגיל, קשה, אכזרי | |
| **קטלניות** | מה משמעות הנפילה בקרב | **סיפורית** (הדמות לא מתה לעולם), **אפית** (מתה רק כשזה חשוב לסיפור), **קוביות** (הקוביות מחליטות) | לפי רמת הקושי: סיפור → סיפורית, קל → אפית, רגיל ומעלה → קוביות |
| **שמירות** | מתי מותר לחזור אחורה | **מוות קבוע** (אף פעם; אפשר רק להתחיל את הקמפיין מחדש), **נקודת ביקורת** (חזרה לסוף הסצנה האחרונה, רק אם הדמות מתה), **חופשי** (חזרה לכל שמירה, ושמירה בכל פעם שמבקשים) | נקודת ביקורת |
| **קפדנות** | עד כמה אוכל, אור, עייפות, משקל נשיאה, מרכיבי לחשים ונסיעות נעשים לפי החוקים | **זורם** (המנחה מדלג עליהם), **חוקים** (כמו שכתוב: לפידים כבים, מנות אוכל נגמרות), **הדמיה** (מעבר לחוקים: בלאי, התקלקלות, מזג אוויר) | זורם |
| **קוביות** | מי מטיל את הקוביות של הדמות | **דיגיטליות** (RPG Engine מטיל, על הדף), **פיזיות** (מטילים בעצמכם ואומרים מה יצא) | |
| **יחידות מידה** | מרחקים ומשקלים בסיפור | מטרי, אימפריאלי | |
| **בני לוויה** | מי מטייל איתך | אף אחד, נוצרים איתך בסשן אפס, נוצרים על ידי המנחה, פוגשים במשחק | |
| **תמונות** | תמונות של מקומות ומשימות | ללא, לפי בקשה, מקומות ומשימות חדשים | נשאל פעם אחת, רק אם המחשב יכול ליצור אותן |
| **קווים אדומים** | מה לא מופיע במשחק לעולם | רשימה, או כלום | |
| **וילונות** | מה יכול לקרות, אבל רק מחוץ למסך | רשימה, או כלום | |
| **שפה** | שפת המשחק והלוח | כל שפה | נלקחת מהאופן שבו כותבים, ומאושרת |

מערכת המשחק יכולה להוסיף הגדרות משלה. המהדורה החמישית מוסיפה **התקדמות**: איך הדמות עולה ברמה, עם **נקודות ניסיון** או ב**אבני דרך** של הסיפור.

**מה משמעות רמת הקושי במשחק.** סיפור: אויבים חלשים ותמימים, רמזים מובנים מאליהם, שפע של הכול; המנחה רשאי לרכך את ההטלות של עצמו. קל: אויבים פשוטים, משאבים נדיבים. רגיל: אויבים הגיוניים, שלושה רמזים לכל מסקנה, מחירים ואוצרות רגילים. קשה: אויבים חכמים, רמזים עדינים, משאבים מועטים, איומים שנעים מהר. אכזרי: אויבים שיוצאים למארבים, נסוגים ומסיימים את הנופלים, משאבים מועטים מאוד, המנוחות הקשות ביותר. הקרבות תמיד מותאמים לחבורה כפי שהיא עכשיו.

**כשאין עולם כתוב**, ההגדרה שואלת עוד שני דברים:

- **הנחת יסוד**: הז'אנר, הטון וכמה מרכיבים של העולם, במילים שלך. למשל: *"פנטזיה נמוכה, קודרת אבל עם תקווה. עיירה על נהר, מעבר מוכה רוחות, כת בגבעות."*
- **הכנה**: **תוך כדי תנועה** (המנחה בונה כל חלק בעולם רגע לפני שצריך אותו; מומלץ) או **הכול בהתחלה**.

אחר כך המנחה מציע שם לקמפיין. כשלא חסר כלום ואומרים שמוכנים, המשחק עובר לסשן אפס.

### 2.7 Session zero: your character

סשן אפס הוא משחק: יוצרים את הדמות עם המנחה, כמו סביב שולחן.

- **כל בחירה היא שלך**, אלא אם מבקשים מהמנחה לבחור. אפשר להגיע עם רעיון מלא ("אישה חצי-אלפית, כוהנת, שעזבה את המקדש שלה"), עם רעיון מעורפל ("מישהי שמרפאה, אבל לא נחמדה") או בלי כלום ("תפתיע אותי, ואחר כך תן לי לשנות").
- **ציוני יכולת.** המנחה מסביר את השיטה ואת רשת הביטחון לפני שמוטלת קובייה כלשהי. במהדורה החמישית: המערך הסטנדרטי, קניית נקודות, או 4d6 בלי הנמוכה. השיטה שמסכימים עליה נשארת בהסכמות של השולחן.
- **הסיפור של הדמות** אף פעם אינו חובה. אם נותנים אחד, המנחה כותב אותו במילים שלך, מקריא אותו פעם אחת, וקושר את האנשים והמקומות שבו לעולם. אפשר גם לכתוב אותו בלוח (ראו [חבורה](#party)).
- **אישיות** (המהדורה החמישית): תכונה, אידיאל, קשר ופגם, מהטבלאות של הרקע או משלך.
- **תמונה.** אחרי שהדמות נוצרה, המנחה מבקש תמונה שלה: קובץ במחשב. אם מארח הבינה המלאכותית יכול לצייר בעצמו, המנחה עשוי להציע ליצור אחת.

המספרים בדף הדמות מחושבים על ידי RPG Engine לפי הבחירות שלך: אף פעם לא צריך לחשב. כשהדמויות נוצרו ומאשרים, הסיפור מתחיל.

## 3. Playing <!-- icon: chat -->

### 3.1 Talking with the master

לכתוב מה הדמות עושה או אומרת, במילים שלך. קצר זה בסדר.

> אני שואל את בעל הפונדק מי עוד עבר כאן הלילה.
>
> "לא באנו לצרות," אני אומר, היד רחוקה מהחרב.
>
> אני מטפס לגג וממתין.

**מחוץ לסיפור**, כותבים בין סוגריים מרובעים:

> [איך עובדת אחיזה?]
>
> [אפשר עדיין להשתמש בתגובה שלי בסבב הזה?]
>
> [בואו נעצור כאן להלילה.]

המנחה עונה גם הוא בסוגריים, ואז חוזר לסיפור.

**אתה אומר מה אתה מנסה; המנחה אומר מה קורה.** דבר ששובר את ההיגיון של העולם או עובדות שכבר נקבעו לא קורה: המנחה אומר זאת, בתוך הסיפור, ומציע מה אפשרי.

**המנחה אף פעם לא מחליט בשביל הדמות.** הוא לא יגרום לה לדבר, להרגיש או לבחור. כשיש ספק, הוא שואל.

**המנחה אף פעם לא מדבר על המנוע.** אם שואלים אותו אם הוא עוקב אחרי דברים, הוא עונה כמו מנחה: "אני שומר הכול: נמשיך מכאן בפעם הבאה."

**אפשר לשאול את המנחה איך משתמשים בלוח.** הוא מכיר את הדף: "איפה רואים את הלחשים שלי?", "איך מטילים ידנית?"

### 3.2 Rolls

**מתי יש הטלה.** המנחה מבקש הטלה רק כשהתוצאה לא ברורה וחשובה. אחרת הוא אומר כן, או "כן, אבל". לפני ההטלה, המנחה אומר מה מונח על הכף ואילו בדיקות מתאימות, ועוצר. מטילים, או משנים את דעתך:

> **המנחה:** הסדק צר ורטוב. אם תחליק, תיפול רחוק אל הנהר. בדיקת זריזות (אקרובטיקה), או שאפשר לחזור ולחפש את המדרגות.
>
> **אתה:** אני אנסה.

**הטלה בלוח.** כשהמנחה מבקש, מופיע בראש הדף באנר עם כפתור לכל בדיקה, למשל *אקרובטיקה +4 · עם יתרון*. לוחצים: הקוביות נופלות על הדף, והמנחה שומע את התוצאה. אפשר גם:

- ללחוץ על השורה המתאימה בדף הדמות, שנדלקת בזהב;
- להטיל את הקוביות המתאימות מהמגש;
- לכתוב בבאנר במילים שלך, אם רוצים לעשות משהו אחר.

**הטלה ידנית.** מי שמעדיף לבחור את הקוביות בעצמו מפעיל **ידנית** בפינת הבאנר (או ב**הגדרות**). כפתור הבדיקה נעלם, והבאנר אומר מה להטיל כמו שמנחה היה אומר: *הטל אקרובטיקה בעצמך, בדף הדמות או עם הקוביות.* לוחצים על השורה בדף הדמות שנדלקת, או מטילים את הקוביות המתאימות מהמגש: RPG Engine מטיל אותן, מוסיף את הבונוס והמנחה שומע את התוצאה. בדיקה שלא ניתן לבצע לא מדף הדמות ולא מהמגש, כמו נזק שמטיל מחדש 1-ים, שומרת על הכפתור שלה. **ידנית** נשאר פעיל בדפדפן הזה עד שמכבים אותו.

**קוביות פיזיות לכל המשחק.** כשהגדרת **הקוביות** על פיזיות, המנחה מבקש הטלות במילים וכותבים את הפאות שיצאו:

> [הטלתי 14.]

RPG Engine מוסיף את המתאמים ודוחה פאה שהקוביות שלך לא יכולות להראות.

**הטלות חופשיות.** לוחצים על כל מספר בדף הדמות, או פותחים את מגש הקוביות, כדי להטיל סתם בשביל הכיף. הטלות חופשיות אף פעם לא נחשבות, לא נרשמות, והמנחה לא רואה אותן. 20 חופשי לא יהפוך לאמיתי אחר כך.

**ההטלות של המנחה.** המנחה מטיל עבור אויבים ואחרים גם הוא עם RPG Engine. רוב ההטלות מוצגות בעמודת ההטלות שלך. כשאסור לראות תוצאה, המנחה מטיל בסתר. תמיד אפשר לשאול:

> [ההטלה ההיא הייתה אמיתית?]

על הטלה גלויה, המנחה נותן את המספרים והסיבה. על הטלה סודית, טביעת אצבע שמוכיחה שההטלה נעשתה לפני ששאלת.

**הטלות בצ'אט** מופיעות בסוגריים, מיד אחרי הרגע שהן מכריעות: *[שכנוע 14 + 3 = 17]*. אחר כך הסיפור מספר את התוצאה.

### 3.3 Scenes and fights

המנחה מנהל את הסיפור ב**סצנות**: קרב, שיחה, חקירה, נסיעה, מנוחה, אתגר (מרדף, מירוץ, חידה). אין צורך לנהל אותן: כך RPG Engine שומר את פרקי הסיפור. בסוף כל סצנה המשחק נשמר מעצמו, והסצנה נכנסת לסיפור שביומן.

**בקרב**, המנחה מספר את כל התורות שאינן שלך, בזה אחר זה, עם כל הטלה, ו**עוצר איפה שאפשר להחליט**: התור שלך, תגובה, בחירה. בתור שלך, אומרים מה עושים:

> אני מטיל את להב הקודש על זה שליד הדלת.

הסעיף **קרב** בלוח מציג את סדר התורות, של מי התור, את נקודות החיים של החבורה, ואיך האויבים נראים פצועים (שלמים, פצועים, מדממים, מפולים: במילים, אף פעם לא במספרים). אם הדמות נופלת, הצלות המוות מופיעות בגדול על הדף.

**כשהקרב כבר הוכרע**, המנחה עשוי להציע לספר את השאר בהודעה אחת.

### 3.4 Time, travel and the world that moves

**זמן.** כל פעולה לוקחת זמן בסיפור, ו-RPG Engine שומר את התאריך: יום 3, בוקר מוקדם. המנחה מספר את הזמן כמו שהעולם מודד אותו: עלות השחר, הפעמון השלישי, רדת הלילה. בין סשנים לא עובר זמן: ממשיכים מהנקודה שבה עצרתם.

**מנוחות.** אומרים שנחים, והמנחה מחיל את מה שמנוחה מחזירה, כמו נקודות חיים ומשבצות לחשים:

> אנחנו מקימים מחנה ונחים מנוחה ארוכה.

**נסיעות.** אומרים לאן רוצים ללכת:

> אנחנו לוקחים את הדרך צפונה אל רוקה.

RPG Engine מחשב את הדרך, את המרחק ואת הימים לפי הקצב שלכם, ומעביר אתכם לשם. מסע נעצר כשקורה משהו מתוכנן בדרך, בסוף כל יום נסיעה ובהגעה. אפשר לשאול כמה רחוק מקום לפני שיוצאים:

> [כמה רחוקה רוקה, וכמה זמן ייקח ללכת אליה ברגל?]

**העולם ממשיך לזוז בלעדיך.** לנבלים יש תוכניות עם מועדים ושעונים. בכל יום חדש המנחה מזיז את האיומים שהזמן קידם, ורואים את סימניהם: שמועה, עקבות, שינוי בעיירה. את השעון עצמו לא רואים אף פעם, רק את מה שהוא משאיר אחריו.

**כסף** נספר במטבעות המשחק. משלמים, מוכרים, מקבלים שכר: RPG Engine מחשב את העודף.

### 3.5 Maps

**מפת העולם** (בלוח: **עולם**) מציגה רק את המקומות שהדמות מכירה, עם הדרכים ביניהם, השביל שצעדתם בו, והערפל על כל השאר. לוחצים על מקום כדי לראות מה ידוע עליו וכמה הוא רחוק.

**מפת מקום** (בלוח: **סצנה**, ו**קרב** בזמן קרב) מופיעה כשהמנחה משרטט אחת למקום שבו אתם נמצאים: קירות, דלתות, הקרקע, ומי עומד איפה, כאסימונים. בקרב, בתור שלך, המשבצות שאי אפשר להגיע אליהן מכוסות בוילון, ולכן רואים במבט אחד לאן אפשר ללכת. כשהמנחה שואל לאן הדמות זזה, הדף פותח את המפה ונוגעים במשבצת, או כותבים אותה, כמו *E4*.

### 3.6 Quests, journal and notes

**משימות.** כשהדמות לוקחת על עצמה משימה, היא נהפכת למשימה ב**יומן**: מי נתן אותה, איפה, עד מתי, המטרות שלה כרשימה, ומה היא מודדת (מועד אחרון עם הזמן שנותר, שעון, ספירה). מסמנים אחת בכוכב שלה כדי לעקוב אחריה: היא נשארת קטנה בראש **סצנה**, עם המטרה הבאה שלה. המשימה מסתיימת כשהסיפור מסיים אותה, אף פעם לא מעצמה.

**הסיפור.** לשונית הסיפור ביומן היא הקמפיין שלך כציר זמן: כל סצנה פרק, עם המקום, התאריך וסיכום קצר, האחרונה ראשונה.

**הפתקים שלך.** בלשונית הפתקים ביומן כותבים פתקים משלך: תאוריות, שמות, תוכניות. הם נשארים במחשב והמנחה לא קורא אותם, אלא אם **לשתף** אחד. פתק משותף מגיע למנחה בתשובה הבאה שלו כמה שאתה חושב, אף פעם לא כעובדה. התאוריה שלך לא נהפכת לאמת רק כי כתבת אותה. פתק שמבקש לעצור או להימנע מתוכן מסוים נחשב כאילו נאמר ליד השולחן.

### 3.7 Your character's story and picture

בדף הדמות, בכרטיס **תיאור** יש תיבה לכתיבת הסיפור של הדמות. שולחים, והמנחה כותב אותו בדמות במילים שלו, אחרי שאומרים כן.

בשביל תמונת הדמות, נותנים למנחה קובץ תמונה בצ'אט, עם המקום שלו במחשב (PNG, JPEG, WebP או SVG, עד 5 MB):

המנחה מעתיק אותו לקמפיין, והוא מופיע על האסימון של הדמות בלוח. אפשר להחליף אותו באותה דרך בכל עת. RPG Engine עצמו מצייר רק מקומות ומשימות (ראו [תמונות](#311-pictures)).

### 3.8 Saves and going back

RPG Engine שומר את כל הקמפיין **בסוף כל סצנה**, מעצמו. מה אפשר לעשות עם השמירות האלה תלוי בהגדרת **שמירות**:

| שמירות | לשמור כשרוצים | לחזור אחורה |
|---|---|---|
| **מוות קבוע** | לא | אף פעם; אפשר רק להתחיל את הקמפיין מחדש |
| **נקודת ביקורת** | לא | לשמירה האחרונה, רק כשהדמות מתה |
| **חופשי** | כן | לכל שמירה, מתי שרוצים |

בכל מצב אפשר **להתחיל מחדש**: מתחילת המשחק עם אותה דמות, או מסשן אפס עם דמות חדשה.

אפשר לעשות את כל זה בצ'אט ("[בואו נחזור לפני הדו-קרב.]") או בסעיף **שמירות** של הלוח.

**אחרי חזרה אחורה, לפתוח צ'אט חדש.** הצ'אט ששיחקתם בו זוכר את מה שבוטל. לפתוח צ'אט חדש עם המנחה (`/clear` ב-Claude Code, `/new` ב-Codex), לכתוב *המשך*, ואז ללחוץ **נפתח צ'אט חדש** בשמירות, או לומר למנחה בצ'אט החדש. לעולם לא לחדש את הצ'אט הישן. עד שמאשרים, המנחה לא ימשיך.

### 3.9 Sessions: stopping and coming back

**מסיימים את הסשן** מתי שרוצים:

> [בואו נעצור כאן להלילה.]

אין "לשמור ולצאת": הכול כבר בקבצים.

**כדי לסגור** את הצ'אט, כותבים `/exit` ב-Claude Code, או `/quit` ב-Codex. הלוח משתתק עד הצ'אט הבא.

**כדי לחזור**, פותחים טרמינל בתיקיית הקמפיין (זו ש-`init` הדפיס), מפעילים שם את המארח וכותבים *המשך*. המנחה קורא איפה המשחק עומד, נותן סיכום קצר ומתחיל במשהו שקורה. צ'אט חדש לא מאבד כלום: הקמפיין חי בקבצים שלו, לא בצ'אט.

המנחה לא שואל שאלות שגרתיות בסוף. רק אם שם לב שמשהו לא עבד, הוא שואל בקצרה.

### 3.10 The master's mood

בראש הלוח נמצא האווטאר של המנחה, רובוט קטן. הפנים שלו עוקבות אחרי הטון של הסיפור: מודאג כשהסכנה גוברת, שמח מרעיון נועז, מופתע מתפנית. הוא מגיב לרגע ל-20 טבעי או ל-1 טבעי. הוא אף פעם לא מראה מה שעוד לא ידוע: אין חיוך לפני שהמלכודת נסגרת. גם האסימונים של החבורה מראים מצבי רוח. כשהצ'אט סגור, הרובוט ישן.

### 3.11 Pictures

RPG Engine יכול ליצור תמונה לכל מקום שמגיעים אליו ולכל משימה שלוקחים, כפי שקובעת הגדרת **התמונות**. הוא משתמש במה שכבר נמצא במחשב:

- **Codex**, עם ההתחברות ל-ChatGPT: תמונה מצוירת בצבע.
- אחרת **Claude Code**, עם ההתחברות ל-Claude: ציור.

התמונה משתמשת בתוכנית שלך, לא בשלנו. סעיף **ההגדרות** אומר אם אפשר ליצור תמונות במחשב, ואם לא, מה השלבים להגדיר זאת. בלי תמונות, הדף מציג במקומן את הסמל של כל סוג מקום. אפשר גם לתת למנחה תמונה משלך לכל מקום או דמות.

### 3.12 Safety: lines, veils and stop

- **קווים אדומים**: מה שלא מופיע במשחק לעולם.
- **וילונות**: מה שיכול לקרות, אבל רק מחוץ למסך.
- **עצירה**: בכל רגע אפשר לעצור תוכן, בלי להסביר. כותבים זאת מחוץ לסיפור:

> [עצור]

המנחה זונח אותו מיד ומוסיף אותו לקווים האדומים שלך, לכל הסשנים הבאים. אפשר לראות ולשנות את הקווים האדומים והוילונות ב**הגדרות**.

### 3.13 Changing your mind

אפשר לשנות כל הגדרה במהלך הקמפיין: בצ'אט ("[בואו נעשה את זה קשה יותר.]") או ב**הגדרות**. המנחה שומע על שינוי בתשובה הבאה שלו. פסיקה שהמנחה נתן בלי הספר הופכת ל**תקדים** ונשמרת, כך ששאלה זהה תקבל אותה תשובה בפעם הבאה.

## 4. The dashboard, section by section <!-- icon: party -->

הלוח הוא דף במחשב שלך. המנחה נותן לך את הקישור אליו בתחילת כל צ'אט. הוא עוקב אחרי המשחק בזמן אמת: כשהמנחה משנה משהו, הדף משתנה גם הוא.

רק הדפדפן של המחשב שבו משחקים יכול לפתוח אותו: לא טלפון או טאבלט, גם לא באותה רשת Wi-Fi. הדף מתאים גם לחלון צר: אז הסעיפים עוברים לסרגל בתחתית, והסמלים לתפריט.

הדף חי כל עוד הצ'אט חי. סוגרים את הצ'אט, ודף שנשאר פתוח מציג *לא מחובר* עם דף הדמות כפי שהיה, והרובוט של המנחה נרדם; פותחים שוב צ'אט בקמפיין, ואחרי שהמנחה ענה, הדף חוזר מעצמו.

### At the top

- **האווטאר של המנחה**, עם מצב הרוח שלו.
- שם הקמפיין, מערכת המשחק, **זמן המשחק** והאם המשחק **מחובר** (הצ'אט מחובר).
- הסעיפים: **חבורה**, **סצנה**, **קרב** (רק בזמן קרב), **יומן**, **עולם**; בסוף השורה, כסמלים: **שמירות**, **עזרה**, **הגדרות**, **אודות**.
- ערכת הנושא הבהירה והכהה, בפינה הימנית העליונה.

כשהמנחה שואל אותך משהו, הבאנר שלו נשאר בראש הדף, בכל סעיף שנמצאים בו.

### Party

דף הדמות שלך, ושל בני הלוויה. כל חלק בדף הדמות הוא כרטיס שאפשר לפתוח ולסגור.

- **ללחוץ על מספר** כדי להטיל אותו בשביל הכיף. להצביע על מספר כדי לראות איך הוא מורכב ("+5: חוכמה +3, מיומנות +2").
- **נקודות חיים, משבצות ושימושים** מוצגים כפסים וכנקודות.
- **מצבים והשפעות** מוצגים עם משך הזמן שלהם.
- **תיאור** מכיל את הטקסט של הדמות, ואת התיבה לשליחת הסיפור של הדמות למנחה.
- ב-0 נקודות חיים, **הצלות המוות** מופיעות בגדול מתחת לשם.
- לצד דף הדמות (מתחתיו במסך צר): **ההטלות**, החדשות ראשונות, שלך ושל המנחה שמותר לך לראות. **ניקוי** מרוקן את הרשימה; **שחזור** מחזיר אותה. הטלות חופשיות מוצגות בקו מקווקו ועמומות.

בן לוויה עם דף יצור, כמו זאב, מציג את דף היצור שלו במקום דף דמות מלא.

### Scene

איפה החבורה נמצאת: התמונה והשם של המקום, המקומות סביבו, מפת המקום כשיש כזו, מי נמצא שם, והסצנה הפתוחה עם מה שקורה עכשיו. המשימה שעוקבים אחריה נמצאת למעלה.

### Combat

רק בזמן קרב. למעלה: הסבב, מי פועל, מי הבא. למטה: סדר התורות, כל לוחם עם מצבו, החבורה במספרים והאויבים במילים; מה שלדמות יש בהישג יד (דרגת שריון, נקודות חיים, התקפות); מפת המקום, כשהפועל מוקף בעיגול. בתור שלך הקישור לקרב פועם בזהב, בכל מקום שנמצאים בו.

### Journal

שלוש לשוניות:

- **משימות**: פעילות, שהושלמו ושנכשלו, כל אחת ככרטיס עם המטרות שלה, המועד האחרון שלה כשעון ספירה והשעונים שלה. הכוכב עוקב אחרי משימה.
- **סיפור**: פרקי הקמפיין, סצנה אחר סצנה, האחרונה ראשונה.
- **פתקים**: הפתקים שלך, פרטיים עד שמשתפים אחד.

### World

מפת העולם כפי שהדמות מכירה אותה, עם הערפל על השאר. גוררים כדי לזוז, גלגלת או צביטה כדי להתקרב. לוחצים על מקום לכרטיס שלו. רשימת המקומות, הקרוב ראשון, נמצאת לצדה. כשיש יותר ממפה אחת (עיר, יבשת, מישור אחר), לשוניות מחליפות ביניהן.

### The dice tray

כפתור הקוביות פותח את המגש: בוחרים קוביות ומתאם, ומטילים. עם שתי קוביות או יותר מאותו סוג, בוחרים מה נספר: **הכול**, **גבוה** (רק הגבוהה ביותר) או **נמוך** (רק הנמוכה ביותר). הקוביות שבחרת נשארות עד שלוחצים **ניקוי**, כך שהטלת נזק זהה היא לחיצה אחת בכל סבב. כשהמנחה מבקש הטלה, המגש אומר אילו קוביות עונות עליה.

### Saves

השמירות שלך, החדשה ראשונה, כל אחת עם המקום שלה, תאריך המשחק ומתי נוצרה. **לשמור עכשיו** (עם שמירות חופשיות), **לחזור לכאן**, ו**להתחיל מחדש**, באדום, בשני שלבים. ראו [שמירות וחזרה אחורה](#38-saves-and-going-back).

### Settings

ההגדרות שלך, בקבוצות: המשחק, לימוד המשחק (המנטור והחוקים שכבר הוסברו לך), קוביות ומידות, גבולות (קווים אדומים ווילונות), תמונות, שפה. לוחצים על ערך כדי לבחור; מתחתיו, מה הוא אומר. אחר כך ההעדפות של הדף עצמו, שנשמרות בדפדפן הזה בלבד: ערכת הנושא, צליל הקוביות, **סט הקוביות** (שרף, מתכת, עץ, אבן), קצוות מעוגלים או חדים, הטלה ידנית.

ההגדרות של המנחה עצמו, כמו חוקי בית ותקדימים, אינן כאן: הן נשארות בצ'אט.

### Help and About

**עזרה**: המדריך הזה. **אודות**: מה זה RPG Engine, הקישורים שלו, הרישיונות שלו, וההוקרות של מערכת המשחק.

### Before play: Settings and session zero

כשקמפיין חדש בשלב הראשון שלו, **הגדרות**, כל הדף שואל את השאלות שלו: אחת בכל פעם, כל אחת עם משמעות הערכים שלה והערך המומלץ. **ההחלטה שלך** משאיר שאלה למנחה, חוץ מקווים אדומים ווילונות, שהם תמיד שלך; **דילוג** משאיר אותה לאחר כך. בסוף, **אפשר להתחיל**.

### Messages from the page

לפעמים הדף מציג הודעה מעל עצמו: בעיה בקבצי הקמפיין (המנחה מתקן), המשחק רחוק (הצ'אט סגור), הדף בתהליך תרגום.

## 5. Game systems and house rules <!-- icon: dice -->

### 5.1 What a game system is

מערכת משחק היא הנתונים של משחק אחד: דף הדמות שלו, המספרים, היצורים, הפריטים, הלחשים וטקסט החוקים. כל קמפיין משחק מערכת אחת.

RPG Engine מחשב את דף הדמות ואת מה שמוצא ומתחדש, כמו נקודות חיים ומשבצות לחשים, כמו שדף דמות דיגיטלי עושה. איך יכולת או לחש עובדים, המנחה קורא בחוקים ומחליט, כמו ליד שולחן.

### 5.2 Fifth edition, included

RPG Engine מגיע עם **5e**, מתוך ה-System Reference Document 5.1 (חוקי 2014, חופשיים תחת Creative Commons). הוא כולל:

- הגזעים, המקצועות, תתי-המקצועות, רקע ומיומנות מיוחדת של ה-SRD;
- 319 הלחשים, הנשקים, השריונות והציוד, הפריטים הקסומים והמפלצות של ה-SRD;
- פרקי החוקים, שהמנחה מחפש לפי הטקסט המדויק שלהם;
- דף הדמות המלא, מחושב: מתאמי יכולת, שמירות, מיומנויות, דרגת שריון, התקפות, דרגת קושי של לחשים, משבצות, קוביות חיים, יכולות לפי רמה, ניסיון ועלייה ברמה;
- מנוחות שמחזירות מה שצריך; מצבים עם טקסט החוק שלהם; תזכורות ריכוז.

**תוכן מעבר ל-SRD.** אפשר לשחק במהדורה החמישית עם תוכן שחסר ב-SRD, כמו מקצוע או מפלצת מספר שברשותך. המנחה מכיר את המשחק, יכול לקרוא את הספרים שלך ויכול לחפש באינטרנט. הוא כותב מה שהוא צריך כדפים של הקמפיין, ו-RPG Engine עובד איתם באותו אופן. מה שאנחנו מספקים מוגבל על ידי הרישיון שלו; מה שהמנחה שלך יודע אינו מוגבל.

RPG Engine תואם למהדורה החמישית.

### 5.3 House rules and your own additions

אין צורך לגעת באף קובץ. מבקשים מהמנחה:

> [חוק בית: 1 טבעי בהתקפה אומר שהנשק נופל לך מהיד.]
>
> [הייתי רוצה לשחק צייד דמים. יש לי את הספר: הנה יכולות המקצוע.]
>
> [בקמפיין הזה, מנוחה קצרה לוקחת 10 דקות.]

המנחה רושם אותם בקמפיין באחת הדרכים האלה:

- **הסכמה של השולחן**, במילים, כמו הנשק שנופל או המנוחה הקצרה למעלה. המנחה שומר אותה עם ההגדרות של הקמפיין ומשחק לפיה מעכשיו. פסיקה שהמנחה נותן בלי הספר נשמרת באותו אופן, כ**תקדים**.
- **דף חדש**, כמו מקצוע, גזע או פריט. מקצוע חדש עובד כמו של המערכת: הרמה שלך, קוביות החיים והיכולות שלך סופרים אותו. גזע חדש יכול להישען על קיים ("כמו האלף, ועוד..."); חרב בעלת שם יכולה להישען על החרב הארוכה.
- **מספרים חדשים לדף הדמות**: שדה, טבלה, נוסחה, מונה שמנוחה מחזירה. למשל, קוביות העליונות של אמן קרב שחוזרות במנוחה קצרה. חוק בית יכול גם להחליף אחת מנוסחאות המערכת.

אם כבר כתבת חוקי בית, אפשר גם לשים אותם כקובצי טקסט בתיקיית `rules` של הקמפיין (ראו [תיקיית הקמפיין](#8-for-the-curious-the-campaign-folder)): המנחה קורא אותם לפני חוק הספר בעל אותו שם.

### 5.4 Adding or importing your own game system

כרגע RPG Engine משחק רק את המהדורה החמישית. מערכות משחק אחרות יגיעו, וכך גם דרך להוסיף מערכת משלך, או להפוך משחק שברשותך למערכת מתוך הספרים שלו. ראו [בקרוב](#9-coming-later).

## 7. Where a campaign comes from, and its language <!-- icon: world -->

### 7.1 Three ways to have a world

**נוצר תוך כדי תנועה.** נותנים הנחת יסוד בהגדרה, והמנחה בונה את העולם תוך כדי: כל מקום, אדם ועלילה רגע לפני שצריך אותם, ונשמרים מאז. זו הדרך המהירה ביותר לשחק: מתקינים, יוצרים, ותוך כמה דקות יוצרים את הדמות. שום דבר שהומצא לא הולך לאיבוד: מה שנאמר נכתב ונשאר נכון.

**מוכן מההתחלה.** אותה הנחת יסוד, אבל עם **הכנה: הכול בהתחלה**, המנחה בונה את המקומות, הפלגים, האיומים והתוכניות שלהם לפני תחילת המשחק. הסשן הראשון מתחיל מאוחר יותר, עם יותר מוכן מאחורי הקלעים.

**מקמפיין או הרפתקה קיימים.** כרגע אין כפתור ייבוא. נותנים למנחה את ההרפתקה (טקסט או PDF שהמארח יכול לקרוא) ומבקשים ממנו להקים אותה:

> [יש לי את ההרפתקה הזו כ-PDF. תקים אותה כקמפיין שלנו: תקרא אותה, ותכתוב את המקומות, הדמויות והסודות שלה. אל תגלה לי שום דבר ממה שכתוב בה.]

המנחה קורא אותה בכלים של מארח הבינה המלאכותית וכותב אותה כדפי קמפיין, כולל הסודות, שתגלו במשחק. Claude Code קורא PDF; עם Codex, קובץ טקסט או markdown הוא בחירה בטוחה יותר. עושים זאת בזמן ההגדרה, לפני סשן אפס.

בזמן שהמנחה עובד, לא לפתוח את הפירוט של מה שהוא קורא או כותב (ב-Claude Code, ctrl+o): הוא מראה את טקסט ההרפתקה, עם הסודות. המנחה עצמו שומר על הסודות, כמו תמיד.

ברגע שיש לקמפיין דפים משלו, ההגדרה מפסיקה לשאול על הנחת יסוד והכנה. גם בקמפיין כתוב, כשהולכים למקום שהטקסט לא מכסה, המנחה יוצר את מה שצריך ורושם אותו.

**קמפיין משחקים פעם אחת.** כדי לשחק שוב את אותה הרפתקה, יוצרים קמפיין חדש. בתוך קמפיין, עדיין אפשר לחזור לשמירה או להתחיל מחדש, כפי שהגדרת השמירות מתירה.

### 7.2 Languages

**שפה אחת לכל קמפיין**: של המנחה. המנחה כותב בה, והלוח עוקב אחריה. המנחה לוקח אותה מהאופן שבו כותבים, ומאשר אותה.

**הלוח** מגיע באנגלית ובאיטלקית (מוקפדות) ועוד 24 שפות: צרפתית, גרמנית, ספרדית, פורטוגזית (ברזילאית), הולנדית, שוודית, נורווגית, דנית, פינית, איסלנדית, רוסית, אוקראינית, פולנית, צ'כית, רומנית, הונגרית, יוונית, טורקית, ערבית, עברית, הינדי, סינית, יפנית, קוריאנית. ערבית ועברית נקראות מימין לשמאל: הדף משתקף, והמפות והקוביות נשארות כפי שצוירו.

**כל שפה אחרת** שבוחרים ב**הגדרות** מתורגמת במחשב שלך, ברקע, על ידי Codex או Claude Code עם ההתחברות שלך, החל מהסעיף שפתוח. זה נעשה פעם אחת לכל שפה, לכל הקמפיינים. עד שזה מוכן, הדף באנגלית. ההגדרות אומרות אם התרגום בתהליך, מוכן, או בלתי אפשרי במחשב שלך.

**מילות המשחק.** המהדורה החמישית מביאה מונחים משלה באיטלקית מה-SRD האיטלקי הרשמי, ולכן שחקנים איטלקים קוראים *Classe Armatura*, *tiro salvezza*, *vantaggio*. בשפות אחרות מונחי המערכת מתורגמים.

**הטקסט של מערכת המשחק עצמה** (הלחשים, המפלצות, פרקי החוקים) נשאר באנגלית. המנחה קורא אותו ומספר לך אותו בשפה שלך.

**החלפת שפה באמצע קמפיין** משאירה את הדפים שכבר נכתבו כמות שהם; המנחה כותב חדשים בשפה החדשה.

## 8. For the curious: the campaign folder <!-- icon: list -->

אין צורך לפתוח אותה לעולם. אם כן, צריך לדעת ש**היא מכילה את הסודות** של הקמפיין: קריאה בה קלקלה את המשחק.

תיקיית קמפיין מכילה:

- `campaign.yaml`: ההגדרות שלך;
- `state.yaml`: איפה המשחק עומד עכשיו: השלב שלו, התאריך, הסצנה הפתוחה;
- `world/`: דף אחד לכל דמות, מקום, פלג, משימה, פריט, אירוע, נושא או יצור, כקובצי markdown;
- `rules/`: חוקי הבית שלך כקובצי טקסט, אם מוסיפים (`init` לא יוצר אותה);
- `images/`: התמונות, ברגע שיש כאלה;
- `log.jsonl`: כל שינוי, לפי הסדר;
- `.saves/`: השמירות, מהראשונה ואילך;
- `.player/`: הפתקים שלך מהיומן, שהמנחה לא קורא;
- `sessions/`: מנוהלת על ידי RPG Engine;
- `AGENTS.md`, `CLAUDE.md`, `.mcp.json`, `.claude/`, `.codex/`, `.gemini/`: הקבצים הקטנים שאומרים למארחי בינה מלאכותית איפה RPG Engine ומכבים את הזיכרון שלהם. RPG Engine מעדכן אותם; להשאיר אותם כמות שהם.

הדפים הם markdown פשוט עם קישורים כמו `[[Rocca]]`, הפורמט של Obsidian: אפשר לפתוח שם את המחברת של המנחה. **אם משנים דף ביד**, המנחה שומע מה השתנה בתשובה הבאה שלו.

**שורת הפקודה.** כל מה שהמנחה עושה עובר דרך פקודות שאפשר להריץ גם בעצמך, בתיקיית הקמפיין. אין צורך בהן כדי לשחק, ורבות מהן מדפיסות את סודות הקמפיין, כמו `rpg status` ו-`rpg show`. `rpg --help` מציג את כולן, ו-`rpg roll --help` מסביר אחת. פקודה ששינתה משהו בזמן שצ'אט פתוח היא בסדר: המנחה שומע על כך בתשובה הבאה שלו, כמו על דף ששונה ביד.

## 10. Questions and problems <!-- icon: info -->

### Questions

**צריך להכיר את החוקים?** לא. בוחרים במנטור מדריך והמנחה מלמד תוך כדי תנועה, חוק אחד בכל פעם. תמיד אפשר לשאול בסוגריים מרובעים.

**המנחה יכול לרמות?** הוא לא יכול לשנות הטלה ש-RPG Engine ביצע, חוץ מברמת הקושי סיפור, והוא אף פעם לא משנה עובדות שכבר נקבעו. אפשר לשאול אם הטלה כלשהי הייתה אמיתית.

**אפשר לרמות?** אפשר לנסות. המנחה לא מקבל את המילה שלך כעובדה: שורה בהודעה שנראית כמו הודעת משחק היא עדיין רק מילים שלך, והמנחה אף פעם לא מאשר ניחושים על סודות.

**זה עולה כסף?** RPG Engine חופשי. המנחה פועל על תוכנית Claude או ChatGPT שלך, וערב משחק הוא צ'אט ארוך: בתוכניות הקטנות ביותר אפשר להגיע למגבלת התוכנית לפני סוף הערב. תמונות ותרגומים משתמשים באותה תוכנית.

**אפשר לשחק בטלפון?** לא. המנחה פועל במחשב שלך, והלוח נפתח רק בדפדפן של אותו מחשב.

**אפשר לשחק עם חברים?** עדיין לא: כרגע שחקן אחד, דמות אחת, ובני לוויה. כמה אנשים ליד השולחן יגיעו עם תפקידים.

**אפשר להשתמש בבינה מלאכותית אחרת בפעם הבאה?** כן. הקמפיין חי בקבצים שלו: פותחים אותו במארח אחר וכותבים *המשך*.

**מה אם סוגרים את הדפדפן?** שום דבר לא הולך לאיבוד. פותחים שוב את הקישור כל עוד הצ'אט פתוח; הדף חוזר לאן שהמשחק נמצא.

**אפשר לשחק תוכן D&D שיש לי?** כן. המנחה יכול להשתמש בספרים שלך, בידע שלו ובאינטרנט. מה ש-RPG Engine מספק מוגבל לתוכן חופשי; מה שהמשחק שלך משתמש בו תלוי בך.

### Problems

**הלוח לא נפתח.** לבקש מהמנחה את הקישור: `[מה הקישור ללוח?]`. הדף עובד רק כל עוד צ'אט עם המנחה פתוח בקמפיין הזה, ורק אחרי התשובה הראשונה של המנחה בצ'אט הזה. כשהצ'אט סגור, הדפדפן לא מגיע לדף; דף שנשאר פתוח אומר *לא מחובר*.

**נראה שהמנחה לא מכיר את המשחק, או ממציא כלים.** מארח הבינה המלאכותית לא טען את RPG Engine.

- קודם, לוודא שהפעלתם את המארח **בתיקיית הקמפיין**, ושאמרתם שסומכים עליה.
- **Claude Code**: לכתוב `/mcp`. אם `rpg` שם אבל נכשל, לבחור בו ואז **Reconnect**. אם הוא חסר, לסגור את Claude Code, לכתוב `claude mcp reset-project-choices` בתיקיית הקמפיין, ולהפעיל אותו שוב.
- **Codex**: לכתוב `codex mcp list` בטרמינל, בתיקיית הקמפיין. אם `rpg` חסר, Codex לא סומך על התיקייה: להפעיל אותו שוב שם ולענות כן כששואל.
- בשניהם: אם `rpg --version` בטרמינל אומר שהפקודה לא נמצאה, להתקין שוב את RPG Engine ([2.2](#22-install)) ולפתוח טרמינל חדש.

**אחרי עדכון, שום דבר לא השתנה.** מנחה שרץ שומר על הגרסה שאיתה התחיל. לפתוח צ'אט חדש, או ב-Claude Code לחבר מחדש את השרת (`/mcp`, ואז `rpg`, ואז **Reconnect**).

**המנחה זוכר משהו שביטלתי.** חזרתם לשמירה אבל המשכתם לשחק באותו צ'אט. לפתוח צ'אט חדש וללחוץ **נפתח צ'אט חדש** בשמירות.

**המנחה שואל שאלות הגדרה שכבר עניתי עליהן בדף.** לומר לו: `[בחרתי אותן בלוח.]`

**לא מופיעות תמונות.** לפתוח הגדרות > תמונות: הוא אומר אם המחשב הזה יכול ליצור אותן, ואם לא, מה השלבים, כל פקודה עם כפתור להעתקה.

**הדף באנגלית אבל בחרתי שפה אחרת.** הוא מתורגם ברקע; ההגדרות אומרות איך זה מתקדם. בלי Codex או Claude Code במחשב הזה, הוא נשאר באנגלית.

**המנחה אומר שיש בעיות בקמפיין.** הוא מתקן אותן בעצמו. אם ערכתם קבצים ביד, הוא עשוי לשאול מה התכוונתם.

**Windows: `npm` נכשל בתיקייה שלי.** לא לשמור את הקמפיין, או את RPG Engine, בנתיב שמכיל `&`.

**ההתקנה נכשלת, או ש-`rpg` לא עולה.** לבדוק את גרסת Node.js עם `node --version`: היא חייבת להיות 22 ומעלה. אם היא ישנה יותר, להתקין את גרסת ה-LTS מ-[nodejs.org](https://nodejs.org), ואז להתקין שוב את RPG Engine.

**הקישור ללוח השתנה.** תוכנה אחרת השתמשה בכתובת הרגילה של הקמפיין, או ש-Windows שמרה אותה. RPG Engine לקח אחרת; המנחה נותן את הקישור החדש. שום דבר אחר לא משתנה.
