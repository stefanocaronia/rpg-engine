# RPG Engine: המדריך המלא

**RPG Engine** מאפשר לשחק משחק תפקידים שולחני עם **בינה מלאכותית בתפקיד המנחה**. מדברים עם המנחה ב**צ'אט**; RPG Engine עובד מאחורי הקלעים: הוא **זוכר את העולם**, **מטיל את הקוביות** ו**מנהל את החשבונות**. לצד הצ'אט משאירים בדפדפן דף פתוח, **הלוח** (dashboard), עם דף הדמות, הקוביות, המפות והיומן.

המדריך הזה מיועד לשחקנים: אין צורך לדעת תכנות.

## התחלה מהירה <!-- icon: send -->

1. להתקין את **Node.js** מהאתר [nodejs.org](https://nodejs.org) (גרסת LTS).
2. להתקין **סוכן בינה מלאכותית**, התוכנה שבה המנחה פועל, ולהתחבר אליו: למשל Claude Code או Codex ([2.4](#24-connect-your-ai)).
3. בטרמינל, להתקין את RPG Engine: `npm install -g rpg-engine`.
4. ליצור קמפיין: `rpg init "The Salt Isles"`.
5. להיכנס לתיקייה החדשה, `cd "The Salt Isles"`, ולהפעיל בה את הסוכן: `claude` עבור Claude Code, `codex` עבור Codex. לאשר כשהוא שואל אם סומכים על התיקייה ([2.4](#24-connect-your-ai)), ואז לכתוב *שלום! בוא נתחיל.* המנחה עונה עם הקישור ללוח.

## 1. מהו RPG Engine <!-- icon: about -->

| מי | מה הוא עושה |
|---|---|
| **אתה** | משחקים את הדמות: מה היא עושה, אומרת ומנסה. |
| **המנחה** (הבינה המלאכותית) | מספר את הסיפור, משחק את כל השאר, מחליט מה קורה, מבקש הטלות. |
| **RPG Engine** | שומר את העולם בקבצים, מטיל את הקוביות, סופר נקודות חיים, כסף, זמן ומרחקים, ושומר סודות עד שמגלים אותם. |

העולם נשאר זהה מערב לערב, גם בצ'אט חדש, וגם עם בינה מלאכותית אחרת:

- **מה שנאמר נשאר נכון.** נבל שמת נשאר מת.
- **הקוביות אמיתיות.** המנחה לא יכול לעוות אותן, אלא ברמת הקושי הקלה ביותר, אם בוחרים בה.
- **סודות נשארים סודות.** המנחה אף פעם לא מספר מה שהדמות אינה יודעת.
- **העולם זז.** איומים מתקדמים בזמן מנוחה או מסע, ואפשר לראות את סימניהם.
- **קמפיין הוא תיקייה** במחשב: אפשר להפסיק מתי שרוצים ולהמשיך מאוחר יותר.

כיום RPG Engine משחק מערכת משחק אחת, **מהדורה חמישית**, מתוך מסמך הכללים החופשי System Reference Document 5.1. אחרות יגיעו ([בהמשך](#9-coming-later)).

## 2. תחילת העבודה <!-- icon: path -->

### 2.1 מה צריך

- מחשב עם Windows, macOS או Linux, ודפדפן.
- **Node.js 22** ומעלה, מהאתר [nodejs.org](https://nodejs.org). הוא מביא איתו את `npm`, שמתקין את RPG Engine.
- **טרמינל**: ב-Windows, Terminal או PowerShell; ב-macOS, Terminal. כדי לפתוח טרמינל בתיקייה, לוחצים עליה בלחצן הימני ובוחרים **Open in Terminal** (ב-Windows) או **Services > New Terminal at Folder** (ב-macOS).
- **סוכן בינה מלאכותית** בשביל המנחה ([2.4](#24-connect-your-ai)), עם **המודל הגדול ביותר** שהוא מציע: מודל קטן קל יותר לשכנע לחשוף סודות או לעקוף כללים.

### 2.2 התקנה

```text
npm install -g rpg-engine
```

הפקודה `rpg --version` בודקת שההתקנה הצליחה. משתמשים ב-`rpg` פעם אחת לכל קמפיין, כדי ליצור אותו; אחר כך הסוכן מפעיל את RPG Engine בעצמו.

### 2.3 יצירת קמפיין

לפתוח טרמינל בתיקייה שבה שומרים את המשחקים ([2.1](#21-what-you-need) מסביר איך):

```text
rpg init "The Salt Isles"
```

הפקודה יוצרת את התיקייה `The Salt Isles` עם קמפיין חדש בתוכה; נכנסים אליה עם `cd "The Salt Isles"`. כדאי לזכור איפה היא: חוזרים אליה בכל פעם שמשחקים. את כל השאר בוחרים אחר כך, בצ'אט או בלוח; `rpg init --help` מציג את האפשרויות לבחור כבר עכשיו, כמו `--language it` או `--difficulty hard`.

המנחה לא יכול ליצור קמפיין: לפני `init`, שום דבר לא אומר לסוכן איפה RPG Engine.

### 2.4 חיבור הבינה המלאכותית

המנחה פועל ב**סוכן בינה מלאכותית**: אפליקציית בינה מלאכותית, בטרמינל או בשולחן העבודה, שיכולה לעבוד עם הקבצים שבמחשב, כמו Claude Code או Codex. צ'אט רגיל כמו claude.ai או ChatGPT, או אפליקציה בטלפון, לא מספיקים: המנחה צריך להגיע לקבצי הקמפיין במחשב. לכל סוכן יש מנוי והתחברות משלו: Claude Code דורש מנוי Claude בתשלום, Codex דורש התחברות ל-ChatGPT. מתקינים אותו פעם אחת, מהדף שלו: [Claude Code](https://code.claude.com/docs/en/setup), [Codex](https://learn.chatgpt.com/docs/codex/cli).

- **Claude Code**: בתיקיית הקמפיין לכתוב `claude`. כשהוא שואל אם סומכים על התיקייה, לבחור **Yes, I trust this folder**; זהירות, התשובה שמסומנת מראש היא *No, exit*.
- **Codex**: בתיקיית הקמפיין לכתוב `codex`, ולאשר כשהוא שואל אם סומכים על התיקייה. באפליקציית שולחן העבודה שלו, לבדוק בהגדרות שהזיכרונות כבויים עבור הצ'אטים של המשחק.
- **סוכן אחר**: להפעיל אותו בתיקיית הקמפיין ולתת לו את שרת ה-MCP `rpg mcp`. RPG Engine הוא שרת MCP סטנדרטי: כל סוכן שתומך ב-MCP יכול להיות המנחה, כולל סוכנים מקומיים.

אנחנו משחקים ובודקים עם **Claude Code**; **Codex** מחובר ונבדק, אבל עדיין לא שוחק איתו קמפיין שלם; `init` מגדיר גם את **Gemini CLI**. הקמפיין מכבה את הזיכרון של הסוכן עצמו: המשחק חי בקבצים שלו, כך שחזרה לשמירה באמת חוזרת אחורה.

### 2.5 הצ'אט הראשון

לכתוב משהו, למשל *שלום! בוא נתחיל.* בתשובה הראשונה בכל צ'אט המנחה נותן את **הקישור ללוח**, משהו כמו `http://127.0.0.1:4750`: לפתוח אותו ולהשאיר לצד הצ'אט.

בין ההודעות של המנחה הסוכן מציג את הכלים שהוא משתמש בהם: לא לפתוח את הפרטים שלהם (ב-Claude Code, ctrl+o), הם עלולים לחשוף סודות.

קמפיין חדש עובר שלושה שלבים, שמוצגים בראש הלוח: **1 הגדרות** (איך רוצים לשחק), **2 סשן אפס** (יוצרים את הדמות, תוך כדי משחק), **3 משחק**.

### 2.6 הגדרות: בחירת אופן המשחק

המנחה שואל רק את מה שעוד חסר, כמה שאלות בכל פעם; השלב **הגדרות** בלוח מציג את אותן שאלות ככרטיסים. אם כותבים "תחליט אתה", המנחה בוחר. אפשר לשנות הכול אחר כך, בצ'אט או ב**הגדרות**.

| הגדרה | מה היא קובעת | ערכים |
|---|---|---|
| **מנטור** | כמה המנחה מלמד את הכללים | כבוי, רמזים, הדרכה |
| **רמת קושי** | כמה קשה העולם | סיפור, קל, רגיל, קשה, אכזרי |
| **קטלניות** | מה משמעות הנפילה בקרב | סיפורית (אף פעם לא מתים), אפית (רק כשזה חשוב), קוביות |
| **שמירות** | מתי אפשר לחזור אחורה | מוות סופי, נקודת ביקורת, חופשי ([3.8](#38-saves-and-going-back)) |
| **קפדנות** | עד כמה אוכל, אור ומסעות מצייתים לכללים | חלק, כללים, סימולציה |
| **קוביות** | מי מטיל את הקוביות | דיגיטליות, פיזיות |
| **יחידות מידה** | מרחקים ומשקלים | מטרי, אימפריאלי |
| **בני לוויה** | מי נוסע איתך | אין, נוצרים יחד, נוצרים על ידי המנחה, פוגשים במשחק |
| **תמונות** | תמונות של מקומות, משימות ומי שפוגשים | אין, לפי בקשה, מקומות חדשים, משימות ומי שפוגשים ([3.11](#311-pictures)) |
| **קווים אדומים** ו**וילונות** | מה לא מופיע לעולם, ומה קורה רק מחוץ למסך | רשימות |
| **שפה** | השפה של המשחק ושל הלוח | כל שפה |

המהדורה החמישית מוסיפה **התקדמות**: נקודות ניסיון או אבני דרך.

כשאין עולם כתוב, המנחה שואל גם **רעיון פתיחה** (ז'אנר, אווירה, כמה מרכיבים, במילים שלך) ואת **ההכנה**: לבנות את העולם תוך כדי משחק, או כולו בהתחלה.

**הסגנון של המנחה** אינו נשאל אף פעם, אבל אפשר לשנות אותו בצ'אט או ב**הגדרות**: **הפרוזה** (פשוטה, ספרותית, פּאלפּ, עוקצנית), **הסיפורים** שהמנחה ממציא (מצבים, קשתות, פרקים, תעלומה), סופר ש**כותבים כמוהו**, או כל דבר אחר **במילים שלך**.

### 2.7 סשן אפס: הדמות

יוצרים את הדמות יחד עם המנחה, כמו ליד שולחן. כל בחירה היא שלך, אלא אם מבקשים מהמנחה לבחור: אפשר להגיע עם רעיון מלא, עם רעיון מעורפל, או בלי כלום. המנחה מסביר איך נקבעים ציוני היכולת לפני שמוטלת קובייה כלשהי. סיפור הרקע אינו חובה; אם נותנים אחד, המנחה כותב אותו במילים שלך. אחר כך המנחה מבקש תמונה של הדמות ([3.7](#37-your-characters-story-and-picture)). RPG Engine מחשב את דף הדמות: אף פעם לא צריך לעשות חישובים.

## 3. משחק <!-- icon: chat -->

### 3.1 שיחה עם המנחה

כותבים מה הדמות עושה או אומרת, במילים שלך:

> אני שואל את בעל האכסניה מי עוד עבר כאן הלילה.

מחוץ לסיפור, כותבים בסוגריים מרובעים: *[איך עובדת היאחזות?]* המנחה עונה גם הוא בסוגריים מרובעים.

אתה אומר מה אתה מנסה לעשות, והמנחה אומר מה קורה. המנחה אף פעם לא מחליט במקום הדמות, ואף פעם לא מדבר על המנוע. אפשר לשאול את המנחה איך משתמשים בלוח הבקרה.

### 3.2 הטלות

המנחה מבקש הטלה רק כשהתוצאה אינה ודאית וחשובה, ואומר קודם מה על הכף. אחר כך:

- **בלוח הבקרה**, באנר מציג כפתור לכל בדיקה, כמו *Acrobatics +4 · with advantage*. לוחצים עליו: הקוביות נופלות על הדף והמנחה שומע את התוצאה. אפשר גם ללחוץ על השורה שנדלקת בדף הדמות, להטיל קוביות מהמגש, או לכתוב משהו אחר באנר.
- **ידנית**, בפינת הבאנר או ב**הגדרות**: הבאנר אומר מה להטיל, ומטילים מדף הדמות או ממגש הקוביות.
- **קוביות פיזיות**, כשהגדרת הקוביות על פיזיות: כותבים את הערכים שהוטלו, *[הטלתי 14.]*, ו-RPG Engine מוסיף את המתאמים.

**הטלות חופשיות**: לוחצים על כל מספר בדף הדמות, או פותחים את המגש, כדי להטיל להנאה. הן אף פעם לא נחשבות והמנחה אף פעם לא רואה אותן.

**ההטלות של המנחה** מופיעות בעמודת ההטלות שלך, חוץ מההטלות הסודיות. תמיד אפשר לשאול *[האם ההטלה הזאת הייתה אמיתית?]*: על הטלה סודית המנחה נותן טביעת אצבע שמוכיחה שההטלה נעשתה לפני ששאלת.

### 3.3 סצנות וקרבות

הסיפור מתנהל ב**סצנות**: קרב, שיחה, חקירה, מסע, מנוחה. בסוף כל סצנה המשחק נשמר מעצמו, והסצנה נכנסת ליומן.

בקרב המנחה מתאר כל תור שאינו שלך, ועוצר איפה שאפשר להחליט. ה**סצנה** מציגה למעלה של מי התור ומי הבא בתור, ואת כרטיס הדמות לצד המפה. סדר התורות, נקודות הפגיעה של החבורה ומצבם של האויבים, במילים, נשארים בצד הדף. אם הדמות נופלת, הטלות ההצלה מפני המוות מופיעות בגדול בדף.

### 3.4 זמן, מסעות והעולם שנע

RPG Engine שומר את התאריך, ואין זמן שעובר בין סשנים. כשכותבים שנחים, *אנחנו נחים מנוחה ארוכה*, המנוחה מחזירה מה שצריך. כשכותבים לאן הולכים, *אנחנו יוצאים בדרך צפונה לרוקה*, RPG Engine מחשב את הדרך, את המרחק ואת הימים, ועוצר כשקורה משהו בדרך. הכסף נספר במטבעות המשחק, כולל עודף.

לנבלים יש תוכניות עם מועדים. בכל יום חדש המנחה מקדם את האיומים שהזמן קידם, ואפשר לראות את סימניהם, אבל אף פעם לא את השעון עצמו.

### 3.5 מפות

**עולם** מציג את המקומות שהדמות מכירה, את הדרכים ביניהם ואת השביל שנעבר, וערפל מכסה על השאר. **סצנה** מציגה את מפת המקום שבו הדמות נמצאת, כשיש כזו, ומי עומד איפה. בקרב, בתור של הדמות, המשבצות שאי אפשר להגיע אליהן מכוסות. כשהמנחה שואל לאן לזוז, נוגעים במשבצת או כותבים אותה, למשל *E4*.

### 3.6 משימות, יומן ופתקים

משימה שהדמות לוקחת הופכת למשימה ב**יומן**, עם המטרות שלה, המועד שלה ומה שהיא מודדת. אפשר לסמן אותה בכוכב כדי שתישאר לעין בראש ה**סצנה**. היומן גם מספר את ה**סיפור**, סצנה אחר סצנה, ושומר את ה**פתקים**: הם פרטיים, אלא אם **לשתף** אחד מהם, ואז המנחה שומע אותו כמה שהדמות חושבת, ולא כעובדה.

### 3.7 הסיפור והתמונה של הדמות

בדף הדמות, בכרטיס **תיאור** יש תיבה לסיפור הדמות: המנחה כותב בה, אחרי שאומרים כן. לתמונה, אפשר לתת למנחה קובץ (PNG, JPEG, WebP או SVG, עד 5 MB) יחד עם המקום שלו במחשב, או להזמין דיוקן ([3.11](#311-pictures)): *[צור לי דיוקן: שיער אפור בצמה, צלקת על הסנטר.]*

### 3.8 שמירות וחזרה אחורה

RPG Engine שומר את כל הקמפיין בסוף כל סצנה. הגדרת ה**שמירות** קובעת את השאר:

| שמירות | שמירה כשרוצים | חזרה אחורה |
|---|---|---|
| **permadeath** | לא | אף פעם |
| **checkpoint** | לא | לשמירה האחרונה, רק כשהדמות מתה |
| **free** | כן | לכל שמירה |

בכל מצב אפשר **להתחיל מחדש**, מתחילת המשחק או מסשן אפס. עושים את זה בצ'אט או ב**שמירות**.

אחרי חזרה אחורה, **פותחים צ'אט חדש**: הצ'אט הישן זוכר את מה שבוטל. כותבים *המשך* בצ'אט החדש, ואז לוחצים על **נפתח צ'אט חדש** ב"שמירות".

### 3.9 סשנים: להפסיק ולחזור

אפשר להפסיק בכל רגע: *[בואו נעצור כאן להערב.]* הכול כבר שמור בקבצים. כדי לחזור, מפעילים את הסוכן בתיקיית הקמפיין וכותבים *המשך*: המנחה נותן סיכום קצר וממשיך.

### 3.10 מצב הרוח של המנחה

הרובוט בראש לוח הבקרה הוא המנחה: הפנים שלו עוקבות אחרי הטון של הסיפור, ואף פעם לא מגלות מה שעדיין לא ידוע. כשהצ'אט סגור, הוא ישן.

### 3.11 תמונות

RPG Engine יכול ליצור תמונות של המקומות שמגיעים אליהם, של המשימות שלוקחים ושל מי שפוגשים, כפי שקובעת הגדרת **התמונות**, ושל דיוקן הדמות כשמבקשים. הוא משתמש במה שיש במחשב, עם ההתחברות שלך: **Codex** מצייר אותן, ואם לא, **Claude Code** משרטט אותן. **הגדרות** אומרת אם המחשב הזה יכול ליצור אותן, ואיך מגדירים אם לא. תמיד אפשר לתת למנחה תמונה משלך.

### 3.12 בטיחות: קווים אדומים, וילונות ועצירה

**קווים אדומים** אף פעם לא מופיעים במשחק, **וילונות** קורים רק מחוץ למסך. בכל רגע אפשר לכתוב *[עצור]*: המנחה זונח את התוכן הזה מיד ומוסיף אותו לקווים האדומים.

### 3.13 שינוי דעה

אפשר לשנות כל הגדרה, בצ'אט או ב**הגדרות**. החלטה שהמנחה מקבל בלי הספר הופכת ל**תקדים**, כדי שאותה שאלה תקבל אותה תשובה בפעם הבאה.

## 4. לוח הבקרה <!-- icon: party -->

דף במחשב שלך, שנפתח רק בדפדפן של אותו מחשב, וחי כל עוד הצ'אט פתוח. כשהצ'אט נסגר, מוצג בו *Not connected*, והוא חוזר מעצמו עם הצ'אט הבא.

- **חבורה**: דף הדמות שלך ושל בני הלוויה. לוחצים על מספר כדי להטיל אותו, ומרחפים מעליו כדי לראות מאיפה הוא בא. לצדו, ההטלות.
- **סצנה**: איפה אתם, התמונה והמפה שלה, מי נמצא שם, מה קורה. בקרב, התורות וכרטיס הדמות.
- **יומן**: משימות, הסיפור, הפתקים שלך.
- **עולם**: מפת העולם כפי שהדמות מכירה אותו.
- **מגש הקוביות**: בוחרים קוביות ומתאם, ומטילים.
- **שמירות**, **עזרה**, **הגדרות** ו**אודות**, כסמלים בסוף השורה. ההגדרות כוללות גם את ההעדפות של הדף עצמו: ערכת נושא, צליל הקוביות, סט הקוביות.

כשהמנחה שואל אותך משהו, הבאנר שלו נשאר למעלה, בכל מקטע שבו נמצאים.

## 5. מערכות משחק וחוקי בית <!-- icon: dice -->

### 5.1 מהי מערכת משחק

הנתונים של משחק אחד: דף הדמות שלו, המספרים, היצורים, החפצים, הלחשים וטקסט הכללים. כל קמפיין משחק מערכת אחת. RPG Engine מחשב את דף הדמות ומה שמוצא ומה שחוזר; איך יכולת פועלת, המנחה קורא בכללים ומחליט, כמו ליד שולחן.

### 5.2 מהדורה חמישית, כלולה

הגזעים, המקצועות, תתי-המקצועות, רקע ויכולת מיוחדת מתוך SRD 5.1; 319 הלחשים, הנשקים, השריונות, החפצים הקסומים והמפלצות; פרקי הכללים, שהמנחה קורא לפי הטקסט המדויק שלהם; דף הדמות המלא, מחושב.

אפשר לשחק גם תוכן שאין ב-SRD, מספר שברשותך: המנחה כותב אותו כדפים של הקמפיין, ו-RPG Engine מתייחס אליהם כאל שלו. RPG Engine מגיע רק עם תוכן פתוח; מה שהמנחה שלך יודע אינו מוגבל.

### 5.3 חוקי בית והוספות משלך

לבקש מהמנחה: *[חוק בית: 1 טבעי בהתקפה אומר שהנשק נופל.]* המנחה שומר אותו כהסכמה של השולחן, או כותב דף או מספר בדף הדמות כשצריך. חוקי בית שכבר כתובים יכולים להיות קובצי טקסט בתיקיית `rules` של הקמפיין.

### 5.4 הוספה או ייבוא של מערכת משחק משלך

עדיין לא: כיום RPG Engine משחק רק מהדורה חמישית ([בהמשך](#9-coming-later)).

## 7. מאיפה בא קמפיין, והשפה שלו <!-- icon: world -->

### 7.1 שלוש דרכים לקבל עולם

- **נוצר תוך כדי משחק**: מתוך רעיון הפתיחה שלך, המנחה בונה כל מקום, אדם ועלילה רגע לפני שצריך אותם, ושומר אותם.
- **מוכן מההתחלה**: אותו דבר, כשהעולם נבנה לפני המשחק.
- **מהרפתקה משלך**: נותנים למנחה טקסט או PDF ומבקשים ממנו להכין אותו, *[הכן את ההרפתקה הזאת בתור הקמפיין שלנו. אל תגלה לי שום דבר ממה שכתוב בה.]* המנחה כותב את המקומות, הדמויות והסודות. עדיין אין לחצן ייבוא.

קמפיין משחקים פעם אחת: כדי לשחק שוב את אותה הרפתקה, יוצרים קמפיין חדש.

### 7.2 שפות

שפה אחת לכל קמפיין, השפה של המנחה, והלוח עוקב אחריה. הלוח מגיע עם 26 שפות. כל שפה אחרת מתורגמת במחשב שלך על ידי Codex או Claude Code, ואם אין אותם, על ידי המנחה בצ'אט. המונחים של המהדורה החמישית באיטלקית באים מה-SRD האיטלקי הרשמי; טקסט הכללים נשאר באנגלית, והמנחה מספר אותו בשפה שלך.

## 8. למי שסקרן: תיקיית הקמפיין <!-- icon: list -->

אין שום צורך לפתוח אותה, והיא מכילה את סודות הקמפיין. יש בה את `campaign.yaml` (ההגדרות), את `state.yaml` (מצב המשחק), את `world/` (דף markdown אחד לכל דמות, מקום, משימה ושאר הדברים), את `rules/` (חוקי הבית), את `images/`, את `log.jsonl` (כל שינוי), את `.saves/`, את `.player/` (הפתקים), ואת הקבצים הקטנים שמסבירים לסוכני AI איפה RPG Engine נמצא. הדפים בנויים בפורמט של Obsidian. אם משנים דף ידנית, המנחה יֵדע על כך בתשובה הבאה שלו.

RPG Engine נשאר בתיקייה הזאת: הוא קורא וכותב את המשחק רק בה, ואף פעם לא נוגע בקבצים האחרים. מחוץ לה הוא שומר רק תיקיית נתונים משלו (התרגומים של הדשבורד, ואת Codex או Claude Code אם מתירים לו להתקין אותם) ותיקיות זמניות בזמן שמציירים תמונה. כל דבר אחר שהסוכן רוצה לעשות במחשב, הוא שואל קודם.

כל פקודה שהמנחה משתמש בה אפשר להריץ גם בתיקיית הקמפיין: `rpg --help` מציג את רשימתן. רבות מהן מדפיסות את סודות הקמפיין.

## 10. שאלות ובעיות <!-- icon: info -->

### שאלות

**צריך להכיר את הכללים?** לא. לבחור מנטור בהדרכה, ולשאול בסוגריים מתי שרוצים.

**המנחה יכול לרמות?** הוא לא יכול לשנות הטלה ש-RPG Engine ביצע, אלא ברמת קושי סיפור, וגם לא עובדות שכבר נקבעו.

**זה עולה כסף?** RPG Engine חינמי. המנחה פועל על המנוי של הסוכן, או על המחשב שלך עם מודל מקומי. ערב משחק הוא צ'אט ארוך: במנויים הקטנים ביותר אפשר להגיע למגבלת המנוי לפני שהערב נגמר. תמונות ותרגומים משתמשים באותו מנוי.

**אפשר לשחק בטלפון?** לא: המנחה פועל במחשב, והלוח נפתח רק שם.

**אפשר לשחק עם חברים?** עדיין לא: כיום שחקן אחד, דמות אחת, ובני לוויה ([בהמשך](#9-coming-later)).

**אפשר להשתמש בבינה מלאכותית אחרת בפעם הבאה?** כן: לפתוח את הקמפיין בסוכן אחר ולכתוב *המשך*.

### בעיות

**הלוח לא נפתח.** לשאול את המנחה: `[מה הקישור ללוח?]`. הוא עובד רק כשצ'אט פתוח בקמפיין הזה, אחרי התשובה הראשונה של המנחה.

**נראה שהמנחה לא מכיר את המשחק.** הסוכן לא טען את RPG Engine. לבדוק שהפעלת אותו בתיקיית הקמפיין ואישרת שסומכים עליה. ב-Claude Code, לכתוב `/mcp` ולחבר מחדש את `rpg`. ב-Codex, `codex mcp list` בתיקיית הקמפיין חייב להציג את `rpg`. אם `rpg --version` לא נמצא, להתקין שוב את RPG Engine ([2.2](#22-install)).

**עדכון.** להריץ שוב `npm install -g rpg-engine`, ואז לפתוח צ'אט חדש: מנחה שכבר רץ נשאר עם הגרסה שהתחיל איתה.

**המנחה זוכר משהו שביטלתי.** לפתוח צ'אט חדש וללחוץ על **נפתח צ'אט חדש** ב**שמירות**.

**לא מופיעות תמונות.** הגדרות > תמונות אומר אם המחשב הזה יכול ליצור אותן, ואיך.

**ההתקנה נכשלת, או ש-`rpg` לא מתחיל.** `node --version` חייב להראות 22 ומעלה. ב-Windows, להרחיק את RPG Engine והקמפיינים מנתיבים שמכילים `&`.

**הקישור ללוח השתנה.** תוכנה אחרת תפסה את הכתובת הרגילה; המנחה נותן את הקישור החדש.
