# RPG Engine: המדריך המלא

**RPG Engine** מאפשר לשחק משחק תפקידים שולחני עם **בינה מלאכותית בתפקיד המנחה**. משחקים ב**לוח בקרה**: חלון במחשב עם דף הדמות, הקוביות, המפות, היומן וה**צ'אט** עם המנחה. RPG Engine עובד מאחורי הקלעים: הוא **זוכר את העולם**, **מטיל את הקוביות** ו**מנהל את החשבונות**.

המדריך הזה מיועד לשחקנים: אין צורך לדעת תכנות.

## התחלה מהירה <!-- icon: send -->

1. להתקין את **Node.js** מהאתר [nodejs.org](https://nodejs.org) (גרסת LTS).
2. פעם אחת, בטרמינל חדש שנפתח אחרי שהותקן Node.js, להתקין את RPG Engine: `npm install -g rpg-engine`. אם Windows מודיעה שהרצת סקריפטים מושבתת, לכתוב פעם אחת `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`, לענות yes ולנסות שוב.
3. לכתוב `rpg open`. הפקודה שואלת אם להוסיף את הסמל של RPG Engine לשולחן העבודה ולתפריט: ללחוץ Enter לאישור. מכאן ואילך מפעילים את RPG Engine מהסמל, בלי טרמינל ([2.2](#22-install)).
4. חלון מציג את הקמפיינים. ללחוץ על **קמפיין חדש**, לתת לו שם וללחוץ על **יצירה** ([2.3](#23-create-a-campaign)): לוח הבקרה שלו נפתח בחלון משלו.
5. בצ'אט עם המנחה, לבחור את אפליקציית ה-AI ואת המודל שלה: Claude Code דורש מנוי בתשלום של Claude, Codex חשבון ChatGPT, חינמי או בתשלום ([2.4](#24-connect-your-ai)). אם האפליקציה חסרה, או שלא מחוברים אליה, הדף מתקין אותה או מחבר אליה. ללחוץ על **פתיחת הצ'אט**, ואז על **להתחיל**. התשובה הראשונה יכולה לקחת כמה דקות. אחר כך המנחה שואל איך רוצים לשחק, ויוצרים יחד את הדמות.

## 1. מהו RPG Engine <!-- icon: about -->

| מי | מה עושים |
|---|---|
| **אתה** | משחקים את הדמות: מה היא עושה, אומרת ומנסה. |
| **המנחה** (ה־AI) | מספר את הסיפור, מגלם את כל האחרים, מחליט מה קורה, מבקש הטלות. |
| **RPG Engine** | שומר את העולם בקבצים, מטיל את הקוביות, סופר נקודות חיים, כסף, זמן ומרחקים, ושומר סודות עד שמגלים אותם. |

העולם נשאר אותו עולם מערב אחד לשני, גם בצ'אט חדש, וגם עם AI אחר:

- **מה שנאמר נשאר נכון.** נבל שמת נשאר מת.
- **הקוביות אמיתיות.** המנחה לא יכול לעוות אותן, חוץ מברמת הקושי הקלה ביותר, אם בוחרים בה.
- **סודות נשארים סודיים.** המנחה אף פעם לא מגלה מה שהדמות אינה יודעת.
- **העולם ממשיך לזוז.** איומים מתקדמים בזמן מנוחה או מסע, ורואים את האותות שלהם.
- **קמפיין הוא תיקייה** במחשב: אפשר לעצור בכל רגע ולהמשיך מאוחר יותר.

משחק מגיע כמערכת משחק, חבילה שהמנחה מתקין לקמפיין: כיום המערכת שלנו היא **המהדורה החמישית**, מתוך ה־System Reference Document 5.1 החופשי. בלי מערכת משחק משחקים בחופשיות, סיפור בלי מספרים. מערכות נוספות יגיעו ([בהמשך](#9-coming-later)).

## 2. תחילת העבודה <!-- icon: path -->

### 2.1 מה צריך

- מחשב עם Windows, macOS או Linux, ודפדפן אינטרנט.
- **Node.js 24** או חדש יותר, מהאתר [nodejs.org](https://nodejs.org). הוא מביא איתו את `npm`, שמתקין את RPG Engine.
- **טרמינל**, פעם אחת, כדי להתקין את RPG Engine: ב-Windows, Terminal או PowerShell; ב-macOS, Terminal. כדי לפתוח טרמינל בתוך תיקייה, ללחוץ עליה לחיצה ימנית ולבחור **פתח בטרמינל של Windows** (ב-Windows) או **שירותים > טרמינל חדש בתיקייה** (ב-macOS). אם Windows מודיעה שהרצת סקריפטים מושבתת, לכתוב פעם אחת `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` ולענות yes.
- **אפליקציית AI** שתשמש כמנחה, עם החשבון שלך ([2.4](#24-connect-your-ai)): הדף יכול להתקין אותה. כדאי לשחק עם **המודל הגדול ביותר** שהיא מציעה: קל יותר לשכנע מודל קטן לחשוף סודות או לעקוף את החוקים.

### 2.2 התקנה

```text
npm install -g rpg-engine
rpg open
```

השורה הראשונה מתקינה את RPG Engine; הפקודה `rpg --version` בודקת שההתקנה הצליחה. אם npm מציע להתעדכן בעצמו, אפשר להתעלם מכך.

הפקודה `rpg open` פותחת את החלון של RPG Engine, עם הקמפיינים. בפעם הראשונה היא שואלת בטרמינל אם להוסיף את הסמל שלו לשולחן העבודה ולתפריט התחלה (ב-Mac: יישומים): ללחוץ Enter לאישור. מכאן ואילך לוחצים לחיצה כפולה על הסמל, ואין עוד צורך בטרמינל. בלי הסמל, לכתוב `rpg open` בכל פעם שמשחקים; `rpg icon` מוסיף את הסמל אחר כך, ו-`rpg icon --remove` מסיר אותו.

### 2.3 יצירת קמפיין

החלון של RPG Engine מציג את הקמפיינים ככרטיסים, והאחרון שנפתח ראשון. ללחוץ על **קמפיין חדש** ולמלא **שם**, **שפה** ו**מערכת משחק**: את השאר המנחה יוצר יחד איתך. הקמפיין נשמר בתיקייה על שמו, בתוך התיקייה `RPG Engine` שבתיקיית המשתמש (ב-Windows, `C:\Users\<name>`); **בחירת תיקייה אחרת…** שומרת אותו בתיקייה ריקה לבחירה. תחת **המנחה** אפשר לבחור כבר את אפליקציית ה-AI ואת המודל לצ'אט הראשון ([2.4](#24-connect-your-ai)). ללחוץ על **יצירה**: לוח הבקרה של הקמפיין נפתח בחלון משלו.

בפעם הבאה, ללחוץ על כרטיס כדי לפתוח את הקמפיין שלו; קמפיין שפתוח מסומן **פתוח כעת**. **פתיחת תיקייה…** מוסיפה קמפיין שכבר יש במחשב הזה. הצלב הקטן שבכרטיס מסיר אותו מהרשימה: הקבצים שלו נשארים במקומם.

### 2.4 חיבור ה-AI

המנחה פועל ב**אפליקציית AI** במחשב שלך, עם החשבון שלך: Claude Code, Codex, OpenCode או Antigravity. צ'אט רגיל כמו claude.ai או ChatGPT, או אפליקציה בטלפון, אינם מספיקים: המנחה צריך לגשת לקבצי הקמפיין שבמחשב. לכל אפליקציה דרוש חשבון משלה: ל-Claude Code מנוי בתשלום של Claude (Pro ומעלה); ל-Codex חשבון ChatGPT, חינמי או בתשלום; ל-Antigravity חשבון Google, ולשימוש החינמי בו יש מגבלות שבועיות; ב-OpenCode יש כמה מודלים חינמיים לזמן מוגבל, או שאפשר להשתמש בספק משלך, כולל מודלים מקומיים.

בצ'אט של לוח הבקרה, לבחור את האפליקציה תחת **אפליקציית ה-AI שלך**, ואז את ה**מודל** ואת **המחשבות של המנחה**: הדף מציע אותם. יותר מחשבה היא איטית יותר וצורכת יותר מהמנוי. אפליקציה שאינה מוכנה אומרת מה חסר לה, עם כפתור שעושה זאת:

- **Claude Code** ו-**Codex**: **התקנת Claude Code** או **התקנת Codex** מורידה את האפליקציה לתיקייה של RPG Engine עצמו במחשב הזה; **התחברות ל-Claude Code** או **התחברות ל-Codex** פותחת בדפדפן את דף ההתחברות שלה. RPG Engine אף פעם לא רואה את הסיסמה.
- **OpenCode** ו-**Antigravity**: **קבלת OpenCode** או **קבלת Antigravity** פותחת את האתר של האפליקציה, שם מתקינים אותה. OpenCode עובד בלי התחברות; ל-Antigravity מתחברים מהאפליקציה שלו עצמה. אחר כך לחזור וללחוץ על **בדיקה חוזרת**.

Antigravity מסומן **בניסיון**: הוא עלול לצאת מהמשחק ולשאול שאלות בדרכו, ולכן עדיף לשחק עם Claude Code, Codex או OpenCode. Antigravity שומר את הצ'אטים הקודמים שלך, ואי אפשר לכבות את הזיכרון שלו: המנחה מקבל הוראה לא לקרוא אותם לעולם. מה שכותבים נשלח ל-Google, שעשויה לתת לאנשים לקרוא אותו: לא לכלול במשחק מידע אישי. RPG Engine אינו מוצר של Google. אנחנו משחקים ובודקים את RPG Engine הכי הרבה עם **Claude Code**: עוד לא שוחק קמפיין שלם עם האחרים.

בצ'אט של לוח הבקרה המנחה נוגע במחשב שלך רק דרך RPG Engine: הוא לא פותח שום קובץ שלך מעצמו. RPG Engine קורא מחוץ לקמפיין רק את מה שנבחר, אחרי שמאשרים בחלון במחשב.

אפשר לשחק גם בצ'אט של אפליקציית ה-AI עצמה, בטרמינל או באפליקציית שולחן העבודה שלה ([2.8](#28-the-other-way-your-ai-apps-own-chat)).

### 2.5 הצ'אט הראשון

אחרי שנבחרו האפליקציה והמודל, ללחוץ על **פתיחת הצ'אט**: האפליקציה מתחילה לפעול, וזה יכול לקחת כמה שניות. אחר כך ללחוץ על **להתחיל**, או לכתוב כל דבר, למשל *שלום! בואו נתחיל.* התשובה הראשונה יכולה לקחת כמה דקות, בזמן שהמנחה בונה את הסצנה.

לצ'אט יש חלק משלו, **משחק**, או שהוא עומד לצד הדף: הכפתורים הקטנים בראשו מציבים אותו **בלשונית שלו**, **בצד שמאל** או **בצד ימין**, וגוררים את הקצה שלו כדי להרחיב אותו.

קמפיין חדש עובר שלושה שלבים, שמוצגים בראש הדשבורד: **1 הגדרות** (איך רוצים לשחק), **2 סשן אפס** (יוצרים את הדמות, תוך כדי משחק), **3 משחק**.

### 2.6 הגדרות: בחירת אופן המשחק

המנחה שואל רק את מה שעדיין חסר, כמה שאלות בכל פעם. השלב **הגדרות** בדשבורד מציג את אותן שאלות ככרטיסים. אם כותבים "תחליט/י אתה", המנחה בוחר. אפשר לשנות הכול אחר כך, בצ'אט או ב**הגדרות**.

| הגדרה | מה היא קובעת | ערכים |
|---|---|---|
| **מנטור** | כמה המנחה מלמד אותך את החוקים | off, hints, tutorial |
| **רמת קושי** | עד כמה העולם קשה | story, easy, normal, hard, brutal |
| **קטלניות** | מה המשמעות של נפילה בקרב | narrative (אף פעם לא מתים), epic (רק כשזה משמעותי), dice |
| **שמירות** | מתי אפשר לחזור אחורה | permadeath, checkpoint, free ([3.8](#38-saves-and-going-back)) |
| **קפדנות** | באיזו מידה אוכל, אור ומסעות כפופים לחוקים | smooth, rules, simulation |
| **קוביות** | מי מטיל את הקוביות | digital, physical |
| **יחידות מידה** | מרחקים ומשקלים | metric, imperial |
| **קולות הדמויות** | מי מדבר בשם הדמויות שפוגשים, מהמנחה ועד הדמויות עצמן: המנחה תמיד; ברגעים מרכזיים הדמות עצמה, כשהיא יודעת רק את מה שהיא יודעת, לפי בחירת המנחה; או תמיד הדמות, לדמויות הראשיות או לכולן, לאט ויקר יותר, במקום שבו אפליקציית ה-AI מאפשרת | the master, sometimes, main characters, everyone |
| **הדמות שלך** | איך הדמות נוצרת בסשן אפס | with the master, by the master, your own ([2.7](#27-session-zero-your-character)) |
| **בני לוויה** | מי מטייל איתך | none, made with you, made by the master, met in play |
| **תמונות** | תמונות של מקומות, משימות ודמויות שפוגשים | none, on request, new places, quests and those you meet ([3.11](#311-pictures)) |
| **קווים אדומים** ו**וילונות** | מה אף פעם לא מופיע, ומה קורה רק מחוץ למסך | רשימות |
| **שפה** | שפת המשחק ושפת הדשבורד | כל שפה |

המהדורה החמישית מוסיפה **התקדמות**: נקודות ניסיון או אבני דרך.

כשאין עולם כתוב, המנחה שואל גם **הנחת יסוד** (ז'אנר, אווירה, כמה אלמנטים, ומה הכי כיף לך במשחק, כמו קרבות, תעלומות, שיחות או חקירה, במילים שלך), את **ההכנה**: לבנות את העולם תוך כדי משחק, צעד אחר צעד, או הכול בהתחלה, ואת **האורך**: ערב אחד, כמה סשנים (שלושה עד חמישה ערבים), או פתוח, הרפתקה אחרי הרפתקה. בסוף סיפור שיש לו אורך תמיד אפשר להמשיך.

**הסגנון של המנחה** אף פעם לא נשאל, אבל אפשר לשנות אותו בצ'אט או ב**הגדרות**: **פרוזה** (פשוטה, ספרותית, פאלפ, צינית), **סיפורים** שהמנחה ממציא (סיטואציות, קשתות עלילה, פרקים, מסתורין), מחבר שאפשר **לכתוב כמו** הסגנון שלו, או כל דבר אחר **במילים שלך**.

### 2.7 סשן אפס: הדמות שלך

יוצרים את הדמות יחד עם המנחה, כמו סביב שולחן משחק. כל בחירה היא שלך, אלא אם מבקשים מהמנחה לבחור: אפשר להגיע עם רעיון מלא, עם רעיון מעורפל או בלי כלום; או לבקש מהמנחה ליצור הכול מכמה מילים. במשחק עם רמות המנחה שואל מאיזו רמה מתחילים: הראשונה, אלא אם רוצים אחרת. המנחה מסביר איך נקבעים ערכי היכולות לפני שמוטלת קובייה כלשהי. סיפור רקע אף פעם לא נדרש; אם נותנים אחד, המנחה כותב אותו במילים שלך. אחר כך המנחה מבקש תמונה של הדמות ([3.7](#37-your-characters-story-and-picture)). RPG Engine מחשב את דף הדמות: אף פעם לא צריך לעשות חישובים.

כבר יש לך דמות, ממשחק אחר או מקמפיין אחר? לבחור **כבר יש לי אחד** בהגדרה ולתת אותה למנחה: להדביק את דף הדמות בצ'אט. בצ'אט של אפליקציית ה-AI עצמה אפשר גם לומר איפה הקובץ שלה נמצא במחשב (PDF, תמונה, טקסט); בצ'אט של לוח הבקרה המנחה לא פותח אף קובץ שלך. המנחה רושם אותה כמות שהיא, ברמה שלה, בודק אותה מול החוקים והעולם, ומסכם איתך כל דבר שלא מתאים.

### 2.8 הדרך האחרת: הצ'אט של אפליקציית ה-AI עצמה

אפשר לשחק גם בצ'אט של אפליקציית ה-AI עצמה, בטרמינל או באפליקציית שולחן העבודה שלה, כשלוח הבקרה פתוח לידו. אז יוצרים את הקמפיין בטרמינל, בתיקייה שבה שומרים את המשחקים ([2.1](#21-what-you-need) מסביר איך), תמיד עם שם: הפקודה `rpg init "The Salt Isles"` יוצרת את התיקייה `The Salt Isles` עם קמפיין חדש בתוכה. RPG Engine מכין בעצמו שם את מה שכל אפליקציה צריכה.

להפעיל את האפליקציה בתיקייה הזאת: `claude` עבור Claude Code, `codex` עבור Codex, `agy` עבור Antigravity, `opencode` עבור OpenCode; או לפתוח את התיקייה באפליקציית שולחן העבודה שלה. לאשר כשהיא שואלת אם סומכים על התיקייה: זהירות, ב-Claude Code התשובה שמסומנת מראש היא *No, exit*. גם כל סוכן אחר שתומך ב-MCP יכול להיות המנחה: מפעילים אותו בתיקיית הקמפיין ונותנים לו את שרת ה-MCP `rpg mcp`.

לכתוב *שלום! בואו נתחיל.* בתשובה הראשונה בכל צ'אט המנחה נותן את **הקישור ללוח הבקרה**, משהו כמו `http://127.0.0.1:4750`: לפתוח אותו ליד הצ'אט.

- בין ההודעות של המנחה האפליקציה מציגה את הכלים שהיא משתמשת בהם: לא לפתוח את הפרטים שלהם (ב-Claude Code, ctrl+o), הם עלולים לחשוף סודות.
- הקמפיין מכבה את הזיכרון של האפליקציה עצמה: המשחק חי בקבצים שלו, כך שחזרה לשמירה באמת מחזירה אחורה. באפליקציית שולחן העבודה של Codex, לבדוק בהגדרות שהזיכרונות כבויים בצ'אטים של המשחק.
- אם המנחה אומר שהוא לא מוצא את הכלים של RPG Engine, לכתוב `rpg init` בתיקיית הקמפיין, ואז לפתוח צ'אט חדש.
- צ'אט אחד בכל פעם משחק קמפיין: כל עוד צ'אט כזה פתוח, הצ'אט של לוח הבקרה ממתין.

## 3. משחק <!-- icon: chat -->

### 3.1 שיחה עם המנחה

כותבים מה הדמות עושה או אומרת, במילים שלך:

> אני שואל את בעל הפונדק מי עוד עבר כאן הערב.

כדי לדבר מחוץ לסיפור, לכתוב `[OOC: …]` (out of character): *[OOC: איך עובדת היאחזות?]* המנחה עונה באותו אופן; בצ'אט של לוח הבקרה דבריו מחוץ למשחק מופיעים בנפרד, מסומנים OOC.

בצ'אט של לוח הבקרה, לכתוב בתיבה שבתחתית וללחוץ Enter כדי לשלוח; Shift+Enter פותח שורה חדשה. בזמן שהמנחה עונה, **עצירה** עוצרת אותו, והטקסט שנכתב ממתין בתיבה. כשהמנחה שואל משהו, הכפתורים שלו מגיעים עם השאלה, כולל הטלות: ללחוץ על אחד, או לכתוב תשובה. מתחת לתיבה רואים את האפליקציה ואת המודל; איפה שהאפליקציה מאפשרת, אפשר ללחוץ על המודל כדי להחליף אותו אחרי שהמנחה ענה. **סגירת הצ'אט** מסיימת את הצ'אט; המשחק נשאר בקבצים שלו.

אתה אומר מה אתה מנסה לעשות, והמנחה אומר מה קורה. המנחה לעולם לא מחליט בשביל הדמות, ולעולם לא מדבר על המנוע. אפשר לשאול אותו איך משתמשים בלוח הבקרה.

**פעולה מתוך הדשבורד**: לוחצים על שם בדף הדמות, כמו נשק, לחש או משהו שהדמות נושאת: הכרטיס שלו אומר מה הוא. תיק נפתח בחץ שלו, וה-ⓘ שלו מציג את הכרטיס שלו. בוחרים מה לעשות עם הפריט. פעולה שלא מכוונת אל אף אחד, כמו **להצטייד**, מבקשת אישור על אותו כפתור, *אישור: אני מצטייד ב-Shield*: לוחצים עליו שוב, והפעולה נשלחת למנחה. פעולה שמכוונת אל מישהו, כמו **לתקוף**, שואלת אל מי, ברשימה או בלחיצה על המפה; אז הכפתור אומר את המשפט המלא, *אני תוקף את Hooded Bandit 1 עם Mace*, ולחיצה אחת שולחת אותו. כדי לומר זאת בדרך משלך, לוחצים על דמות כדי לדבר איתה, או כותבים בצ'אט. המנחה שומע זאת כאילו נאמר בצ'אט, פוסק לגביו כמו בכל פעולה אחרת, ושואל בכפתורים על מה שחסר. כשאין לאפליקציית ה-AI דרך להודיע למנחה מיד, המנחה קורא זאת ברגע שכותבים שוב בצ'אט; אם הצ'אט נסגר קודם, **לומר שוב** שולח זאת פעם נוספת.

### 3.2 הטלות

המנחה מבקש הטלה רק כשהתוצאה אינה ודאית וחשובה, ומספר קודם מה על הכף. אחר כך:

- **בלוח הבקרה**, מופיע כרזה עם כפתור לכל בדיקה, כמו *Acrobatics +4 · with advantage*. לוחצים עליו: הקוביות נופלות על הדף והמנחה שומע את התוצאה. אפשר גם ללחוץ על השורה שנדלקת בדף הדמות, להטיל קוביות מהמגש, או לכתוב משהו אחר בכרזה.
- **ידנית**, בפינת הכרזה או ב**הגדרות**: הכרזה אומרת מה להטיל, וההטלה נעשית מדף הדמות או מהמגש.
- **קוביות פיזיות**, כשהגדרת הקוביות היא פיזיות: כותבים את הערכים שהוטלו, *[הטלתי 14.]*, ו-RPG Engine מוסיף את המתאמים.

**הטלות חופשיות**: לוחצים על כל מספר בדף הדמות, או פותחים את המגש, כדי להטיל להנאה. הן אף פעם לא נספרות, והמנחה אף פעם לא רואה אותן.

**ההטלות של המנחה** מופיעות בעמודת ההטלות שלך, חוץ מהסודיות. תמיד אפשר לשאול *[האם ההטלה ההיא הייתה אמיתית?]*: על הטלה סודית המנחה נותן טביעת אצבע שמוכיחה שההטלה נעשתה לפני ששאלת.

### 3.3 סצנות וקרבות

הסיפור מתנהל ב**סצנות**: קרב, שיחה, חקירה, מסע, מנוחה. בסוף כל סצנה המשחק נשמר מעצמו, הסצנה נכנסת ליומן, וכשהסיפור מתהפך המנהל כותב את הסצנות מאז הפרק האחרון כפרק חדש בספר הסיפור שלך.

בקרב המנחה מספר על כל תור שאינו שלך, ועוצר איפה שאפשר להחליט. ב**סצנה** מוצג למעלה של מי התור ומי הבא אחריו, וכרטיס הדמות שלך מוצג לצד המפה. סדר התורים, נקודות הפגיעה של החבורה ומצבם של האויבים, במילים, נשארים בצד הדף. אם הדמות נופלת, הטלות ההצלה מול המוות מופיעות בגדול על הדף.

**פקודות קבע**: אומרים לבני הלוויה משהו שצריך להימשך, כמו *מעכשיו, תמיד משאירים אחד בחיים*, והמנחה שומר על כך עד שמבטלים את הפקודה. בני הלוויה מצייתים לה ככל שהאופי של הדמות שלהם מאפשר, ואם אחד מהם לא יציית, הוא אומר זאת. את הפקודות שלך אפשר למצוא ב**הגדרות**, ושם אפשר להוסיף אותן ולהסיר אותן.

### 3.4 זמן, מסעות והעולם שנע

RPG Engine עוקב אחרי התאריך. בין סשנים זמן המשחק נעצר, אלא אם בוחרים ב**הגדרות** לתת לו לרוץ, למשל יום במשחק על כל שבוע של היעדרות, או מבקשים מהמנחה. אומרים שנחים, *אנחנו נחים מנוחה ארוכה*, וכשהמנחה מסכים, המנוחה מחזירה את מה שצריך. במנוחה קצרה המנחה עשוי לשאול בלוח הבקרה כמה קוביות פגיעה להוציא: מטילים אותן אחת אחת, רואים כמה כל אחת מרפאה, ועוצרים מתי שרוצים. אומרים לאן הולכים, *אנחנו יוצאים בדרך צפונה לרוקה*, ו-RPG Engine מחשב את הדרך, המרחק והימים, ועוצר כשמשהו קורה בדרך. כסף נספר במטבעות המשחק, כולל עודף.

לנבלים יש תוכניות עם מועדים. בכל יום חדש המנחה מקדם את האיומים שהזמן קידם, ורואים את סימניהם, אף פעם לא את השעון עצמו.

### 3.5 מפות

**עולם** מציג את המקומות שהדמות מכירה, את הדרכים ביניהם ואת השביל שנצעד, עם ערפל על השאר. **סצנה** מציגה את מפת המקום שבו נמצאים, כשיש לו מפה, ומי עומד היכן. בקרב, בתור שלך, המשבצות שאי אפשר להגיע אליהן מכוסות. כשהמנחה שואל לאן זזים, נוגעים במשבצת או כותבים אותה, כמו *E4*.

**עולם** גם שומר את מה שהדמות יודעת. **ידע** מפרט את האנשים, המקומות, הפלגים, היצורים והסיפורים שהדמות מכירה, כל אחד כפי שהיא מכירה אותו: אפשר לחפש בו, או לפתוח פריט כדי לקרוא אותו במלואו. שם בטקסט מוביל לדף שלו. **מסמכים** שומר את המכתבים, ההודעות והדפים שנמצאו, לקריאה חוזרת. **לוח שנה** מציג את היום, את מועדי המשימות עם הזמן שנותר, ואת ימי הסיפור: יום עם סצנות מוביל אליהן ב**ציר הזמן** של היומן.

### 3.6 משימות, יומן ופתקים

משימה שהדמות לוקחת על עצמה הופכת למשימה ב**יומן**, עם המטרות שלה, המועד שלה ומה שהיא מודדת. מסמנים אותה בכוכב כדי להשאיר אותה בולטת בראש ה**סצנה**. תחת **סיפור** היומן מספר את סיפור הדמות כספר: המנחה כותב פרק בפרוזה בכל פעם שהסיפור מתהפך, ומספר בו את הסצנות מאז הפרק הקודם, בסגנון שנבחר. קוראים פרק אחר פרק, האחרון מסומן בסימנייה שלו, ואפשר להוריד את הסיפור כ-Markdown או כדף אינטרנט, להדפסה או להעברה. במשחק שהתחיל קודם, אפשר לבקש מהמנחה לכתוב את הסיפור עד כה. **ציר זמן** מפרט את הסצנות, ממוספרות, ומה קרה בכל אחת. היומן שומר גם את **הפתקים** שלך: פרטיים, אלא אם **לשתף** אחד מהם. המנחה שומע אותו כמחשבה של הדמות, אף פעם לא כעובדה. תחת **בני לוויה** קוראים את היומנים של בני הלוויה: מדי פעם, בסוף יום או משימה, הם כותבים כמה שורות על מה שהם חושבים ומרגישים.

### 3.7 הסיפור והתמונה של הדמות

בדף הדמות, בכרטיס **תיאור** יש תיבה לסיפור של הדמות: המנחה כותב בה אחרי שמאשרים. לתמונה, נותנים למנחה קובץ (PNG, JPEG, WebP או SVG, עד 5 MB) יחד עם המיקום שלו במחשב, או מבקשים ליצור דיוקן ([3.11](#311-pictures)): *[צור לי דיוקן: שיער אפור בצמה, צלקת על הסנטר.]*

### 3.8 שמירות וחזרה אחורה

RPG Engine שומר את כל הקמפיין בסוף כל סצנה. הגדרת **שמירות** קובעת את השאר:

| שמירות | לשמור כשרוצים | לחזור אחורה |
|---|---|---|
| **permadeath** | לא | אף פעם |
| **checkpoint** | לא | לשמירה האחרונה, רק כשהדמות מתה |
| **פנוי** | כן | לכל שמירה |

בכל מצב אפשר **להתחיל מחדש**, מתחילת המשחק או מסשן אפס. עושים זאת בצ'אט או ב**שמירות**.

אחרי חזרה אחורה, **לפתוח צ'אט חדש**: הצ'אט הישן זוכר את מה שבוטל. בצ'אט של לוח הבקרה, ללחוץ על **סגירת הצ'אט**, ואז על **צ'אט חדש**; בצ'אט של אפליקציית ה-AI עצמה, לפתוח שיחה חדשה (`/clear` ב-Claude Code). לכתוב *המשך* בצ'אט החדש. אחר כך לומר למנחה שהצ'אט חדש: ללחוץ על **נפתח צ'אט חדש** ב**שמירות**, או לומר זאת בצ'אט. עד אז המנחה לא ממשיך.

מי שלא יודע מהו git יכול לדלג על הפסקה הזאת. אם תיקיית הקמפיין היא מאגר git, ב**הגדרות** יש חלק **Git**, שכולו כבוי עד שבוחרים: קומיט בתחילת כל סשן, בכל שמירה ובסוף כל סצנה, ודחיפה אחריו אם רוצים. קומיט הוא תצלום של הקמפיין ברגע מסוים; דחיפה שולחת את התצלומים למאגר ברשת, למשל ב-GitHub, כך שעותק נשמר גם מחוץ למחשב הזה. השמירות והצ'אטים עם המנחה נשארים מחוץ למאגר אלא אם מכניסים אותם; כדאי להכניס את הצ'אטים רק אם המאגר פרטי.

### 3.9 סשנים: לעצור ולחזור

אפשר לעצור מתי שרוצים: *[בואו נעצור כאן להערב.]* הכול כבר שמור בקבצים. כדי לחזור, לפתוח את RPG Engine מהסמל וללחוץ על הקמפיין. אם הצ'אט נשאר פתוח, הוא חוזר מעצמו. אם הוא נסגר, ללחוץ על **המשך הצ'אט**. אחר כך ללחוץ על **להמשיך את הסיפור**: המנחה מספר בכמה שורות איפה נעצר המשחק, וממשיך. אם המשחק נסגר בזמן שהמנחה עוד ענה, או בזמן ששאלה שלו המתינה, הכפתור הזה נקרא **להמשיך מכאן**. **צ'אט חדש** פותח צ'אט חדש על אותו משחק. בצ'אט של אפליקציית ה-AI עצמה, להפעיל אותה בתיקיית הקמפיין ולכתוב *המשך*.

### 3.10 מצב הרוח של המנחה

הרובוט בראש לוח הבקרה הוא המנחה: הפנים שלו עוקבות אחרי הטון של הסיפור, ולעולם לא מגלות את מה שעוד לא ידוע. כשלוח הבקרה לא מחובר למשחק, הרובוט ישן.

### 3.11 תמונות

RPG Engine יכול ליצור תמונות של המקומות שמגיעים אליהם, של המשימות שלוקחים ושל מי שפוגשים, לפי הגדרת **תמונות**, ואת הדיוקן של הדמות כשמבקשים. אפליקציית ה-AI שלך יוצרת אותן בכלים משלה, עם ההתחברות שלך, בתוכנית שלך ובמגבלות שלה: **Claude** מצייר אותן כתמונות וקטוריות, **Codex** ו-**Antigravity** מציירים אותן בצבע, **OpenCode** מצייר בצ'אט תמונות וקטוריות פשוטות. ב-**הגדרות > קמפיין > תמונות** אפשר לבקש מ-Codex או מ-Antigravity ליצור אותן גם כשהמנחה הוא אפליקציה אחרת: במקום שבו האפליקציה שנבחרה לא יכולה, הצ'אט שלך יוצר אותן. ב-**הגדרות** כתוב אם המחשב הזה יכול ליצור אותן, ואיך להגדיר אם לא. תמיד אפשר לתת תמונה משלך, לדמות או לכל דף שרואים: מעבירים את המצביע מעל אחת מהתמונות שלו, ובפינה מופיע כפתור תמונה קטן (גם במקלדת, ותמיד בטלפון); ב-**עולם** בדף שנפתח יש גם **החלפת תמונה…**, או **הוספת תמונה…** כל עוד אין לו תמונה. כשהמצביע מעל תמונה, או שהכפתור שלה בפוקוס, אפשר גם להדביק תמונה שהועתקה, עם Ctrl+V (⌘V ב-Mac). התמונה שלך תופסת את מקום התמונה הקיימת. או שאפשר לשים את הקובץ בתיקיית **inbox** של הקמפיין ולומר למנחה לאיזה דף הוא מיועד.

### 3.12 בטיחות: קווים אדומים, וילונות ועצירה

**קווים אדומים** אף פעם לא מופיעים במשחק. **וילונות** קורים רק מחוץ למסך. בכל רגע אפשר לכתוב *[עצור]*: המנחה זונח מיד את התוכן הזה ומוסיף אותו לקווים האדומים שלך.

### 3.13 שינוי החלטה

אפשר לשנות כל הגדרה, בצ'אט או ב**הגדרות**. פסיקה שהמנחה נותן בלי הספר הופכת ל**תקדים**, כך ששאלה זהה תקבל את אותה תשובה בפעם הבאה.

## 4. הלוח <!-- icon: party -->

דף במחשב שלך, בחלון משלו, שנפתח רק באותו מחשב. הוא פעיל כל עוד החלון שלו פתוח, עם צ'אט או בלעדיו; כשלושים שניות אחרי שסוגרים אותו, המשחק נעצר, והצ'אט איתו. שום דבר לא הולך לאיבוד: הכול בקבצים. בצ'אט של אפליקציית ה-AI עצמה, הוא פעיל כל עוד הצ'אט הזה פתוח. כשהמשחק לא נמצא, הדף מציג *Not connected*: ללחוץ על **פתיחה מחדש של הקמפיין**, או, באפליקציה עצמה, לפתוח את הצ'אט הבא. הכפתור **קמפיינים**, עם הבית, מחזיר לכל הקמפיינים.

- **משחק**: הצ'אט עם המנחה, כשהוא לא לצד הדף ([2.5](#25-the-first-chat)).
- **חבורה**: דף הדמות שלך ודפי הדמות של בני הלוויה. ללחוץ על מספר כדי להטיל אותו; מעבר עם העכבר מעליו מראה מאיפה הוא בא, וכשחץ מסמן את הקובייה שלו, מה משפר את ההטלה או מחליש אותה. כשהמנחה מכין בחירות, כמו ברמה חדשה, הודעה בדף הדמות פותחת אותן: אפשר לבחור מתי שנוח, לקרוא את הדפים שהאפשרויות מציינות, להטיל איפה שאפשרות דורשת הטלה, ואז לאשר; הסיפור נמשך בינתיים. לצד זה, ההטלות.
- **סצנה**: המקום שבו נמצאים, התמונה והמפה שלו, מי נמצא שם ומה קורה; בקרב, התורות וכרטיס הדמות.
- **יומן**: משימות, הסיפור כספר, ציר הזמן שלו, היומנים של בני הלוויה והפתקים שלך.
- **עולם**: מפת העולם, מה שהדמות יודעת, המסמכים שנמצאו ולוח השנה.
- **מגש קוביות**: לבחור קוביות ומתאם, ולהטיל; ‏×2 מכפיל את הקוביות, אף פעם לא את המתאם, כמו בפגיעה קריטית.
- **שמירות**, **עזרה**, **הגדרות** ו**אודות**: סמלים בסוף השורה. ב**הגדרות** יש גם, תחת **לוח בקרה**, את ההעדפות של הדף עצמו: מצב, צליל הקוביות, סט הקוביות, ו**ערכת נושא**, כלומר הצבעים, הפנים והתמונות של הדף. אפשר לבחור את ערכת הנושא של מערכת המשחק, ערכת נושא שנוספה ב-Packages › Add (מהקטלוג, מקישור GitHub, מקובץ .zip או מתיקייה), או את זו של הדף עצמו. אם הסגנון של ערכת נושא מקשה על הקריאה בדף, לכבות שם את **הסגנון הייחודי של ערכת הנושא**: ההגדרות תמיד מופיעות בלעדיו, בכתובת של הדף עם `#/settings/page` בסופה.

כשהמנחה שואל משהו, הבאנר שלו נשאר בראש הדף, בכל חלק שבו נמצאים.

## 5. מערכות משחק וחוקי בית <!-- icon: dice -->

### 5.1 מהי מערכת משחק

הנתונים של משחק אחד: דף הדמות שלו, המספרים, היצורים, הפריטים, הלחשים וטקסט החוקים. כל קמפיין משחק במערכת אחת. RPG Engine מחשב את דף הדמות ואת מה שמוצאים ומה שחוזר; איך תכונה עובדת, המנחה קורא בחוקים ומחליט, כמו ליד שולחן המשחק.

### 5.2 המהדורה החמישית

הגזעים, המקצועות, תתי המקצועות, רקע ויכולת מיוחדת (feat) של ה-SRD 5.1; 319 הלחשים, הנשקים, השריונות, הפריטים הקסומים והמפלצות; פרקי החוקים, שהמנחה קורא לפי הטקסט המדויק שלהם; דף הדמות המלא, מחושב.

זו חבילה בפני עצמה: המנחה מציע אותה בעת הגדרת קמפיין ומתקין אותה. קמפיין שמשחק בה מתקין אותה בעצמו בפעם הראשונה שהוא נפתח במחשב שאין בו החבילה, והמנחה מודיע על כך.

אפשר גם לשחק תוכן שחסר ב-SRD, מספר שבבעלותך: המנחה כותב אותו כדפים של הקמפיין, ו-RPG Engine מתייחס אליהם כאל דפים משלו. RPG Engine כולל רק תוכן פתוח; מה שהמנחה מכיר אינו מוגבל.

אפשר להפוך את המדריכים שלך לספרייה: לומר למנחה היכן הם, *[המדריכים שלי נמצאים ב-D:\Books\5e.]*, או להוסיף את התיקייה שלהם בחבילות › ספרייה, ולאשר בחלון שהמחשב מציג, פעם אחת. RPG Engine קורא אותם במחשב הזה; כל קמפיין משתמש בתיקיות שהפעלת שם, והמנחה מחפש בהן כשהוא מכריע בחוק, אחרי ה-SRD, ומציין את הספר והעמוד. הם נקראים הכי טוב כטקסט, או כקובצי PDF שאפשר לסמן בהם טקסט; קובץ PDF סרוק נקרא מתמונות העמודים שלו, ב-Windows בלבד, תוך כמה דקות ועם כמה טעויות. RPG Engine אף פעם לא משנה את המדריכים שלך, לא שולח את הטקסט שלהם לשום מקום ולא מעתיק אותו לתוך קמפיין.

### 5.3 חוקי בית והוספות משלך

אפשר לבקש מהמנחה: *[חוק בית: 20 טבעי בהטלת תקיפה פירושו שהנשק נופל.]* המנחה שומר אותו כהסכם של השולחן, או כותב דף או מספר בדף הדמות כשצריך. חוקי בית שכבר כתובים אפשר לשים כקובצי טקסט בתיקיית `rules` של הקמפיין.

כשהמנחה משנה דף של מערכת המשחק עבור הקמפיין, למשל נקודות הפגיעה של יצור או הטווח של לחש, הדשבורד מסמן זאת בכוכבית קטנה אחרי שם הדף בכל מקום שבו הוא מופיע. חבילות › מותקנות מציג את מה ששונה, מתחת למערכת המשחק, לצד מה שהמערכת נתנה; יצור שהדמות אינה מכירה מופיע שם בשמו בלבד. שם אפשר להחזיר דף למצב שבו המערכת כותבת אותו, אחרי שהסצנה המתנהלת מסתיימת; הדשבורד אינו יכול לבטל את השינוי, רק המנחה יכול לכתוב אותו שוב.

### 5.4 הוספה או ייבוא של מערכת משחק משלך

מערכת משחק היא חבילה: המנחה מתקין אחת מ-npm, מתיקייה או מקובץ, ואת מי שאינה שלנו רק באישורך, בטופס של הסוכן שלך או בחלון של המחשב שלך. יצירת מערכת היא עבודה של מפתחים, והיא מתוארת במסמכים של RPG Engine ב-GitHub. הפיכת ספר שלך למערכת משחק עדיין אינה זמינה ([בהמשך](#9-coming-later)).

## 7. מאיפה בא קמפיין, ובאיזו שפה <!-- icon: world -->

### 7.1 שלוש דרכים לקבל עולם

- **נבנה תוך כדי משחק**: מהנחת היסוד שלך, המנחה בונה כל מקום, דמות ועלילה רגע לפני שצריך אותם, ושומר אותם.
- **מוכן מההתחלה**: אותו דבר, כשהעולם נבנה לפני המשחק.
- **מהרפתקה או מספר משלך**: לתת למנחה את הקובץ, *[ייבא את ההרפתקה הזאת כקמפיין שלנו: D:\Books\adventure.pdf. אל תגלה לי שום דבר ממה שכתוב בה.]* קובץ מחוץ לקמפיין נקרא רק אחרי שמאשרים בחלון במחשב; קובץ שמניחים בתיקייה **inbox** של הקמפיין נקרא מיד. הכי טוב לקרוא אותו כטקסט, EPUB, מסמך Word או PDF שאפשר לסמן בו טקסט; PDF סרוק נקרא מתוך תמונות הדפים שלו, רק ב-Windows, לאט ועם כמה טעויות. אפליקציית ה-AI שלך קוראת אותו מחוץ לצ'אט, ואם לא, המנחה בצ'אט, על המנוי שלך: ב-Claude Code או ב-Codex אחד משני אלה קורא אותו, ב-Antigravity ה-Antigravity שלך, וב-OpenCode המודל שנבחר בו לאחרונה. המסמך כולו נשלח ליצרן של מי שקורא אותו, לפי תנאי החשבון שלך והבחירה שלו לגבי אימון. לוח הבקרה מראה כמה כבר נקרא; מתוך רומן, המנחה מציע מאיפה להתחיל. המנחה כותב את המקומות, הדמויות והסודות.

קמפיין משחקים פעם אחת: כדי לשחק שוב באותה הרפתקה, יוצרים קמפיין חדש.

### 7.2 שפות

שפה אחת לכל קמפיין, זו של המנחה, והדשבורד עוקב אחריה. הדשבורד מגיע עם 26 שפות. כל שפה אחרת מתורגמת במחשב שלך בידי אפליקציית ה-AI שלך מחוץ לצ'אט (Codex או Claude Code; ב-Antigravity וב-OpenCode, האפליקציות עצמן), ואם אין כזו שיכולה, בידי המנחה בצ'אט. המונחים של המהדורה החמישית באיטלקית מגיעים מה-SRD האיטלקי הרשמי; טקסט החוקים נשאר באנגלית, והמנחה מספר אותו בשפה שלך.

## 8. למי שסקרן: תיקיית הקמפיין <!-- icon: list -->

אין צורך לפתוח אותה אף פעם, והיא מכילה את הסודות של הקמפיין. יש בה את `campaign.yaml` (ההגדרות), `state.yaml` (מצב המשחק), `world/` (דף markdown אחד לכל דמות, מקום, משימה ושאר הדברים), `rules/` (חוקי הבית), `images/`, `log.jsonl` (כל שינוי), `sessions/` (השיחות עם המנחה כטקסט, מ-Claude Code ומ-Codex), `.saves/`, `.player/` (הפתקים), והקבצים הקטנים שאומרים לסוכני AI איפה RPG Engine. הדפים בפורמט של Obsidian. אם משנים דף ביד, המנחה ישמע על כך בתשובה הבאה שלו.

RPG Engine נשאר בתיקייה הזאת: הוא קורא וכותב את המשחק רק בה, ולעולם לא נוגע בשאר הקבצים; את תיקיות המדריכים הוא רק קורא. מחוץ לה הוא שומר רק תיקיות נתונים משלו (התרגומים של הדשבורד, הטקסט שנקרא מהמדריכים, ו-Codex או Claude Code אם מאשרים לו להתקין אותם) ותיקיות זמניות בזמן שמציירים תמונה. כל דבר אחר שהסוכן רוצה לעשות במחשב, הוא שואל קודם. מערכת משחק או הרחבה היא קוד, כמו כל חבילת npm: זו שאינה שלנו רצה במחשב עם ההרשאות שלך, ו-RPG Engine מתקין אותה רק באישורך, בטופס של הסוכן שלך או בחלון של המחשב שלך. כדאי לאשר רק חבילות שסומכים על מחבריהן.

כל פקודה שהמנחה משתמש בה אפשר להריץ גם בתיקיית הקמפיין: `rpg --help` מציג את רשימתן. רבות מהן מדפיסות את סודות הקמפיין.

**צריך להכיר את החוקים?** לא. לבחור במנטור הדרכה, ולשאול ב-`[OOC: …]` מתי שרוצים.

**המנחה יכול לרמות?** הוא לא יכול לשנות הטלה ש-RPG Engine ביצע, חוץ מברמת קושי סיפור, ולא עובדות שכבר נקבעו.

**זה עולה כסף?** RPG Engine חינמי. המנחה פועל על המנוי של אפליקציית ה-AI שלך, או על המחשב שלך עם מודל מקומי. ערב משחק הוא צ'אט ארוך: במנויים הקטנים ביותר אפשר להגיע למגבלת המנוי לפני שהערב נגמר. תמונות, תרגומים וייבוא משתמשים באותו מנוי. RPG Engine עצמו אף פעם לא משתמש במפתח API, שמשלמים עליו לפי קריאה: להתחבר לאפליקציית ה-AI עם החשבון, לא עם מפתח.

**אפשר לשחק בטלפון?** לא: המנחה פועל על המחשב שלך, ולוח הבקרה נפתח רק שם.

**אפשר לשחק עם חברים?** עוד לא: כיום שחקן אחד, דמות אחת, ועוד בני לוויה ([בהמשך](#9-coming-later)).

**אפשר להשתמש ב-AI אחר בפעם הבאה?** כן: לבחור אפליקציה אחרת בצ'אט לפני שפותחים אותו, או לפתוח את הקמפיין באפליקציה אחרת ולכתוב *המשך*.

### בעיות

**קמפיין לא נפתח.** לפתוח שוב את RPG Engine מהסמל, או עם `rpg open` בטרמינל, וללחוץ על הקמפיין. אם לוח הבקרה שלו מציג *Not connected*, ללחוץ על **פתיחה מחדש של הקמפיין**. כרטיס שכתוב עליו **התיקייה לא נמצאה** איבד את התיקייה שלו: להסיר אותו מהרשימה, ולהוסיף אותו שוב עם **פתיחת תיקייה…** איפה שהיא נמצאת עכשיו. בצ'אט של אפליקציית ה-AI עצמה, לוח הבקרה עובד רק כשצ'אט של אותו קמפיין פתוח: לשאול את המנחה `[OOC: מה הקישור ללוח הבקרה?]`. באפליקציית Claude צ'אט שנשאר זמן מה ברקע נרדם, והדף איתו: ללחוץ על הצ'אט, והדף חוזר לאותה כתובת.

**נראה שהמנחה לא מכיר את המשחק.** זה קורה בצ'אט של אפליקציית ה-AI עצמה: היא לא טענה את RPG Engine. לבדוק שהאפליקציה הופעלה בתיקיית הקמפיין ושאושר לסמוך על התיקייה. ב-Claude Code, לכתוב `/mcp` ולחבר מחדש את `rpg`. ב-Codex, הפקודה `codex mcp list` בתיקיית הקמפיין חייבת להציג את `rpg`. אם `rpg --version` לא נמצא, להתקין את RPG Engine שוב ([2.2](#22-install)).

**Windows לא מוצאת את `claude`.** זה קורה כשמתקינים את Claude Code ידנית. תוכנית ההתקנה שלו אומרת זאת בהערה צהובה, עם התיקייה שאליה הותקן: להוסיף את התיקייה הזאת ל-PATH (מאפייני מערכת > משתני סביבה), ואז לפתוח טרמינל חדש.

**עדכון.** כשיוצאת גרסה חדשה של RPG Engine, לוח הבקרה מודיע על כך: ב-Packages › Installed, RPG Engine מופיע ראשון, עם **עדכון**; ואז לעשות מה שהדף אומר. או להריץ שוב `npm install -g rpg-engine` בטרמינל, ואז לפתוח צ'אט חדש: מנחה שכבר רץ נשאר עם הגרסה שבה התחיל.

**המנחה זוכר משהו שביטלתי.** לפתוח צ'אט חדש וללחוץ על **נפתח צ'אט חדש** ב-שמירות.

**ההתקנה של אפליקציה לא מצליחה.** הדף אומר למה: ללחוץ על **לנסות שוב**. או להתקין אותה מהאתר של היצרן, ואז ללחוץ על **בדיקה חוזרת**.

**דף ההתחברות לא נפתח בדפדפן.** בזמן שהדף ממתין, ללחוץ על **פתיחה מחדש של דף ההתחברות** איפה שהוא מופיע, או על **ביטול** ולנסות שוב.

**הצ'אט של לוח הבקרה אומר שצ'אט אחר משחק.** צ'אט שנפתח באפליקציית ה-AI משחק עכשיו בקמפיין הזה: להמשיך שם, או לסגור אותו כדי לשחק בלוח הבקרה.

**לא מופיעות תמונות.** הגדרות > קמפיין > תמונות אומר אם המחשב הזה יכול להכין אותן, ואיך.

**ההתקנה נכשלת, או ש-`rpg` לא עולה.** `node --version` חייב להראות 24 או חדש יותר. אם Windows משיבה שהרצת סקריפטים מושבתת, ראו [2.1](#21-what-you-need). ב-Windows, להרחיק את RPG Engine ואת הקמפיינים מנתיבים שמכילים `&`.

**הקישור ללוח הבקרה השתנה.** בצ'אט של אפליקציית ה-AI עצמה, לכל קמפיין יש כתובת משלו, והיא זהה מצ'אט לצ'אט. היא משתנה רק כשתוכנה אחרת כבר משתמשת בה: המנחה נותן את הקישור החדש, ומאותו רגע הוא נשאר. צ'אט שני של אותו קמפיין משאיר את הדף באותה כתובת, ומשתלט עליו אחרי שסוגרים את הראשון.
